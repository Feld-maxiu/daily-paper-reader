## 摘要
Lux AI 第三赛季要求智能体在部分可观测、回合级动态随机化以及五局三胜制比赛结构下行动，既奖励战术执行，也奖励快速适应。我们提出 HORIZON，一种分层智能体，融合了对称性感知的空间感知、双记忆信念追踪、以遗物为中心的图注意力、信息增益驱动的探索以及对手条件化策略混合。HORIZON 将短视界控制与跨对局元推理分离，同时通过辅助信念与世界模型目标稳定学习。该智能体在基于 JAX 的大规模模拟器中用 PPO 训练，能够显式推断隐藏游戏参数与对手风格。实验表明，与强循环和前馈基线相比，HORIZON 在对局胜率、回合胜率、适应增益和联赛评分上均取得一致提升。

## Abstract
Lux AI Season 3 requires agents to act under partial observability, randomized episode level dynamics, and a best of five match structure that rewards both tactical execution and fast adaptation. We present HORIZON, a hierarchical agent that combines symmetry aware spatial perception, dual memory belief tracking, relic centric graph attention, information gain driven exploration, and an opponent conditioned policy mixture. HORIZON separates short horizon control from cross match meta reasoning, while auxiliary belief and world model objectives stabilize learning. Trained with PPO in a large scale JAX simulator, the resulting agent explicitly infers hidden game parameters and opponent style. Experiments show consistent gains in match win rate, episode win rate, adaptation gain, and league rating over strong recurrent and feed forward baselines.

## 1. 论文的核心问题与整体含义

- **研究背景**：Lux AI Season 3 是一个部分可观测的多智能体对抗环境，具有以下特点：
  - 地图地形、传感器范围、星云视觉削弱、能量节点、酸液消耗、隐藏遗物得分掩码等参数在每局（episode）开始时随机生成，并在该局的 5 场比赛中保持不变。
  - 每场比赛持续 100 个时间步，智能体只能观察自身传感器范围内的信息，其余部分为未知。
  - 比赛采用五局三胜制，要求智能体既具备局部战术执行能力，又能在同一局的不同比赛之间快速适应对手和隐藏参数。

- **核心问题**：现有强化学习智能体要么忽略跨局元结构，把每场比赛独立处理，要么只依靠普通循环记忆，无法显式分离“短期战术记忆”与“跨局元记忆”，也较少利用地图几何对称性和对手行为结构。

- **整体含义**：论文提出 HORIZON 智能体，通过分层信念建模显式推断隐藏游戏参数和对手风格，实现零样本对手适应，在同一局比赛序列中“先探索、后利用”，从而在 Lux AI Season 3 中同时提升战术得分和跨局适应能力。

## 2. 论文提出的方法论

HORIZON 将 Lux Season 3 建模为分层部分可观测随机博弈：每局包含 5 场比赛，共享潜在参数向量 θ，策略需要最大化总回报。核心组件如下：

- **观测张量化与 FiLM 条件注入**
  - 将 JSON 观测转换为 24 通道稠密张量，包含地形类型、能量、双方单位计数与能量、遗物节点、贝叶斯信念图、可见性掩码等。
  - 可见参数向量 ξ（地图尺寸、单位移动成本、酸液成本等）通过 MLP 生成 γ(ξ) 和 β(ξ)，以 FiLM（Feature-wise Linear Modulation）方式注入空间骨干的残差块，使网络显式感知静态参数。

- **对称等变空间骨干（SESB）**
  - 利用地图沿反对角线对称的先验，强制卷积权重满足 D₂ 等变性：W ⋆ ρ(σ)X = ρ(σ)(W ⋆ X)。
  - 采用 U-Net 风格残差编码器，3×3 等变卷积、GELU 激活、循环填充，并在输出端进行“雾感知门控”：不可见区域用可学习的未知嵌入替换，并施加 stop-gradient，避免不可见位置产生虚假特征。

- **遗物中心图注意力（RC-GAT）**
  - 将隐藏遗物得分掩码视为隐变量推断问题。每个候选网格 v 维护一个伯努利信念 b_t(v)，根据观测到的得分增量 Δp_t 进行贝叶斯更新。
  - 信念 b_t(v) 既作为输入通道进入空间骨干，也直接注入图注意力 logit：e_{uv}^{(m)} = LReLU(a_mᵀ [W_m z_u ‖ W_m z_v ‖ b_t(v)])。
  - 通过 4 头图注意力，智能体被引导向信息量最大的遗物候选网格，实现围绕遗物的探索与利用平衡。

- **双记忆信念编码器（DMBE）**
  - 维护两个循环隐状态：
    - 快速状态 h_fast_t：GRU，在每个比赛开始时重置，捕捉单场内的战术信息。
    - 慢速状态 h_slow_k：仅在比赛边界更新，将比赛摘要 s_k 通过门控更新吸收，且只在整局结束时重置，携带跨局元信息。
  - 拼接 h_t = [h_fast_t ‖ h_slow_k(t)]，并学习变分后验 q_ψ(θ | o_1:t) 以近似潜在参数，用于显式元推理。

- **信息增益内在奖励（IGIR）**
  - 在外部奖励基础上增加内在奖励，奖励减少变分后验 q_ψ 的熵和遗物信念 b_t(v) 的二元熵：
    r_int_t = β₁(k)·[H(q_{t-1}) - H(q_t)] + β₂(k)·Σ_v [H(b_{t-1}(v)) - H(b_t(v))]。
  - 系数 β_i(k) 随比赛编号线性衰减，鼓励早期探索、后期利用。

- **对手条件策略混合（OCPM）**
  - 维护 4 个低秩子策略头，分别针对激进、防守、领地、经济四种对手风格。
  - 对手分类器 q_η(m | h_slow_k) 在比赛边界根据对手轨迹进行贝叶斯更新。
  - 最终策略是各子策略的加权混合；每个子策略按动作类型和 (Δx, Δy) 坐标进行条件分解，并通过 action mask 处理非法动作和酸液范围限制。

- **训练目标与算法**
  - 使用 PPO + GAE 优化裁剪替代损失。
  - 辅助损失包括：价值损失、熵奖励、世界模型损失（预测下一帧张量）、遗物信念一致性损失、θ 回归损失、对手分类损失。
  - 总损失 L = L_PPO + c₁L_V + c₂L_H + c₃L_WM + c₄L_relic + c₅L_θ + c₆L_opp，系数通过网格搜索确定。

## 3. 实验设计

## 6. 论文的主要结论与发现

- HORIZON 在所有指标上均优于基线，尤其是：
  - MWR = 0.72，EWR = 0.77，Δadapt = +0.16，TrueSkill = 29.1。
  - 与最强基线 RL²-Recurrent 相比，Δadapt 提高 0.06，TrueSkill 提高 2.7。

- **消融结论**：
  - 移除 DMBE 或 IGIR 会大幅降低 Δadapt，表明这两者对跨局元适应至关重要。
  - 移除 RC-GAT 导致 MWR 和 TrueSkill 下降最大，因为无法推理隐藏遗物得分网格。
  - 移除 SESB 造成适度下降，说明对称等变性是有用的归纳偏置。
  - 移除 OCPM 主要影响面对多样对手时的鲁棒性。

- **总体结论**：显式双记忆元推理、隐遗物图推断和对手感知策略混合，是解决部分可观测、非平稳多智能体博弈（超越 Lux Season 3）的有效组合。
