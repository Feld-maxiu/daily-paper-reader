## 摘要
本研究提出了 Gander，一个端到端模型，在单一框架内统一了全模态感知、实时交互和智能体能力。与传统的轮次式范式不同，Gander 持续接收跨视频、语音和文本等多模态的流式输入，从而在日常对话和复杂工作流导向的智能体场景中实现自然的全双工交互。用户可以随时打断模型，而模型也可以主动提供中间反馈或提出后续问题。为原生支持这些能力，Gander 采用了两项关键架构设计：1）采用小脑-大脑协作框架，小脑负责实时交互和全模态对话能力，而大脑处理复杂推理和高层智能体任务；两个组件通过工具调用和智能体编排运行时持续交互。2）小脑基于流式 Thinker-Talker 架构构建，用户输入和模型输出被进一步扁平化为块级别的有序 token 流，为低延迟、连续交互提供统一表示。我们在四个维度上对 Gander 进行了全面评估：对话能力、全模态理解、交互能力和智能体智能。内部人工评估表明，Gander 保持了 SOTA 开源模型的自然且富有表现力的口语对话能力，同时在全模态交互方面取得了具有竞争力的表现。Gander 还在具有挑战性的真实场景中表现出鲁棒性，包括背景噪声干扰、多方交互和反馈式沟通。我们发布 Gander 及其模型、代码和数据，以促进社区的进一步研究与发展。

## Abstract
In this work, we present Gander, an end-to-end model that unifies omni perception, realtime interaction, and agentic capabilities within a single framework. In contrast to turn-based conventional paradigms, Gander continuously receives streaming inputs across multiple modalities, including video, speech, and text, enabling natural full-duplex interaction in both everyday conversations and complex workflow-oriented agent scenarios. Users can interrupt the model at any time, while the model can also proactively provide intermediate feedback or ask follow up questions. To natively support these capabilities, Gander adopts two key architectural designs: 1) It employs a Cerebellum-Brain collaborative framework, in which the Cerebellum is responsible for realtime interaction and omni conversational capabilities, while the Brain handles complex reasoning and higher-level agentic tasks. The two components interact continuously through tool calling and the agent orchestration runtime. 2) The Cerebellum is built upon a streaming Thinker-Talker architecture, user inputs and model outputs are further flattened into an ordered token stream at the chunk level, providing a unified representation for low latency, continuous interaction. We conduct comprehensive evaluations of Gander across four dimensions: conversational ability, omni understanding, interactive capability, and agentic intelligence. Internal human evaluations demonstrate that Gander maintains the natural and expressive spoken dialogue capabilities of SOTA open source models while achieving competitive performance in omni interaction. Gander also demonstrates robustness in challenging real-world scenarios, including background noise interference, multi-party interactions, and backchannel communication. We release Gander together with its models, code, and data to facilitate further research and development in the community.

- **研究动机**：大语言模型正从轮次式文本对话向能自主完成复杂任务的智能体演进，但人机交互仍以“用户说完—模型回答”的离散轮次为主，与人类自然对话中的连续倾听、同步说话、随时打断、主动反馈等特征存在根本差异。
- **核心问题**：能否用单一模型统一实现三项能力：
  1. 对语音、视觉、文本的持续多模态感知与理解；
  2. 低延迟、双向、可打断的实时全双工交互；
  3. 面向复杂工作流的智能体规划、工具调用与长程任务执行。
- **关键挑战**：
  - 实时交互需要毫秒级响应，而复杂智能体任务需要长时间推理，单一模型很难同时兼顾。
  - 传统 VAD + ASR + LLM + TTS 级联方案难以可靠建模中断、插话、多人对话、背景噪声等真实交互行为。
- **整体含义**：论文提出 Gander，一个端到端“全模态交互智能体”，把实时感知、对话交互与智能体执行统一到一个框架中，推动 AI 从“被动问答接口”走向“持续参与的协作者”。

## 2. 论文提出的方法论

### 2.1 总体架构：小脑—大脑协作框架

- **前端小脑（Cerebellum）**：实时、全双工的多模态模型，负责连续感知流式语音、摄像头/屏幕画面，并自主决定“听、说、打断、调用工具”等交互动作。
- **后端大脑（Brain）**：通用任务执行智能体，负责复杂推理、代码/文件操作、信息检索等长程工作流。大脑是训练无关、可插拔的，可直接由 Codex、Claude Code 等实例化。
- **智能体编排运行时（Agent Orchestration Runtime）**：协调小脑与大脑，统一实时多模态推理和异步后台任务编排；包含网关、任务账本、工作器适配器等。

### 2.2 小脑—大脑交互机制

- 小脑通过结构化工具调用与运行时交互，支持三种主要操作：
  - `task_start`：创建后台任务。
  - `task_send`：向已有任务追加/修正用户指令，支持 `main`（修改主任务）和 `fork`（只读旁路查询）两种路由。
  - `task_resolve`：任务生命周期控制，包括 `cancel`、`allow_once`、`allow_session`、`deny`。
- 运行时提供两种控制模式：
  - **lean 模式**：直接执行小脑分类的任务动作，延迟低、确定性高。
  - **coordinator 模式**：引入独立控制平面模型，根据可信请求和有界系统状态生成推理强度、权限策略、结果交付策略等声明式控制方案。
- 大脑训练无关，可通过 `context_fetch`、`memory_search`、`share` 等接口与小脑异步交换任务上下文、记忆和中间结果。

### 2.3 流式 Thinker-Talker 架构

- **全模态感知**：
  - 视觉：采用任意分辨率切分 + SigLIP ViT + query resampler，把每帧压缩为少量视觉 token，分辨率最高 448×448，约 16× 压缩。
  - 音频：流式 chunk-wise 语音编码器输出约 50 帧/秒特征，经 MLP 投影做 5× 时间下采样，降到约 10 token/秒。
- **流式 chunk 扁平化**：
  - 将连续交互按 1 秒固定窗口划分为 chunk。
  - 每个 chunk = 该窗口内的时间对齐视觉/音频 token + 一个预测控制 token + 模型选择的 N 个文本 token（N 可为 0）。
  - 所有 chunk 串接成单一因果 token 流，由标准 LLM backbone 处理。
  - 上下文预算固定为 128 个 chunk，约 2 分钟滑动窗口。
- **控制 token**：
  - `listen`：当前窗口保持沉默，继续观察。
  - `speak`：当前窗口生成口语内容。
  - `interrupt`：在上下文变化时中止正在进行的回复。
  - 在生成任何内容前预测控制 token，将“是否说”与“说什么”解耦。
- **语音生成**：
  - 不直接让 LLM 自回归生成语音 token，而是分两阶段：主干输出文本和隐藏状态 → 小型自回归语音 token 解码器产生离散语义 token → 流式 flow-matching 解码器生成波形。
  - 支持零样本声线控制，参考音频决定音色。

### 2.4 数据构建管线

- 总规模约 2.7M 样本，分为四类：
  1. **语音交互数据（约 37%）**：包括通用对话、指令遵循、全双工交互、口语问答、同声传译；其中 InteractionSpeech 通过专门管线合成包含打断、插话、多轮交互的数据。
  2. **音视频交互数据（约 40%）**：来自 JoyAI-VL、LiveCC、Streamo，覆盖流式视频 QA、流式视频叙述、主动视觉响应。
  3. **智能体交互数据（约 13%）**：包括音频智能体交互、全模态智能体交互、工具辅助推理，覆盖任务启动、约束更新、进度查询、取消、结果交付等全生命周期。
  4. **鲁棒性与负样本数据（约 6.3%）**：包括无关视频、无指令环境、抗噪声干扰、多人交互等，训练模型在不相关场景下保持沉默或正确追踪说话人。

## 6. 论文的主要结论与发现

- **交互时序领先**：Gander 在 Full-Duplex-Bench 上取得最佳抢话行为：100% 在合适时机接话，提前打断率仅 8.0%，优于 GPT-Realtime（13.5%）和级联方案（33.0%），说明将交互决策纳入自回归建模比外部 VAD 更稳定。
- **任务准确率有差距**：Gander 的 Pass@1 为 0.400，低于最强基线 GPT-Realtime 的 0.600；但“仅后端大脑”条件下 ToolSel 达 0.934，说明后端执行能力不是瓶颈，性能损失主要来自前端小脑与语音通道的决策和识别误差。
- **口语知识能力保留较好**：在全双工流式模型组中，Gander 在 SpokenQA 两个子集上均领先，且可比肩部分轮次式模型；说明流式 chunk 训练并不会必然损害语言 backbone 的知识保留。
- **全模态理解接近基座**：Daily-Omni 仅比 MiniCPM-o 4.5 低 1.67 分，但 WorldSense 下降 6.08 分；模态消融显示联合输入比单一模态最高提升 8.88 分，Daily-Omni 上融合增益达 19.13 分，表明模型确实在跨模态对齐推理，而非简单依赖单一强模态。
- **架构可分离且可扩展**：小脑与大脑解耦后，大脑可以训练无关地替换为更强推理模型，后端性能可直接受益于上游模型进步。
- **数据方案有效**：鲁棒性负样本和 InteractionSpeech 合成流程使模型在噪声、多人对话、无指令环境中能抑制误响应。

## 7. 优点

- **统一框架**：将实时全双工交互、多模态感知、智能体执行原生融合到一个端到端系统中，而不是简单级联多个模块。
- **双脑解耦设计**：小脑处理低延迟交互，大脑处理高延迟推理；大脑训练无关、可插拔，系统智能可以随外部模型升级而扩展。
- **流式 chunk 扁平化**：把多模态输入与输出统一为时间对齐 token 流，并以控制 token 显式建模“听/说/打断”，使交互状态成为模型内在能力。
- **高效语音生成**：采用“文本主干 + 小型语音 token 解码器 + 流式 flow-matching”两级方案，在保持语言能力的同时降低语音合成延迟。
- **精细的数据构建**：InteractionSpeech 对打断、插话、隐藏续说等做了专门标注和时序同步；鲁棒性负样本覆盖无关视频、噪声、多人说话等挑战场景。
- **评估多维且包含消融**：不仅报告系统级任务指标，还通过仅后端大脑、不同模态输入条件等消融定位瓶颈。
- **开源承诺**：计划发布模型、代码和数据，有助于社区复现与后续研究。

## 8. 不足与局限

- **任务执行准确率不足**：Full-Duplex-Bench 上 Pass@1 仅 0.400，低于多个商用系统；工具选择 F1 和参数正确率也处于表中后段。
- **部分交互指标不理想**：Filler 率为 51.6%，明显高于多个基线；虽然作者解释为后端任务执行时保持话轮，但仍可能影响用户体验。
- **理解能力存在退化**：WorldSense 从基座 MiniCPM-o 4.5 的 55.70 降至 49.62，说明面向交互的训练削弱了细粒度静态视觉属性理解。
- **口语生成质量有限**：AlpacaEval 和 SD-QA 在相关组内不领先，说明长文本口语表达和重口音鲁棒性仍需加强。
- **通信机制较简单**：小脑与大脑之间主要依赖 ASR 转录文本，缺少更丰富的结构化双向信息流。
- **未使用高级后训练方法**：当前版本未充分使用 on-policy distillation、强化学习等，长程任务中的信用分配和稳定性仍有待探索。
