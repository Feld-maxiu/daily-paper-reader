## 摘要
以用户为中心的智能体强化学习受限于在线反馈收集的成本、延迟和风险，以及在同一用户状态下难以进行反事实比较。本文提出通过反事实用户参与模拟进行世界模型引导的强化学习（WMG-RL）框架，其中冻结的用户模拟器在真实用户暴露之前提供奖励监督。受语言世界模型启发，我们将该模拟器实例化为用户参与世界模型（UEWM），将推荐项目视为智能体动作，将用户的异构反馈视为环境观测。UEWM并非学习单一的固定环境转移，而是从交互历史中推断用户特定动态，并将其应用于候选项目。在WMG-RL中，下游策略针对相同历史提出多个候选项目；UEWM并行预测相应的参与反馈；模拟反馈被转换为稠密奖励，用于策略优化。实验表明，UEWM在不同领域提供可靠且可迁移的奖励信号，WMG-RL使紧凑的1.7B学生策略在下游推荐任务上达到或超过更大规模的LLM。

## Abstract
Reinforcement learning for user-centric agents is limited by the cost, latency, and risk of collecting online feedback, as well as by the lack of counterfactual comparisons under the same user state. In this paper, we propose World Model-Guided Reinforcement Learning via counterfactual user engagement simulation (WMG-RL), a framework in which a frozen user simulator provides reward supervision before real user exposure. Motivated by language world models, we instantiate the simulator as a User Engagement World Model (UEWM), which treats a recommended item as the agent action and the user's heterogeneous feedback as the environment observation. Rather than learning one fixed environment transition, UEWM learns to infer user-specific dynamics from engagement history and apply them to candidate items. In WMG-RL, a downstream policy proposes multiple candidate items for the same history; UEWM predicts the corresponding engagement feedback in parallel; and the simulated feedback is converted into dense rewards for policy optimization. Experiments show that UEWM provides reliable and transferable reward signals across domains, and that WMG-RL enables a compact 1.7B student policy to match or surpass much larger LLMs on downstream recommendation tasks.

- **研究背景**：以用户为中心的智能体（如推荐、内容生成、用户建模）通常依赖真实用户反馈进行强化学习，但在线收集反馈存在成本高、延迟大、风险高的问题。

- **整体含义**：论文提出 **WMG-RL（World Model-Guided Reinforcement Learning via counterfactual user engagement simulation）** 框架，利用一个冻结的用户参与世界模型（UEWM）作为反事实模拟环境，在真实用户暴露之前为下游策略提供稠密、个性化的奖励监督，从而在不访问真实用户反馈的情况下训练紧凑的学生策略。
- **与语言世界模型的关系**：该工作把用户参与模拟视为语言世界建模——推荐项是动作，异构反馈（点赞、分享、收藏、不喜欢、评论/评分）是观测，历史交互是状态；模型需要从历史中推断“用户特定的动态规则”，而非学习单一总体转移函数。

## 2. 论文提出的方法论

### 2.1 用户参与世界模型（UEWM）

- **形式化定义**：给定用户历史 \(H_t^u\) 和候选项目 \(i_{t+1}^u\)，UEWM \(\pi_E\) 预测反馈 \(\hat{s}_{t+1}^u \sim \pi_E(\cdot | i_{t+1}^u, H_t^u)\)。
- **关键思想**：不同用户具有不同的潜在参与动态 \(f_u\)（兴趣、厌恶、响应倾向、反馈通道依赖）。UEWM 是共享的摊销模型，学习从历史中恢复用户特定规则并应用于新动作。
- **两层次泛化**：
  - **跨用户**：对新用户从未见过的历史推断其动态。
  - **跨领域**：将推断过程从中文短视频迁移到英文电商、本地服务等领域，即使项目语义和反馈模式改变。

### 2.2 UEWM 训练配方

基于 Qwen3-8B 主干，逐步训练：

1. **自回归预训练**：将历史与候选项目序列化，生成目标反馈序列 \(y\)，优化标准语言建模损失
   \[
   L_{AR} = -\sum_{k=1}^{|y|} \log \pi_E(y_k | x, y_{<k})
   \]
2. **思维链（CoT）中间训练**：使用 Doubao-Seed-1.6-thinking 合成推理数据，让模型先生成用户偏好分析，再输出最终反馈。
3. **奖励对齐（GRPO）**：对离散信号用准确性奖励，对评论文本用 ROUGE-Lsum 奖励，校准模拟器保真度。
- 数据：来自中文短视频平台，2.5M 用户、636M 事件，过滤后得到 435K 样本（150 步历史），其中 355K 预训练、20K CoT 合成、20K 后训练。

### 2.3 WMG-RL 策略优化

- **核心流程**（Algorithm 1）：
  1. 给定同一历史 \(H_t\)，下游策略 \(\pi_\phi\) 采样 \(G\) 个候选项目 \(\{i_k\}_{k=1}^G\)。
  2. 冻结 UEWM 对每个候选并行预测反馈 \(\hat{s}_k = \pi_E(\cdot | i_k, H_t)\)。
  3. 通过向量化函数 \(v(\hat{s}_k)\) 将反馈映射为数值向量，计算奖励 \(R_k = w^\top v(\hat{s}_k)\)（实验中采用预测评分 \(\hat{r}_k \in \{1,\dots,5\}\) 作为单标量奖励）。
  4. 对奖励做批内标准化：\(A_k \leftarrow \frac{R_k - \mu_R}{\sigma_R + \epsilon}\)。
  5. 使用 PPO 风格的裁剪代理目标 \(J_k = \min(\rho_k A_k, \text{clip}(\rho_k, 1-\epsilon, 1+\epsilon) A_k)\)，并加入对参考策略的 KL 惩罚：
     \[
     L_{WMG} = -\frac{1}{G}\sum_{k=1}^G \left( J_k - \beta D_{KL}(\pi_\phi \| \pi_{ref}) \right)
     \]
- **优势**：所有候选在同一历史状态下评估，提供真实的反事实比较；反馈多样，可组合不同信号；学生策略可以探索而不仅是模仿教师。

## 6. 主要结论与发现

- **模拟保真度**：完整 UEWM 在平均准确率、Macro-F1、评论生成上均优于 vanilla Qwen3-8B 和 Qwen3-235B-A22B；Macro-F1 提升 7.21 个百分点，ROUGE-Lsum 从约 1.2 提升到 2.87。
- **跨域迁移**：UEWM（8B）零样本在 Amazon Books、Amazon Movies、Google Local 上显著优于通用 LLM 和专用基线，显示其学习的是可迁移的“从历史推断用户动态”的过程；用户嵌入按兴趣域形成聚类。
- **下游策略学习**：1.7B 学生策略经 WMG-RL 在三个推荐任务上达到 41.91%、42.84%、37.95% 准确率，超过 DeepSeek-GRM 奖励和 SFT 蒸馏，并匹配或超过更大 LLM。
- **奖励质量**：UEWM 预测奖励与真实评分 Pearson 相关系数达 0.70；对历史注入负面反馈会显著降低预测兴趣（4.72 → 2.15）。
- **长期模拟**：WMG-RL 智能体在 10 轮模拟中累积奖励高于 vanilla Qwen3-235B 和 SFT 蒸馏基线。
- **失败边界**：48% 错误属于随机不确定性，22% 是风格错配，18% 知识截断，12% 推理幻觉；UEWM 是有效的奖励代理而非确定性人类行为预言机。

## 7. 优点

- **问题定义新颖**：将用户参与模拟形式化为语言世界建模，并提出反事实同状态比较的强化学习设置，解决在线反馈和日志偏差问题。
- **方法设计合理**：冻结大型世界模型作为奖励源，训练小型策略，在计算和风险上都更经济；摊销用户动态建模支持跨用户、跨域泛化。
- **实验充分且客观**：多数据集、多基线、多消融，含统计置信区间、超参敏感性和错误分类，增强可信度。

## 8. 不足与局限

- **缺乏在线验证**：没有真实用户或在线 A/B 实验，长期模拟用 UEWM 自身作为环境可能形成自我确认偏差，模拟误差会随轮次累积。
- **训练数据不可复现**：核心训练日志为私有数据，影响外部复现和同行验证。
- **模态单一**：仅使用文本模态，忽略视觉、音频等对视频理解重要的信号。
- **模型范围受限**：UEWM 只建模用户侧动态，不包含曝光分配、内容供给、平台生态和用户-创作者-系统交互，无法反映完整市场均衡。
- **跨域评估有限**：仅覆盖英文电商和本地评论，缺少更多文化、语言、平台背景的检验；针对跨文化行为审计不足。

- **超参与计算细节缺失**：未报告 GPU 型号、数量或训练时长，难以准确评估计算成本。
