## 摘要
大型语言模型（LLMs）在许多领域被用作自主决策与规划的策略。尽管它们具有强大的推理能力，LLM在长程任务中仍面临困难，尤其是在部分可观测条件下。世界模型是在训练和推理过程中提升策略性能的一种有前景的方法。在推理过程中，智能体目前使用世界模型在承诺执行某个动作之前模拟候选动作的后果，这可以改善决策。然而，我们认为，仅靠模拟对于部分可观测条件下的决策来说是一个不完整的接口：模拟无法充分捕捉关于当前状态的不确定性，而智能体可能需要这些不确定性来做出准确决策。我们通过基于信念的世界模型（BB-WMs）来解决这一局限，该模型建模并维护一个信念，LLM可以查询该信念以获取关于当前状态已知和不确定的信息。在开发学习精确BB-WMs的方法之前，我们首先提出一个更基本的问题：将世界模型的信念直接暴露给LLM策略是否会改善决策？我们的结果表明，让LLM智能体访问世界模型信念可以提升部分可观测条件下的任务性能，同时与现有的基于模拟的世界模型互补。代码发布于 https://github.com/skumar-ml/belief-world-models。

## Abstract
Large language models (LLMs) are being used as policies for autonomous decision-making and planning in many domains. Despite their strong reasoning capabilities, LLMs struggle with long-horizon tasks, especially under partial observability. World models are a promising way to enhance policy performance, both during training and inference. During inference, agents currently use world models to simulate the consequences of candidate actions before committing to an action, which can improve decision-making. However, we argue that simulation alone is an incomplete interface for decision-making under partial observability: simulation doesn't adequately capture uncertainty about the current state, which agents may need for accurate decision-making. We address this limitation with Belief-Based World Models (BB-WMs), which model and maintain a belief that LLMs can query to access information on what is known and uncertain about the current state. Before developing methods to learn accurate BB-WMs, we first ask a more fundamental question: does exposing a world model's belief directly to an LLM policy improve decision-making? Our results show that giving LLM agents access to world model beliefs improves task performance under partial observability, while remaining complementary to existing simulation-based world models. Code is released at https://github.com/skumar-ml/belief-world-models.

- **整体含义**：提出 **基于信念的世界模型（Belief-Based World Models, BB-WMs）**，在传统模拟接口之外增加信念查询接口，使 LLM 策略能够直接查询世界模型对当前状态的信念（概率分布），从而改善部分可观测环境中的决策。论文首先验证这一接口是否真正有益，而暂不涉及如何学习准确信念模型。

## 2. 方法论

### 2.1 BB-WM 核心思想
- 世界模型内部表示 **`xt = (bt, ξt)`**，其中 **`bt = P(st | ht)`** 是对当前隐状态 `st` 的信念，`ξt` 为其他附加信息。
- 提供两个接口：
  - **模拟接口**：给定候选动作 `a_t^(i)`，预测下一状态 `x̂_{t+1}^{(i)}` 并输出策略可读的结果 `y_sim = R_sim(x̂_{t+1})`，用于评估动作后果。
  - **信念查询接口**：策略无需提供假设动作，可直接查询当前后验信念 `b_t`，获得自然语言回答 `y_bel = R_bel(b_t, q)`。
- 策略在执行动作前可在两个接口间多次查询，响应作为决策条件。

### 2.2 状态空间与信念更新
- 论文为隔离“暴露信念是否有用”这一研究问题，**手工指定状态空间和更新规则**，不涉及学习。
- **确定性组件**：目标、容器属性、对象属性、智能体位置与库存等。
- **概率组件**：目标对象位置服从分类分布。在 ALFWorld 中，分布定义在可放置容器的集合上；在 ScienceWorld 中，分布定义在十个房间上。
- **信念更新规则**：采用“出现/未出现重归一化”：
  - 若在某个容器/房间中找到对象，信念坍缩为点质量；
  - 若未找到，将该位置概率置零，并在剩余未搜索位置间重新归一化。
- 初始先验来自环境引擎或领域知识（如对象可放置的容器类型、房间约束）。

### 2.3 实例化
- **ALFWorld**：
  - 状态空间：确定性部分包括目标、容器、对象、智能体位置和库存；概率部分仅建模目标对象位置。
  - 模拟接口采用 **WALL-E**：一个基于规则的神经符号世界模型，检查动作在当前静态状态下是否可行，返回有效/无效及简要反馈。
  - 信念查询接口支持 `query where is <object>`、`query what is in <recep>`、`query searched <recep>`、`query state`。
- **ScienceWorld**：
  - 状态空间类似，但对象以自然语言指代，容器嵌套关系更复杂。
  - 模拟接口使用 **Oracle WALL-E**：直接利用环境判断动作有效性，保证判断正确但反馈较通用。
  - 信念查询接口类似，返回房间级概率分布及容器信息。

## 3. 实验设计

## 6. 论文的主要结论与发现

- **BB-WM 在几乎所有情况下提升基础智能体的性能和效率**，尤其在较小模型（Llama-3.1-8B）上提升显著。
- **信念查询与模拟查询互补**：两者分别解决不同问题（不确定性感知 vs. 动作后果评估），组合后性能最优。
- **信念（概率不确定性）比单纯记忆更重要**：消融实验显示，去掉概率信念后性能明显下降，有时甚至回落到基础智能体水平。
- **对于能力足够强的模型（如 Sonnet 4.6）**，在较简单任务上可能已能隐式跟踪状态，世界模型带来的性能增益有限，但仍观察到效率提升。
- **定性分析表明**：信念查询能帮助智能体避免搜索无关位置、发现非直觉但有先验概率的位置（如垃圾箱中的鸡蛋），从而减少无效探索。

## 7. 优点

- **新颖的接口设计**：将 POMDP 中的信念概念引入 LLM 世界模型，并通过自然语言暴露给策略，无需针对特定信念表征重新训练 LLM。
- **实验隔离变量**：手工设计信念和更新规则，精准回答了“暴露信念是否有利”这一基本问题，避免了学习误差的干扰。
- **多模型、多环境、多框架验证**：增强了结论的鲁棒性和可推广性。
- **消融实验清晰**：区分记忆与信念，证明不确定性建模的核心价值。
- **定性案例**：直观展示了 BB-WM 如何改变智能体的搜索策略和动作选择。
- **代码开源**：提供了可复现的实验设置。
