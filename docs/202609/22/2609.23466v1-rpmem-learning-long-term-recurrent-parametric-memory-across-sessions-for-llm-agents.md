## 摘要
长期运行的 LLM 智能体需要能够在会话之间持续存在并演化的记忆。基于文本的记忆在每次查询时检索并重建过去的交互，随着历史增长，长期性能越来越依赖检索质量和上下文推理。参数化记忆将经验直接编码到模型计算中，但现有方法对跨会话记忆演化的支持有限。它们与特定骨干模型的耦合进一步限制了模型替换后记忆的重用。我们提出 RPMem，一种两阶段架构，通过前向计算将每个会话编译为与模型无关的潜在记忆，并通过任务训练的循环门控将其与保留的记忆选择性整合。随后，整合后的记忆被映射到骨干模型特定的低秩适配（LoRA）参数，从而使编码能力能够在骨干模型被替换时迁移。在三个长期记忆基准和五种不同骨干模型上的评估表明，该方法具有广泛的泛化能力，且更新成本和内存占用几乎恒定。在 PERMA 上使用 Qwen3-8B 时，RPMem 达到 85.52%，分别比最强的参数化基线和基于文本的基线高出 5.32 和 12.98 个百分点。消融实验验证了会话编译与跨会话整合的互补作用，而动力学分析揭示该门控会习得任务特定的记忆整合策略。这些结果将 RPMem 确立为一种与生命周期无关的参数化记忆框架，能够维护不断演化的跨会话记忆，并在骨干模型替换后仍可重用。我们的实现可在 https://github.com/Quark-Medical/rpmem/tree/main 获取。

## Abstract
Long-running LLM agents require memory that persists and evolves across sessions. Text-based memory retrieves and reconstructs past interactions at every query, making long-horizon performance increasingly dependent on retrieval quality and contextual reasoning as histories grow. Parametric memory encodes experience directly into model computation, but existing approaches provide limited support for cross-session memory evolution. Their coupling to a specific backbone further restricts memory reuse after model replacement. We introduce RPMem, a two-stage architecture that compiles each session into a model-independent latent memory through forward computation and selectively integrates it with retained memory via a task-trained recurrent gate. The consolidated memory is then mapped to backbone-specific low-rank adaptation (LoRA) parameters, allowing the encoding capability to transfer when the backbone is replaced. Evaluation across three long-term memory benchmarks and five diverse backbones demonstrates broad generalization with near-constant update cost and memory footprint. With Qwen3-8B on PERMA, RPMem reaches 85.52%, outperforming the strongest parametric and text-based baselines by 5.32 and 12.98 percentage points, respectively. Ablations validate the complementary roles of session compilation and cross-session consolidation, while dynamics analyses reveal that the gate acquires task-specific memory integration strategies. These results establish RPMem as a lifecycle-independent parametric memory framework that maintains evolving cross-session memory that remains reusable across backbone replacements. Our implementation is available at https://github.com/Quark-Medical/rpmem/tree/main.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：长期运行的 LLM 智能体需要在多个会话之间保持并更新记忆。现有两大类记忆方法各有明显缺陷：
  - **文本记忆**：每次查询时检索并重建历史，长期性能高度依赖检索质量和上下文推理，且随历史增长上下文成本上升。
  - **参数记忆**：将经验直接编码进模型参数，不占用输入上下文，但现有方法普遍缺乏跨会话增量更新能力，且记忆与特定骨干模型深度耦合，模型替换后记忆无法继续使用。
- **论文核心问题**：如何构建一种**生命周期独立**的参数化记忆，使其既能跨会话持续演化，又能在更换底层 LLM 骨干后继续重用。
- **整体含义**：提出 RPMem，将记忆编译、跨会话整合、骨干解耦三者统一到一个框架中，实现前向计算更新、固定内存占用、可跨模型迁移的长期记忆。

## 2. 论文提出的方法论

- **总体架构**：RPMem 为两阶段结构，包含会话编码、循环整合、模型特定解码三部分。
  - **阶段一：单会话记忆编译**：用冻结的上下文编码器（ModernBERT-base）提取会话特征，经可训练的 Perceiver 重采样器压缩为固定形状的潜在记忆 \(q_t\)；随后由模型特定的 LoRA 解码器将 \(q_t\) 映射为该骨干模型的低秩适配参数。
  - **阶段二：跨会话记忆整合**：对按时间到达的会话表示 \(q_1,\dots,q_T\)，使用轻量循环门控选择性融合新旧记忆：
    - 门控计算：\(z_t = \sigma([h_{t-1}; q_t] W_g + b_g)\)
    - 状态更新：\(h_t = z_t \odot h_{t-1} + (1-z_t) \odot q_t\)
    - 该门控共享于所有层/模块/秩维度，参数量极小（\(2d^2+d\)），且仅通过下游任务监督训练。
- **训练目标**：
  - **编译阶段**：使用固定参考响应上的前向 KL 散度，让“适配器条件下的模型输出分布”逼近“上下文条件下的模型输出分布”，并保留 top-K 之外的概率质量作为尾部类别。
  - **整合阶段**：冻结编译器和骨干模型，仅训练循环门控，采用目标任务交叉熵损失，使整合后的 LoRA 适配器能正确回答与历史相关的问题。
- **生命周期独立性**：记忆状态 \(h_t\) 存储在模型无关的潜在空间中；更换骨干时保留会话编码器、记忆状态和门控，仅需训练新的骨干特定解码器，即可将同一记忆映射到新模型参数。

## 6. 论文的主要结论与发现

- **主结果**：在 PERMA 上，Qwen3-8B + RPMem 达到 85.52% 核心平均准确率，超过最强参数基线 Metis-9B 5.32 个百分点、文本基线 Full Context 12.98 个百分点；在 PersonaMem-v2 上也取得最高非参考性能。

- **消融结论**：
  - 编译目标采用固定参考轨迹的前向 KL 最优，显著优于 SFT 和反向 KL。
  - 学习门控显著优于所有固定整合规则，尤其在多域历史中优势最大。
- **生命周期与部署**：积累记忆可在骨干替换后通过解码器适配继续使用；更新和内存成本近恒定；对通用能力影响有限。
- **记忆动力学**：门控会赋予“域建立”事件更大的写权重，并对同域旧记忆进行选择性修订，使关键信息长期存活。

## 7. 优点

- **生命周期独立性**：首次显式解决参数记忆跨骨干迁移问题，记忆状态不绑定具体模型。
- **前向更新、无需梯度**：部署时通过前向计算更新记忆，避免重复梯度优化，适合规模化部署。
- **固定内存、成本近恒定**：无论历史多长，记忆大小不变，更新时间和内存增长极小。
- **两阶段解耦设计**：编译与整合分离，便于根据目标任务适配；门控参数量极少，训练成本低。
- **深入的分析**：不只报告性能，还通过可解释的动力学分析揭示记忆组织策略。
- **实验丰富且规范**：多个基准、多个骨干、消融、迁移、效率、通用能力保留等，验证全面。

## 8. 不足与局限

- **任务类型较单一**：实验主要基于多项选择问答，未充分验证开放式生成、长序列交互或复杂工具使用等场景。
- **应用特定整合策略**：门控针对特定任务训练，迁移到记忆需求差异较大的新场景是否有效仍待研究；作者也提出未来需要跨场景学习。
- **编译训练成本较高**：共享编译器需约 338 GPU 小时，对资源有限的研究者可能不友好。
- **基线覆盖有限**：未与 MEMORYLLM、M+、PAM、SELF-PARAM 等更多参数记忆方法直接比较，仅以 Metis 为重点对象。
- **骨干适配仍需训练**：更换骨干模型时虽然保留记忆，但仍需为新骨干训练解码器，并非完全零训练。
