## 摘要
使用强化学习训练智能体需要一个训练场（gym），其中包括任务、可执行环境（可在其中尝试任务）以及能够可靠区分成功与失败的验证器。构建此类训练场仍然是人工、昂贵且静态的。随着模型改进，任务集会趋于饱和，并且越来越容易受到污染。合成生成能提供规模，但单轮合成产生的任务其难度在很大程度上只是表面性的。能力相当的模型即便面对绕弯的表述也能解决这些任务，而正确性必须由不可靠的 LLM 评判器事后裁定。我们提出 AutoGym，一个仅从极少的领域种子或先前模型轨迹生成完整训练场（任务、可执行环境和验证器）的框架。AutoGym 引入了三种机制。（1）蓝图优先生成在环境具体化之前指定有效解空间、环境需求和验证标准，使可解性成为构建的先决条件，而非事后验证的性质。（2）显式生成参数控制任务拓扑、交互深度、能力维度、问题混淆和干扰项构成，从而实现细粒度的难度调控。（3）主动课程合成利用基于性能信息的校准，随着模型能力演变调整这些参数的分布。在生产力与时间推理场景中，AutoGym 生成了覆盖能力谱系的训练场，包括挑战前沿模型的实例。

## Abstract
Training agents with reinforcement learning requires a gym, comprising a task, an executable environment in which the task can be attempted, and a verifier that reliably distinguishes success from failure. Constructing such gyms remains manual, expensive, and static. Task sets saturate as models improve and are increasingly exposed to contamination. Synthetic generation offers scale, but single-pass synthesis produces tasks whose difficulty is largely cosmetic. Models comparable in capability solve them despite convoluted phrasing, and correctness must be adjudicated post-hoc by unreliable LLM judges. We present AutoGym, a framework that generates complete gyms (tasks, executable environments, and verifiers) from a minimal domain seed or prior model trajectories. AutoGym introduces three mechanisms. (1) Blueprint-first generation specifies the valid solution space, environment requirements, and verification criteria before the environment is materialized, making solvability a construction prerequisite rather than a property verified after the fact. (2) Explicit generation parameters control task topology, interaction depth, capability axes, question obfuscation, and distractor composition, enabling fine-grained difficulty steering. (3) Active curriculum synthesis uses performance-informed calibration to adjust the distribution over these parameters as model capabilities evolve. Across productivity and temporal-reasoning settings, AutoGym generates gyms spanning the capability spectrum, including instances that challenge frontier models.

  - 已有环境生成系统往往先产生任务，再检查环境是否包含可验证的解路径，导致可解性与可验证性成为事后问题。

- **论文核心目标**：提出 **AutoGym**，从极少的领域种子或已有模型轨迹自动生成完整的 agent gym（任务、可执行环境、验证器），并让可解性成为构建时的前置条件，同时实现细粒度难度控制和能力自适应。

## 二、论文提出的方法论

- **总体思想：蓝图优先生成**  
  AutoGym 反传统生成顺序：先构造“蓝图”，明确有效解空间、环境需求、验证标准，再实例化可执行环境。可解性因此成为设计约束，而非事后检查。

- **三种核心机制**

  1. **蓝图优先生成**  
     - 在环境具体化之前，蓝图就规定解空间（涉及实体、属性、关系、条件）与验证标准。  
     - 增加依赖结构，但不强制唯一智能体轨迹。  
     - 通过受控混淆决定哪些关键值出现在问题中、哪些必须由智能体从环境中发现；通过干扰项设置误导分支，但保证至少一条有效解路径。  
     - 进行“和解检查”，确保所有解所需实体被指定、被隐藏信息可发现、工具接口支持目标解。

  2. **显式生成参数控制难度**  
     - 参数独立于领域与工具接口，包括：
       - **任务拓扑**：Tier 1 直接检索；Tier 2 多跳 / 多约束 / 列表聚合；Tier 3 跨源比较 / 并行综合 / 多跳 + 合并 / 复杂比较。
       - **交互深度**：最大工具调用次数等。
       - **能力轴**：定量计算、穷尽聚合、排序比较、时间推理、负验证、隐式标准、跨源对账等。
       - **混淆梯度**：0–1 连续值，控制问题中保留多少任务相关信息，越高越模糊。
       - **干扰项预算**：来自 persona（权限边界）、content（近似记录、过期值、冲突版本）、tool（分页、截断、瞬时故障）三类通道。
     - 每个能力轴带有验证谓词，确保在具体任务中真正被触发，而非只是标签。

  3. **主动课程合成**  
     - 基于模型表现校准生成参数分布：低于 0.30 成功率的维度视为过难并放宽，高于 0.80 的维度加强。
     - 从失败轨迹中识别反复出现的能力缺口和干扰项模式，更新采样权重，形成闭环。
     - 更新步幅有界，减少震荡；直到性能稳定或达到迭代上限。

- **流水线阶段**（见图 1）  
  ① 蓝图初始化：生成场景、persona，采样生成参数。  
  ② 蓝图构建：指定解空间、混淆、干扰项，执行和解检查。  
  ③ 迷宫具体化：将蓝图变为可执行环境（资源、关系、权限、干扰项）和工具接口。  
  ④ 地面真值 + 验证器组装：沿解路径对实际环境计算地面真值，创建结果正确性、过程质量、干扰项抗性、persona 约束等验证器。  
  ⑤ 评估：给定任务、环境、工具，不提供蓝图其他上下文，多次 rollout，按验证器得分分 hard/medium/easy。  
  ⑥ 失败分析：将反复出现的能力缺口和干扰项模式转为新生成参数，进入下一轮。

- **验证机制**  
  - 满足“可回答性不变式”：任务和环境联合包含足够信息满足验证标准，难度来自查找、过滤、对账，而非隐藏状态不可达。
  - 确定性结果用程序化规则检验；开放端部分采用三阶段 judge 流程（过程 judge、结果 judge、元 judge），限制每个 judge 的上下文，并显式组合“答案是否正确”与“方法是否合理”。
  - 若验证发现缺资源、不可达标准或不一致推导，只修复生成组件并重新具体化；智能体在有效 gym 上的失败不触发修复。

## 七、优点

- **范式创新**：蓝图优先将可解性和可验证性变成构建前置条件，而非事后修补。
- **细粒度难度控制**：拓扑、能力轴、混淆、干扰项等多维参数可独立调节，且参数在相同平台/工具接口内可移动难度分布。
- **闭环自适应**：失败分析驱动的主动课程合成能针对具体模型弱点持续生成新任务，保持 gym 不过时。
- **验证可靠性**：多信号验证器组合程序化规则和分阶段 judge，并引入“答案正确性”与“过程合理性”的显式分解，降低单一 LLM judge 偏差。
- **成本与效率**：自动生成大幅降低每任务成本和时间，并具备跨域扩展能力。
- **实验透明度**：提供完整运行示例、prompt 模板、配置表、修复前后对比和人工检查，可复现性较好
