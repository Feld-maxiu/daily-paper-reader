## 摘要
随着 AI 智能体能力日益增强，由智能体驱动的机器人控制正成为一种引人注目的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口并不适合智能体驱动控制：指称歧义、空间不精确、与智能体固有的语言理解能力冗余，并将意图与执行纠缠在一起。我们提出了 AR-WAM，一种视觉条件化、智能体就绪的世界动作模型，它将语言替换为两个互补条件：视觉定位提示（目标边界框）表示交互对象和位置，以及一个可学习的操作令牌指定要执行的原子技能。我们的紧凑 0.5B 参数模型采用冻结的预训练视觉编码器且没有语言编码器，在紧凑潜在状态中预测场景演化并同时解码动作，通过显式、可监督的推理信号揭示策略的意图。一个与模型无关的兼容层提供了三种原语（检测、执行和查询），使本地 VLM 或在线智能体 API 能够直接驱动该策略，并将长时程记忆和闭环错误恢复交由智能体侧负责。在 RoboTwin 2.0、RMBench 和真实的 Astribot S1 双臂平台上，AR-WAM 在标准操作任务上与最强基线持平（平均成功率 87.2%），并在依赖记忆和真实机器人长时程任务上超越它们，成功率分别提高 5.9% 和 36.7%，同时保持最低的推理延迟（14.1 毫秒）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

- **核心问题**：当前主流的视觉-语言-动作模型（VLA）和世界动作模型（WAM）几乎都用自然语言指令来指定操作任务，但这一接口在智能体驱动控制下存在系统性缺陷：
  - **指称歧义**：面对多个相似物体时，文本无法唯一指定目标。
  - **空间不精确**：文本无法精确传达位置、姿态等空间信息。
  - **冗余**：语言理解本就是智能体的强项，在策略中重复学习语言编码浪费训练计算。
  - **黑盒纠缠**：理解、规划、记忆和动作生成被塞进同一个不可解释模型，失败时难以区分是意图错误还是执行错误。
- **整体含义**：论文提出应把策略接口从“语言”切换为“空间”。由智能体负责开放词汇感知和目标定位，策略只接收视觉定位提示（目标边界框）和可学习操作令牌，从而让策略专注于动作生成，智能体保留规划、记忆与错误恢复能力。

## 2. 论文提出的方法论

### 2.1 核心思想

- 用两类互补条件替代语言指令：
  - **视觉定位提示（visual grounding prompt）**：目标边界框 `g = (x1, y1, x2, y2)`，归一化图像坐标，指定“在哪里操作”。
  - **可学习原子操作令牌（learnable operation token）**：来自有限技能集 `S = {pick, place, handover, click, pull, ...}` 的嵌入向量 `e_s`，指定“执行哪种技能”。
- 将“在哪里操作”（grounding，由外部智能体承担）与“如何操作”（control，由紧凑策略承担）解耦。

### 2.2 模型结构

- **视觉编码器**：冻结的预训练 DINOv3 编码器，无语言编码器；模型总参数约 0.5B（0.2B transformer + 冻结 0.3B 视觉编码器）。
- **任务条件注入**：`e_s`、参与者属性 `e_u`（左/右/双手）、风格属性 `e_w`（如将物体放在另一个物体上方/旁边）以及边界框嵌入 `φ(g)` 通过 **AdaLN 条件调制**融合为任务条件令牌，调制下游推理专家和世界动作专家。
- **形式化**：
  
  \[
  \hat{a}_{t:t+H-1} \sim \pi_\theta(\cdot \mid o_t, p_t, \phi(g), e_s, e_u, e_w)
  \]
  
  其中 `o_t` 是视觉观测，`p_t` 是本体感受状态，输出长度为 `H` 的动作块。

### 2.3 推理专家（Reasoning Expert）与可监督意图

- 一组可学习推理查询令牌 `q_reas` 探测观测与任务条件，产生推理令牌 `q_t`。
- 轻量推理头解码出三类显式、可监督的当前步预测：
  - 目标物体的掩码 `m̂_t`；
  - 技能结束时双臂末端执行器位姿 `T̂_t`；
  - 任务抽象 `ĉ_t`（one-hot 结构化描述，如使用哪只手臂、如何抓取和放置）。
- 推理损失：
  
  \[
  L_{\text{reas}} = \text{BCE}(\hat{m}_t, m_t) + \text{CE}(\hat{c}_t, c_t) + \|\hat{T}_t - T_t\|^2
  \]
  
  这些信号使策略意图可监督、可诊断。

### 2.4 潜在世界动作专家与双级未来对齐

- 离线预训练一个 **foresight-gist 提取器**：将两帧观测的潜在表示压缩为紧凑的“未来要点”：
  
  \[
  f_{t_0 \to t_1} = G_{\text{IDM}}(E(o_{t_0}), E(o_{t_1}))
  \]
  
  并通过潜在前向动力学模块重建未来帧，损失为潜在重建损失。
- 世界动作专家通过 **flow matching** 单去噪器同时去噪三个模态：
  - **动作块**：回归插值速度，损失 `L_act`；
  - **视觉未来预测**：对齐离线提取的 foresight gist（视觉层面“未来会怎样”），损失 `L_vis`；
  - **语义未来预测**：对齐未来帧经共享推理主干产生的推理令牌（语义层面“未来意味着什么”），损失 `L_sem`，且对目标使用 stop-gradient。
- 注意力掩码防止动作/未来分支污染推理输出；推理前向与第一步去噪共享一次前向，后续步骤复用 KV cache。
- 联合训练目标：
  
  \[
  L(\theta) = L_{\text{act}} + \lambda_{\text{reas}} L_{\text{reas}} + \lambda_{\text{vis}} L_{\text{vis}} + \lambda_{\text{sem}} L_{\text{sem}}
  \]

### 2.5 智能体兼容层与闭环控制

- 将智能体建模为“模型 + harness”：系统提示、规则、可调用工具、交互历史和控制循环。
- 暴露三个与模型无关的原语：
  - `detect(y) → g`：智能体侧用自身视觉能力将查询 `y` 定位为边界框；
  - `execute(g, s, u, w) → ξ`：策略执行直到触发事件（末端位移超阈值、夹爪闭合、夹爪张开、固定时间间隔）；
  - `query(ξ) → b`：将执行反馈结构化为智能体下一步推理所需信息。
- 长时程记忆完全由智能体历史承担，策略保持 **Markovian**；失败恢复也由智能体重新定位、重新执行，重试预算受控。
