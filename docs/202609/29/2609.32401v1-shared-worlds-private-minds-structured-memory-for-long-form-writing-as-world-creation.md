## 摘要
撰写长篇小说的 LLM 智能体需要对不断演变的故事世界拥有显式记忆，以使新事件与既定事实保持一致。这种记忆必须将异质叙事信息区分开，跨粒度整合故事发展，并恢复写作请求中隐含的依赖关系。我们提出 NarraWorld，一个用于长篇写作的结构化记忆系统，它将记忆构建视为世界创建。基于共享的证据锚定图，NarraWorld 派生出四个相互关联的视图：世界事实、逐角色信念、开放性发展以及假设性分支（可能世界的延续）。带原子闭包的层次化聚合将事件整合为场景、情节线和情节，使每个更高层节点都可追溯到其构成来源片段。在检索方面，计划式重建从当前叙事情境和记忆预览中推断查询的依赖关系，然后在令牌预算内组装相关记录。在三个写作基准上，NarraWorld 取得了最强的综合结果。其记忆还可迁移到情境化角色扮演，并在通用长期记忆基准上大体保持召回率，为智能体在多样叙事任务中维持连贯故事世界铺平了道路。

## Abstract
LLM agents that write long-form fiction need an explicit memory of the evolving storyworld to keep new events consistent with established facts. Such memory must keep heterogeneous narrative information distinct, integrate story developments across granularities, and recover dependencies that a writing request leaves implicit. We present NarraWorld, a structured memory system for long-form writing that treats memory construction as world creation. From a shared evidence-grounded graph, NarraWorld derives four connected views: world facts, per-character beliefs, open developments, and hypothetical branches (possible-world continuations). Hierarchical aggregation with atomic closure consolidates events into scenes, plotlines, and plots, keeping each higher-level node traceable to its constituent source spans. For retrieval, planned reconstruction infers a query's dependencies from the current narrative situation and a preview of memory, then assembles the relevant records within a token budget. Across three writing benchmarks, NarraWorld achieves the strongest aggregate results. Its memory also transfers to situated role-playing and largely preserves recall on a general-purpose long-term memory benchmark, paving the way for agents that sustain coherent storyworlds across diverse narrative tasks.

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 智能体越来越多地被用于长篇虚构写作，如起草故事、将提纲扩展为完整叙事、与人类作者共同创作。
- **核心矛盾**：长篇写作质量高度依赖**叙事一致性**，即新事件必须与已建立的故事事实相符；但故事历史会迅速超出模型上下文，且即使长上下文中，远距离或中间位置的信息访问也会退化。
- **三个关键挑战**：
  1. **叙事信息异构**：同一段落可能同时混合客观世界事实、角色信念、情节发展与伏笔可能性，这些信息可能相互冲突，难以从表面文本检测。
  2. **跨粒度发展**：一个背叛可能在多章中通过细小行为逐步积累，记忆需要在多个粒度上整合证据又不丢失具体事实。
  3. **写作查询隐含依赖**：如“改写背叛场景”这类请求，不仅需要背叛本身的记忆，还需要可能受影响的人物关系等隐含依赖，基于相似度的检索无法覆盖。
- **整体含义**：论文提出将**记忆构建视为世界创建**，而非仅存储表面故事文本；需要保留故事世界的潜在状态、角色视角与可能世界，才能支撑连贯的后续写作。

## 2. 论文提出的方法论

### 2.1 基于共享图的四视图记忆
- NarraWorld 在共享的、证据锚定的叙事结构图 `Gτ` 上维护四个相互关联的记忆视图：
  - **Wτ（共享世界）**：已发生事件、当前有效事实、实体状态与关系。
  - **Bτ[c]（私人心智）**：角色 `c` 当前的知识、信念、误解，可能包含与世界事实冲突的命题。
  - **Dτ（叙事发展）**：跨段落/章节的目标、冲突、关系演变，记录其为开放、推进、受阻或已解决。
  - **Hτ（可能世界）**：与未解决发展相关的有界假设性延续，标记为假设状态。
- 四视图从共享图投影得到，共享实体、事件、时间与证据，但赋予不同的认识论地位。

### 2.2 增量记忆构建
- 新文本单元 `Uτ` 更新图：`Gτ = Update(Gτ-1, Uτ)`，包含四个阶段：
  1. **实体解析**：将新增实体链接到已有实体，未匹配则创建新记录。
  2. **事件与事实提取**：添加事件及由事件支持的事实、状态变化；状态变化保留旧状态的有效期，而非覆盖。
  3. **角色访问跟踪**：根据观察、交流、推理等方式将角色连接到事件/命题，记录获取模式。
  4. **发展更新与可能性生成**：更新叙事发展状态；对未解决发展生成受当前世界与角色知识约束的条件候选，加入 Hτ。
- 关键实例：Mara 把钥匙从抽屉移到书里而 Leo 不在场时，世界事实更新为“钥匙在书里”，Mara 的信念视图更新，Leo 的信念视图仍保留“钥匙在抽屉里”。

### 2.3 跨粒度层次组织与原子闭包
- 记忆按 `事件 → 场景 → 情节线 → 情节` 组织：
  - **事件**：原子节点，保留参与者、时间范围、来源单元与支持证据。
  - **场景**：聚合局部单元内相关事件、状态变化、关系演变。
  - **情节线**：跨场景识别持久的角色、目标、冲突或关系，生成摘要并保留场景引用。
  - **情节**：合并共享参与者且有连续性的情节线，构成叙事弧。
- **原子闭包**：每个高层节点保存其成员事件、W/B/D 记录及来源片段，检索时可先选高层摘要，再展开为具体事实与证据。

### 2.4 检索：计划式重建
- 写作请求被视为欠指定的检索查询，检索分四步：
  1. **情境条件记忆访问**：根据故事时间、披露状态、聚焦者与分支，投影出可允许的视图 `Vq`。
  2. **预览引导依赖规划**：规划器读取请求、叙事情境与紧凑记忆预览（角色名册、简要描述、W/B/D/H 目录），输出证据形式需求、焦点角色、检索意图与缺失信息需求。
  3. **尺度自适应检索**：结合词法与语义匹配，支持时间、认知与发展访问；高层匹配展开为支持记录。
  4. **预算内组装**：在令牌预算内将证据按 W/B/D/H 分区渲染为可读上下文，B 按角色组织，H 保留前提与条件，不将假设当作事实。

## 6. 论文的主要结论与发现

- **综合写作质量领先**：在三个写作基准上，NarraWorld 取得最强汇总结果。
  - ConStory-Bench CED 为 **0.185**，优于 Full Context（0.200）和 Graphiti（0.385）。
  - LSGC Overall 为 **90.24**，领先 StructMem（86.92）和 Full Context（85.03）。

- **消融显示组件贡献非均匀**：

  - 移除**可能世界**降低创造力与发展（→ 88.74）。
- **预览引导依赖规划**在所有 ConStory 任务上降低 CED，续写与完成任务收益最大。
- **可迁移性**：在 RMTBench 上，NarraWorld 在四个 1–5 评分维度领先；在 LoCoMo 上总体召回最高/持平，并在预算扫描中始终第一。
- **任务条件记忆视图**：QA 场景下排除 H 视图可提升 LoCoMo 总分（0.614 vs 0.570），说明事实问答与创意续写需要不同的可允许视角。

## 7. 优点

- **叙事学启发的四视图设计**：区分共享世界事实与角色私密信念，从根本上解决了“角色是否知情”这一叙事一致性问题。
- **层次化原子闭包**：既支持跨章节开发的紧凑摘要，又保留到原子事件与来源片段的完整追溯，检索时可灵活展开。
- **计划式重建**：引入依赖规划步骤，使检索不再受限于查询显式文本，能恢复隐含的人物关系、知识边界与未决后果。
- **任务条件可允许视图**：允许同一记忆针对写作、角色扮演或 QA 使用不同视图，兼具创造性与事实性。
- **实验全面**：覆盖多个基准、多样基线、组件消融、检索消融、预算敏感性与人类评估，且保持较严格的控制条件。
- **可解释的定性案例**：通过具体案例展示记忆如何转化为叙事行为，增强了说服力。

## 8. 不足与局限

- **构建与规划成本较高**：NarraWorld 平均约 200 次模型调用，高于部分轻量基线；论文明确指出成本是一个权衡，尚未优化。
