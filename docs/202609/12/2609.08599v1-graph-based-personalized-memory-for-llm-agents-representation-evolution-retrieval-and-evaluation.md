## 摘要
大型语言模型（LLM）智能体正从单次会话工具向长期个人助理演进，需要在不同任务、上下文和交互中适应用户个体。这一转变使记忆成为个性化的核心需求，因为用户偏好、目标、约束、关系及过往经历是逐步积累且往往随时间变化的。基于图的个性化记忆通过显式关系、时间上下文和证据链接，为建模此类用户信息提供了一种结构化方式。这类表示不仅能刻画智能体对用户记住了什么，还能刻画记忆如何被连接、修正和检索以支持个性化决策。然而，现有研究分散于个性化智能体和通用图记忆框架之间，难以从整体上理解设计空间。本综述围绕LLM智能体的基于图个性化记忆，提出以生命周期为导向的视角。我们围绕记忆表示、记忆演化、记忆检索和记忆评估组织现有研究。进一步比较关键设计选择，讨论当前评估实践，并指出构建可靠长期个性化智能体所面临的开放挑战。本综述旨在阐明基于图的记忆如何支持自适应、可控且以用户为中心的LLM智能体。

## Abstract
Large Language Model (LLM) agents are evolving from single-session tools toward long-term personal assistants that must adapt to individual users across tasks, contexts, and interactions. This shift makes memory a core requirement for personalization, since user preferences, goals, constraints, relationships, and past experiences are accumulated gradually and often change over time. Graph-based personalized memory provides a structured way to model such user information through explicit relations, temporal context, and evidence links. Such representations can model not only what an agent remembers about a user but also how memories are connected, revised, and retrieved to support personalized decisions. However, existing work remains fragmented across personalized agents and generic graph memory frameworks, making it difficult to understand the design space as a whole. This survey develops a lifecycle-oriented view of graph-based personalized memory for LLM agents. We organize existing studies around memory representation, memory evolution, memory retrieval, and memory evaluation. We further compare key design choices, discuss current evaluation practices, and open challenges in building reliable long-term personalized agents. This survey aims to clarify how graph-based memory can support adaptive, controllable, and user-centric LLM agents.

## 2. 论文提出的方法论

论文本身是综述，不提出新的算法，而是给出一个**分类框架（taxonomy）**：

- **总体生命周期框架**  
  - 图式个性化记忆系统包含：记忆摄入 → 结构构建 → 演化更新 → 检索利用 → 评估反馈的闭环。  
  - 论文围绕四条主线组织：**表示（Representation）**、**演化（Evolution）**、**检索（Retrieval）**、**评估（Evaluation）**。

- **记忆表示：元素层 + 结构层**  
  - **元素层**  
    - 节点角色：证据节点、事实节点、抽象节点、领域特定节点。  
    - 关系类型：时序关系、来源关系、关联关系、领域特定关系。  
    - 生命周期元数据：时间戳、有效期、失效标记等，用于区分历史和当前状态。  
  - **结构层**：归纳为五类模式  
    - **扁平图**：如 UMGR、KGT、Mem0g，只有节点和边，无显式抽象层级。  
    - **层级图**：如 GAAMA、Bi-Mem、GAM、SGMem，将原始证据、事实、抽象/人格分层，保留跨层链接。  
    - **超图**：如 HingeMem、HyperMem，用超边保留多个元素共同构成的上下文。  
    - **混合图**：如 H-Mem、LiCoMemory、MemWeaver，图与其他存储（树、摘要库、段落库）结合。  
    - **多独立图**：如 DEMENTIA-PLAN，按时间尺度或用途拆分多个图实例。

- **记忆演化：五个操作**  
  - **准入（Admission）**：决定新证据是否进入持久记忆，如 KGT、MemORAI、MemGuard。  
  - **整合（Integration）**：将新证据写入图结构，如 LiCoMemory 的 append-and-link，Mem0g 的节点复用与边失效。  
  - **冲突消解（Conflict Resolution）**：区分时间替代、用户纠正、上下文共存三类冲突，如 AriadneMem、GRAVITY、ZEP。  
  - **巩固（Consolidation）**：长期写后重组，如 GAM 提升到主题层、All-Mem 的拓扑编辑。  
  - **移除（Removal）**：分遗忘（降低分辨率/权重，如 ScrapMem）和删除（如 Kumiho 的版本化修订），并提醒依赖传播问题。

- **记忆检索：三种机制**  
  - **基于相似度的检索**：词汇/关键词/稠密向量匹配，产生候选或图锚点，如 EMG-RAG。  
  - **基于结构的检索**：利用图关系、层级、时序视图扩展证据，如 GAM、MAGMA、AssoMem、xMemory。  
  - **自适应/智能体式检索**：根据查询意图和中间证据控制探索、停止、压缩，如 MRAgent、PRISM、HingeMem、APEX-MEM。

- **记忆评估：五类信号**  
  - 答案质量、证据检索、用户状态建模、记忆演化与结构、效率（上下文大小、token、延迟、存储）。

## 6. 论文的主要结论与发现

- **图记忆不是“用了图就更好”**  
  - 图结构只有在其表示暴露有意义的用户关系、演化保持状态有效、检索返回相关证据时才有价值。  
  - 表示只是后续演化和检索的基础，而不是个性化质量的保证。

- **生命周期各阶段的关键取舍**  
  - 表示：证据丰富的设计可溯源但存储成本高；事实/抽象中心的设计紧凑但可能传播提取错误。  
  - 演化：需区分时间替代、用户纠正、上下文共存三类冲突，不能简单“最新覆盖”。  
  - 检索：相似度、结构、自适应三种机制可以组合，但结构扩展可能引入无关节点和上下文成本。  
  - 评估：当前主要测最终答案正确性，对图本身质量、用户控制、生命周期有效性的评估不足。

- **未来方向**  
  - 可扩展的终身个人记忆：支持数年交互、偏好漂移、高存储效率。  
  - 多模态个人记忆图：融合语音、图像、文档、位置、行动等异构信号。  
  - 因果与反事实用户建模：理解“为什么偏好存在、何时变化、不同上下文会怎样”。
