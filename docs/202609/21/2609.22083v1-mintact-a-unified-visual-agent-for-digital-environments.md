## 摘要
我们提出了 MintAct，这是一个视觉-语言模型系列，统一了 UI 定位、跨移动端、桌面端和网页的多步骤导航以及视觉工具使用，并分别在 2B、4B 和 8B 规模上训练。通过精心设计环境、数据和训练策略，MintAct 模型在所有这些能力上与各领域专用模型表现相当。为实现这一目标，我们开发了可扩展的环境与强化学习（RL）基础设施。在环境侧，我们在异构的各领域后端上托管数百个并发实例，同时服务于轨迹数据收集和在线强化学习。为了实现高效且可扩展的 RL 训练，一个异步框架对跨领域训练分布保持显式控制，并在嘈杂环境反馈和离策略漂移下保持稳定。实验结果表明，MintAct 在同等模型规模下，在广泛的基准测试中达到了最先进的性能（在 OSWorld-Verified 上为 48.9）。

## Abstract
We present MintAct, a family of vision-language models that unifies UI grounding, multi-step navigation across mobile, desktop, and web, and visual tool use, trained at 2B, 4B, and 8B scales. Through careful design of our environments, data, and training recipes, MintAct models match the performance of per-domain specialists across all of these capabilities. To enable this, we develop a scalable environment and reinforcement learning (RL) infrastructure. On the environment side, we host hundreds of concurrent instances across heterogeneous per-domain backends, serving both trajectory data collection and online RL. To enable efficient and scalable RL training, an asynchronous framework keeps explicit control over the cross-domain training distribution and remains stable under noisy environment feedback and off-policy drift. Experimental results show that MintAct achieves state-of-the-art performance (48.9 on OSWorld-Verified) across a wide range of benchmarks at comparable model sizes.

- **研究背景**：视觉-语言智能体可以直接从屏幕像素出发操作数字设备，是通用数字助手的重要方向。但当前能力高度碎片化：UI 定位、移动端导航、桌面控制、网页导航、视觉工具使用等通常由彼此独立的专用模型完成。

- **困难所在**：各领域在观察空间、动作空间、交互方式、数据来源和可执行环境上差异很大；简单合并动作集或混合数据会导致领域间干扰。此外，在线强化学习需要与异构、缓慢、不可靠的环境后端交互，并处理长多模态轨迹，训练不稳定且资源消耗大。
- **整体含义**：MintAct 通过在环境、数据、训练策略三方面的协同设计，证明统一视觉智能体是可行的，并能在多个基准上达到或超过同规模的领域专用模型；其异步强化学习基础设施也为跨域智能体训练提供了可扩展方案。

## 2. 论文提出的方法论

### 2.1 统一设计原则

- **共享观察与定位空间**：所有 UI 领域都只使用原始截图，动作通过像素坐标定位，不依赖 DOM、无障碍树或平台 API；坐标统一归一化到 999×999。
- **提示条件化动作集**：不把所有领域动作合并成一个动作空间，而是通过**领域特定系统提示** `c` 引导模型从对应动作集中输出动作，从而避免动作集互相干扰。
- **均衡跨域混合**：在 SFT 和 RL 阶段都显式保持训练分布均衡，防止某一领域主导训练。

### 2.2 多阶段训练流程

1. **高分辨率单步 SFT**
   - 目标：建立基础 UI 定位和单步导航能力。
   - 数据：GroundCUA、Molmo-Point、GUI-Odyssey、AndroidControl 等。
   - 每张图最多 2,116,800 像素，学习率 1×10⁻⁵，训练 1 个 epoch。

2. **低分辨率多步 SFT**
   - 目标：学习多步导航和视觉工具使用。
   - 数据来自各领域环境：移动端约 42.7k、桌面约 23.5k、网页约 51.7k、视觉工具使用约 59.8k 条轨迹。
   - 四个域按 25%:25%:25%:25% 均衡混合；每条轨迹以 append-only 多轮格式输入，方便后续 RL 复用 KV cache。
   - 每个截图最多 921,600 像素；移动/桌面/网页最多 30 轮，工具使用最多 100 轮；学习率 1×10⁻⁵。
   - **视觉工具使用的动态工具注册问题**：工具列表会在轨迹中动态变化，因此采用“工具注册感知的轨迹切分”，每当工具集变化就切分段落，并对损失做 masking，保证每个动作只被监督一次。

3. **RFT：拒绝采样蒸馏**
   - 先为每个领域训练一个 RL 专家模型。
   - 专家在各自领域的 SFT 任务上生成轨迹，用强 VLM judge 过滤出成功轨迹，再对 SFT 模型进行拒绝采样微调。
   - 数据量约为：移动 37.8k、桌面 21k、网页 7k、工具使用 24k；四个领域仍按 25% 均衡混合。

4. **联合异步强化学习**
   - 基于 verl 和 rLLM 构建异步 RL 框架，包含：
     - **Rollouter**：通过 SGLang 路由器并发执行 rollout，处理多轮交互。
     - **Environment manager**：维护移动、网页、桌面、合成环境、视觉工具环境等异构环境池，提供隔离访问。
     - **Trainer**：从消息队列取轨迹组，用当前 Megatron actor 重算 log-probability，再进行策略更新。
     - **Message queue**：FIFO 缓冲，限制容量以控制样本陈旧度；图片写入磁盘，队列只保留引用，降低内存占用。
     - **Parameter synchronizer**：每 K 步训练后把最新权重同步到推理端，控制离策略程度。
   - 支持数百个并发环境实例，用于在线 RL rollout。

### 2.3 RL 训练策略与目标函数

- **多轮输入格式**：UI 领域沿用 append-only 轨迹；视觉工具使用保留完整历史，并采用动态工具注册切分。
- **动态组过滤**：基于 VLM judge 给任务完成二元奖励；借鉴 DAPO 风格过采样，在线过滤掉“全成功”或“全失败”的轨迹组，只保留有学习信号的组。
- **优势函数**：组相对优势，不做标准差归一化：
  
  \[
  \hat A_i = R_i - \frac{1}{|G(i)|}\sum_{j\in G(i)}R_j
  \]

- **离策略目标**：
  - 采用**非对称 dual-clipped surrogate**，对低于组均值的样本限制下界，防止离策略更新快速发散。
  - 采用**截断重要性采样权重** \( \rho_{i,t} \)，上界截断 C=2，不下界截断，以缓解训练端与推理端数值差异。
  - 最终损失：
  
  \[
  L(\theta)=\frac{1}{S}\sum_i\sum_t w_{i,t}\,\ell^{clip}_{i,t}
  \]
  
  其中 S 与响应 mask 无关，避免掩码导致权重重新分配。
- **不使用 KL 锚或熵奖励**。

### 2.4 跨域混合控制

- **每域配额**：trainer 按每域配额从共享队列取轨迹组，只有该域未满额时才接受。
- **配额归一化背压**：生产者根据各域已接受组数决定是否暂停某一域的生产，防止快速领域过度消耗算力。
- **回退机制**：若某域长期无法达到配额，则放开上限，由其他有生产力领域补满批次。

### 2.5 合成环境

- 利用编码智能体生成轻量、确定性的合成操作系统环境，覆盖移动和桌面。
- 采用“能力飞轮”流程：选择能力 → 生成环境与任务 → 用数据进行 SFT/RL/评估。
- 约使用 16,300 个任务、3,348 个 fork 环境；合成环境可以转移到真实基准，但在有真实数据时不如真实 RL 有效。

- **统一模型不会牺牲单域性能**：MintAct 在定位、移动、桌面、网页导航和工具使用上，能够匹配或超过同规模的领域专用模型。
