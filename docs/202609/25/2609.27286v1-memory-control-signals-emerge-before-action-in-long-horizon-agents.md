## 摘要
长时程语言模型智能体不断累积交互历史，既增加了计算成本，又使相关信息的保存和重用变得更加困难。现有的上下文管理方法主要关注如何压缩或检索历史，但在很大程度上尚未回答：模型自身是否在这些记忆操作发生前就已经表征了对这些操作的需求。我们研究了每个智能体动作发生前的隐藏状态，发现压缩和回忆需求已被编码在模型内部表示中。这些信号不能简单地由上下文长度或交互进度来解释，并且它们在模型不同深度上表现出不同的形成模式。我们进一步表明，大部分记忆决策信息保存在紧凑的近期上下文中，而选择性恢复的历史证据补充了近期上下文所遗漏的长程依赖。基于这些发现，我们提出了带证据检索的动作前记忆（PaMER），它将状态引导的压缩与外部证据检索相结合。PaMER+ 进一步引入步骤级证据选择，仅恢复当前任务所需的历史信息。在 WorkBuddyBench 上、跨多个上下文管理基线和模型主干的实验表明，我们的框架在保持有竞争力的任务性能的同时，大幅降低了上下文消耗。

## Abstract
Long horizon language model agents continuously accumulate interaction history, increasing computational cost while making relevant information harder to preserve and reuse. Existing context management methods mainly focus on how to compress or retrieve history, but largely leave open whether the model itself already represents the need for these memory operations before they occur. We study the hidden state immediately before each agent action and find that compression and recall needs are already encoded in the model's internal representations. These signals cannot be explained by simple context length or interaction progress, and they exhibit distinct formation patterns across model depth. We further show that most memory decision information is preserved in a compact recent context, while selectively restored historical evidence complements the long range dependencies that recent context misses. Based on these findings, we propose Preaction Memory with Evidence Retrieval (PaMER), which combines state guided compression with external evidence retrieval. PaMER+ further introduces step level evidence selection to recover only the historical information required by the current task. Experiments on WorkBuddyBench, across multiple context management baselines and model backbones, show that our framework substantially reduces context consumption while maintaining competitive task performance.

- **研究背景**：长时程（long-horizon）语言模型智能体在持续交互中会不断积累历史上下文，导致计算成本、延迟和显存开销上升，同时使模型更难以有效利用分散在长上下文中的关键信息。

## 2. 论文提出的方法论

### 2.1 动作前记忆决策信号的探测（Probing）

- **决策点建模**：将智能体执行下个动作前的上下文记为 \(o_t\)，定义两类二值目标：
  - **压缩 \(y_t^c\)**：当前历史是否需要被压缩、同时保留任务相关信息；
  - **召回 \(y_t^r\)**：当前推理状态是否需要早期已不在活跃上下文中的证据。
- **表示提取**：使用冻结的 Qwen3.5-9B 模型，取最后一个输入 token 经过输出 RMSNorm 后的隐藏状态 \(h_t = \phi^{(L)}(o_t)[-1] \in \mathbb{R}^{4096}\)。
- **探针训练**：对每个目标训练独立线性探针（以及作为对照的单隐藏层 MLP），采用类别加权二元交叉熵；只更新探针参数，冻结语言模型。
- **关键分析设置**：
  - 按 **question 分组**划分训练/验证/测试（70/15/15），避免同任务内高度相关状态泄漏；
  - 比较隐藏状态与可观测控制变量（上下文长度、轮数、工具类型、动作类型等）；
  - 分析不同层、不同池化方式（last token vs mean pooling）下信号的强弱。

### 2.2 PaMER：Preaction Memory with Evidence Retrieval

- **状态引导压缩**：
  - 保留 system/task prefix \(P_t\) 和最近两个完整交互块 \(R_t\)；
  - 对较早的完整交互块构成压缩候选；
  - 当候选 token ≥ 1,024 时，五个独立训练压缩头读取 \(P_t \oplus R_t\) 的最终状态，若至少三头超过各自阈值则触发压缩；
  - 压缩头使用 Recent2 上的 **决策蒸馏（decision distillation）** 训练：损失 = 加权 BCE + 0.5×与 Full Context 教师预测的 BCE。
- **外部证据检索**：
  - 压缩时生成摘要，用 Qwen3-Embedding-8B 编码并存储；
  - 后续请求中以 task+Recent2 构造 embedding query，按余弦相似度检索 Top3 摘要插入到 prefix 和近期块之间；
  - 论文使用的在线召回不依赖学习到的召回探针作为门控。
- **PaMER+ 的步骤级证据选择**：
  - 为每个摘要记录 `step_details`，在召回时明确指定需要的原始历史步骤；
  - 只恢复当前任务所需的具体步骤，而非恢复摘要覆盖的全部历史。
