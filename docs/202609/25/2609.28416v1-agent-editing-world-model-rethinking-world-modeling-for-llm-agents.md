## 摘要
近期大语言模型（LLMs）的进展使智能体能够在多种环境中处理长程任务。为了进一步提升智能体性能，现有语言世界模型通常预测环境观测；然而，在可获得真实反馈的情况下，重建高熵且依赖执行的工具响应价值有限。同时，智能体还受到任务状态污染的影响：未经证实的假设与过时计划会残留在历史中，扭曲后续决策。我们提出智能体编辑世界模型（AEWM），它建模推理与动作如何塑造未来任务进展，而非模拟工具响应。AEWM 将用于区分关键、探索和噪声决策的动作判断器（Action Judge）与用于编辑来自相同观测历史的噪声推理-动作延续的状态修订（State Revision）相结合。EditAct 将这些能力与真实执行集成，直接改变后续决策所依赖的状态，而不仅仅是提供批评。我们通过中期训练和监督微调，在搜索、终端和软件工程任务上训练 AEWM。AEWM 在我们的 Action Judge 基准上达到 70.5% 的宏 F1 分数，比最强前沿基线高出 10.6 个百分点。在六个基准和三种智能体骨干上，EditAct 相比最强基线将平均得分提高 3.2–6.7 分。此外，在经验证的 EditAct 轨迹上进行拒绝采样微调（称为 AEWM-RFT），在没有在线 AEWM 引导的情况下，在三个领域中比 Self-RFT 提高 2.2–2.6 分。

## Abstract
Recent advances in large language models (LLMs) have enabled agents to tackle long-horizon tasks across diverse environments. To further improve agent performance, existing language world models typically predict environment observations, yet reconstructing high-entropy, execution-dependent tool responses offers limited value when real feedback is available. Meanwhile, agents suffer from \emph{task-state contamination}, where unsupported assumptions and outdated plans persist in history and distort subsequent decisions. We propose the \textbf{Agent-Editing World Model (AEWM)}, which models how reasoning and actions shape future task progress rather than simulating tool responses. AEWM combines \textbf{Action Judge} to distinguish \textsc{Critical}, \textsc{Exploratory}, and \textsc{Noisy} decisions with \textbf{State Revision} to edit noisy reasoning--action continuations from the same observed history. \textbf{EditAct} integrates these capabilities with real execution, directly changing the state underlying subsequent decisions rather than merely providing critiques. We train AEWM across Search, Terminal, and Software Engineering through mid-training and supervised fine-tuning. AEWM achieves 70.5\% macro-F1 on our Action Judge benchmark, exceeding the strongest frontier baseline by 10.6 points. Across six benchmarks and three agent backbones, EditAct improves average scores by 3.2--6.7 points over the strongest baseline. Furthermore, rejection sampling fine-tuning on verified EditAct trajectories, termed \textbf{AEWM-RFT}, improves over Self-RFT by 2.2--2.6 points across three domains without online AEWM guidance.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体已在搜索、终端操作、软件工程等长程任务中取得进展，但现有语言世界模型通常预测环境观测（如工具响应、网页内容、终端输出），这类观测往往具有高熵、依赖执行细节，当真实环境反馈可用时，重建它们的价值有限。
- **核心问题**：论文指出两个关键缺陷：
  1. **环境观测预测的价值有限**：搜索排名、终端运行状态等观测高度执行依赖，预测困难且无法替代真实反馈，甚至可能引入虚构证据。
  2. **任务状态污染（task-state contamination）**：智能体在历史中保留未经证实的假设、过时计划或局部成功误判，这些错误持续存在并通过后续“局部合理”决策被放大，扭曲后续推理和行动。
- **整体含义**：世界模型的建模目标应从“预测环境观测”转向“预测推理与动作对未来任务进展的影响”，并直接编辑智能体的状态（推理-动作延续），从而在真实执行前修正污染，提升长程可靠性和决策质量。

## 2. 论文提出的方法论

- **核心思想**：构建**智能体编辑世界模型（AEWM）**，它不模拟工具响应，而是建模当前智能体状态（历史+提议的推理-动作对）对未来任务进展的影响，并通过编辑噪声决策直接干预状态。
- **两个核心能力**：
  - **Action Judge（动作判断器）**：给定预执行状态 \(s_t = h_t \oplus (\hat{r}_t, \hat{a}_t)\)，预测决策标签 \(y_t \in \{\text{critical}, \text{exploratory}, \text{noisy}\}\)。关键决策属于紧凑解路径；探索决策能有效减少不确定性或测试合理分支；噪声决策贡献低、重复、无关或方向错误。
  - **State Revision（状态修订）**：当动作被判断为噪声时，从相同历史 \(h_t\) 重新生成推理-动作对 \((\tilde{r}_t, \tilde{a}_t)\)，形成编辑后的状态 \(\tilde{s}_t\)。修订内容需调和冲突信息、修正假设或更新计划，并转化为真实环境中的下一步交互。
- **EditAct 集成**：
  1. 智能体提出 \((\hat{r}_t, \hat{a}_t)\)。
  2. Action Judge 输出标签；若为 critical/exploratory，保留原提议；若为 noisy，调用 State Revision 替换。
  3. 执行被选中的动作 \(a_t\)，获得真实观测 \(o_t\)，更新历史 \(h_{t+1} = h_t \oplus (r_t, a_t, o_t)\)。
  4. 智能体基于更新后的历史继续生成下一步。整个过程通过真实环境反馈接地，而非停留在批评层面。
- **训练流程**：
  - **数据合成**：
    - Action Judge 数据：用强标注代理对成功轨迹逐轮标注 critical/exploratory/noisy，生成前向推理轨迹和标签；经一致性、未来信息泄漏、逻辑支撑等过滤。
    - State Revision 数据：提案代理生成决策，Action Judge checkpoint 识别噪声，修订代理生成替换，真实执行并仅保留产生实质进展的样本。
  - **两阶段训练**：先在约 52B 令牌的三领域混合语料上做中期训练（mid-training），再在 120K 高质量样本上做监督微调（SFT），激活并校准判断与修订能力。
  - **AEWM-RFT**：利用 EditAct 在真实环境中产生的高质量轨迹进行拒绝采样微调，将状态校正模式内部化到代理模型中，使其在无在线世界模型引导时也能避免和恢复任务状态污染。

## 3. 实验设计

## 6. 论文的主要结论与发现

- **Action Judge 性能**：AEWM 在 Action Judge 基准上达到 70.5% 宏 F1，比最强基线 DeepSeek-V4-Pro（59.9%）高 10.6 个百分点；在搜索、终端、SWE 三个领域分别领先 10.3、10.5、13.4 点，表明其学习到跨领域、鲁棒的决策效果判断能力。
- **EditAct 提升任务性能**：在所有六个基准和三个骨干上，EditAct 均超过 ReAct 和两种 Best@3 基线；相对最强基线平均提升 3.2–6.7 分；相对 ReAct 平均提升 6.6–13.3 分。较小的 9B 模型配合 EditAct 可超越 35B 模型单独使用 ReAct。
- **AEWM-RFT 可转移**：在不使用在线 AEWM 的情况下，AEWM-RFT 相比基础代理在 BrowseComp、Terminal-Bench 2.0、Doc2Repo 分别提高 4.5、6.4、5.8 分，且比 Self-RFT 高 2.2–2.6 分；同时减少了部分任务的平均步数。
- **消融结论**：直接编辑优于随机干预、代理重采样或仅提供提示；联合推理-动作修订优于仅修订单一组件；专门训练的 AEWM 优于用自我模型或强通用模型替代；两阶段训练（mid-training + SFT）比单独任一步更有效。
- **状态污染修复机制**：通过案例和统计发现，AEWM 能纠正“偏爱结论而忽视矛盾证据”、“将中间成功误判为完成”、“遗忘不可变性或兼容性要求”等污染模式，并引导代理获取更具区分性的证据或执行正确验证。

## 7. 优点

- **概念创新**：重新定义语言世界模型的预测目标，从“预测环境观测”转向“预测决策效果并编辑状态”，更贴合任务导向智能体的实际需求。
- **任务状态污染洞察**：明确识别并命名了长期存在的历史污染问题，为后续研究提供清晰的问题范式。
- **统一模型与集成设计**：单一 AEWM 同时支持判断与修订，EditAct 简洁地嵌入现有 ReAct 框架，无需改变底层智能体。
- **跨领域泛化**：在搜索、终端、软件工程三个差异显著的领域中训练和验证，显示方法不依赖特定环境动力学。
- **可转移学习**：AEWM-RFT 使编辑能力可蒸馏到代理自身，推理时无需额外世界模型，便于部署。
- **实验严谨性**：多骨干、多基准、强基线、多次运行、丰富消融和案例，证据链完整。
- **工程细节透明**：附录提供完整提示词、数据构建和过滤规则，增强了可复现性。

## 8. 不足与局限

- **算力与资源未披露**：缺少 GPU 型号、数量、训练时长等信息，难以评估实际成本和环境足迹。

- **有限失败案例分析**：案例均为成功干预，缺少失败或误编辑的示例，对方法的适用范围和潜在副作用讨论不足。
- **安全性/伦理维度缺失**：没有讨论编辑动作可能带来的错误执行风险，或对不可逆环境操作（如删除文件）的保护机制。
- **AEWM-RFT 数据规模较小**：RFT 使用的轨迹数量有限（搜索 4,000，终端 7,095，SWE 1,456），可能不足以证明其在更广泛任务上的稳健性。
- **基准指标选择**：Action Judge 仅用宏 F1 和准确率，未报告混淆矩阵之外的更细粒度错误类型（如关键 vs 探索的混淆率），对实际应用中的风险权衡解释有限。
