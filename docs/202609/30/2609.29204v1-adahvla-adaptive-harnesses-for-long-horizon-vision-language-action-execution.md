## 摘要
视觉-语言-动作（VLA）模型提供了强大的局部控制和指令跟随能力，但在需要持久记忆和规划的长程任务上往往表现不佳。任务协调框架通过保留任务历史并跟踪执行各阶段的进展，为智能体推理提供持久上下文。为了将这些互补能力结合起来，我们提出了 AdaHVLA，这是一个自适应协调框架，通过机器人经验优化基于代码的协调策略，从而更好地将智能体推理和记忆与 VLA 执行对齐。其解耦的多智能体适应过程将证据分析、协调框架修订和行为评估分离到不同的工作上下文中，使用可测试的协调假设来指导修订，并利用后续 rollout 评估其预测效果。一个有状态的修订图将执行证据、假设、修订和观察到的效果连接起来，保留备选协调框架和适应记忆，以指导跨多次尝试的细化以及跨任务和环境的持续适应。在仿真中，AdaHVLA 将 NaVILA-LH 的平均测试成功率从 22.5% 提升至最高 57.5%，并在三个 VLA 骨干网络上将操作测试成功率相对于初始协调框架提高了最多 30.8 个百分点。真实世界部署进一步说明适应后的策略如何支持跨任务阶段的稳定执行。

## Abstract
Vision-language-action (VLA) models offer strong local control and instruction following but often struggle with long-horizon tasks requiring persistent memory and planning. Task harnesses provide persistent context for agent reasoning by retaining task history and tracking progress across execution stages. To bring these complementary capabilities together, we introduce AdaHVLA, an adaptive harness that refines code-based coordination policies through robot experience to better align agent reasoning and memory with VLA execution. Its decoupled multiagent adaptation process separates evidence analysis, harness revision, and behavioral assessment into distinct working contexts, using testable coordination hypotheses to guide revisions and subsequent rollouts to assess their predicted effects. A stateful revision graph links execution evidence, hypotheses, revisions, and observed effects, preserving alternative harnesses and adaptation memory to guide refinement across repeated attempts and continued adaptation across tasks and environments. In simulation, AdaHVLA raises mean test success on NaVILA-LH from 22.5\% to as high as 57.5\% and improves manipulation test success across three VLA backbones by up to 30.8 percentage points over the initial harness. Real-world deployment further illustrates how the adapted policies support stable execution across task stages.

- **研究背景**：视觉-语言-动作（VLA）模型在局部控制、视觉定位和指令跟随上表现很强，但在长时程任务中容易缺乏持久记忆、阶段性进度跟踪与全局规划能力。

## 2. 论文提出的方法论

- **核心思想**：将任务协调逻辑表示为可编辑、可执行的代码策略，通过机器人 rollout 经验迭代改进该策略，而不是只改进计划或只修改 VLA 参数。
- **关键组件**：
  - **Harness VLA 策略**：负责维护运行时状态 \(m_t\)，根据交互历史 \(H_t=(x,o_{\le t},a_{<t})\) 和当前状态决定：
    - 发送给 VLA 的局部指令 \(q_t\)；
    - 观察上下文 \(\kappa_t\)；
    - 更新后的状态 \(m_{t+1}\)；
    - 任务终止标志 \(z_t\)。
  - **可编辑协调内容**：包括何时推进子目标、是否保留原始指令或改用局部目标、何时刷新视觉缓冲、何时启动/维持/结束纠错、何时判定任务完成等。
- **多智能体适应流程**：
  - **证据分析**：将摄像头观测、日志、轨迹按请求 ID 对齐到具体代码版本，区分“观察到的事件”与“解释”。

  - **行为评估**：在新 rollout 中评估补丁是否被触发、是否产生预期效果，以及整体行为和最终成功。
- **归因门控**：

## 3. 实验设计

- **导航任务**：

  - 10 个实例用于 adaptation，40 个用于 held-out 测试；
  - 场景：Unitree Go2 四足机器人在 Matterport3D 环境中，通过 Isaac Lab 和 Isaac Sim 仿真，使用预训练 locomotion controller 将 NaVILA 命令转换为运动。
- **操作任务**：
  - 使用 **VLA-Arena Long Horizon suite**；
  - 每个 level 50 个实例，10/40 adaptation/test 划分；
  - L1：独立原子技能组合；L2：更长工作流和阶段依赖；
  - 场景：Panda 机械臂在 RoboSuite + MuJoCo 中，RGB 观测和 7 维动作。
- **对比方法**：
  - **Single VLA**：直接使用 VLA 执行长程指令；
  - **Initial Harness VLA**：非自适应初始协调策略，保留在线推理和状态更新，但不进行代码修订；
  - **AdaHVLA**：经过自适应修订后的协调策略。
- **模型配置**：
  - 导航 adaptation models：GPT-5.6-sol Max、GPT-5.6-terra Max、Kimi K3、Qwen3.7-Max、GPT-5.6-luna Max、Qwen3.6-Max；
  - 操作 adaptation model：GPT-5.6-sol Max；
  - 运行时推理 agent：Qwen3.7-Flash；
  - 导航 VLA：NaVILA；
  - 操作 VLA 骨干：SmolVLA、OpenVLA-OFT、π0.5。
- **评估方式**：
  - 每个配置从初始 harness 重启 adaptation 三次；
  - AdaHVLA 每次最多自动评估 16 个候选（0–15，包括初始 harness）；
  - 测试集固定，最终 harness 源码固定，在线推理和状态更新继续；
  - 结果取三次运行均值，报告样本标准差。

## 6. 论文的主要结论与发现

- **导航性能**：Initial Harness VLA 相比 Single VLA 将平均测试 SR 从 2.5% 提升到 22.5%（+20.0 个百分点）；AdaHVLA 在不同 adaptation model 下进一步达到 31.7%–57.5%，即额外提升 9.2–35.0 个百分点。
- **操作性能**：
  - 在所有 6 个 backbone–level 组合中，Initial Harness VLA 优于 Single VLA，AdaHVLA 又优于 Initial Harness VLA；
  - L1 最终 SR 达到 25.8%–55.8%；L2 达到 10.8%–38.3%；
  - 以 π0.5 为例，L1 从 20.0%（Single VLA）→25.0%（Initial）→55.8%（AdaHVLA），提升 30.8 个百分点；L2 从 10.0%→38.3%，提升 28.3 个百分点。
- **消融发现**：
  - 导航对完成检查（completion check）和紧凑内存（context memory）最敏感；
  - 操作 L1 对视觉刷新（buffer reset）最敏感；L2 对恢复机制（recovery）和保留上下文更敏感；
  - 移除修订图（W/O Graph）导致导航 SR 从 57.5% 降至 42.5%，操作 L2 从 38.3% 降至 26.7%；
  - 仅用成功率选择候选（SR Select）会降低性能，说明行为证据和归因验证对候选选择很重要；
  - 共享上下文（Shared Context）和单智能体（Single Agent）也会降低导航和 L2 性能。
- **执行稳定性**：模拟和真实世界轨迹显示，adaptation 后的 harness 能维持任务级进度，在偏离目标后正确触发恢复并继续执行，无需重新开始整个任务。
- **总体结论**：通过机器人执行经验自适应修订高层协调代码，是提升长程 VLA 执行可靠性的一条可行路径。

## 7. 优点

- **架构清晰且解耦**：将证据分析、harness 修订和行为评估分离，避免不同阶段信息互相污染。
- **可测试假设与归因门控**：通过 \(\chi\) 门明确何时可把行为变化归因于代码修改，提高改进可信度。
- **有状态修订图**：保留备选分支和失败证据，支持累积式探索，避免“只跟踪最新版本”带来的信息丢失。
- **跨任务适应记忆**：将压缩后的协调问题、假设、修订和效果带到新任务中，支持持续改进。
- **不修改 VLA 参数**：在保持执行器固定的前提下，通过协调策略优化获得显著提升，资源开销相对可控。
- **多机器人、多 backbone 验证**：覆盖四足导航与机械臂操作，以及三种不同规模/类型的 VLA 骨干，体现一定通用性。
- **真实世界验证**：提供真实部署定性结果，说明方法不仅限于仿真。

## 8. 不足与局限

- **算力信息缺失**：论文未提供 GPU 型号、数量、训练时长等资源信息，难以评估方法计算成本。

  - 视觉/空间推理错误可能同时影响代码修订和行为评估。
- **应用限制**：

  - 代码化协调策略的修改空间依赖于预定义接口和可观测状态，复杂任务中可能不充分。
