## 摘要
大语言模型（LLM）智能体越来越依赖外部记忆来支持长程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立上下文片段进行检索，忽略了多步执行背后的过程性依赖。随着记忆规模扩大，这种扁平化检索会导致上下文碎片化和跨任务干扰，从而产生结构不一致的推理轨迹。我们提出 ActiveMem，一个分层记忆框架，将智能体经验递归组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索和剪枝策略。在多个智能体基准上的实验表明，与现有基于记忆的智能体相比，ActiveMem 在任务完成度、推理稳定性和记忆效率方面均有持续提升。此外，ActiveMem 使紧凑的开源权重模型能够取得与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

### 2. 论文提出的方法论
- **核心思想**：用**层级潜在记忆树（Hierarchical Latent Memory Tree, HLMT）** 取代扁平记忆池，树节点编码可复用的子任务级推理抽象，边表示执行依赖关系；检索时沿树进行粗到细的层级遍历，得到依赖一致的推理路径。
- **关键技术细节**：
  - **树结构**：节点 `ni = (ei, pa(i), ch(i))`，其中 `ei` 为节点嵌入，`pa(i)` 为父节点指针，`ch(i)` 为子节点集合。树根为虚拟节点。
  - **检索过程**：以当前隐藏状态 `ht` 为查询，从根开始递归选择余弦相似度最大的子节点，直到最大相似度低于阈值 `τstop`，得到激活路径 `Pt`。
  - **双头记忆控制器**：一个轻量级控制器 `Wϕ` 处理检索路径与当前隐藏状态，生成共享表示 `ut`，并分两路输出：
    - **潜在注入头**：生成连续潜在前缀 `mt = Wlatent ut`，直接前置到输入嵌入层，作为动态软提示引导冻结 LLM 的推理（不修改 LLM 权重）。
    - **树动作头**：输出离散拓扑操作（插入、更新、合并、删除）的概率分布。
  - **即时执行（Immediate Execution）**：在线更新树拓扑。插入操作将新节点作为检索路径叶子的子节点；更新操作通过门控机制 `α = σ(Wgate ut)` 对叶子嵌入进行加权更新，并对嵌入做 L2 归一化。
  - **延迟执行（Deferred Execution）**：在回合结束时，基于指数移动平均效用 `SEMA(ni)` 剪除低效用节点，并将高相似度的兄弟节点合并，保持拓扑紧凑。
  - **训练目标**：采用 GRPO 优化控制器参数 `ϕ`，联合优化潜在注入目标和树动作目标。层次优势 `Ai = λg * 全局优势 + λl * 局部优势`，其中全局优势衡量节点相对于组内平均效用的贡献，局部优势衡量节点相对于父节点的改进。损失函数包含 clipped surrogate objective 和 KL 惩罚，避免策略崩溃。
  - **核心公式**：
    - 树更新：`Tt = TreeUpdate(Tt-1, atree_{t-1})`
    - 记忆条件策略：`πθ,ϕ(at | st) = πθ(at | st, mt(ϕ))`
    - 优化目标：`max ϕ E[R(τ)]`

### 6. 论文的主要结论与发现

- **性能优势**：ActiveMem 在多个长程推理与决策基准上显著优于现有记忆增强方法，尤其在 ALFWorld、ScienceWorld、WebShop 等需要多步执行依赖的任务中取得最高成功率；在 TriviaQA、FEVER、GPQA 等知识密集与科学推理任务上，其 EM/F1 或准确率也超过参数记忆基线（SFT、GRPO）和检索记忆基线（MemoryBank、AWM）。
- **组件有效性**：消融实验表明，层级潜在记忆树（HLMT）是性能提升的核心，移除后模型退化为扁平记忆检索，准确率大幅下降；树动作头（插入/更新/合并/删除）使记忆能够动态适应新任务，若固定拓扑则跨任务泛化能力减弱；层次优势信号在 GRPO 训练中稳定了策略更新，避免局部最优；潜在注入头以连续软提示形式引导冻结 LLM，既避免了全参数微调带来的灾难性遗忘，又比离散文本检索更高效地传递执行上下文。
- **效率与可扩展性**：在多目标多跳 QA 任务中，ActiveMem 的峰值 token 使用和推理时间随目标数量（2/8/16）呈亚线性增长，显著优于需要将全部历史轨迹装入上下文的基线；树剪枝与合并操作在回合结束时有效控制了记忆节点规模，使长期运行中的检索开销保持稳定。
- **跨域泛化能力**：单数据集训练后跨数据集评估显示，ActiveMem 学到的依赖感知执行树能够迁移到相关但不完全相同的目标领域（如 ALFWorld→ScienceWorld、TriviaQA→FEVER），说明树结构编码的是任务无关的过程性依赖，而非特定领域表面的文本模式。
- **与现有方法的本质差异**：相比 MemoryBank、ExpeL 等扁平检索记忆，ActiveMem 通过树结构保留了子任务之间的顺序依赖，避免了将功能相关但顺序不兼容的片段拼凑进上下文；相比 SoftCoT、MemGen 等潜在计算基线，ActiveMem 将离散拓扑操作与连续潜在注入结合，既具备可解释的树结构，又保留了软提示的灵活性与参数效率。
- **总体结论**：ActiveMem 提出并验证了一种依赖感知的潜在执行树记忆机制，通过强化学习动态优化记忆的扩展、检索与剪枝策略，有效缓解了长程推理中的上下文碎片化和跨任务干扰问题。该方法在保持骨干 LLM 冻结的前提下，实现了优于现有参数记忆和检索记忆基线的性能，并展现出良好的效率与泛化能力。
