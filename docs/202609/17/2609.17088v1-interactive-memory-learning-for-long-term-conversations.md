## 摘要
近期大语言模型的进展显著增强了智能体建模长期对话的能力。尽管取得这些成功，现有方法通常采用静态启发式范式，信息被被动归档，缺乏自适应的记忆价值评估。因此，这些方法无法自我进化，也无法使记忆管理与不断变化的用户需求保持一致。为解决这一问题，我们提出 ICML（InteraCtive Memory Learning，交互式记忆学习），一个多智能体框架，将记忆机制从被动档案转变为可学习的交互式记忆策略。具体而言，我们首先采用会话合成流水线生成专家数据，促进在未见场景中的快速测试时适应。在此基础上，ICML 利用在线强化学习机制，其中 Planner 智能体选择性编码高价值信息，Trigger 智能体动态检索这些信息以优化响应质量，两个智能体通过持续交互反馈共同进化。关键的是，两个智能体通过延迟奖励机制同步，该机制将未来反馈传播回早期的存储决策，确保记忆策略与用户期望精确对齐。实验结果表明，ICML 显著优于强基线，展现出随着交互积累持续提升响应质量的独特能力。

## Abstract
Recent advancements in large language models have significantly enhanced the capabilities of agents in modeling long-term conversations. Despite these successes, existing approaches typically adopt a static heuristic paradigm, where information is passively archived without adaptive memory valuation. Consequently, these methods fail to self-evolve or align their memory management with evolving user needs. To address this, we propose ICML (InteraCtive Memory Learning), a multi-agent framework that transforms the memory mechanism from a passive archive into a learnable, interactive memory policy. Specifically, we first employ a session synthesis pipeline to generate expert data, facilitating rapid test-time adaptation in unseen scenarios. Building on this, ICML utilizes an online reinforcement learning mechanism where a Planner agent selectively encodes high-value information and a Trigger agent dynamically retrieves it to optimize response quality, whereby the two agents co-evolve through continuous interaction feedback. Crucially, both agents are synchronized through a delayed reward mechanism that propagates future feedback back to earlier storage decisions, ensuring memory policies are precisely aligned with user expectations. Experimental results demonstrate that ICML significantly outperforms strong baselines, exhibiting the unique capability to continuously improve response quality as interactions accumulate.

### 2.2 Retrospective Session Synthesis（回顾式会话合成）

为解决冷启动问题，提出专家数据合成流水线：

- **Backward Storyline Generation（反向故事线生成）**：
  - 以新用户首次暴露偏好/约束的会话为 `Sseed`，利用 LLM 作为用户模拟器，递归生成逻辑上支撑该 seed 的前置会话 `Sprev`，保证历史与当前偏好的因果一致性。
- **Forward Dependency Annotation（正向依赖标注）**：
  - 为 Planner 生成二值标签 `yp ∈ {0,1}`，表示该回合是否包含高价值长期信息。
  - 为 Trigger 生成目标检索索引 `yt`，并混合 hard negatives（同会话不相关轮次）和 soft negatives（全局随机记忆）以增强判别力。
- 产出专家数据集 `Dexpert`，用于在线部署前的监督预热。

### 2.3 ICML 核心框架

ICML 由两个协作的 Actor-Critic 智能体组成，联合优化：

#### Planner Agent（记忆规划）

- 目标：识别并保留高价值记忆，过滤低价值噪声。
- 策略：输入用户查询 `uk`，输出保存（`apk=1`）或丢弃（`apk=0`）。
- **Proxy Reward（代理奖励）**：使用骨干 LLM 判断当前回合的内在信息价值 `rproxy_k ∈ [0,1]`，提供密集训练信号。
- **Miss-penalty（遗漏惩罚）**：若 Planner 丢弃了高价值信息，施加负奖励 `-αrproxy_k`，避免信息丢失。

#### Trigger Agent（记忆触发）

- 目标：从动态记忆中检索最相关信息以优化最终响应质量。
- 策略：输入查询、对话历史、候选记忆，输出记忆索引；选择 0 表示不使用记忆。
- **Quality Reward（质量奖励）**：使用骨干 LLM 对生成响应进行多维评分，得到综合质量奖励 `rqual_k ∈ [0,1]`。

#### 响应生成

- 将选中的记忆 `matk` 与当前上下文拼接，生成个性化响应 `r∗`。

### 2.4 Cross-Session Truth Reward（跨会话真值奖励）

- 为解决记忆效用的**延迟验证**问题，维护 **Pending Reward Buffer** 存储 Planner 的待验证存储经验。
- 当未来某时刻 Trigger 激活记忆 `mi` 并获得质量奖励 `rqual_kfuture` 时，追溯到该记忆的创建回合 `kpast`，计算真值奖励：

```text
rtruth_kpast = rproxy_kpast + λ · rqual_kfuture · I(mi is triggered)
```

- 该机制将未来反馈传播回早期存储决策，使 Planner 和 Trigger 的目标与长期会话效用对齐。

### 2.5 在线优化

- 采用 **PPO（Proximal Policy Optimization）** 端到端联合优化 Planner 与 Trigger。
- **Critic 损失**：最小化价值函数估计与实际回报的均方误差。
- **Actor 损失**：使用 clipped surrogate objective，加入重要性采样比、优势函数和熵正则项。
- 通过在线 rollouts 收集经验轨迹，实现两个智能体的共同进化。
