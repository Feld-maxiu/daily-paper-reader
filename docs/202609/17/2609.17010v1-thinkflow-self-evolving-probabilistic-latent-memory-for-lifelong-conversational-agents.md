## 摘要
终身对话智能体依赖记忆系统来维持与用户之间深度、情境感知的交互。然而，现有显式文本记忆流程存在严重的信息瓶颈，常常丢失细微的行为模式和情绪变化。此外，这些流程在部署后通常是静态的，无法在没有人工反馈的情况下自主适应用户的个人习惯与偏好。认知科学则表明，人类纯粹在潜空间中维护心智模型，并通过预测编码不断加以精炼。受此启发，我们提出 ThinkFlow，一个面向终身对话智能体的新型端到端潜记忆框架。ThinkFlow 通过将会话流动态压缩为概率性潜在记忆技能，绕过文本瓶颈，将复杂用户状态自主整合为解耦的连续向量，避免语义干扰。为突破这一障碍，我们引入测试时演化范式。通过将教师引导的潜在空间对齐（用于引导初始状态）与自监督的下一用户话语预测任务（用于持续精炼）相结合，该框架成功克服冷启动挑战，实现无标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于主流记忆系统，在扩展的多会话交互中提供高度个性化且上下文准确的响应。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

## 2. 论文提出的方法论

### 2.1 核心思想

- **绕过文本瓶颈**：不保存离散文本历史，而是在潜空间中将会话压缩为多个连续向量，即 **概率性潜在记忆技能（PLMS）**。
- **技能解耦**：将记忆分解为 K 个专门技能向量，自主捕捉用户事实、情绪、偏好等不同侧面，避免语义干扰。
- **自监督终身学习**：通过两阶段训练实现冷启动和持续自适应。

### 2.2 关键技术组件

- **概率性潜在记忆技能（PLMS）**：
  - 使用交叉注意力将当前 turn 的隐藏状态 \(E_t \in \mathbb{R}^{L\times D}\) 压缩为 K 个密集记忆技能。
  - 注意力输出 \(C_t = \text{Softmax}\left(\frac{S E_t^T}{\sqrt{D}}\right)E_t \times \frac{1}{\sqrt{c}}\)，其中 \(c = L/K\) 为压缩率。
  - 通过两个线性层输出均值 \(\mu_t\) 和对数方差 \(\log \sigma_t^2\)，使用重参数化技巧采样新技能 \(\hat{S}_{new} = \mu_t + \sigma_t \odot \epsilon\)，\(\epsilon \sim \mathcal{N}(0, I)\)。
  - 用 KL 散度损失 \(L_{KL}\) 将后验推向标准高斯先验，防止方差坍缩。

- **门控潜记忆整合器（GLC）**：
  - 引入信息增益门 \(g_t \in (0,1)^{K\times D}\)，由 MLP 对新旧技能拼接计算：\(g_t = \sigma(W_2 \text{ReLU}(W_1[\hat{S}_{new} \| S_{old}]))\)。
  - 结合 GRU 进行条件更新：\(S_t = g_t \odot \text{GRU}(\hat{S}_{new}, S_{old}) + (1-g_t) \odot S_{t-1}\)。
  - 有效过滤噪声（如寒暄）、缓解语义稀释、实现优雅遗忘。

- **上下文感知超对齐器（CAHA）**：
  - 用超网络根据当前用户查询 \(x_t\) 生成低秩变换矩阵 \(W_{adapt} = W_{down}(x_t) \times W_{up}(x_t)\)，秩为 \(r\)。
  - 残差投影得到对齐记忆技能 \(S_{aligned} = S_t + S_t \times W_{adapt}\)。
  - 将 \(S_{aligned}\) 作为软提示前置到 LLM，弥合历史潜在技能与当前语义上下文的分布差距。

### 2.3 自监督测试时演化范式

- **阶段一：教师引导潜对齐（Phase 1）**
  - 解决冷启动问题：教师模型读取完整明文历史 \(H_{<t}\) 并输出目标分布 \(P_T(y|H_{<t}, x_t)\)。
  - 学生模型仅读取当前查询 \(x_t\) 和潜记忆技能 \(S_t\)，输出预测分布 \(P_S(y|S_t, x_t)\)。
  - 最小化目标：\(\mathcal{L}_{Phase1} = D_{KL}(P_T \| P_S) + \alpha L_{KL}\)。
  - 教师和学生基于同一基础 LLM 实例化，以保证表示空间对齐。

- **阶段二：下一用户话语预测（Phase 2）**
  - 从第 2 个会话起教师下线，利用用户隐式反馈作为免费监督信号。
  - 在 turn \(t\) 生成回复 \(a_t\) 并更新记忆到 \(S_{t+1}\)；在 turn \(t+1\) 预测用户下一话语 \(x_{t+1}\)。
  - 若预测失败（高交叉熵 \(L_{CE}\)），说明记忆未捕获核心上下文，梯度会迫使 GLC 门关闭，防止记忆污染。
  - 引入最小熵置信先验 \(L_{Conf}\) 防止语义模糊坍缩。
  - 总损失：\(\mathcal{L}_{Phase2} = L_{CE}(x_{t+1}|S_{t+1}, a_t) + \beta L_{Conf} + \alpha L_{KL}\)。
