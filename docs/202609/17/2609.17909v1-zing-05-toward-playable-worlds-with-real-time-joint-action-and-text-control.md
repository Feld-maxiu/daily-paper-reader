## 摘要
我们提出Zing-0.5，一个50亿参数的自回归世界模型，旨在实现可玩性：用户能够探索生成的世界，影响正在发展的事件，并通过联合键盘与在线文本控制对所产生的反馈作出响应。我们的方法汇集了三项技术贡献：（1）统一动作与文本条件化，将幅度感知的键盘输入与时间对齐的文本指令以及联合标注的视频相结合，在同一序列中学习导航与事件控制；（2）面向增量生成的事件尺度监督，使用在连接的多提示视频上训练的分段级教师，通过分布匹配蒸馏来监督块级因果学生；（3）低成本实时交互，将四步生成与上下文保持流式传输相结合，以支持832 x 480分辨率、24帧/秒的推理，估计服务器租赁成本约为每流分钟0.009美元。Zing-0.5在158个WBench导航用例中取得了81.0的总体得分和88.5的一致性得分。一个联合控制演示展示了在持续导航过程中由文本引导的事件变化，而无需重新开始生成。我们发布了模型权重、推理代码和Zing-SGLang服务实现，以支持可玩生成世界的进一步研究。

## Abstract
We introduce Zing-0.5, a 5B autoregressive world model designed for playability: users can explore generated worlds, influence unfolding events, and respond to the resulting feedback through joint keyboard and online text control. Our approach brings together three technical contributions: (1) Unified action and text conditioning, combining magnitude-aware keyboard inputs with temporally aligned text instructions and jointly annotated videos to learn navigation and event control within the same sequence; (2) Event-scale supervision for incremental generation, using a segment-level teacher trained on connected multi-prompt videos to supervise a block-level causal student through distribution-matching distillation; and (3) Low-cost real-time interaction, combining four-step generation with context-preserving streaming to support 832 x 480 inference at 24 FPS at an estimated server rental cost of approximately USD 0.009 per stream-minute. Zing-0.5 achieves an overall score of 81.0 and a consistency score of 88.5 across 158 WBench Navigation cases. A joint-control demonstration shows a text-directed event change during continued navigation without restarting generation. We release the model weights, inference code, and Zing-SGLang serving implementation to support further work on playable generated worlds.

## 1. 论文的核心问题与整体含义

- **研究背景**：交互式世界模型已能单独支持键盘/相机控制或语言引导的事件变化，但二者通常是分离的交互模式，难以在同一连续生成会话中同时“导航、干预事件并接收反馈”，而这正是“可玩性”的核心。
- **核心问题**：
  - 现有模型难以将连续键盘导航与在线文本指令结合在同一个自回归生成流中；
  - 事件往往跨越多个生成块，而增量生成需要短块因果预测，二者时间尺度难以统一；
  - 实时交互要求低延迟、低成本，而扩散模型多步采样和长上下文缓存带来算力压力。
- **整体含义**：论文提出 Zing-0.5，一个 50 亿参数的自回归世界模型，目标是“可玩世界”——用户既能探索生成场景，也能用文本影响事件，并根据反馈继续行动。它在一个 WBench 导航基准上取得有竞争力的成绩，并展示了无需重启会话即可改变文本指令触发新事件的联合控制能力。

## 2. 论文提出的方法论

### 2.1 统一动作与文本条件

- **幅度感知键盘输入**：
  - 将用户输入表示为 8 个非负强度通道：W/A/S/D 表示移动，I/J/K/L 表示视角变化；
  - 每个通道为连续强度值，允许多键同时激活，表达组合控制；
  - 强度表示相对控制强度，而非绝对物理位移，来源不同时进行校准。
- **动作编码器**：
  - 在视频潜在帧窗口内对控制值做平均，输入轻量动作编码器；
  - 编码器使用正弦幅度嵌入 + 残差 MLP + 因果时间卷积，输出特征广播到视觉 token 后相加；
  - 零初始化以保留预训练骨干初始能力；参数量仅约 368 万（约占 5B 骨干的 0.074%）。
- **多提示条件化**：
  - 每个文本提示对应一个视频时间区间，区间内视觉 token 通过交叉注意力只关注该提示；
  - 推理时若提示更新，仅刷新文本 K/V 缓存，保留视觉 K/V 缓存，以维持现有场景上下文；
  - 动作与文本在时间轴上分离对齐，允许二者独立变化。

### 2.2 事件尺度监督与增量生成

- **分段级教师（segment-level teacher）**：
  - 在连接的多提示视频上训练，每个提示段内采用双向注意力联合去噪，跨段采用因果注意力；
  - 可以整合整段未来上下文，为跨多个生成块的事件提供监督。
- **块级生成器（block-level generator）**：
  - 采用 4 个潜在帧组成的因果块，逐块自回归生成；
  - 第一帧建模与后续视频延续分离：T2V 拆成 T2I + I2V，便于用大量图文对监督首帧质量；
  - 两个分支都共享第一帧分离结构，保证蒸馏一致性。
- **历史增强**：
  - 训练时混合干净、加噪、空间模糊的历史，并加入对潜在通道均值的缩放扰动；
  - 目标潜在和参考帧保持未破坏，以降低推理时对生成历史的敏感性。

### 2.3 蒸馏与训练流程

- **四阶段训练**：
  1. **双向适应**：从 Wan2.2-TI2V-5B 出发，加入动作分支，混合动作标注视频与无动作高质量图文/视频数据，使用流匹配目标；
  2. **自回归适应**：分别训练分段级教师与块级生成器，并加入 30 秒长序列数据；
  3. **ODE 初始化 + 局部一致性蒸馏**：
     - 用因果教师沿 ODE 轨迹生成配对数据，训练学生预测终端清洁潜在；
     - 再进行局部一致性蒸馏，使学生在相邻噪声水平上预测一致；
  4. **分布匹配蒸馏（DMD）**：
     - 学生在自身 rollout 输出上训练，由冻结教师与可学习的假评分器估计分布梯度；
     - 采用 rollout-replay 两阶段实现，分离生成与带梯度重放，降低长序列训练内存；
     - 混合 DMD 与 Data-Forcing Distillation（DFD），减少运动幅度波动和视觉退化；
     - 训练时引入引导，推理时不需额外无条件前向，每块 4 步去噪。

### 2.4 系统与实时推理

- **训练系统**：用 token 预算的可变长度输入管线，FlashAttention / FlexAttention 稀疏掩码，Ulysses 序列并行 + FSDP，激活检查点，复用缓存。
- **推理系统**：8 张 RTX 5090，每 GPU 承载一个完整副本（DiT + 有界 KV 缓存 + 本地 TAEHV 解码器）；
- **性能**：832×480，每块 4 步去噪生成 4 个潜在帧并解码为 16 帧，达到 24 FPS 客户端可见帧率，未限速实测 24.63 FPS；估计每流分钟成本约 $0.009。
- **上下文管理**：视觉 KV 缓存有界，包含固定前缀 sink、滑动窗口、以及提示切换后的 pin 机制，保持场景初始上下文和事件切换后的关键视觉参考。
