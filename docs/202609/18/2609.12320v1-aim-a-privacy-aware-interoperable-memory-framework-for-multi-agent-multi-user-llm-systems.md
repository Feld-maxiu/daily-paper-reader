## 摘要
传统的大语言模型（LLM）仅限于单个用户会话，其知识被限制在单一对话中，无法学习随时间演变的用户偏好。现有的智能体记忆系统解决了这一局限，但通常在单用户层面运行，限制了本可跨用户共享以改进下游响应的公共知识。我们提出了 AIM（Agentic Interoperable Memory，智能体可互操作记忆），一个统一的、隐私感知的记忆框架，使多智能体、多用户的 LLM 系统能够持久地管理私有和共享记忆。AIM 动态地将信息分类为私有——仅限一个用户且其他用户无法访问——或公共——所有用户均可访问。它实施索引级访问控制，使私有记忆只能由其所有者检索，从而保护敏感数据，同时允许有益的共享知识改善协调与一致性。我们还引入了 MUMBench（Multi-User Memory Benchmark，多用户记忆基准），这是一个包含四个领域中私有和可共享信息的多用户交互数据集。据我们所知，MUMBench 是首个旨在评估多用户环境中多种记忆操作（包括检索、创建、更新和删除）的公开数据集。在 MUMBench 上的三次独立运行中，AIM 实现了 96.0% 的可见性分类准确率、58.8% 的严格操作准确率和 70.5% 的状态感知操作准确率。

## Abstract
Traditional large language models (LLMs) are scoped to individual user sessions, limiting their knowledge to a single conversation and preventing them from learning user preferences that evolve over time. Existing agentic memory systems address this limitation but generally operate at the individual-user level, restricting the public knowledge that could be shared across users to improve downstream responses. We introduce AIM (Agentic Interoperable Memory), a unified, privacy-aware memory framework that enables multi-agent, multi-user LLM systems to persistently manage private and shared memory. AIM dynamically classifies information as private, scoped to one user and inaccessible to others, or public, accessible to all users. It enforces index-level access controls so that private memories are retrievable only by their owner, protecting sensitive data while allowing beneficial shared knowledge to improve coordination and consistency. We also introduce MUMBench (Multi-User Memory Benchmark), a dataset of multi-user interactions containing private and shareable information across four domains. To our knowledge, MUMBench is the first public dataset designed to evaluate multiple memory operations, including retrieval, creation, update, and deletion, in a multi-user environment. Across three independent runs on MUMBench, AIM achieves 96.0% visibility classification accuracy, 58.8% strict operation accuracy, and 70.5% state-aware operation accuracy.

  - 跨用户共享公共记忆，提升协作一致性和系统智能；
  - 严格保护用户私有记忆，防止跨用户隐私泄露；

## 2. 论文提出的方法论

AIM 是一个模块化、系统无关的记忆服务，其核心流程分为写路径和读路径，所有操作均受可见性谓词 \(V(u, m_i)\) 约束：

\[
V(u, m_i) = (v_i = \text{PUBLIC}) \lor (v_i = \text{PRIVATE} \land u_i = u)
\]

即公共记忆对所有用户可见，私有记忆仅对所属用户可见。

- **多标签意图检测（Multi-Label Intent Detection）**  
  将每条用户消息映射到操作集合 \(\{C, R, U, D\}\) 的子集，允许单条消息同时触发多个操作（如“我刚搬到旧金山，推荐餐厅”同时触发创建和读取）。通过上下文学习和约束解码实现。

- **结构化记忆提取（Structured Memory Extraction）**  
  当检测到创建或更新操作时，用提示 LLM 以 JSON 模式提取结构化记忆元组，包括文本内容、关键词标签和来源元数据。

- **隐私感知可见性分类（Privacy-Aware Visibility Classification）**  
  对每条提取的记忆，LLM 分类为 PUBLIC 或 PRIVATE。提示中编码了公共信号（团队会议、组织公告、共享资源）和私有信号（个人偏好、个人日程、敏感数据）的归纳偏置。

- **上下文语义去重（In-Context Semantic Deduplication）**  
  候选记忆与范围内已有记忆（公共记忆比对全部公共记忆；私有记忆只比对同一用户的私有记忆）进行三路分类：CREATE（无重复）、UPDATE（存在过期信息）、NO-OP（已存在相同内容）。范围限制防止跨用户信息泄露。

- **记忆表示与索引（Memory Representation and Indexing）**  
  使用 text-embedding-3-large 生成 3072 维稠密嵌入；若存在标签，则将内容与标签拼接后编码，形成关键词引导的表示。向量索引采用 HNSW，支持元数据谓词过滤。

- **级联记忆检索（Cascaded Memory Retrieval）**  
  三阶段检索：
  1. **可见性约束稠密检索**：在索引层用谓词过滤，返回 top-k 候选；
  2. **标签级语义重评分**：计算查询与候选标签的相似度，只有内容相似度和标签相似度均超过阈值才进入下一阶段；
  3. **LLM 重排序 + 时间融合**：用 LLM 对候选记忆打分（\(s_{rel} \in [0,1]\)），与归一化时间新近度 \(s_{rec}\) 取算术平均得到最终排序分数 \(s_{final}\)，并按分数截断返回。

- **模块化与可消融性**  
  所有组件（意图检测、提取、分类、去重、嵌入模型、重排序器、向量索引）均通过抽象接口和配置工厂实例化，可独立替换或禁用，便于消融实验。

## 3. 实验设计

- **主要基准：MUMBench**  
  - 由 GPT-4o 合成生成，经人工验证的多用户记忆基准。
  - 包含 672 条按时间顺序排列的交互，覆盖 93 个用户、4 个领域：编程（150 条）、客户支持（218 条）、教育（160 条）、旅行规划（144 条）。
  - 交互中混合了私有和公共记忆，包含 60 条对抗性查询（试图访问他人私有信息）。
  - 操作分布：创建 205、读取 152、更新 117、删除 77、无操作 131。
  - 评估指标：严格操作准确率（strict）、状态感知操作准确率（state-aware）、可见性匹配、内容质量、内容保真度、标签重叠、检索相关性、判断决策准确率等。

- **对比方法 / 模型**  
  - 在 MUMBench 上，使用 5 个不同模型家族作为主模型：GPT-5.4、GPT-5.4-mini、DeepSeek-V3.2、Mistral-Large-3、Llama-3.3-70B-Instruct。每个模型进行 3 次独立运行。

- **隐私分类表现突出**：可见性分类准确率所有模型平均接近或超过 90%，最佳模型 GPT-5.4 达到 96.0%，旅行领域有 3 个模型达到 100%。

## 7. 优点

- **隐私与共享的统一设计**：通过索引级访问控制和可见性谓词，从结构上阻止私有记忆被非所有者检索，而非依赖概率性过滤。
- **多标签操作检测**：允许单条消息触发多个记忆操作，更符合真实对话场景，区别于以往的单操作假设。
- **首个多用户记忆基准**：MUMBench 填补了多用户、隐私感知、多操作评估的空白，且包含对抗性查询，测试访问控制鲁棒性。

- **多模型、多领域评估**：使用 5 个模型和 4 个领域，结果具有一定的普适性。
