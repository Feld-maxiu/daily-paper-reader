## 摘要
执行长时程任务的具身智能体需要一种记忆表示，其中动态对象的状态转换在数小时至数天的观测时间跨度内仍可用自然语言进行查询。现有系统要么丢弃细粒度运动（片段级视频-语言嵌入），要么仅以原始坐标保留（几何SLAM），要么围绕即时任务上下文进行组织（智能体工作记忆）。这些系统均未为智能体提供每个对象的时间线，使其状态转换本身可用语言查询。我们的主要贡献是语言轨迹编码（LTE），它通过结合自然语言描述、稀疏空间锚点和视觉锚点的混合表示来压缩动态对象的运动历史。LTE 根据运动复杂度自适应压缩：将没有可靠观测的时段锚定到最后出现的位置，同时用几何路径点和语言描述来表示运动，以保持准确性。为了在更长的时间跨度上评估这些能力，我们基于 EgoLife 多日记录构建了空间记忆基准（SMB），针对现有基准中缺失的能力：语义轨迹检索和长时程对象检索。在 SMB 上，基于 LTE 的系统在语义轨迹检索中达到 45.3% 的成功率，在长时程对象检索中达到 48.7%，优于结构化记忆和视觉语言模型基线（先前最佳：31.9% 和 34.4%）。LTE 在 24 小时视频上实现了 8.7 倍至 26.1 倍的轨迹压缩，查询延迟低于一秒。在 Ego4D 自然语言查询上，该系统达到 28.75% / 55.10% 的 R@1/R@5，比 EgoVLPv2 高出 +15.80 / +31.30 个百分点。

## Abstract
Embodied agents performing long-horizon tasks require a memory representation in which the state transitions of dynamic objects remain queryable in natural language across hours-to-days observation horizons. Existing systems either drop fine-grained motion (clip-level video-language embeddings), keep it only as raw coordinates (geometric SLAM), or organise it around immediate task context (agent working memories). None of them gives the agent a per-object timeline whose state transitions are themselves queryable in language. Our key contribution is \textbf{Linguistic Trajectory Encoding} (LTE), which compresses dynamic object motion histories via a hybrid representation combining natural language descriptions, sparse spatial anchors, and visual anchors. LTE adapts compression to motion complexity by anchoring periods without reliable observations to the last seen location, while representing motion with geometric waypoints and linguistic descriptions to preserve accuracy. To evaluate these capabilities across extended time horizons, we construct the \textbf{Spatial Memory Benchmark} (SMB) from EgoLife multi-day recordings, targeting capabilities absent in existing benchmarks: semantic trajectory retrieval and long-horizon object retrieval. On SMB, the LTE-based system achieves $45.3\%$ success in semantic trajectory retrieval and $48.7\%$ in long-horizon object retrieval, outperforming structured-memory and VLM baselines (best prior: $31.9\%$ and $34.4\%$). LTE achieves trajectory compression by factors of $8.7\times$ to $26.1\times$ with sub-second query latency on $24$\,h video. On Ego4D natural-language queries, the system reaches $28.75\%$ / $55.10\%$ R@1/R@5, $+15.80$ / $+31.30$ pts over EgoVLPv2.

## 1. 论文的核心问题与整体含义

- **研究问题**：具身智能体在长时间跨度（数小时到数天）内观测环境后，需要能够用自然语言查询**动态对象的运动历史与状态转换**。例如：“我最后把洗过的苹果放在哪里了？”这类查询同时涉及语言语义（“洗过”）、空间位置（“哪里”）、时间定位（“最后”）三种检索模式。
- **现有方法的不足**：
  - 几何 SLAM 保留 3D 坐标但无法用自然语言查询语义状态。
  - 视频语言模型（VLM）匹配自由文本与片段特征，缺乏 3D 空间索引，“在哪里”退化为无空间剪枝的穷举扫描。
  - 记忆增强视频智能体将观测组织成事件，但**不维护每个对象的轨迹**，对象个体历史被折叠进更宽泛的事件中。
  - 任务导向的智能体工作记忆只连接与当前任务相关的短期空间状态，偶然对象无查询记录。
- **整体含义**：论文提出并验证一个“中间层”——**对运动阶段（motion phases）进行语言化描述**，而不是对片段或静态对象属性进行语言化，从而弥补几何 SLAM 与视频语言模型之间的空白，实现高效、可查询的长时程空间记忆。

## 2. 论文提出的方法论

- **核心思想**：为每个被跟踪的动态对象构建 **语言轨迹编码（Linguistic Trajectory Encoding，LTE）**，用混合表示压缩运动历史，使轨迹的语义状态、空间位置和视觉身份都可查询。
- **LTE 的形式化定义**：对于对象 \(o_i\) 的轨迹 \(\tau_i = \{(p_t,t)\}\)，LTE 输出三元组：
  \[
  \text{LTE}(o_i) = (C, A_{\text{spatial}}, A_{\text{visual}})
  \]
  - \(C\)：带时间区间的自然语言运动描述序列，如“苹果从水槽移到台面”。
  - \(A_{\text{spatial}}\)：稀疏 3D 空间锚点位置，由 Douglas-Peucker 简化保留轨迹拐点。
  - \(A_{\text{visual}}\)：同一锚点处的视觉裁剪图，用于身份验证和视觉查询。
- **自适应压缩策略**：
  - **跟踪缺失时段**（tracking-gap intervals，连续缺失超过 \(\theta_{\text{static}}=2\) 秒）：只存一个 3D 位置（最后观测位置）。
  - **运动时段**（motion intervals）：使用 Douglas-Peucker（容差 0.15 m）保留几何拐点，并用视觉语言模型生成一句话运动描述。
  - 视觉锚点在跟踪缺失时段只存边界帧，在运动时段按路径点采样。
- **支持多种查询类型**：语义查询匹配字幕文本；空间查询测试锚点位置与查询区域；视觉查询对视觉锚点做嵌入相似度；时间查询在相邻锚点间插值。
- **配套记忆架构**：
  - **八叉树空间索引**：对静态场景做区域剪枝，节点关联房间级语义标签（由 VLM 推断）。
  - **五个互补视图**：Object、Scene、Text、Event、Image，复用同一套 LTE 记录，支持级联过滤。
  - **查询处理流水线**：解析 → 路由 → 过滤 → 聚合，统一支持 NLQ、VQ2D、STR、LOR 四类任务。
- **不确定性量化**：查询响应附带 HIGH / MEDIUM / LOW 置信度，区分窗口内观测、外推最后已知位置和仅历史数据。

## 3. 实验设计

- **数据集与基准**：
  - **Ego4D**：NLQ（5,462 个查询，303 个验证视频，平均 8.2 分钟）和 VQ2D（4,500 个查询，1,200 个验证片段）。
  - **SMB（Spatial Memory Benchmark）**：从 EgoLife 多日记录（7 天，300 小时，6 名参与者，单次会话最长 50 小时）构建，包含两个新任务：
    - **语义轨迹检索（STR）**：300 个查询，要求根据运动状态和语义空间区域定位对象。
    - **长时程对象检索（LOR）**：300 个查询，要求在 2–24 小时回溯窗口内检索对象的最后出现。
  - 成功标准：检索帧位于对象真实时间区间内且边界框 IoU ≥ 0.3（也报告 IoU ≥ 0.5 的结果）。
- **对比方法**：
  - **Ego4D NLQ**：监督方法 EgoVLPv2、GroundNLQ、EgoVideo、OSGNet；零样本 VideoAgent。
  - **Ego4D VQ2D**：监督 VQLoC、PRVQL；零样本 RELOCATE。
  - **SMB**：两类基线：
    1. VLM 基线：Qwen3-VL-8B/235B + Grounding-DINO，按 2 秒滑动片段扫描视频。
    2. 结构化记忆基线：Keyframe Memory（3D-Mem 风格）、VideoAgent。
- **消融实验**：删除文本字幕、空间锚点、视觉锚点、整个 LTE、八叉树、LTE+八叉树，分别测试对 NLQ、VQ2D、STR、LOR 的影响。

## 6. 论文的主要结论与发现

- **LTE 混合表示有效**：在 SMB 上，LTE 系统 STR 达到 45.3%，LOR 达到 48.7%，分别比最强 VLM 基线（Q3VL-235B+GD）高 +13.4 和 +14.3 个百分点。
- **文本字幕是主导通道**：移除文本字幕导致 STR 下降 −11.8 点，接近移除整个 LTE 的 −16.5 点。
- **视觉锚点对 VQ2D 最关键**：移除视觉锚点使 VQ2D 成功率下降 −6.1 点。
- **八叉树对 LOR 最重要**：移除八叉树使 LOR 下降 −3.5 点。
- **通道间存在超加性交互**：单个通道对 STR 的增益总和为 +11.4，而完整 LTE 增益为 +16.5，多出的 +5.1 表明通道协同作用。
- **效率优势**：LTE 压缩 8.7×–26.1×，24 小时视频查询延迟 0.43 s，而 VLM 基线为 98.3 s；总查询时间 2.2 分钟 vs 8.2 小时（300 个 SMB 查询）。
- **在标准基准上接近监督方法**：Ego4D NLQ 上 R@1/R@5 为 28.75/55.10，接近 OSGNet；VQ2D 上为零样本最强（stAP 0.36，成功率 59.5%）。

## 7. 优点

- **创新表示**：首次将动态对象轨迹压缩为“语言阶段 + 稀疏空间锚点 + 视觉锚点”的混合结构，兼顾语义可查询性与空间精度。
- **自适应压缩**：根据跟踪缺失和运动复杂度动态决定锚点密度，在长时程视频中实现高效存储。
- **系统设计清晰**：LTE 与八叉树、五视图组织、查询路由解耦，模块化程度高，消融实验验证了各组件的独立贡献与协同效应。
- **新基准有针对性**：SMB 填补了长时程空间记忆评估的空白，任务定义明确，标注协议和一致性（Fleiss’ κ）报告充分。
- **错误分析深入**：提供了失败案例分类（跟踪失败、字幕模糊、点云漂移等），并给出不确定度量化和置信度标签，增强了实际可用性。
- **效率显著**：亚秒级查询延迟和大幅压缩比，使其适合真实长时间部署。

## 8. 不足与局限

- **上游感知误差传播**：对象跟踪 ID 切换、丢失、点云漂移等会直接破坏 LTE 记录，论文虽分析但未自动纠正。
- **对象表示粒度粗**：只跟踪刚体对象的整体轨迹，不建模部件级动态（如门角度、抽屉伸展）。
- **环境单一**：所有长时程评估仅在 EgoLife 家庭环境（6 名参与者）上完成，未在办公室、仓库、户外等环境验证跨场景泛化。
- **构建成本高**：离线内存构建 24 小时视频需约 42 小时（并行），可能限制实时或快速部署场景。
- **多环境与多相机未支持**：假设单一持久环境，未处理跨环境对象重识别和地图对齐；不支持多相机融合。
- **依赖多个大模型**：系统组合了多个 VLM/LLM/检测/深度模型，整体复杂度较高，消融显示各组件贡献不均衡，部分组件（如 Event view）的直接增益未完全隔离验证。
- **实验偏差风险**：SMB 标注跳过小目标 73%，可能使 VLM 基线同样受难但不同系统的失败模式未完全对齐；对比中系统集成优势可能部分掩盖表示本身的贡献。
