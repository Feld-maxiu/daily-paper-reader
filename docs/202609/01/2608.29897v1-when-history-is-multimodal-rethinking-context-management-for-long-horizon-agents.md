## 摘要
长程智能体需要上下文管理器将不断增长的交互历史压缩到有界的工作上下文中，可通过被动策略或主动策略决定记忆的访问和重组方式。与此同时，先前的光学记忆工作主要将像素视为文本化历史的密集编解码器，通常预设将上下文渲染为光学记忆相对于文本会带来显著性能下降，因此将该表示与监督微调、自蒸馏或强化学习相结合以缩小差距，但仍未解决：(i) 在公平、受控的比较下，视觉渲染作为上下文管理器的表现如何，以及 (ii) 当历史本身是多模态时，这种载体是否具有原生优势。在本文中，我们将上下文管理形式化为预算受限的历史变换，并提出视觉渲染（VR）作为一种表示性上下文管理器。在共享实验框架、策略模型、触发器和任务域下，我们在四个以文本为中心和三个多模态基准上将 VR 与四个基线（无压缩、全部丢弃、滑动窗口、摘要）进行了评估，发现视觉记忆是原生视觉证据的天然载体。基于这一发现，我们提出了 VERA（面向长程智能体的视觉证据保留策略），这是一种免训练的上下文管理器，建立在确定性渲染之上，且不暴露任何记忆操作：在以文本为中心的基准上，它像 VR 一样渲染文本历史；在多模态基准上，它保留原生视觉观测而不是将其转换为文本。在几乎所有基准上，与无压缩相比，VERA 将累计非缓存 token 减少了 31.5%–63.1%，在以文本为中心的任务上与现有管理器相当，并在多模态任务上在所有基线中取得最高准确率，支持了长程上下文管理中保留模态的观点。

## Abstract
Long-horizon agents need a context manager to compress growing interaction histories into a bounded working context, via passive strategies or active strategies that decide how memory is accessed and reorganized. Meanwhile, prior optical-memory work mainly treats pixels as a dense codec for textualized histories, often presupposing that rendering context into optical memory incurs a significant performance drop relative to text, thus coupling this representation with SFT, self-distillation, or reinforcement learning to close this gap, leaving unresolved (i) how visual rendering performs as a context manager under a fair, controlled comparison, and (ii) whether this carrier offers a native advantage when history is inherently multimodal. In this paper, we formulate context management as a budget-constrained history transformation and introduce Visual Rendering (VR) as a representational context manager. Under a shared harness, policy model, trigger, and task domain, we evaluate VR on four text-centric and three multimodal benchmarks against four baselines (No Compression, Discard-All, Sliding Window, Summarization), finding visual memory is a natural carrier of native visual evidence. Building on this finding, we propose VERA (Visual Evidence-Retaining strategy for long-horizon Agents), a training-free context manager built on deterministic rendering with no exposed memory operations: on text-centric benchmarks it renders textual history as VR does, while on multimodal benchmarks it retains native visual observations instead of translating them into text. Across nearly all benchmarks, VERA cuts cumulative non-cache tokens by 31.5%-63.1% versus No Compression, matches existing managers on text-centric tasks, and achieves the highest accuracy among all baselines on multimodal tasks, supporting a modality-preserving view of long-horizon context management.

## 2. 论文提出的方法论

- **核心定义：上下文管理作为预算受限的历史变换**  
  - 给定交互历史 \(H_t\) 和工作上下文预算 \(B\)，上下文管理器定义为变换：
    \[
    \tilde{H}_t = M(H_t; B)
    \]
  - 该变换输出满足预算约束的工作上下文，并且必须满足：
    \[
    \tilde{H}_t \neq \emptyset, \quad 0 < \kappa(\tilde{H}_t) < \kappa(H_t)
    \]
  - 即它必须是一个非空的、严格比原始历史更便宜的表示。  
  - 基于此定义，无压缩（No Compression）和全部丢弃（Discard-All）被排除在真正的上下文管理器之外，分别作为全保留和重置的边界控制。  

- **固定管理器与主动管理器的区分**  
  - 固定管理器（如滑动窗口、摘要、视觉渲染）应用预定规则，不依赖智能体发出的编辑操作。  
  - 主动管理器允许智能体或学习控制器动态决定如何选择、丢弃、重写或总结历史片段。  
  - 本文为公平比较，只评估固定管理器，以避免模型训练、外部存储和推理成本等混杂因素。  

- **视觉渲染（Visual Rendering, VR）**  
  - 将最近若干轮 \(H_t^r\) 保持原样，其余历史 \(H_t^c\) 渲染为图像：
    \[
    M_{\text{VR}}(H_t; B) = \left( H_t^r, \text{Render}(H_t^{c,\text{text}}, H_t^{c,\text{native}}; B) \right) = (H_t^r, I_t)
    \]
  - “原生视觉证据”指决策相关信息已经由像素或空间布局承载，无需先生成文字描述。例如多模态搜索中的原始搜索图像、截图、裁剪、放大的区域；数据分析中的表格、图表、数据库输出的可视化视图等。  
  - 这种定义将“模态保留”与 OCR 式打包区分开：OCR 式打包渲染的是已经文本化的历史，而 VR 保留的是原生视觉或结构化证据。  

- **VERA：保留原生证据的渲染策略**  
  - VERA 是 VR 的训练免费、harness 级实现，使用确定性渲染器，不引入学习的构建策略、专门的阅读器或智能体可调用的记忆操作。  
  - **文本轨迹**：按时间顺序、用角色和工具标签保留出处，将历史文本渲染为结构化画布。  
  - **多模态任务**：将 `image_search`、`image_crop`、`image_zoom_in` 等工具返回的图像放置在对应交互旁边，而不替换为文字描述；对分析工具，自动检测结构化输出并渲染为紧凑表格，移除重复的纯文本表格。  
  - **分辨率管理**：最近 \(N\) 轮保留全分辨率视觉渲染，较旧的渲染页面逐步降采样，以控制高分辨率图像占用上下文窗口。主实验使用 \(0.75\times\) canvas scale。  
  - **无暴露记忆操作**：VERA 不暴露任何记忆读取/写入动作，仅作为上下文插件在观测-动作循环中拦截并转换历史。  

## 3. 实验设计

- **统一实验框架**  
  - 所有策略通过开源 Hermes-agent 框架的上下文插件实现，保持智能体规划策略、提示模板不变。  
  - 使用 128k token 上下文窗口，触发阈值为 64k 激活上下文 token。  
  - 策略模型统一为 Gemini-3.5-flash-thinking，通过公共 API 调用。  
  - 每次问题执行 \(R=3\) 次独立 rollout（avg@3），超时后从现有上下文恢复并最多重试 5 次，避免乐观偏差。  

- **数据集与基准**  
  - **文本中心基准**（4 个）：  
    - BrowseComp-EN：随机采样 200 题（全文随机打乱后抽取）；  
    - BrowseComp-ZH：全量 289 题；  
    - XBench-DeepResearch-2510：100 题；  
    - Seal-0：111 题。  
  - **多模态基准**（3 个）：  
    - BrowseComp-V3：多步图像搜索和局部视觉检查；  
    - MM-BrowseComp：多模态浏览智能体综合基准；  
    - AgenticDataBench：对 CSV 文件、表格、图表、数据库输出进行长程数据分析。  

- **对比方法**  
  - 四个基线/边界控制：  
    - **No Compression**：保留完整历史；  
    - **Discard-All**：丢弃被管理的历史，仅保留最近上下文；  
    - **Sliding Window**：保留最近上下文，驱逐窗口外的工具响应；  
    - **Summarization**：将被管理历史递归压缩为结构化文本摘要。  
  - 提出的 **VERA (Visual Rendering)**：渲染相同被管理历史为结构化视觉画布，并在多模态任务上保留原生视觉产物。  

- **评价指标**  
  - 任务成功率（Acc，avg@3 平均）；  
  - 累计非缓存 token 消耗（Token，所有 API 调用的未缓存输入和输出 token 总和，平均到所有评估轨迹）；  
  - 对于 AgenticDataBench，使用官方评估器产生的平均分数。  

- **研究问题（RQ）**  
  - **RQ1**：在文本中心历史上，视觉渲染与四个基线相比如何？  
  - **RQ2**：保留原生视觉证据是否优于将其翻译为纯文本？  
  - **RQ3**：历史保留与视觉保真度如何影响准确率和搜索成本？

## 6. 论文的主要结论与发现

- **RQ1 结论**  
  - 没有单一策略在所有文本中心基准上一致最优。No Compression 在 XBench 最强，Discard-All 在 BrowseComp-ZH 和 Seal-0 上最高或并列最高，Visual Rendering 在 BrowseComp-EN 最强。  
  - 聚合来看，视觉渲染取得最高综合准确率（74.2%），比 Discard-All 高 0.5 个百分点，同时无需特定于 VR 的训练、强化学习、自蒸馏或专门阅读器。  
  - 视觉渲染在所有文本基准上使用最少的累计非缓存 token，相比 No Compression 减少 44.7%、54.8%、52.1%、31.5%。  
  - Discard-All 作为重置控制仍接近最优，可能受益于在固定轮数预算内多次重置路径；但丢弃证据无法支持跨段推理。  

- **RQ2 结论**  
  - 在多模态搜索和数据分析上，VERA 取得最高准确率：BrowseComp-V3 31.7%（对比 No Compression 27.3%），MM-BrowseComp 28.5%（对比 23.3%），AgenticDataBench 平均分 0.41（所有基线中最高）。  
  - 文本渲染移除原生视觉证据后，准确率明显下降：BrowseComp-V3 从 31.7% 降至 25.0%，MM-BrowseComp 从 28.5% 降至 21.5%；数据分析从 0.41 降至 0.37。  
  - 表明多模态增益来自视觉接口保留的域特定证据，而非单纯的光学打包。  

- **RQ3 结论**  
  - 保留旧视觉历史可带来小幅准确率提升（+1.1pp），并显著减少 token（−20.4%）、API 调用（−20.5%）和轮次（−16.8%）。  
  - 保真度影响是非单调的：0.7× 和 0.8× 渲染达到最高准确率 71.0%，而 1× 只有 64.0%；0.8× 同时具有最低 token 和 API 调用。  
  - 1× 相比 0.75× 约多出 77.8% 的视觉 token，可能放大冗余细节和注意力竞争。主实验因此统一采用 0.75× 渲染尺度。  

## 7. 优点

- **训练免费、部署简单**  
  - VERA 无需监督微调、强化学习、自蒸馏、专门阅读器或智能体暴露记忆动作，易于集成到现有智能体框架中。  

- **公平的受控比较**  
  - 统一了策略模型、框架、触发器、工具接口和提示模板，只改变上下文管理策略，有效隔离了表示层因素。  
  - 将 No Compression 和 Discard-All 定义为边界控制而非上下文管理器，概念清晰，避免了比较不公平。  

- **明确的模态区分**  
  - 区分了 OCR 式文本打包与原生视觉证据保留，揭示了视觉记忆在多模态历史中的独特价值。  

- **消融实验完整**  
  - 通过 RQ3 对旧历史保留和渲染保真度进行系统消融，提供了准确率-成本权衡的经验依据，并据此确定主实验的超参数。  

- **对“重置效应”提供解释**  
  - 给出重试概率公式解释 Discard-All 为何可能受益于重复重置，而不是将其简单视为下界。

- **模型和模态范围有限**  
  - 仅使用 Gemini-3.5-flash-thinking 一种策略模型，结果未必可推广到其他 VLM。  
  - 多模态实验主要覆盖视觉证据（图像、表格、图表），未验证音频、视频、原始数据库状态等其他模态。  

- **实验偏差风险**  
  - 文本基准中部分结果差异较小，未报告统计显著性检验；采用平均准确率而非置信区间，可能受随机波动影响。  
  - BrowseComp-EN 使用 200 题采样，虽然做了全基准随机打乱，但仍存在采样不确定性。  
  - 多模态基准的规模和难度可能有限，尤其数据分析基准中平均分数差异仅为 0.04 左右。  

- **超参数选择依赖经验**
