## 摘要
面向LLM智能体记忆的基准测试通常先生成对话，后提取答案关键点——存在已记录的标注错误和污染问题——并且绝大多数仅衡量短期交互历史。我们反转了这一流程：在生成任何文本之前，一个带种子的生命脚本采样器先发出带有有效区间、易变性类别和来源渠道的事实；LLM渲染器根据每个事件的事实清单撰写聊天和邮件；保真度验证器确认每个植根事实；问题则从脚本机械地实例化，因此黄金答案在构造上即由脚本验证有效，并另行验证可回答性。这个合成的虚构语料库（约380个问题，15种类型）嵌入了我们所调查的基准测试中缺失的特征：每个事实的有效区间、发送/接收信任区分、在无害套具中的注入探针，以及截至时间点的问题集。在将五种记忆架构与无记忆对照组（固定回答者、版本化LLM评判员、三次重复、两个时间范围）进行基准测试时，我们发现后端排名会随历史长度发生反转：在第三周领先的预算式精选映射记忆，到第九周时对已淘汰内容的回忆率从96%跌至72%，而基于来源类型的图则升至90%；在完全跨家族重新评判下，这种反转为所有六名用户正向显著（精确p值=0.031）。完全渲染历史记录的基线系统在短时间范围内持平或略胜最佳记忆系统，但在第九周时并未显示出不依赖评判员的优势，且读取成本约为两倍。写入阶段质量与下游质量强相关（书写质量不佳的事实失败率为24%，对比2%），而抗注入能力与表示中是否保留来源边界有关。在两种区间下，分层架构在所有记忆系统中表现最佳（短时间范围96.8%），并作为开源库Veracium发布，同时提供语料生成器和测试套件。

## Abstract
Benchmarks for LLM-agent memory typically generate conversations first and extract answer keys afterwards -- with documented label-error and contamination problems -- and they overwhelmingly measure short interaction histories. We invert the pipeline: a seeded life-script sampler emits facts with validity intervals, volatility classes, and source channels before any text exists; an LLM renderer writes chat and email from per-event fact manifests; a fidelity verifier confirms every planted fact; and questions are instantiated mechanically from the script, so gold answers are script-valid by construction and separately validated for answerability. The synthetic, fictionalized corpus (~380 questions, 15 types) embeds features absent from the benchmarks we survey: per-fact validity intervals, sent/received trust distinctions, injection probes in a benign harness, and as-of-date question sets. Benchmarking five memory architectures against a no-memory control (fixed answerer, versioned LLM judge, three replicates, two horizons), we find backend rankings invert with history length: the budgeted curated-map memory that leads at three weeks loses recall of evicted content by nine weeks (96% to 72%) while a provenance-typed graph rises to 90%; the inversion is positive for all six users under complete cross-family re-judging (exact p=0.031). A full-rendered-history baseline ties or exceeds the best memory system at the short horizon but shows no judge-independent advantage at nine weeks, at about twice the read cost. Write-stage quality strongly correlates with downstream quality (weakly-written facts fail 24% vs 2%), and injection resistance tracked whether provenance boundaries survive representation. A layered architecture performs best among the memory systems in both regimes (96.8% short-horizon) and is released as Veracium, an open-source library, with the corpus generator and harness.

# 论文详细总结：《Ground Truth First: A Longitudinal Evaluation Instrument for Agent Memory, and the Tenure Crossover in Memory-Architecture Rankings》

## 1. 论文核心问题与整体含义

*   **核心问题**：现有的LLM智能体记忆基准测试普遍采用“先生成对话，再提取答案”的管道，这存在两大缺陷：
    *   **标签错误**：从对话中提取的答案关键点可能本身有误（例如，LoCoMo基准中6.4%的答案关键点被审计为错误）。
    *   **数据污染**：由于使用了真实世界的实体，前沿模型可能通过预训练数据“背出”答案，而非依靠记忆能力。
    *   **评估范围局限**：绝大多数测试仅衡量短期交互历史，无法评估长时间跨度下的记忆性能。事实上，在对话量少时，直接读取完整历史记录（full-context answering）甚至优于专门的记忆系统，这使得短期评测难以区分不同架构的真正优劣。
*   **整体含义**：该研究旨在逆转现有评估管道，构建一个“真相优先、纵向评估、多通道、对抗性”的智能体记忆评测工具，旨在揭示记忆架构设计中长期性能的跃迁现象，特别是随时间推移（如经过九周）记忆架构排名会发生反转。它强调了长期助理需要能在长时间跨度下可靠运行的记忆系统，而现有的短期基准无法正确评估这类系统。

## 2. 论文提出的方法论

*   **核心思想**：**“真相优先”（Ground Truth First）**，即在生成任何对话文本之前，先确立无误的标准答案，从而从源头上消除标签错误和污染。
*   **关键技术细节与流程**：
    1.  **生命脚本采样器**：一个确定性的、带种子的采样器，生成一个虚构用户的生活事实时间线。每个事实都带有：
        *   **有效区间**：事实在哪个时间段内为真。
        *   **易变性类别**：记录是永久的、持久的、缓慢变化的、瞬时的还是短暂的。
        *   **来源渠道**：区分事实是通过聊天陈述，还是通过邮件接收，并区分发送与接收（接收邮件被视为第三方的低信任度证据和注入攻击面）。
    2.  **LLM渲染器**：使用与回答模型、评判模型不同家族的LLM（Amazon Nova Pro），将每个脚本事件根据事实清单渲染成聊天记录或邮件。
    3.  **保真度验证器**：检查每一个植根事实是否确实出现在渲染的文本中，如果缺失则重新生成或标记警告。
    4.  **问题生成**：问题由脚本机械地实例化生成，而非从生成的文本中提取，因此**黄金答案是构造上即由脚本验证有效的**。
    5.  **可回答性审计**：使用一个可以查看完整语料库的“神谕”系统回答所有生成的问题，以确保在渲染后的语料中确实能找到答案，剔除因渲染问题而无法回答的题目。
    6.  **评测工具包**：构建了一个包含两种时间范围的完全合成化、虚构化的语料库，并嵌入了该研究调查的基准中所缺失的特征：每事实有效区间、发送/接收信任区分、无害套具中的注入探针、以及截至特定日期的提问集（tenure curves）。

## 3. 实验设计

*   **数据集/场景**：
    *   **短时间范围语料**：14个用户，275个验证问题，双通道（聊天/邮件）。
    *   **长时间范围（持久期）语料**：6个用户，跨度9周的个人历史，108个问题在三个时间节点（第3、6、9周）实例化为“截至此刻”提问集，总计每个后端在每个时间节点需评判324个答案。问题类型包括单事实、推理、时间、知识更新、偏好、过期状态、冲突解决等15种，并包含专门针对最早材料的早期章节探针。
*   **基准设定**：
    *   **回答模型**：固定为 `claude-haiku-4-5-20251001`。
    *   **LLM评判员**：固定为 `claude-sonnet-5`，并使用版本化的评判标准，将其视为基准定义的一部分。实验还用完全不同的模型（DeepSeek v3.2）进行了完整的跨家族重新评判以验证稳健性。
    *   **对照组**：包含一个“无记忆”控制组。
    *   **随机化**：每个配置进行三次独立的随机重复试验。
*   **对比的方法**：
    *   **无记忆控制组**。
    *   **策展映射（Curated Map）**：类似PEEK的预算式上下文映射。
    *   向量检索（Vector）：基于Titan-v2嵌入的无界池检索。
    *   **来源类型图**：一个类型化的标签属性图，将第三方声明存储为带有来源声明的“声明”边。
    *   **混合v1**：将图直接编译为映射（效果不佳）。
    *   **混合v2（分层架构）**：图的类型化边 + 提炼器的事件记录，每用户编译成预算式维基百科，并以问题相关的子图检索作为补充。

## 6. 论文的主要结论与发现

*   **记忆架构排名随历史长度反转（The Tenure Crossover）**：
    *   在短期（第3周）领先的**预算式策展映射**，到第9周时，对早期被淘汰内容的回忆率从96%降至72%，总体准确率从81.2%降至78.4%。
    *   **基于来源类型的图**在相同时间内，回忆率从94%升至100%，总体准确率从75.9%升至**90.4%**。
    *   这种反转在用户层面和跨家族重新评判下均呈现稳健显著性。
    *   机制是预算式映射会淘汰最早的信息，而无界图则保留了内容。
*   **分层架构表现最佳**：**混合v2架构**在所有时间范围内表现均为一流，短期达96.8%，长期准确率最高，并展现出最稳健的综合性能。
*   **写入阶段质量是下游质量的有力相关因素**：事实审计显示，写入不良（遗漏或错误）的事实，下游问题失败的概率是写入良好事实的**约15倍**。79%的下游失败都与其背后写入不良的事实相关。
*   **抗注入能力与表示方法有关**：来源类型图通过将第三方声明结构化地存为“声明”而非“事实”，对所测试的非自适应注入探针表现出完全的抵抗力。而压平后的断言性存储则会有部分失败。关键不在于是否使用图拓扑，而在于**信源边界是否在表征中得以保存**。
*   **准确性不等于审慎**：准确率最高的系统（混合v2）在回答错误时，几乎**从不弃权**，而是自信地输出错误的特定信息，这暴露了一个关键的“适时弃权”机制缺失。

## 7. 优点

*   **方法论创新**：提出的“真相优先”评估管道，从根本上解决了现有基准的数据污染和标签错误问题，为生成具有复杂时间属性的标准答案提供了全新思路。
*   **评估维度全面**：评测工具集成了有效区间、多通道、信任区分、注入探针、截至日期提问等多项前沿特性，是现有基准的显著扩展。
*   **发现深刻**：揭示并详细解释了“排名反转”现象，证明了长期持有下的性能与短期截然不同，警示了仅基于短期基准做系统选择的危险。
*   **实验设计严谨**：严格控制了回答者和评判模型，设置了多层基线（无记忆、完全历史），并进行了跨家族重新评判和详尽的统计分析，极大地增加了结论的稳健性。
*   **开源与透明**：完整地开源了获胜架构（Veracium库）、语料生成器和全套测试工具，并公开了所有日志，利于复现与后续研究，具有极高的学术价值。

## 8. 不足与局限

*   **语料外部效度**：使用合成和虚构的数据，尽管避免了污染，但生成的用户交互可能比真实世界更“干净”，无法完全代表真实场景的复杂性和噪声。
*   **LLM评判员偏差**：尽管进行了跨家族评判，LLM评判员仍然存在误差，且可能与特定的回答风格（如冗余度、弃权表达）相关，影响了以评判员为准的绝对分数。评判员错误未得到充分量化测量。
*   **单一回答模型**：所有对比仅基于一个固定的回答模型（Claude Haiku），发现的写路径和拓扑结构的影响可能依赖于该模型，泛化性有待验证。
*   **小样本聚类限制**：长时间范围实验仅基于6个用户聚类，样本量小限制了某些统计检验（如符号置换检验）的效力，无法达到某些常规显著性阈值。
*   **注入探针的现实性**：注入探针为非自适应、模板化的内容，可能不足以模拟高级、多步的持久性攻击（如内存中毒攻击中的“洗白”技术），对每探针断言率的上限估计也较宽松（~19%）。
*   **开发集信息泄漏**：表现最佳的混合v2架构是在同一短时间范围语料上观察了v1失败后设计的，因此其短期分数部分具有开发集性质（尽管长时间结果在全新的用户上得到了验证）。
