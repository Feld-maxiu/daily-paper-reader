## 摘要
人工智能智能体在每次运行的片段中都会遇到学习机会，却几乎全部丢弃：底层模型在部署时被冻结，因此一个今天解决了困难请求的智能体明天遇到同样问题时仍要从零开始。然而，常规操作本身就会产生反馈，形式包括结果判定和事后纠正。我们表明，当冻结模型与一个外部记忆相结合，将每个片段提炼为可检索的自然语言规则时，这种反馈足以支撑持续学习。在τ-bench的银行领域，与检索完整策略语料的静态RAG对照相比，从一位结果判定中学习将单次试验成功率提升至基线的1.6倍，而从纠正中学习则提升至2.6倍，使基线无法解决的84个任务中的22个得以完成。这一结果覆盖了部署谱系：在有数据主权需求的组织可以自托管的开放权重模型Mistral Large上测量，并在前沿模型Claude Sonnet 5上得到复现。积累的记忆还具有可迁移性：每个模型读取对方构建的存储后，表现都超越了自身无记忆的基线。实验框架、协议和数据均已发布。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

### 2. 论文提出的方法论

核心思想是将一个冻结权重的大语言模型与一个名为 **Spark** 的外部记忆服务配对，形成一个“记忆增强智能体”。该方法论的关键技术细节如下：

*   **知识单元**：记忆的基本单位是“Insight”（洞见），它是一个紧凑的自然语言陈述，包含标题、内容和检索查询，形式为“WHEN（场景） THEN（行动）”的规则。
*   **智能体-记忆交互接口**：智能体通过四个工具与记忆系统交互：
    *   `search`: 在任务中，根据当前情境检索相关的历史洞见。
    *   `create_memory`: 在任务片段结束后，根据反馈创建新的洞见。
    *   `enrich_memory`: 丰富已有的记忆。
    *   `share_feedback`: 对检索到的记忆提供正向/负向反馈，影响未来检索的信任权重。
*   **学习流程**：
    1.  **任务执行**：智能体在执行任务时，被提醒要通过`search`检索相关知识，且记忆的权威性次于环境提供的基础知识库。
    2.  **获取反馈**：任务片段结束后，系统提供一个监督信号。
    3.  **事后反思与写入**：智能体进入一个专门的反思阶段。根据收到的反馈信号，它将本片段的经验提炼为一个“WHEN-THEN”规则，并通过`create_memory`写入外部记忆库。为防止记忆污染，写入操作仅在反思阶段进行，而非任务中途。
*   **两种反馈信号**（也是实验条件）：
    *   **Experience（经验）**：仅接收一位结果判定（成功或失败）。在失败时，智能体只能生成“AVOID（避免）”类型的规则，因为它不知道正确答案是什么。
    *   **Instruction（指令）**：在失败片段中，除了结果判定，还会额外接收任务验证过的正确行动序列和行动差异对比。这使得智能体能够写出确切的“VERIFIED RULE（已验证规则）”。

### 3. 实验设计

*   **数据集/场景**：实验基于 `τ-bench` 的银行领域，该领域属于知识密集型，要求智能体与模拟客户进行多轮对话，并使用工具来操作数据库。关键挑战在于，智能体必须通过检索大约700个相互关联的政策文档来发现业务规则，而非预先获取。
*   **Benchmark 与指标**：
    *   **主要指标**：`pass^k` (k=1,2,3,4)，即在一个任务的多次独立试验中全部成功的比例，这是一个严格的可靠性指标。
    *   **新增指标**：论文引入了“每轮试验成功率曲线”和“Hold Rate（保持率，即上一轮成功则下一轮也成功的概率）”来衡量知识的获取与保持。
    *   **任务分层**：为深入分析，任务被分为“地板层”（基线在所有试验中从未解决的任务）和“胜任层”（其余任务）。
*   **对比方法/条件**：
    *   **No-memory Baseline（无记忆基线）**：标准的静态RAG智能体，使用BM25检索完整政策语料，但在试验之间不保留任何状态。
    *   **Experience（经验条件）**：记忆增强智能体，仅从结局判定中学习。
    *   **Instruction（指令条件）**：记忆增强智能体，从结局判定和事后纠正中学习。
    *   **跨模型迁移**：使用一个模型通过“Instruction”条件构建的记忆库，让另一个模型以只读方式调用，并对比其无记忆基线。
*   **模型选择**：覆盖了两种模型以体现普适性——可自托管的开源模型 **Mistral Large** 和前沿模型 **Claude Sonnet 5**。模拟客户则使用GPT-5.2。

### 6. 论文的主要结论与发现

*   **反馈是充分的学习信号**：在Mistral Large上，仅靠“经验”就能使单次成功率（`pass^1`）提升至静态RAG基线的**1.6倍**；而“指令”的学习效果更强，提升至基线的**2.6倍**，并将基线无法解决的84个任务中的**22个**转换为成功。这一提升效应在更强的Claude Sonnet 5模型上得到复现。
*   **积累的记忆可跨模型迁移**：一个模型（如Mistral Large）读取另一个模型（如Claude Sonnet 5）构建的冻结记忆库后，其最终表现均能超越自身无记忆基线。这表明记忆规则包含了通用的任务知识，而非仅适用于编写模型的风格化快捷方式。这种迁移甚至是“向上”的，即强模型也能从弱模型的经验中获益。
*   **长期记忆能够保持**：“经验”模式下智能体解决过的问题保持率（Hold Rate）高达`0.88`，而“指令”模式下的保持率也达到了`0.65`，均表明学到的知识能被有效保留。

### 7. 优点

*   **架构上的创新实用性**：提出了一种无需修改模型权重、无梯度、低成本的持续学习范式，对数据主权敏感或缺乏大规模算力的组织极具吸引力。
*   **周密的实验设计**：以强大的静态RAG为基线，明确衡量了记忆的纯增量价值。引入的“Hold Rate”等指标比传统的`pass^k`更能刻画记忆条件下的学习动态与知识保持。
*   **细致的反馈信号分级**：将“结果判定”和“事后纠正”作为两种不同等级的反馈信号进行研究，量化了不同监督强度对学习效果的贡献，对实际部署有指导意义。
*   **可复现性与开源性**：完整公开了实验框架、协议和数据，保证了研究的透明度和可复现性。

### 8. 不足与局限

*   **实验范围的局限性**：
    *   **单次运行的风险**：所有条件（尤其是记忆条件）均只进行了一次完整运行。由于记忆库是跨任务共享和累积的，任务间可能存在耦合效应。单次运行无法估计由记忆累积路径不同带来的运行间差异。
    *   **反馈噪声的缺失**：实验假定从评估器获得的反馈是完全可靠的。但在实际部署中，客户反馈可能是延迟、缺失、错误或主观的。论文明确指出反馈噪声的处理不在本项研究范围之内。
*   **泛化能力的未明确检验**：协议设计让智能体在同一个任务集上重复试验，导致模型学到的规则可能过度拟合于该任务集的特定分布。虽然跨模型迁移部分证明了规则的泛化性，但其对全新类型任务的泛化能力并未得到直接验证。
*   **特定条件的覆盖不全**：由于成本原因，“经验”模式未在Claude Sonnet 5上进行测试，削弱了关于“仅凭一位信号学习”这一结论在高能力模型上的普适性证据。
