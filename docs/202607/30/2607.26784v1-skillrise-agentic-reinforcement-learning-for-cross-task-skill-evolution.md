## 摘要
大型语言模型智能体经常遇到相关但不同的任务，这些任务共享可复用的解决方案模式。然而，标准的智能体强化学习将任务视为独立回合，而现有技能学习方法要么专注于单一任务的重复尝试，要么使用包含提取、检索和执行多个阶段的流水线，这些阶段相互纠缠。我们提出了SkillRise，一个用于跨任务学习技能的统一强化学习框架。SkillRise将相关实例组织成难度递进的序列，并使用单一策略在任务求解与整理不断演化的技能文档之间交替，该文档直接传递给下一个任务。跨任务的解耦信用分配使用当前任务结果监督求解，并使用折扣的下游结果监督整理。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在比较方法中取得了最强的Pass@1性能，相较于最强基线提升2.3至8.5个百分点。尽管在不同任务上训练，其学习到的整理策略在相同任务的重复尝试中依然有效。进一步分析揭示了跨任务的测试时扩展特性：即使每个任务仅尝试一次，随着相关任务序列变长，性能也会提升。这一趋势表明SkillRise在跨任务中复用了可迁移技能，而非受益于同一任务的重复采样。SkillRise在显著降低多阶段技能学习流水线的运行时开销的同时，保持了强大性能。这些结果共同为LLM智能体提供了一种简单高效的训练范式，用于跨任务提取、精炼和复用可迁移技能。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

### 2. 方法论：核心思想与关键技术细节

#### 2.1 核心思想：跨任务技能进化的统一RL框架
- **任务序列化**：将同一任务家族中相关但不同的实例组织成**难度递增的序列**（如按产品所需属性数量、任务复杂度排序），形成跨任务上下文。早期任务的经验可以指导后期任务，后期任务的性能则直接衡量技能的可迁移性。
- **统一策略与技能文档**：使用**单一的LLM策略**交替执行两个角色：
    - **任务求解**：基于当前技能文档 \(S_{i-1}\) 生成动作轨迹，获得任务奖励 \(r_i\)。
    - **技能策展**：在任务完成后，根据轨迹与结果将文档更新为 \(S_i\)，提炼通用流程、失败教训，并去除具体实例细节。该文档是任务间传递信息的**唯一通道**。
- **端到端训练**：整个流程（求解+策展）通过RL端到端联合优化，无需外部教师模型、独立记忆库或检索模块。

#### 2.2 关键技术：解耦信用分配与角色感知组相对优化
- **解耦回报**：根据时间角色对学习信号进行分离。
    - 任务求解阶段：回报 \(G_{i,{solve}} = r_i\)（仅由当前任务结果监督）。
    - 技能策展阶段：回报 \(G_{i,{curate}} = \sum_{j=i+1}^{K} \gamma^{j-i} r_j\)（由折扣后的**下游任务奖励**监督，\(\gamma\) 为跨任务折扣因子，更关注邻近任务）。
- **组相对优势**：在计算优势函数时，将同一任务位置 \(i\)、同一阶段 \(z\) 的多个平行试验（\(N\) 次）归为一组，组内计算均值与优势 \(A_{i,z} = G_{i,z} - \bar{G}_{i,z}\)。这确保求解与策展阶段的学习信号不会互为基准，同时消除不同序列位置带来的难度差异。
- **联合优化目标**：采用类似PPO的截断目标，对所有求解和策展响应的token进行统一优化，实现任务执行能力与技能抽象能力的共同提升。

#### 2.3 算法流程概览
对于每个训练步骤，从任务家族中采样 \(K\) 个难度递增的任务序列，并平行执行 \(N\) 次独立试验。每条试验线从空技能文档开始，依次执行：任务求解（基于当前文档）→ 计算当前奖励 → （若非最后任务）执行技能策展，生成新文档供下一任务使用。最后，利用上述解耦回报与组相对优势计算梯度，更新单一策略参数。

### 3. 实验设计

- **基准环境**：三个交互式文本环境。

    - **WebShop**：在线购物任务（搜索、配置、购买），使用1000件商品的版本。
    - **ScienceWorld**：基础科学推理与实验任务。
- **评价指标**：主要使用 **Pass@1 成功率**，并评估了Pass@2和Pass@3（对同一任务重复尝试，同时允许技能文档跨尝试演化）。
- **比较方法**：

    - **标准RL基线**：PPO、RLOO、GRPO、GiGPO（均独立处理每个任务）。
    - **元RL基线**：LaMer，通过对同一任务多次尝试的轨迹进行文本反思来实现任务内自适应。
- **骨干模型**：Qwen3-1.7B 和 Qwen3-4B。
- **训练设置**：每个更新步骤处理等量的任务交互（384次任务播放）。SkillRise使用 \(K=3\) 的任务序列和 \(N=8\) 个平行试验，LaMer使用 \(N=8\) 试验和3次重试，任务独立RL使用单任务24次采样。跨任务折扣因子 \(\gamma=0.6\)。

### 6. 主要结论与发现

- **性能最优**：SkillRise在全部三个基准上取得了最高的Pass@1成功率，分别超越最强基线（GiGPO）**2.3（ALFWorld）、7.1（WebShop）、8.5（ScienceWorld）个百分点**。

- **展现跨任务测试时扩展定律**：随着评估时给出的相关任务序列长度增加（\(K\) 从2到6），SkillRise的Pass@1性能**单调提升**（从83.6%至87.5%），而对比方法（GiGPO、GRPO、LaMer）未呈现此趋势。这证明模型可持续利用过去任务提炼技能以改进新任务，而非依赖简单重试。
- **高效简洁**：在性能持平或更优的前提下，SkillRise的端到端训练时间仅为多阶段流水线（RetroAgent, SkillRL）的**约1/4.3至1/6**，以极简框架实现了高效跨任务技能学习。
- **关键组件有效性**：消融实验证实技能策展是性能增益的主要来源，且框架对跨任务折扣因子 \(\gamma\) 不敏感，鲁棒性强。

### 7. 优点

- **方法设计简洁而优雅**：用单一策略和在线更新的文本技能文档替代了复杂的外部存储、检索与教师蒸馏模块，降低了系统复杂度和运行时开销。
- **学习信号明确**：通过解耦信用分配，自然地将“如何做事”与“如何总结”的学习目标对齐到各自的直接后果上，避免了多阶段流水线中信号混淆的问题。
