## 摘要
近年来，AI智能体的进展越来越多地将原生能力内化至其底层基础模型，催生了多模态基础模型和大推理模型。然而，智能体记忆仍主要通过外部模块实现，原生记忆能力在很大程度上尚未被探索。在本文中，我们朝着这个方向迈出了第一步，提出了记忆基础模型，赋予基础模型原生的记忆能力。我们从两个角度形式化原生记忆：主干网络内持久且动态演化的记忆状态，以及通过模型计算自主存储和利用信息的原生记忆过程。我们表明原生记忆在架构、端到端优化和效率方面具有优势。基于这一构想，我们提出Metis，首个记忆基础模型的原型。Metis引入了一种新架构，为基础模型配备原生记忆状态，允许历史信息被压缩进模型并通过记忆注意力进行访问。我们构建了大规模的记忆专用训练数据，并引入多个优化目标，通过中期训练来获得这些原生记忆过程。Metis的在线记忆维护无需梯度，记忆更新仅需一次前向传递。在推理时，所有已学习的模型权重保持冻结，而原生记忆状态则通过标准前向计算自主变换。通过大量实验，我们展示了Metis表现出原生记忆能力，并进一步详细分析了其优势、局限性和行为。为促进未来对记忆基础模型的研究，我们发布了项目和模型检查点。

## Abstract
Recent advances in AI agents have increasingly internalized native capabilities into their underlying foundation models, giving rise to multimodal foundation models and large reasoning models. However, agent memory is still primarily implemented through external modules, leaving the native memory capability largely unexplored. In this paper, we take a first step toward this direction by introducing memory foundation models, which empower foundation models with native memory capabilities. We formalize native memory from two perspectives: a persistent and dynamically evolving memory state within the backbone, and native memory procedures that autonomously store and utilize information through model computation. We show that native memory offers advantages in architecture, end-to-end optimization, and efficiency. Based on this formulation, we propose Metis, the first prototype of memory foundation models. Metis introduces a new architecture that equips a foundation model with a native memory state, allowing historical information to be compressed into the model and accessed through memory attention. We construct large-scale memory-specific training data and introduce multiple optimization objectives to acquire these native memory procedures through mid-training. The online memory maintenance of Metis is gradient-free, and the memory update requires only a forward pass. At inference time, all learned model weights remain frozen, while the native memory states are autonomously transformed through standard forward computation. Through extensive experiments, we show that Metis exhibits native memory capabilities and further provide a detailed analysis of its strengths, limitations, and behaviors. To facilitate future research on memory foundation models, we release our project and model checkpoints.

### **2. 方法论：核心思想与关键技术细节**

*   **核心架构：Metis 模块**
    *   Metis 在基础 Transformer 模块中插入 **Metis 模块**，由两块组成：
        1.  **本地记忆模块**：
            *   维护动态演化的**密集记忆网络 (Dense Memory Network) M** 和**查询-键归一化向量 S**，作为模型参数的一部分，构成原生记忆状态。
            *   初始化为0，在推理过程中随时间步更新。
        2.  **超记忆模块**：
            *   包含静态、可学习的参数（如投影矩阵 \( \tilde{W}_Q, \tilde{W}_K, \tilde{W}_V \)），负责定义记忆程序的函数空间。
            *   它根据当前步的隐状态，指导本地记忆模块的参数如何更新（记忆存储）。
*   **关键技术细节：记忆程序的实现**
    *   **原生记忆存储程序**:
        1.  **自适应聚合**：使用一个可学习的权重向量对当前步所有 token 的隐状态进行评分。
        2.  **Top-ρ 选择**：依据评分，选择累积概率达到阈值ρ的最关键 token 子集，进行信息压缩，剔除噪声。
        3.  **记忆更新**：使用选中的 token 子集计算记忆键 \( \tilde{K} \) 和值 \( \tilde{V} \)，通过一个门控Delta更新规则（GDU）将新信息整合进本地记忆模块的参数 M 和 S 中。此过程仅需前向计算，无需求梯度。
    *   **原生记忆利用程序**:
        1.  引入 **记忆注意力** 机制。
        2.  使用当前输入计算出的**记忆查询状态** \( \tilde{Q} \)，与存储在本地记忆块中的密集记忆网络 M 交互。
        3.  \( \tilde{Q} \)与 \( M \) 的交互结果，经过查询-键归一化处理（抑制噪声），作为辅助信息显式地加到原始 Transformer 的自注意力输出上，影响最终预测。
*   **训练与优化**:
    *   **中期训练**: 冻结基础模型的参数，仅优化 Metis 模块中的超记忆模块参数。
    *   **数据构建**: 基于27个公开基准数据集，合成了大规模、多轮交互的记忆专用数据。定义了四种核心记忆操作（**记住、遗忘、更新、反思**），并构建了显式/隐式指令、纯净/噪声环境等多样本。
    *   **多目标联合优化**:
        1.  **记忆重构目标**: 迫使模型无损地存储并重建信息，建立存储上限。
        2.  **记忆操作目标**: 教会模型根据指令执行特定的记忆操作（记住、更新等），并产生一致性回答。
        3.  **正则化目标**: 通过多实体绑定、选择性遗忘和防污染对话数据，提升模型在复杂场景下的鲁棒性，避免信息混淆和记忆泄露。

### **6. 主要结论与发现**

*   Metis 在没有外部历史文本的情况下，其原生记忆能力在所有对比的同类方法（Temp-LoRA, δ-Mem）中取得了**最佳性能**，验证了原生记忆范式的有效性。
*   **规模化效应**：Metis 的性能随着基础模型规模的增大（4B -> 27B）而显著提升，表明更大的基础模型能为原生记忆提供更好的支撑。
*   **不同操作难度差异**：“遗忘”操作是所有记忆操作中最困难的，即使在27B模型上，其泛化性能依然有限。
*   **关键组件有效性**：消融实验证实，自适应信息聚合和查询-键归一化对性能至关重要；单独的记忆查询投影有助于区分相关信息与噪声。
*   **有损压缩的必然性**：记忆容量实验表明，Metis 的原生记忆是“有损”的，性能随存储信息量增加和交互步数增加而下降，在长期记忆方面仍有局限。
*   **训练数据的重要性**：正则化数据（如多事实交互）对于提升模型在复杂场景下的鲁棒性、防止记忆混淆和泄露至关重要。
*   **高效的存储和推理**：低秩分解实验表明，记忆状态存在大量冗余，可以大幅度压缩（到秩64）而无损性能。效率分析显示，Metis在处理长上下文时，其延迟和存储开销远低于保留全量KV缓存的方案。

### **7. 优点**

*   **概念上的开创性**：首次明确定义了“记忆基础模型”并提出了“原生记忆”的框架，将记忆从一种工程化模块提升为模型的内在能力。
*   **架构设计精巧**：Metis 模块的解耦设计（本地记忆块负责存储，超记忆块负责操作），巧妙地结合了参数化记忆和神经网络运算，既保持了记忆的持续性，又允许模型学习如何操控记忆。
*   **训练策略完备**：自建大规模、多维度（操作类型、指令显隐、噪声水平）的记忆训练数据，并配合以多目标（重建、操作、正则化）的训练流程，是一套系统性的原生能力“激活”方案。
*   **实验评估全面深刻**：不仅展示了 SOTA 性能，更通过容量、OOD泛化、效率、可压缩性等大量分析性实验，坦诚地揭示了原生记忆的能力边界和内在特性（如有损性），提升了研究的深度和可信度。

### **8. 不足与局限**

*   **长期记忆退化**：将信息压缩至固定大小的参数中必然导致信息丢失，这是架构的固有局限。论文在长期容量实验中也证实了性能随步长增加而持续下降的问题。
*   **信息混淆风险**：在语义相近的事实同时存在时，模型仍可能出现混淆，尤其在大容量、长序列场景下。
*   **对通用能力的影响**：虽然初始化时对通用能力影响不大，但在存储信息后（Active Stage），尤其是在严格指令遵循任务（IFEval）上，性能下降明显，表明记忆状态的噪声会干扰模型的其他行为。
*   **“遗忘”操作的挑战**：实验结果表明，“遗忘”是一个更难的操作，尤其是在 OOD 场景下，其在参数化的记忆空间中泛化更难，这表明选择性、无损的擦除仍是一个开放问题。
*   **骨干网络迁移的局限性**：论文在 Llama 上的迁移实验显示性能并不一致，表明 Metis 当前的实现可能对特定的基础模型架构（如 Qwen 的混合注意力机制）有一定依赖，其作为即插即用模块的通用性有待进一步验证和完善。
*   **复杂操作的一致性**：案例研究显示，模型在执行遗忘指令的当下回复中可能重复旧信息，未能做到行为上的完全对齐，表明记忆过程与语言生成过程之间的一致性还有提升空间。
