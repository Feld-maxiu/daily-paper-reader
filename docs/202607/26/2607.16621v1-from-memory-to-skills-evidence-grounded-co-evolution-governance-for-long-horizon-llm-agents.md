## 摘要
现有的长程LLM智能体记忆系统通常将先前的轨迹作为被动上下文检索，而不是将其转化为可执行的能力。在本文中，我们提出了MSCE，一个无需训练的“记忆-技能协同进化”框架，将智能体经验组织为有依据的步骤轨迹、可复用过程性策略以及声明式环境认知。MSCE将具有正向估计增益且有证据支持的L2策略结晶化为可调用的技能，这些技能保留了证据链接、适用边界、决策指导、验证规则和可靠性估计。它还引入了反思加权的价值回填机制，通过密集的局部自我反思传播稀疏的终端反馈，从而产生证据校准的轨迹价值，用于管控记忆和技能的进化。在EvoAgentBench和LoCoMo上的实验表明，MSCE显著优于最先进的技能增强型和记忆驱动型智能体基线方法，展现出强大的跨域迁移能力和终身进化能力。

## Abstract
Existing memory systems for long-horizon LLM agents often retrieve prior traces as passive context rather than converting them into executable capabilities. In this paper, we propose MSCE, a training-free Memory--Skill Co-Evolution framework that organizes agent experience into grounded step traces, reusable procedural policies, and declarative environmental cognition. MSCE crystallizes evidence-backed L2 policies with positive estimated gain into callable skills that retain evidence links, applicability boundaries, decision guidance, verification rules, and reliability estimates. It further introduces reflection-weighted value backfilling, which propagates sparse terminal feedback through dense local self-reflections to produce evidence-calibrated trace values for governing memory and skill evolution. Experiments on EvoAgentBench and LoCoMo demonstrate that MSCE significantly outperforms state-of-the-art skill-augmented and memory-driven agent baselines, exhibiting strong cross-domain transferability and lifelong-evolution capabilities.

### 2. 论文提出的方法论（MSCE框架）

MSCE的核心思想是通过一个三层治理的记忆体系，将经验逐步抽象和固化为可调用的技能，并利用双信号（密集的自反思和稀疏的终端反馈）来驱动整个记忆和技能的更新与进化。

*   **三层治理记忆体系**：
    *   **L1 轨迹记忆（Trace Memory）**：存储原始的、可审计的步骤级交互证据 `f(1) = (状态, 动作, 观察, 自反思, 价值)`。这是所有上层抽象的锚定基础。
    *   **L2 策略记忆（Policy Memory）**：从跨episode的L1轨迹中归纳出的可复用程序性策略 `f(2) = (触发条件, 程序, 验证规则, 适用边界, 证据支撑)`。
        *   **策略归纳**：当相似结构的L1证据在多个不同episode中出现，且步骤价值超过阈值 `v_min` 时，会触发L2策略的归纳，防止对单一轨迹的过拟合。
        *   **策略收益 (G)**：通过计算采用该策略的轨迹价值加权平均值与未采用该策略的轨迹价值混合平均值之差来估算，以此判断策略的有效性。
    *   **L3 环境认知记忆（Environmental Cognition Memory）**：从多个L2策略中抽象出的声明式、关于“环境是什么样的”知识 `f(3) = (实体/结构, 规律, 约束)`，例如代码仓库的组织结构或特定操作系统的特性。它为技能调用提供背景知识，但不包含具体的操作指令。

*   **从记忆到技能的结晶化**：
    *   技能 `k` 是从符合条件的L2策略衍生出的可调用对象，它不仅是L2策略的格式化，更是一个**有门槛的晋升过程**。
    *   **晋升门槛**：源L2策略必须 (1) 保留有证据支撑，(2) 具备正收益 `G > θ_G`，(3) 状态稳定（近期证据未导致触发条件、程序或边界的重大改写）。
    *   **技能属性**：结晶后的技能不仅包含L2的程序和边界，还附带了**证据锚点、决策指引、验证规则和可靠性评分(η)**，确保其可追溯、可指导、可验证。
    *   **技能生命周期**：技能具有试用期、激活、归档三个状态，通过追踪其调用成功/失败次数来动态调整其可靠性 `η = (n_pass + 1) / (n_trial + 2)`，并相应地进行强化、修正或归档。

*   **反思加权价值回填（Reflection-Weighted Value Backfilling）**：
    *   **问题**：任务完成后的终端反馈 `R_i` 是稀疏且可靠的，但无法直接评价中间步骤的贡献。中间步骤的自反思 `ρ` 密集但可能不忠实。
    *   **方法**：将这两种信号结合，将稀疏的终端奖励 `R_i` 沿时间步回传，分配给每一步轨迹价值 `V`。其核心公式为：
        `V(f_t) = α_t * R_i + (1 - α_t) * γ * V(f_{t+1})`
    *   **机制**：`α_t` 是步骤 `t` 的反思权重，由一个LLM评估器根据反思的忠实性、因果洞察力、可迁移性和具体性进行打分。这确保了越关键、反思越有价值的步骤，其分配到的奖励份额越大，从而为价值校准提供了精细化的信号。
