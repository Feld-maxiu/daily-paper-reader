## 摘要
记忆、规划、反思和工具使用常被作为特征标签进行比较，这掩盖了决定智能体实际运行方式的控制语义。本综述连接了十个历史认知架构、八个语言智能体运行时家族以及四十二个以机制为中心的现代系统。我们通过状态、控制、转换、持久性、故障、学习和资源治理来重构每种机制，然后分别对证据关系（E1-E4）和迁移深度（D0-D4）进行编码。由此得到的图景并不均衡。现代智能体已经实现了自适应记忆、故障恢复、动态团队选择、工作流搜索、技能归纳、资源调度和不确定性条件下的行动等大部分功能，尽管这些往往是通过独立趋同而非有文献记载的继承来实现的。最主要的剩余机会在于机制之间的耦合。最近基线筛选弥合了一个被提出的差距：GraSP已经结合了校准的多技能选择、类型化编译、验证、有界修复以及重规划或ReAct回退。还有五个残留的机制束：带延迟和动作效用的激活；带孤立子状态和解决编译的类型化僵局；带广播和接纳学习的有界内容竞争；带重新考虑和实时方法授权的持久意图；以及带资源分配、中断和停止的不确定性。我们贡献了一个独特机制目录、一个可审计的证据深度框架，以及一个可证伪的议程，用于将这些机制束作为可组合的运行时不变性进行测试。

## Abstract
Memory, planning, reflection, and tool use are often compared as feature labels, obscuring the control semantics that determine how an agent actually runs. This review connects ten historical cognitive architectures, eight language-agent runtime families, and forty-two mechanism-focused modern systems. We reconstruct each mechanism through state, control, transition, persistence, failure, learning, and resource governance, then code evidence relation (E1-E4) separately from migration depth (D0-D4). The resulting landscape is uneven. Modern agents have operationalized substantial parts of adaptive memory, failure recovery, dynamic team selection, workflow search, skill induction, resource scheduling, and uncertainty-conditioned action, although often through independent convergence rather than documented inheritance. The strongest remaining opportunities lie in couplings among mechanisms. Closest-baseline screening closes one proposed gap: GraSP already combines calibrated multi-skill selection, typed compilation, verification, bounded repair, and replanning or ReAct fallback. Five residual bundles remain: activation with latency and action utility; typed impasse with isolated substates and resolution compilation; bounded content competition with broadcast and admission learning; persistent intention with reconsideration and live method authority; and uncertainty with resource allocation, interruption, and stopping. We contribute a distinctive-mechanism catalog, an auditable evidence-depth framework, and a falsifiable agenda for testing these bundles as composable runtime invariants.

### **主要结论与发现**
1.  **迁移图景不均衡 (Uneven Migration Landscape)**：现代智能体已经在运行层面实现了历史架构中的大部分概念，如状态存储、工具使用、执行循环等，并实现了D3/D4级的自适应控制，但**大多源于独立的结构性趋同（E3/E4），而非有记录的继承（E1）**。
2.  **关键空白在于机制耦合 (Gaps are in Couplings)**：单个机制已被大量实现，但历史架构设计的核心价值——**多个机制之间的耦合关系**，在多数现代系统中是缺失的。这些耦合正是剩余的研究机会。
3.  **一个候选差距已关闭**：通过基线筛选，确认 GraSP 系统已经综合了 B5（技能治理：校准选择、验证、修复、回退）的完整控制链，因此该议题从研究空白中移除。
4.  **五个残留机制束 (Five Residual Bundles)** 被明确定义为未来的研究议程：
    *   **B1 (激活-延迟-效用)**: 将记忆项的激活值、检索延迟、下游动作效用与维护成本耦合为一个统一的控制律。
    *   **B2 (类型化僵局-子状态-编译)**: 将故障分类、受保护的恢复子状态、类型化解决结果的返回和安全编译耦合。
    *   **B3 (内容竞争-工作区-广播学习)**: 在受限的工作区周期内，基于结果对类型化内容（而不仅仅是智能体）进行接纳学习与广播。
    *   **B4 (意图-重新考虑-方法授权)**: 将持久的目标意图与显式的重新考虑条件、委托/中止生命周期以及实时切换推理方法的权威性耦合。
    *   **B6 (不确定性-资源-中断-停止)**: 让一个校准过的不确定性对象贯穿整个推理和行动阶段，统一分配算力、工具调用、中断和停止的决策权。

4.  **自我修正与批判**：通过“对标基线筛选”直接关闭了B5这个看似合理的差距，展现了方法论的内在纠错能力。同时，论文对自身的局限性（如单一编码、语料库截止日期）有坦诚的讨论。

### **不足与局限**
1.  **编码可靠性未经验证**：尽管论文公开了编码包以备审计，但坦诚地指出**尚未完成独立的第二编码者信度检验**。所有D3/D4级声明仍是“暂定的”，存在单一编码者的主观偏差风险。
2.  **语料库的时效性与覆盖度**：分析语料库截至一个固定的日期（2026年7月26日），这是一个自我设限的综述。在该日期之后发表的研究可能会改变某些结论。其搜索策略是目标导向而非穷举，可能存在遗漏。
3.  **理论与实践的鸿沟**：该综述停留在架构设计层面，明确声明**不对历史机制的性能做任何默认假设**，也不对提出的“残留机制束”的实际跨领域因果价值做出判断。历史上有效的机制在现代技术栈下可能增加不必要的工程开销，而论文将“反证这些耦合无效”也视为其议程的成功。
4.  **未涉及性能基准测试**：由于是机制映射综述，它不包含任何定量实验来证明实现某个“残留束”比现有基线在具体任务上带来多少性能提升。其价值在于提出“可证伪的控制假设”，而非性能报告。
