## 摘要
我们提出状态转换预训练（STP）作为GUI智能体的新扩展维度。在STP阶段，我们通过联合优化逆向动力学（从状态变化预测动作）和正向动力学（从当前状态和动作预测下一状态），在视觉状态转换上持续预训练统一多模态模型。该优化使模型具备更好的动作锚定视觉表征和GUI动力学的内部世界模型。随后在带有任务指令的轨迹上微调时，我们的STP训练模型在桌面和移动GUI场景的智能体基准测试（AgentNetBench、AndroidControl和GUIOdyssey）中，始终优于仅通过直接轨迹微调训练的基线。进一步实证研究表明，联合动力学优化相比单目标训练带来稳定提升，且下游性能随转换数据量稳步扩展。

## Abstract
We introduce State Transition Pretraining (STP) as a new scaling axis for GUI agents. During the STP stage, we continually pretrain a unified multimodal model on visual state transitions by jointly optimizing inverse dynamics (predicting actions from state changes) and forward dynamics (predicting next states from current states and actions). This optimization equips the model with better action-grounded visual representations and an internal world model of GUI dynamics. When subsequently fine-tuned on trajectories with task instructions, our STP-trained models consistently outperform baselines trained solely via direct trajectory fine-tuning across agent benchmarks in both desktop and mobile GUI scenarios (AgentNetBench, AndroidControl, and GUIOdyssey). Further empirical studies show that joint dynamics optimization yields stable improvements over single-objective training, and downstream performance scales steadily with the volume of transition data.

### 2. 论文提出的方法论

*   **核心思想**：提出**状态转换预训练（State Transition Pretraining, STP）**。在轨迹微调之前，先在一个统一的模型上利用大量步骤级转换数据`(s_t, a_t, s_{t+1})`进行预训练，让模型学习GUI操作的基础动力学，而不涉及任何任务指令。
*   **关键技术细节**：
    *   **数据来源**：从现有的轨迹数据集中分解出原子元组`(s_t, a_t, s_{t+1})`，即两张连续截图和中间的动作。此数据无需任务级标注，成本低且易于规模化。
    *   **模型骨架**：采用统一多模态模型（Unified Multimodal Model, UMM）作为骨干网络，因为它能原生地处理“图像+文本”到“文本”以及“图像+文本”到“图像”的多种任务格式。
    *   **联合优化目标**：
        *   **逆向动力学（Inverse Dynamics）**：给定状态对`(s_t, s_{t+1})`，预测动作`a_t`。这是一个“图像+图像 -> 文本”的任务，旨在迫使模型识别交互位置，提取与动作相关的细粒度视觉特征。其损失函数为：`L_inv = -log p_θ(a_t | s_t, s_{t+1})`
        *   **正向动力学（Forward Dynamics）**：给定当前状态和动作`(s_t, a_t)`，预测下一状态`s_{t+1}`。这是一个“图像+文本 -> 图像”的任务，旨在让模型学习动作与视觉状态变化之间的因果关系，构建GUI动力学的内部世界模型。其损失函数为生成损失`L_fwd = L_gen(s_{t+1}; s_t, a_t, θ)`。
    *   **训练流程**：首先，在转换数据集上优化联合预训练目标`L_pre = L_fwd + λ L_inv`。然后，在此预训练模型的基础上，再使用带任务指令的完整轨迹进行标准的监督微调。
