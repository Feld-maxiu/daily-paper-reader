## 摘要
现有的自演化记忆系统主要基于文本输出（如任务轨迹和反思）来改进智能体记忆。然而，这种基于文本的范式很少纳入内部的机制性信号，导致检索到的记忆在任务执行过程中实际如何被利用的问题未得到充分探索。这一局限可能导致不可靠的错误归因和虚假的记忆修改。本文中，我们展示了检索头注意力提供了一种揭示片段级记忆利用的机制性信号。通过聚合记忆片段和决策步骤上的注意力，我们构建了一个上下文利用矩阵，该矩阵揭示了反复出现的记忆使用模式并指明了相应的精化策略。基于此观察，我们提出了注意力引导记忆精化（AGMR）框架，该框架利用注意力揭示的利用模式来指导有针对性的片段级记忆更新。AGMR 对失败执行进行记忆修正或增强，对成功执行进行记忆简化，并通过重新执行验证每次更新。在交互式决策基准上的实验表明，AGMR 比纯文本记忆精化基线方法在任务性能和记忆效率上均有提升。代码可在 https://anonymous.4open.science/r/AGMR_code-3262/ 获取。

## Abstract
Existing self-evolving memory systems mainly improve agent memory based on textual outputs, such as task trajectories and reflections. However, this text-based paradigm rarely incorporates internal mechanistic signals, leaving how retrieved memory is actually utilized during task execution underexplored. This limitation can lead to unreliable error attribution and hallucinated memory modifications. In this work, we show that retrieval-head attention provides a mechanistic signal for revealing segment-level memory utilization. By aggregating attention over memory segments and decision steps, we construct a context utilization matrix that exposes recurring memory-use patterns and indicates corresponding refinement strategies. Building on this observation, we propose Attention-Guided Memory Refinement (AGMR), a framework that uses utilization patterns revealed by attention to guide targeted segment-level memory updates. AGMR corrects or enhances memory for failed executions, simplifies memory for successful executions, and verifies each update through re-execution. Experiments on interactive decision-making benchmarks show that AGMR improves both task performance and memory efficiency over text-only memory refinement baselines. ### 2. 论文提出的方法论
论文提出了一个名为**注意力引导记忆精化（AGMR）**的框架，其核心思想是利用**检索头注意力**作为机制性信号，诊断记忆利用模式并指导片段级更新。

*   **核心思想与关键技术细节**：
    1.  **检索头识别**：通过构造一个监督数据集（包含需检索的关键上下文及其对应的模型输入），计算每个注意力头从输入末尾Token到关键上下文的注意力得分，筛选出得分最高的“检索头”。实验通过掩码这些头验证了它们在记忆检索中的功能重要性。
    2.  **上下文利用矩阵构建**：将检索到的轨迹记忆分割成连续的步骤片段，在任务执行过程中，追踪并聚合所有“检索头”在每个决策步骤上对每个记忆片段的注意力强度，构造一个“片段 × 步骤”的**上下文利用矩阵**。该矩阵可视作记忆实际利用情况的“热力图”。
    3.  **记忆利用模式诊断**：通过分析上下文利用矩阵，将任务失败归因于三种模式：
        *   **关注但错误**：智能体关注了正确片段，但记忆内容有误导。
        *   **遗漏相关记忆**：存在正确的记忆片段，但未获得足够注意力。
        *   **被无关记忆干扰**：不相关的片段获得了异常高的注意力，干扰决策。
        *   **成功执行则诊断出“低利用冗余片段”**。
    4.  **两阶段记忆精化**：
        *   **语义反射器**：基于文本分析，初步定位失败步骤和可支持正确行为的候选记忆片段，或识别成功执行中的语义冗余片段。
        *   **注意力引导精化器**：结合上下文利用矩阵，精确诊断上述模式，并对目标片段执行针对性更新（如：纠正内容、增强显著性、删除冗余）。
    5.  **重执行验证**：所有候选更新在正式写入记忆库前，必须通过重新执行相同任务进行验证。失败则回滚或重试，成功才提交，确保更新的有效性。
*   **核心公式/指标**：
    *   **头得分**（用于筛选检索头）：$\text{score}_{l,h} = \sum_{i=1}^{N} \sum_{t \in \text{key\_context}^{(i)}} \text{Attention}^{(i)}_{l,h}(\text{last\_token}^{(i)} \to t)$

    *   **片段利用统计量**：用于识别冗余的指标，包括片段在所有步骤上的平均利用 $\bar{c}_\ell$ 和最大利用 $c^\text{max}_\ell$。
