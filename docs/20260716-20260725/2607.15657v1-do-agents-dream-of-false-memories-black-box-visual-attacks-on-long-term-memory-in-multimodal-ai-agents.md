## 摘要
多模态AI智能体日益依赖持久长期记忆，以将生成建立在过去的视觉和文本片段之上。我们表明，对视觉数据的无条件信任造成了一个关键漏洞。我们提出Lucid，这是一个黑盒对抗框架，可在严格限定于图像范围内的威胁模型下破坏多模态记忆流水线，无需访问目标多模态大语言模型（MLLM）、目标检索编码器或文本通道。Lucid制作难以察觉的扰动，根据历史上下文的可用性实现两种不同的故障模式：（1）记忆投毒，一种上下文内攻击，其中对抗性图像替换了良性图像，而良性图像的内容得到先前文本上下文的强化，从而可靠地破坏视觉回忆，并将智能体引向攻击者选择的叙事；（2）记忆注入，一种上下文外攻击，在缺乏先前文本基础的对话轮次中，对抗性图像替换良性图像，导致智能体生成受攻击者影响的响应，且没有来自记忆的纠正信号。我们在各种对话领域和五种黑盒记忆架构上评估了Lucid，包括图结构、LLM摘要和商业部署的系统。Lucid在投毒上达到61.6%的攻击成功率（ASR），在注入上达到58.4%的ASR，揭露了多模态记忆流水线中的结构性漏洞。

## Abstract
Multimodal AI agents increasingly rely on persistent long-term memory to ground generation in past visual and textual episodes. We show that unconditional trust in visual data creates a critical vulnerability. We propose Lucid, a black-box adversarial framework that compromises multimodal memory pipelines under a strictly image-bounded threat model, requiring no access to the target MLLM, target retrieval encoder, or the text channel. Lucid crafts imperceptible perturbations to enable two distinct failure modes based on the availability of historical context: (1) Memory poisoning, an in-context attack where the adversarial image replaces a benign one whose content is reinforced by prior textual context, reliably corrupting visual recall and steering the agent toward attacker-chosen narratives; (2) Memory injection, an out-of-context attack where the adversarial image replaces a benign one in a conversation turn devoid of prior textual grounding, causing the agent to generate attacker-influenced responses with no corrective signal from memory. We evaluate Lucid across various conversation domains and five black-box memory architectures, including graph-structured, LLM-summarized, and commercially deployed systems. Lucid achieves 61.6% ASR on poisoning and 58.4% ASR on injection, exposing a structural vulnerability in multimodal memory pipelines.

### **2. 论文提出的方法论：Lucid**

Lucid是一个黑盒对抗性攻击框架，其核心思想是通过精心设计的、难以察觉的图像扰动，在仅操纵图像像素的条件下，实现对多模态长期记忆的破坏。该框架包含三个主要阶段。

*   **核心思想**：
    *   攻击者的唯一自由度是对用户分享的图像施加扰动。Lucid通过优化扰动，使图像的视觉嵌入在语义空间中发生偏移，指向攻击者选择的目标概念，而图像本身仍被检索系统视为与原始查询高度相关。
    *   根据历史上下文的可用性，攻击分为两种模式：上下文内的**记忆投毒**（Memory Poisoning）和上下文外的**记忆注入**（Memory Injection）。

*   **关键技术细节与流程**：
    *   **阶段1：对抗性目标设计**：
        *   **目标**：从大规模图像-文本语料库（ShareGPT4V-100K）中，为每个受害者查询（QA对）选择一个在语义上相互矛盾的视觉概念（`(x*, c*)`）。
        *   **方法**：采用一个复合评分函数`S(p; q, a_{gt}) = α ΦR(p, q) + β Φ_{contra}(p, q) - γ ΦC(p, a_{gt})`。
            *   `ΦR`（检索位移分数）：使用CLIP作为黑盒代理，评估候选图像与查询的文本嵌入的相似度，模拟其被检索的可能性。
            *   `Φ_{contra}`（槽位矛盾分数）：由本地LLM提取问题的属性-值对和备选答案，奖励那些标题与错误答案更接近、与正确答案更远的候选图像。
            *   `ΦC`（良性对齐惩罚）：惩罚标题语义上与正确答案重叠的候选图像，防止攻击效果减弱。
            *   通过词汇和主题硬性筛选后，得分最高的候选成为攻击目标。

    *   **阶段2：对抗性载荷构建**：
        *   **记忆投毒（In-context Poisoning）**：
            *   攻击对话历史中已存在的包含图像的轮次`(u_j, a_j, x_j)`。
            *   保留所有文本`(u_j, a_j)`不变，仅将原始图像`x_j`标记为扰动源，目标是指向阶段1选出的`x*`。
            *   形成源-目标对`(x_j, x*)`，进入阶段3。
        *   **记忆注入（Out-of-context Injection）**：
            *   在对话中插入一个全新的、主题中立的用户轮次`u_+`（如“这是我最近活动的一张照片”），并附带一个随机抽取的源图像`x_+`。
            *   该新轮次没有任何先前的文本上下文可以验证其真实性。
            *   形成源-目标对`(x_+, x*)`，进入阶段3。

    *   **阶段3：对抗性扰动**：
        *   **目标**：求解优化问题 `max_{δ:∥δ∥∞≤ε} L(x_s + δ, x*, c*)`，生成扰动`δ`，使对抗图像`˜x = x_s + δ`的嵌入接近目标图像`x*`和目标标题`c*`。
        *   **损失函数 `L`**：
            *   `L(˜x, x*, c*) = L_{OT}(˜x, x*) + λ_{txt} L_{txt}(˜x, c*)`。
            *   `L_{OT}`：基于“特征最优对齐（FOA）”攻击目标，在一个替代模型集合上（CLIP-ViT-B/16, CLIP-ViT-B/32, LAION-CLIP），结合全局余弦对齐和局部最优传输（Optimal Transport, OT）簇分配，使对抗图像和目标图像在每个替代模型的嵌入空间中都高度相似。模型权重`w_m`会根据优化进度动态更新。
            *   `L_{txt}`：**本文在FOA-Attack上的扩展**。它将对抗图像与目标标题`c*`直接在CLIP的联合文本-图像空间中对齐，确保下游记忆后端的MLLM在描述`˜x`时，能生成符合`c*`语义的内容。
        *   **优化过程**：在替代模型集合上，使用投影迭代快速梯度符号法（I-FGSM），在`ℓ∞`范数球（ε=16/255）内进行`T=1000`步的带符号梯度上升，最终输出对抗图像`˜x`。整个优化过程无需访问目标MLLM、检索编码器等任何目标系统组件。

### **6. 论文的主要结论与发现**

*   **攻击高度有效**：攻击框架Lucid在完全黑盒、仅图像扰动的条件下，成功实现了对多模态长期记忆的投毒和注入。平均攻击成功率（ASR）分别为**61.6%和58.4%**，接近理想攻击（Oracle）的水平。
*   **漏洞的普遍性**：该漏洞存在于所有被测试的五种记忆架构和五种MLLM中，证明这是一个**结构性漏洞**，而非特定实现的缺陷。
*   **检索与生成阶段脱钩**：
    *   成功攻击依赖于高检索率，证实了对抗图像能有效误导检索系统。
    *   **“检索-行动差距”**：在某些MLLM（如Claude-Haiku-4.5、GPT-4o-mini）上观察到检索成功但行动失败（ASR较低）的现象，说明**生成阶段的鲁棒性是独立于检索鲁棒性的安全维度**。
*   **防御的挑战**：
    *   **图像预处理**（高斯模糊、JPEG压缩）是当前最有效的防御，可降低攻击成功率（ASR），但仍有漏网之鱼。
    *   **文本层面的防御**（如LLM审查、语义漂移过滤、异常评分）**基本无效**，因为生成的文本描述在此攻击情境下是流畅且合理的，且注入的轮次在语义上与查询高度相关。
    *   有效的防御必须作用于**图像层面**，在生成描述之前进行，但现有简单方法难以完全抵御更先进的对抗攻击。
*   **攻击的隐蔽性与持久性**：注入攻击难以检测，它在文本上不留痕迹。消融实验表明，攻击不会随时间衰减，甚至在UniversalRAG架构上随时间推迟而增强。

### **7. 优点**

*   **威胁模型严格且新颖**：首次提出并验证了在“仅图像扰动”的极端受限黑盒条件下，对多模态AI智能体持久情景记忆的攻击。这比所有先前工作设定的攻击者能力都要弱，从而更具现实威胁。
*   **方法论贡献扎实**：
    *   提出了完整的三阶段攻击流水线，特别是在攻击目标设计上，通过复合评分函数（结合检索、语义矛盾和反良性对齐）实现了高度自动化和有效的目标选择。
    *   在扰动优化中，创造性地引入**文本对齐损失**`L_{txt}`，确保生成的对抗图像不仅能骗过视觉编码器，还能诱导下游MLLM生成符合攻击者意图的描述，打通了攻击的“最后一公里”。
*   **实验评估极其全面**：
    *   跨5种记忆架构、5种MLLM、4种检索编码器的组合验证，极具说服力。
    *   包含Oracle和Adversarial条件的对比，清晰界定了攻击的上下限。
    *   系统性的防御评估不仅报告了防御效果，还深入分析了其失效机理，为未来防御研究指明了方向。
*   **发现了关键科学问题**：明确指出了**检索鲁棒性与生成鲁棒性的分离**现象，为设计更安全的多模态系统提供了一个新的分析视角。

### **8. 不足与局限**

*   **对抗样本的特定性**：攻击的成功率依赖于高质量的对抗目标选择（阶段1）。在缺乏合适候选图像的情况下，攻击效果可能会下降，尽管论文使用的大规模语料库在很大程度上缓解了此问题。
*   **防御评估的深度**：虽然评估了多种防御，但主要是针对“检测”和“预处理”的简单方法。研究未探讨更复杂的防御，如其标题中暗示的**跨模态一致性检查**（在存储时验证图像内容与文本描述是否一致），这可能是作者自己提出的防御方向。
*   **攻击的现实世界可行性**：论文提出了图像篡改的途径（如CDN compromised, malicious SDK etc.），但这些在实际中的利用难度和成本未被深入讨论。攻击仍需要对用户的环境或服务链有相当的控制力。
*   **记忆后端的模拟**：虽然测试了5种记忆后端，包括一个面向生产的系统（Mem0Memory），但这些仍是在研究环境下的模拟。对Mem0Memory的攻击需要对抗性图像能骗过“视觉预传”的MLLM描述过程，这是一个更严格的条件，其ASR也相对较低，结果也反映了这一点。
*   **对少数领域数据集的依赖**：实验全部基于Mem-Gallery基准。这是一个精心设计的基准，但其对话领域有限，未来需要在更广泛、更真实的和嘈杂的对话数据上验证。
