## 摘要
尽管在数据理解和决策方面具有强大的能力，自主数据科学智能体仍然严重依赖涉及昂贵计算的试错工作流。这一瓶颈催生了能够在实际执行前预测数据科学操作效果的模型。本文中，我们引入了数据科学世界模型的概念，它通过根据当前工作流状态和候选操作来预测环境状态转换，从而对数据科学执行环境进行建模。我们进一步提出了DSWorld，这是一个实用的框架，结合了结构化状态构建、成本感知路由、轻量级实际执行以及基于大语言模型的昂贵操作模拟器。为了支持训练，我们构建了一个8K规模的转换轨迹数据集，并引入了反思性世界模型优化，这是一种用于改进转换预测的错误感知强化学习策略。实验表明，DSWorld将基于强化学习的智能体训练加速了约14倍，基于搜索的推理加速了约3-6倍，同时保持了有竞争力的性能，并且在转换预测任务上比最强的大语言模型基线高出35.6%。代码可在https://anonymous.4open.science/r/DSWorld获取。

## Abstract
Despite strong capabilities in data understanding and decision-making, autonomous data science agents still heavily rely on trial-and-error workflows that involve expensive computation. This bottleneck motivates models that can anticipate the effects of data science operations before real execution. In this paper, we introduce the concept of Data Science World Model, which model the data science execution environment by predicting environment state transitions conditioned on current workflow states and candidate operations. We further propose DSWorld, a practical framework that combines structured state construction, cost-aware routing, lightweight real execution, and an LLM-based simulator for expensive operations. To support training, we construct an 8K-scale transition trajectory dataset and introduce Reflective World Model Optimization, an error-aware reinforcement learning strategy for improving transition prediction. Experiments show that DSWorld accelerates RL-based agent training by approximately $14\times$ and search-based inference by approximately $3$-$6\times$ while maintaining competitive performance, and outperforms the strongest LLM baseline by 35.6% on transition prediction tasks. The code is available at https://anonymous.4open.science/r/DSWorld.

## 2. 论文提出的方法论
- **核心思想**：构建一个由状态构造器、成本感知路由器、轻量级编译器、LLM 模拟器组成的混合框架 **DSWorld**，联合建模执行环境的动态变化。
- **关键技术细节**：
  - **状态构造器（State Constructor）**：将原始执行环境（任务描述、数据集预览、环境配置、历史输出等）转化为结构化的文本状态表示 \( S_t \)。
  - **成本感知路由器（Router）**：通过动作编码器提取稠密嵌入，判断当前操作是否属于低开销操作（如简单数据查询）。轻量操作→编译器直接真实执行；重量操作（如大模型训练）→模拟器预测下一步状态 \( \hat{S}_{t+1} \)。同时内置超时机制以兜底处理路由错误。
  - **编译器（Compiler）**：直接与环境交互，获得真实的执行反馈与下一个状态。
  - **LLM 模拟器（Simulator）**：基于大语言模型，输入当前状态 \( S_t \) 与候选动作 \( A_t \)，预测执行后的下一个状态（包括输出、错误信息、性能指标等）。
- **训练策略**：
  - **SFT 预热**：在自建的 8K 转换轨迹数据集上进行监督微调，赋予模拟器基础的转换建模能力。
  - **反思性世界模型优化（Reflective World Model Optimization）**：一种新颖的 RL 优化策略。在生成初步预测后，利用LLM对预测与真实结果的误差进行“反思”，然后基于反思信息生成修正后的状态，最后使用 GRPO（Group Relative Policy Optimization）基于原始与修正样本的奖励进行联合优化。奖励函数衡量执行状态、错误信息、性能等的预测准确性。
- **训练数据构建（DSWorld-8K）**：
  - 真实轨迹：通过运行真实数据科学智能体记录状态转换三元组，并利用LLM生成推理过程（CoT）。
  - 合成轨迹：从 MMTU 等数据源采样环境，结合预建的操作/错误库合成动作，真实执行后过滤验证，同样补充 CoT 推理。

- **高效加速**：在保证智能体性能极具竞争力的前提下，DSWorld 将 RL 智能体训练加速约 **14 倍**，将搜索式智能体的推理速度提升约 **3–6 倍**。

- **训练策略有效**：SFT 为模型提供了强大的初始化能力，而反思性世界模型优化通过错误感知反思进一步提升了预测的精准度。
- **可扩展性好**：性能随训练数据和模型规模的增加而持续提升，展现出良好的可扩展潜力。

## 7. 优点
- **问题定义具有前瞻性**：将世界模型思想成功引入数据科学领域，抓住了计算开销这一核心痛点。
- **框架设计精巧务实**：通过“路由”机制平衡了效率与准确性，是实际落地的重要设计。
- **训练策略新颖**：反思性世界模型优化通过分析自身错误来改进，相比单纯 GRPO 能提供更具指向性的训练信号。
- **实验扎实且立体**：实验不仅评估了世界模型的预测能力，更真正将其接入智能体的训练和推理闭环中验证了其功利价值（加速与性能保留）。

## 8. 不足与局限
- **覆盖范围有限**：当前仅建模数据科学转换，未涵盖智能体工作流中常见的外部工具调用（如搜索、文件操作）。
- **性能上限受制于 LLM**：模拟器的预测质量仍然受限于基座 LLM 的能力，在处理需要复杂算法推理（如锦标赛性能排名）的任务时表现相对较弱。
- **潜在的分布偏差**：合成轨迹与真实自主工作流之间可能存在差异，这可能影响模型在真实场景下的泛化性能。
- **任务覆盖面**：主要聚焦于表格和结构化数据的建模任务，在其他类型（如图像、音频）的数据科学任务中的表现有待验证。
