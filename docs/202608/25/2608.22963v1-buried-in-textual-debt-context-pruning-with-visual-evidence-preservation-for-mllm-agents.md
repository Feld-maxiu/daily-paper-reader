## 摘要
多模态大语言模型（MLLMs）越来越多地被部署为多步智能体，其中显式推理支持任务分解与工具协调，但也积累自生成文本。在长轨迹中，这些文本会主导上下文并抑制视觉证据，形成文本债务。我们观察到，一旦任务相关的视觉证据得到锚定，推理就变得冗余；而在锚定仍不确定时，陈旧的假设可能误导后续推断。因此，剪枝必须移除冗余文本，同时不丢弃视觉证据。我们提出了 SPARE，一个以 Kullback–Leibler（KL）散度为指导的框架，用于剪枝多模态工具使用智能体中累积的推理内容。SPARE 使用紧凑的任务状态摘要作为特权诊断上下文。对于每个候选片段，它在原始上下文和以摘要为条件的上下文中重放同一模型。来自同策略自蒸馏（OPSD）的反向 KL 散度随后检验该摘要是否充分覆盖该片段，且不干扰未来推理。我们进一步通过监督微调（SFT）对摘要器进行微调，从而实现更紧凑的摘要、更广泛的覆盖和更大程度的剪枝。在多步视觉工具使用基准上，SPARE 在剪枝方法中取得了最高的平均准确率，同时移除了 37.89%–64.58% 的推理 token。这一有利的准确率–上下文权衡表明，减少文本主导性能够恢复对视觉证据的依赖，并缓解对自生成语言的过度依赖。

## Abstract
Multimodal Large Language Models (MLLMs) are increasingly deployed as multi-step agents, where explicit reasoning supports task decomposition and tool coordination but also accumulates self-generated text. Over long trajectories, this text can dominate the context and suppress visual evidence, creating textual debt. We observe that reasoning becomes redundant once task-relevant visual evidence is grounded, while stale hypotheses can misguide later inference when grounding remains uncertain. Pruning must therefore remove redundant text without discarding visual evidence. We propose SPARE, a Kullback--Leibler (KL)-guided framework for pruning accumulated reasoning in multimodal tool-use agents. SPARE uses a compact task-state summary as privileged diagnostic context. For each candidate segment, it replays the same model under the original and summary-conditioned contexts. Reverse-KL divergence from on-policy self-distillation (OPSD) then tests whether the summary sufficiently covers the segment without disrupting future reasoning. We further fine-tune the summarizer with supervised fine-tuning (SFT), enabling more compact summaries, broader coverage, and more aggressive pruning. Across multi-step visual tool-use benchmarks, SPARE achieves the highest average accuracy among pruning methods while removing 37.89--64.58\% of reasoning tokens. This favorable accuracy--context trade-off shows that reducing textual dominance restores reliance on visual evidence and mitigates over-conditioning on self-generated language.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：多模态大语言模型（MLLMs）常被部署为多步智能体，通过显式推理来分解视觉任务、协调工具调用、整合中间观察。
- **文本债务现象**：每一轮交互都会在上下文中累积自生成文本；在长轨迹中，这些文本逐步占据主导地位，甚至压制原始图像和工具返回的视觉证据。
- **关键观察**：
  - 当任务相关视觉证据已经被正确锚定时，后续推理往往变得冗余；
  - 当早期推理未能正确关注视觉区域时，累积文本会形成“陈旧假设”，可能误导后续判断。
- **核心问题**：如何在多步工具使用过程中，剪除冗余的推理文本，同时不丢失对后续决策至关重要的视觉证据。
- **整体含义**：剪枝不仅是为了节省计算和上下文长度，更是一种 **grounding 机制**——通过减少对陈旧自生成语言的过度依赖，恢复模型对视觉输入的注意力。
- **与现有工作的区别**：已有方法主要压缩视觉 token 或缩短单轮推理，而本文关注的是多步轨迹中累积的**文本侧冗余**。

## 2. 论文提出的方法论

论文提出 **SPARE（Selective Pruning of Accumulated Reasoning with Visual Evidence Preservation）**，一种基于 KL 散度引导的选择性推理剪枝框架。

- **核心思想**：使用一个紧凑的任务状态摘要作为“特权诊断上下文”，判断历史推理片段是否已经被摘要充分覆盖；若覆盖充分，则剪除该片段，否则保留或重建为视觉证据。
- **关键技术步骤**：

  1. **自适应摘要触发**  
     - 仅当模型自行调用 `summarize_the_task` 工具并生成紧凑摘要 $\sigma$ 后，SPARE 才被触发；
     - 摘要包含原始问题、已完成的工具调用、累积视觉证据和残余不确定性；
     - 短轨迹不会产生剪枝开销。

  2. **摘要条件重放（Summary-conditioned replay）**  
     - 将候选历史推理片段拼接为 token 序列 $x$；
     - 在两种上下文中重放同一模型：
       - 学生上下文：$\rho_{\text{stu}} = \rho_0$
       - 教师上下文：$\rho_{\text{tea}} = \rho_0 \| \sigma$
     - 同一模型分别输出下一 token 分布 $p^{\text{stu}}_k$ 和 $p^{\text{tea}}_k$，无需外部教师或奖励模型。

  3. **Top-K 反向 KL 覆盖分数**  
     - 对每个 token 位置 $k$，在学生 top-K（$K=20$）词表支持上计算反向 KL：
       \[
       d_k = \sum_{u \in \Omega_k^{\text{stu}}} p_k^{\text{stu}}(u)\left(\log p_k^{\text{stu}}(u) - \log p_k^{\text{tea}}(u)\right)
       \]
     - 若教师分布缺失某 token，则将其 log 概率设为 $-20$；
     - 对每个剪枝事件内的 $d_k$ 做 min-max 归一化得到 $\tilde{d}_k$；
     - 高 KL 表示该 token 仍受原始上下文影响，摘要未能充分覆盖；低 KL 表示该 token 已可被摘要解释。

  4. **片段级剪枝规则**  
     - 将 token 级分数映射回原始推理片段；
     - 采用**计数阈值**而非平均分数：若某片段内至少有 $\kappa=2$ 个 token 的 $\tilde{d}_k > \tau=0.2$，则保留该片段；否则剪除；
     - 理由：关键视觉证据（如 OCR 字符串、坐标、候选标签）往往稀疏，平均分容易稀释这些信号。

  5. **证据保留重建**  
     - 高 KL 片段重建为简洁、可验证的结构化视觉证据（如裁剪位置、识别文本、数值、候选关系），而非保留原始长推理；
     - 低 KL 片段被完全删除；
     - 工具调用、工具观察、图像 token 均保持不变；
     - 摘要 $\sigma$ 不作为持久上下文写入轨迹，仅作为辅助诊断探针。

  6. **通过 SFT 强化摘要器**  
     - 使用更强模型（Qwen3-235B）为轨迹生成高质量紧凑摘要；
     - 对 agent 模型进行下一 token 监督微调；
     - 更强的摘要覆盖率使更多片段落入低残差区间，从而支持更激进的剪枝。

## 3. 实验设计

- **基准数据集**：
  - **VisualToolBench (VTB)**：多步视觉工具使用，要求主动“用图像思考”；
  - **m&m’s (MNMS)**：4000+ 多步多模态任务，覆盖 33 种工具；
  - **GTA**：真实世界任务，人类编写查询与可执行工具链；
  - **V\***：高分辨率图像上的引导式视觉搜索；
  - **BLINK-Jigsaw (B-Jig.)**：空间感知与图像碎片拼接。

- **骨干模型**：
  - Qwen3-VL-8B-Instruct
  - Qwen3-VL-30B-A3B-Instruct
  - Llama-3.1-Nemotron-Nano-VL-8B-V1

- **对比方法**（同一工具调用框架下）：
  - **Tool Baseline (Full Trace)**：保留完整推理–动作–观察历史；
  - **−Tools (Direct Answer)**：不调用工具直接回答；
  - **+ Delete All Reasoning**：删除所有推理段，保留动作、观察和图像；
  - **+ Visual Evidence-Only**：非选择性地将所有推理段改写为结构化视觉证据；
  - **+ SPARE（本文）**：选择性剪枝 + 证据重建。

- **评估指标**：
  - 各基准官方 accuracy / success（↑）；
  - **Pruned (%)**：相对 Full Trace 移除的推理侧历史 token 百分比，排除动作、工具观察和图像 token；
  - 主表报告跨基准宏平均剪枝率。

- **实现细节**：纯测试时应用，无参数更新；$\tau=0.2$、$\kappa=2$、$K=20$ 在所有模型和基准上固定。
