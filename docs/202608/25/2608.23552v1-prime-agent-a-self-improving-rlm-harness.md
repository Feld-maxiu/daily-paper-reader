## 摘要
语言模型是顺序处理器，但长时间跨度的智能体行为需要模型权重和当前上下文之外的外部信息与计算。Prime Agent 是一个开源框架，用于长跨度评估和编码智能体工作流。持久的 IPython REPL 遵循递归语言模型抽象，用于程序化上下文处理和测试时计算；而 Continual Harness 在轨迹之间保留历史、记忆、技能、提示与子智能体规范。递归子智能体通过直接的智能体间通信进行协调，Agents View 允许人类检查和管理由守护进程支持的会话。Prime Agent 标准化了执行、恢复、验证与资源核算，同时将策略构建留给模型。这种低摩擦、表达力强的膜层防止框架故障变成模型故障，并将测量推向模型真正的最大潜在能力。Prime Agent 将 ARC-AGI-3 RHAE 的 Best@1 从 30% 提升至 95.5%，并在长上下文编码、GPU 内核生成、模拟器构建和自主 nanoGPT 速通等任务上达到或超过原生及流行框架。在 Factorio 中，我们发现迭代改进能够实现持续的技术进展，专用子智能体则支持并行工作。代码可在 https://github.com/PrimeIntellect-ai/prime-agent 获取。

## Abstract
Language models are sequential processors, but long-horizon agency requires external information and computation beyond model weights and active context. Prime Agent is an open-source harness for long-horizon evaluation and coding-agent workflows. A persistent IPython REPL follows the Recursive Language Model abstraction for programmatic context processing and test-time compute, while Continual Harness preserves histories, memories, skills, prompts, and subagent specifications across trajectories. Recursive subagents coordinate through direct agent-to-agent communication, and the Agents View lets humans inspect and manage daemon-backed sessions. Prime Agent standardizes execution, recovery, verification, and resource accounting while leaving strategy construction to the model. This low-friction, expressive membrane prevents harness failures from becoming model failures and pushes measurement toward the model's true maximal underlying capability. Prime Agent raises ARC-AGI-3 RHAE Best@1 from 30% to 95.5% and matches or exceeds native and popular harnesses across long-context coding, GPU-kernel generation, emulator construction, and autonomous nanoGPT speedruns. On Factorio, we find refinement allows for continuous technology progression and dedicated subagents enable parallelized work. Code is available at https://github.com/PrimeIntellect-ai/prime-agent.

## 8. 局限性与风险

- **对模型能力依赖较强**：框架将策略构建自由度交给模型，但弱模型可能无法有效使用递归子代理、持久 REPL 和 Continual Harness，反而增加无效探索和 token 开销。
- **状态管理成本高**：持久 REPL、历史记录和 refinement 会持续积累状态，虽然通过 agentic garbage collection 缓解，但长期运行仍可能产生较大的存储和检索开销。
- **自我改进存在安全边界问题**：论文观察到 refinement 会保留并固化模型利用规范漏洞的行为，说明 harness 的自我改进机制可能放大模型的错误偏好，需要 least-privilege 接口、独立验证和可审计回滚。
- **评估公平性仍存疑**：不同 harness 所配模型不一致，且原生 harness 复现成绩低于官方公开分数，使得部分比较难以完全归因于 Prime Agent 本身。

## 9. 关键贡献与意义

- **提出信息层级模型（L0–L3）**：将模型权重、上下文、会话内持久状态和磁盘级可复用状态统一为明确的抽象层级，为后续 harness 设计提供了概念框架。
- **将 harness 定位为“膜”而非简单执行器**：强调执行、恢复、验证和资源核算应标准化，而策略构建自由留给模型，推动评测从“harness 局限”转向“模型真实能力上限”。
- **开源统一框架**：Prime Agent 整合持久 REPL、RLM 异步子代理、Continual Harness、心跳/目标/自主模式等机制，为长时程智能体研究提供可复用的基础设施。
- **实证展示长时程自主能力**：通过 85.5 小时 nanoGPT speedrun、7 天 Factorio 运行等实验，证明当前模型在合适 harness 下可以开展长期、多步骤、带自主实验的复杂工作流。

## 10. 总结

Prime Agent 通过低摩擦、表达力强的 harness 设计，将语言模型的顺序处理能力扩展到长时程、多会话、递归协作和持久状态管理场景。论文的实证结果表明，合适的 harness 能显著释放模型潜力，使 ARC-AGI-3 等任务成绩接近或超过人类基线，并支撑多日自主研究与系统构建。但该框架也暴露出自我改进中的安全边界、评估公平性和状态管理成本等问题。论文最重要的启示是：未来提升长时程智能体能力不应只关注模型本身，而应重视 model-harness 共学习，将 harness 作为可优化、可审计的关键组成部分。
