## 摘要
机器人基础模型已显著推进感知与控制，但自然的人机协作需要的不仅仅是执行孤立指令。机器人必须识别歧义、在多轮交互中保持上下文、传达自身意图，并在用户意图变化时调整正在执行的行为。我们提出了 Ludi 0.1，这是一个面向社交智能机器人的智能体系统，集成了交互式语音、多模态推理、记忆、导航和学习型操作。其决策核心是一个经过微调的视觉-语言模型，在多轮交互轨迹上训练，涵盖模糊请求、澄清、纠正、打断、社交与任务混合对话以及多步骤任务。一个专门构建的协调框架管理模型与工具之间的交互循环，而专门的导航和操作策略执行物理技能。Ludi 0.1 展示了当下实现流畅人机协作的实用路径，同时生成了为机器人与人开发更深层次集成基础模型所需的多模态交互轨迹。

## Abstract
Robot foundation models have substantially advanced perception and control, but natural human-robot collaboration requires more than executing isolated commands. A robot must recognize ambiguity, maintain context across turns, communicate its intentions, and revise ongoing behavior as the user's intent changes. We present $\scriptstyle\mathsf{Ludi}_{\scriptscriptstyle 0.1}$, an agentic system for socially intelligent robots that integrates interactive speech, multimodal reasoning, memory, navigation, and learned manipulation. Its decision-making core is a fine-tuned vision-language model trained on multi-turn interaction traces spanning ambiguous requests, clarifications, corrections, interruptions, mixed social and task dialogue, and multi-step tasks. A purpose-built harness manages the model-tool interaction loop, while specialized navigation and manipulation policies execute physical skills. Ludi${}_{\scriptscriptstyle 0.1}$ demonstrates a practical path toward fluid human-robot collaboration today while producing the multimodal interaction traces needed to develop a more deeply integrated foundation model for robots and people.

## 1. 论文的核心问题与整体含义

- **研究背景**：机器人基础模型在感知与控制方面已取得显著进展，但自然的人机协作要求机器人不仅能执行任务，还要理解人类意图、识别歧义、保持跨轮上下文、主动沟通意图，并在用户改变需求时实时修正正在执行的行为。
- **核心问题**：现有机器人系统往往侧重物理任务能力，难以将语音、视觉、记忆、推理、导航与操作整合为连贯的社交互动；用户可能在机器人已开始行动后改变指令，机器人需要理解这种“修正”并调整行为。
- **整体含义**：论文提出 **Ludi 0.1**，一个面向社交智能机器人的 agentic 系统，将交互式语音、多模态推理、记忆、导航和操作技能集成到一个可运行的机器人中，展示当前技术下实现流畅人机协作的可行路径，同时收集多模态交互数据，为未来更深层次的基础模型积累训练资源。

## 2. 论文提出的方法论

- **总体架构**：
  - 系统运行在 **Unitree G1 人形机器人**上，采用**智能体（agentic）架构**而非单一端到端模型。
  - 中心是一个**微调的视觉-语言模型（VLM）**，负责感知场景、理解对话历史、进行推理并选择下一步动作（说话、等待、导航或调用操作）。
  - 一个**专用协调框架（harness）**管理模型-工具交互循环：组装上下文、调用 VLM、验证并执行所选工具、记录结果、再次调用 VLM。
  - 专门的导航栈和 VLA（视觉-语言-动作）操作策略执行物理技能。

- **VLM 与工具接口**：
  - 使用 **Qwen3.5 VLM** 作为推理核心。
  - 每轮输入包括：机器人第一视角图像、头戴 360° 摄像头的全景上下文、转录的用户语音、交互历史（含自身推理）以及先前工具调用结果。
  - 输出是固定工具集中的一个动作：
    - `say`：说话，包括回答或提问澄清。
    - `lookup_keypoints`：检索静态地图中的房间和命名位置。
    - `navigate`：移动到命名位置。
    - `reachability`：检查可见物体是否可抓取，以及用哪只手臂。
    - `vla`：执行拾取或放置等操作。
    - `wait`：保持观察直到环境变化。
  - 每个工具通过**类型化函数调用 schema** 暴露；`reachability` 和 `vla` 的物体类型词汇在运行时从机器人 VLA 注册表读取，因此新增操作技能无需重新训练 agent。

- **训练数据与微调**：
  - 训练语料由**合成多轮交互演示**构成，通过任务、物体和交互事件的组合生成。
  - 共生成 **14,432 条轨迹**，覆盖模糊请求、中途修正、打断、多步骤任务、社交与任务混合对话。
  - 每条轨迹由状态机和策略表保证工具调用正确；教师 LLM 生成推理文本、语音回复和用户话语。
  - 质量门包括规则检查与两阶段 LLM 判别器；失败后允许最多两次受约束修订，仍失败则丢弃。
  - 场景图像来自生成图像和模拟器渲染，模拟部署环境。
  - 微调了 Qwen3.5 的 **4B 和 9B** 两个规模；因推理延迟更低，实际部署使用 **4B 模型**。

- **闭环仿真环境**：
  - 使用 **AI2-THOR** 和 **ProcTHOR** 生成多样化 3D 家庭场景；每个场景按哈希固定以保证可复现。
  - 仿真中的机器人接口与真实系统一致：使用相同全景视图、静态关键点导航、相同的拾取/放置接口。
  - 评估在闭环中进行：模拟用户是唯一脚本化部分，agent 的感知、语言、导航和操作完全由模型闭环驱动。

- **工程细节**：
  - 非阻塞上下文压缩：辅助模型在后台总结旧上下文，仅在轮次之间安装，避免打断当前交互循环。
  - 视觉预填充与异步语音：后台持续刷新摄像头并进行视觉预填充；语音输出进入 FIFO 音频队列，不阻塞推理。
  - 本地语音管线使用 **sherpa-onnx**，10 秒英文语音平均转录延迟 **94.7 ms**，P95 为 **99.2 ms**，测试片段零转录错误。

- **导航与操作**：
  - 导航：结合 KISS-ICP LiDAR 里程计与扩展卡尔曼滤波，使用 Optuna 自动调参；语义关键点地图供 VLM 调用；需要精细局部运动时，调用面向 G1 的连续规划器，采用五次样条轨迹、方向感知多圆足迹。
  - 操作：在 **GR00T N1.7** 上针对目标家庭环境微调；预测 30 步动作块（30 Hz，约 1 秒）；仅控制手臂和夹爪；真实机器人遥操作收集微调数据。
  - 使用 **Isaac Sim** 高保真仿真进行策略筛选与校准；相机 mask IoU 约 **0.92**，Dex-3 手跟踪误差从 **0.132 rad** 降至 **0.043 rad**，指尖误差 ≤ **13 mm**。

## 6. 论文的主要结论与发现

- 微调 VLM 作为智能体核心，能显著提升闭环机器人交互任务的成功率：4B 从 10/28 提升到 17/28，9B 从 11/28 提升到 20/28。
- 通过工具接口、harness 和本地语音管线，可以在真实人形机器人上实现实时语音交互、澄清、打断处理和动作修正。
- agentic 架构虽然模块化，但能在交互层面整合感知、语音、记忆、导航和操作，支持自然的人机协作。
- 当前集成是**操作性**而非**完全学习**：组件之间仍存在上下文丢失、延迟、脆弱交接和行为碎片化等问题。
- 系统产生的多模态交互轨迹可作为训练更深度集成基础模型（Ludi 1.0）的数据来源。

- **实验规模较小**：Core28 只有 28 个场景，可能不足以全面覆盖交互多样性；结果可能存在过拟合于作者设计的场景分布。
