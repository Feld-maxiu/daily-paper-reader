## 摘要
智能体技能是从交互轨迹中提炼的结构化产物，并可从技能库中动态重用，已成为使基于大语言模型（LLM）的自进化智能体能够从过往经验中学习的核心机制。然而，现有研究主要关注技能的操作层面，如获取、演化与检索，却尚未解决一个更根本的可靠性问题：智能体技能库中积累的技能是否真正做出了正向的机制性贡献？我们通过在不同技能库组成和部署领域下进行系统性的技能库审计来研究这一问题，并衡量智能体行为所产生的变化。这些审计揭示了两类反复出现的可靠性失效：联盟污染，即技能库层面的收益掩盖了联盟层面的负面技能贡献；以及跨领域效用反转，即在源领域有益的技能在迁移后效果发生逆转。这些发现促使我们提出两种可靠性干预方法：技能积累过程中的联盟感知技能选择，以及迁移后的无标签技能掩码。联盟感知技能选择（CASS）利用采样的 Shapley 边际值为当前技能库选择更可靠的候选技能。无监督技能掩码联盟优化器（u-SMCO）会掩码那些在被排除后能提升未标注目标领域数据检索质量的迁移技能。在 LoCoMo、LongMemEval、HotpotQA 和 ALFWorld 上的智能体实验表明，相较于强基线技能型自进化智能体，CASS 和 u-SMCO 能持续提升任务性能和跨领域泛化能力。除准确率之外，基于联盟条件的可靠性建模还降低了强化学习过程中对噪声结果奖励波动的敏感性，并揭示了基于隔离的技能评估的局限性。

## Abstract
Agent skills, structured artifacts distilled from interaction trajectories and dynamically reused from skill banks, have become a central mechanism for enabling large language model (LLM)-based self-evolving agents to learn from past experience. Yet existing work has largely focused on the operational aspects of skills, such as acquisition, evolution, and retrieval, while leaving a more fundamental reliability question unresolved: Do accumulated skills in an agent's skill bank actually make positive mechanistic contributions? We investigate this question through systematic skill-bank audits across alternative bank compositions and deployment domains, measuring the resulting changes in agent behavior. These audits reveal two recurring reliability failures: coalition pollution, where bank-level gains conceal negative coalition-level skill contributions, and cross-domain utility reversal, where source-beneficial skills reverse their effects after transfer. These findings motivate two reliability interventions: coalition-aware skill selection during skill accumulation and label-free skill masking after transfer. Coalition-Aware Skill Selection (CASS) selects more reliable candidate skills for the current bank using sampled Shapley marginals. Unsupervised Skill-Masked Coalition Optimizer (u-SMCO) masks transferred skills whose exclusion improves retrieval quality on unlabeled target-domain data. Agentic experiments on LoCoMo, LongMemEval, HotpotQA, and ALFWorld show that CASS and u-SMCO consistently improve task performance and cross-domain generalization over strong skill-based self-evolving agent baselines. Beyond accuracy, coalition-conditioned reliability modeling reduces sensitivity to noisy outcome-reward fluctuations during reinforcement learning and exposes the limits of isolation-based skill evaluation.

## 1. 论文的核心问题与整体含义

- **研究背景**：基于大语言模型（LLM）的自进化智能体通过从交互轨迹中提炼“技能”（skill），并存入持久化技能库，在推理时动态检索复用，从而从历史经验中学习。
- **核心问题**：现有工作大多关注技能的全生命周期操作（获取、演化、检索、组合），但忽略了一个更根本的问题——**技能库中积累的技能是否真正做出了正向的机制性贡献**。
- **整体含义**：论文提出“技能可靠性”不是技能的内在属性，而是**技能、所在技能库联盟、部署领域三者共同决定的联合属性**。仅靠结果奖励（outcome-only gate）判断技能是否值得保留，在结构上无法识别技能的负面贡献。
- **研究动机**：通过系统性的技能机制可靠性审计（SMRA），作者发现两类反复出现的可靠性失效：
  - **联盟污染（coalition pollution）**：技能库层面的收益掩盖了联盟层面的负面技能贡献。
  - **跨领域效用反转（cross-domain utility reversal）**：源领域有益的技能在迁移到目标领域后，贡献发生逆转，甚至产生负面影响。

## 2. 论文提出的方法论

### 2.1 技能机制可靠性审计（SMRA）

- 采用 Shapley 边际贡献视角，将技能视为“玩家”，`V_D(C)` 表示技能联盟 `C` 在领域 `D` 上的下游任务价值。
- 对每个技能 `s`，通过 **knockout 干预** 计算其在完整技能库 `B` 中的边际贡献：
  - `∆_s^D(B) = V_D(B) − V_D(B \ {s})`
- 进一步引入 Shapley 值，对技能 `s` 在所有可能的子集联盟 `C ⊆ B \ {s}` 上的边际贡献做加权平均，得到更全面的贡献度量 `ϕ_s^D(B)`。
- 通过在不同技能库组成和不同部署领域下重复审计，暴露两类可靠性失效。

### 2.2 联盟感知技能选择（CASS）

- **目标**：在技能演化过程中，解决联盟污染问题。
- **核心思想**：不再只依赖结果奖励判断是否接受新技能，而是使用**采样的 Shapley 边际值**来估计联盟条件下的可靠性。
- **具体流程**（一次 gate 决策）：
  1. 从当前技能库 `B` 中，通过蒙特卡洛采样构造 `N` 个不同的技能联盟 `S`；联盟大小 `|S|` 在 `{1, …, k}` 上均匀采样，再在该大小下均匀选取子集。
  2. 对每个采样联盟 `S`，计算 knockout 边际：
     - `∆_S(B) = [V(B) − V(B \ S)] / |S|`
     - 该式将移除 `S` 带来的联合损失平均分摊给联盟成员，体积大于 1 的联盟能捕捉技能间交互。
  3. 将这 `N` 个边际值平均，得到 `b̄Δ_N(B)`。
  4. 与在线结果奖励 `r_out(B)` 结合，得到最终评分：
     - `σ(B) = b̄Δ_N(B) + λ · r_out(B)`，其中 `λ = 0.2`。
  5. 仅当候选技能库的分数超过所有历史分数时，才接受新技能；否则回滚。
- **特点**：与基线 gate 的区别只在于被排序的标量从纯结果奖励换成了联盟感知分数，保留了 best-so-far gate 的规则。

### 2.3 无监督技能掩码联盟优化器（u-SMCO）

- **目标**：在跨领域迁移后，解决跨领域效用反转问题。
- **核心思想**：在部署阶段，利用**未标注的目标领域查询**，对迁移后的技能库进行掩码优化；仅保留对检索质量有正向贡献的技能。
- **具体流程**：
  1. 给定训练好的技能库 `B`、未标注目标查询 `Q_tgt` 和目标上下文 `C_tgt`。
  2. 对技能集合 `A ⊆ B`，在目标上下文上重建记忆库 `M(A)`；对每个查询 `q`，取与 `q` 余弦相似度最高的记忆集合 `Top(q)`。
  3. 定义检索质量分数：
     - `RQ(A) = (1/|Q_tgt|) · Σ_q mean_{m∈Top(q)} cos(e_q, e_m)`
  4. 对每个技能 `s`，计算掩码分数：
     - `ψ(s) = RQ(B) − RQ(B \ {s})`
     - 该分数衡量移除 `s` 后检索质量的变化。
  5. 贪心掩码：每次掩码分数最低的技能，直到最低分数不低于阈值 `τ` 为止。
- **特点**：不需要任何目标领域标签，只需要未标注查询及其原始上下文；记忆库重建复杂度为 `O(K²)`，每个掩码步骤约 6–10 分钟。

### 2.4 理论结果

- **Theorem 1（Outcome-only non-identifiability）**：对于只观察 `V(B_e)` 和 `V(B̃_{e+1})` 的结果 gate，即使 `V(B̃_{e+1}) − V(B_e) > 0`，也无法识别 `B̃_{e+1}` 中是否包含负面贡献技能。
- 这一结构性盲区说明：仅凭结果奖励无法发现联盟污染，因此需要 CASS 的联盟采样审计。

## 6. 论文的主要结论与发现

- **技能可靠性不是内在属性**：技能贡献取决于所在联盟和部署领域，而非技能本身的固定特质。
- **结果奖励门（outcome-only gate）在结构上无法识别技能的负面贡献**：Theorem 1 证明其只能观察端点，不能分辨联盟污染。
- **CASS 通过采样 Shapley 边际估算联盟条件可靠性**，在技能演化阶段有效减少联盟污染：在 12 个候选技能中只接受 1 个，且被拒绝的技能在最终技能库中总体为负贡献。
- **u-SMCO 能在无目标标签条件下检测并掩码跨域效用反转的技能**：在所有 6 个技能库上均带来提升，且对 MemSkill 技能库提升更大，说明训练期污染越重，部署期清理收益越高。
- **代理偏好信号失效**：选择策略熵下降与标签基排序负相关，证明训练奖励通道本身带有偏差；u-SMCO 的未标注检索质量信号与标签基排序高度正相关。
- **联盟条件可靠性建模还能降低强化学习中结果奖励波动噪声的敏感性**，进一步证明联盟视角的稳健性。

## 7. 优点

- **问题定位清晰且具原创性**：从“技能是否可用”转向“技能在特定联盟和领域中是否可靠”，抓住了自进化技能库的关键盲点。
- **理论+实证双重支撑**：通过 Theorem 1 证明结果门的结构性局限，同时用 SMRA 审计数据揭示两类失效模式，动机充分。
- **方法设计简洁、咬合问题**：
  - CASS 不改变 gate 的整体框架，只替换排序标量，易于集成。
  - u-SMCO 完全无监督，只需未标注查询，适合真实部署。
- **实验公平性较好**：使用匹配协议进行消融，对 MemSkill 基线进行严格复现，且保持 3 个种子评估。
- **成本可控**：训练期仅增加约 5% 时间，部署期一次 O(K²) 重建，推理无额外开销。
- **分析深入**：通过相关性分析、案例研究、K 控制消融等，将现象与机制解释紧密结合。

## 8. 不足与局限

- **基座框架单一**：所有方法均在 MemSkill 框架上验证，结论是否适用于其他技能型自进化智能体仍需进一步验证。
- **领域覆盖有限**：主要聚焦文本会话、问答和 ALFWorld 具身环境，未覆盖更复杂的多智能体协作、工具调用、代码生成等场景。
- **u-SMCO 信号间接**：用检索质量（余弦相似度）作为任务效用的代理，虽无监督且与标签基排序相关，但不能完全保证与最终任务性能一致。
- **目标探测集小**：u-SMCO 实验中仅使用约 20 个未标注查询，可能影响掩码决策的稳定性和泛化性。
- **统计显著性有限**：部分跨域效用反转的贡献估计置信区间包含零，结论更偏向方向性观察而非强显著性。
- **CASS 计算开销与采样质量**：虽然单次成本可控，但每个外层 epoch 仅固定 8 次联盟评估，采样预算有限，可能低估某些稀有关键交互；如何自适应分配采样预算未被探讨。
- **未完全解决跨域标签问题**：u-SMCO 依赖于目标域未标注查询，若目标分布偏离查询分布，可能失效。
- **泛化到非文本

场景的验证不足，对代码生成、工具调用、多模态或跨模态技能库的适用性尚未讨论，联盟污染与效用反转在这些场景中的表现可能与文本场景不同。  
- **结果奖励噪声下的稳定性未充分考察**：CASS 依赖对完整技能库价值 `V(B)` 的可靠估计，但若任务成功信号稀疏或结果奖励噪声较大，采样的 Shapley 边际可能不稳定；论文未给出噪声条件下的鲁棒性分析或误差界。  
- **u-SMCO 对检索器质量敏感**：u-SMCO 以固定嵌入和余弦相似度作为检索质量代理，未考虑检索器随技能库共同演化或检索器本身存在偏差的情况；检索器质量较差时，掩码分数可能产生误导。  
- **贡献归因方法比较缺失**：除结果 gate 与 Shapley 边际外，未与留一法（LOOCV）、影响函数、基于梯度的归因等方法对比，无法证明 Shapley 边际在技能可靠性审计中是最优或最必要的选择。  
- **超参数选择依据不足**：`λ = 0.2`、采样次数 `N`、掩码阈值 `τ` 等关键超参数主要基于实验经验设定，缺少系统性的敏感性分析或自适应调节机制。  
- **样本规模与统计效力有限**：虽然采用 3 个种子并报告均值和标准差，但候选技能提案仅 12 个、目标探测查询约 20 个，个体技能层面的因果结论仍需更大规模验证。  

## 9. 总体评价与展望

总体而言，论文将“技能可靠性”从静态属性重构为**联盟-领域联合属性**，并通过 CASS 与 u-SMCO 分别在训练期与部署期提供可操作的治理机制。其核心贡献在于证明结果门在结构上无法识别负面技能，并提出低开销、无监督的干预方案。未来工作可从三方面推进：一是将联盟审计扩展到更多自进化框架与跨模态技能；二是为 CASS 提供采样复杂度和估计误差的理论保证；三是将 u-SMCO 的检索质量代理替换为更直接的任务效用估计或在线自适应掩码，以进一步提升实际部署中的可靠性。
