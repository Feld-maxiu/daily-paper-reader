## 摘要
自动化实证研究是人工智能长期追求的方向。近期的自动研究（AutoResearch）智能体使这一目标触手可及，因为现代大语言模型展现出独立实现解决方案并从执行结果中学习的能力。这些进展的背后，后训练（尤其是强化学习）发挥着核心作用。在本文中，我们指出了在为这些智能体扩展强化学习时的一个根本性矛盾：每条 AutoResearch 轨迹的两个组成部分（智能体生成和环境执行）的扩展方式截然不同，因为所有生成通过批处理共享计算资源，而每次执行都占用其专属的沙箱和真实机器时间。因此，随着轨迹增长，环境执行主导训练成本并成为瓶颈。为解决这一矛盾，我们提出了世界模型强化学习（WMRL），用世界模型替代环境执行以消除该瓶颈。此外，世界模型可能不完美，其奖励会受到偏差和噪声的污染。因此，我们进一步为 WMRL 配备两种缓解措施：在线去偏和逆方差去噪，分别抵消偏差和抑制噪声。理论上，我们证明了 WMRL 的这两种缓解措施严格改善了收敛保证。实验上，WMRL 在不同智能体规模的各种任务中将训练加速了 3-4 倍，同时性能超过了标准强化学习基线。此外，我们后训练得到的 4B 和 9B 智能体在留出基准上优于大得多的 48B 和 120B 开放权重智能体。除 AutoResearch 外，WMRL 还可迁移到后训练具身 VLA 策略，这证明了我们方法的泛化性。

## Abstract
Automating empirical research is a long-standing direction of AI. Recent automatic research (AutoResearch) agents bring this goal within reach, as modern LLMs show the capability to independently implement solutions and learn from the execution outcomes. Behind these gains, post-training (especially RL) plays a central role. In this paper, we identify a fundamental tension when scaling RL for these agents: the two components of every AutoResearch trajectory (agent generation and environment execution) scale in very different manners, since all generation shares compute through batching, while each execution occupies its exclusive sandbox and real machine time. As a result, the environment execution dominates the training cost and becomes the bottleneck as trajectories grow. To resolve this tension, we propose World Model RL (WMRL), which replaces environment execution with a world model to remove this bottleneck. Additionally, the world model can be imperfect, as its rewards are corrupted by bias and noise. Therefore, we further equip WMRL with two mitigations, Online Debiasing and Inverse-Variance Denoising, which offset the bias and suppress the noise respectively. Theoretically, we prove that both mitigations of WMRL strictly improve the convergence guarantee. Empirically, WMRL accelerates training by 3-4x on various tasks at different agent scales, while exceeding the performance of standard RL baselines. Moreover, our post-trained 4B and 9B agents outperform much larger open-weight agents of 48B and 120B on held-out benchmarks. Beyond AutoResearch, WMRL also transfers to post-training embodied VLA policies, which demonstrates the generalizability of our method.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将 RL 训练中的奖励信号来源从昂贵的真实环境执行替换为**世界模型的前向预测**。世界模型接收与真实环境相同的任务上下文和智能体生成的解决方案，预测执行结果并给出估计分数 `r̂(τ)`。
- 由于世界模型输出可能存在系统偏差 `b(τ)` 和随机噪声 `ξ(τ)`（数学模型：`r̂(τ) = r(τ) + b(τ) + ξ(τ)`），直接使用该信号会引入额外的收敛误差。因此，论文保留少量真实执行作为**锚点信号（anchor signal）**，用来校准世界模型。

### 2.2 关键技术细节

#### （1）世界模型替代环境执行
- 世界模型与智能体使用相同的 backbone（如 Qwen3.5-4B / 9B），只通过提示（prompting）预测执行结果，不进行微调，避免引入外部知识。
- RL 训练流程不变：智能体生成一组解 → 世界模型打分 → 计算组内优势 `Âi = r̂(τ_i) - (1/n) Σ_j r̂(τ_j)` → 梯度上升。
- 由于世界模型推理可以批处理并共享计算，其扩展方式与生成环节一致，从根本上消除了执行瓶颈。

#### （2）在线去偏（Online Debiasing）
- 在训练过程中，随机选择一小部分 group（约 10%）作为**锚点组（anchor groups）**，这些组同时由世界模型和真实执行打分，得到分数对 `P = {(r̂_j, r_j)}`。
- 基于锚点分数对，通过**等渗回归（isotonic regression）**拟合一个单调映射 `f̂`，使得 `f̂(r̂_j)` 尽量接近真实分数 `r_j`。
- 所有世界模型分数先经过 `f̂` 重映射，再用于计算优势。该映射随着新锚点对的到来不断重新拟合，以跟踪世界模型在训练过程中的漂移。

#### （3）逆方差去噪（Inverse-Variance Denoising）
- 每个训练步中，group 被分为锚点集 `G_E`（真实执行打分）和世界模型集 `G_WM`（世界模型打分），分别计算梯度估计 `g_E` 和 `g_WM`。
- 两个梯度流具有不同方差：锚点流方差较小但样本少，世界模型流样本多但方差大。利用**逆方差加权**融合两个梯度流：
  - 最优权重与方差倒数成正比，即 `ĝ = (V_E^{-1} g_E + V_WM^{-1} g_WM) / (V_E^{-1} |G_E| + V_WM^{-1} |G_WM|)`。
- 实际中，该融合简化为仅有一个未知比例 `ρ = V_WM / V_E`。理论推导给出 `ρ = 1 + c σ²`，其中噪声项由锚点组上校准分数与真实分数的残差 `η̂²` 在线估计，常数 `c` 由 warmup 结束时的一次测量固定。
- 当噪声测量值变大时，锚点流权重自动上升，使 WMRL 退化为标准 GRPO，避免从被污染信号中学习；该退化行为由测量值驱动，无需人为预设混合比例。

### 2.3 理论分析要点

- **定理 3（纯世界模型奖励的收敛界）**：训练于世界模型奖励的 GRPO 满足  
  `J⋆ - E[J(θ_T)] ≤ (1 - γμ/4)^T Δ0 + O(M²B²) + O(γ V_WM)`  
  其中 `O(M²B²)` 是偏差带来的永久地板，无法通过更多训练消除；`O(γ V_WM)` 是噪声导致的方差误差。
- **定理 4（WMRL 的收敛界）**：  
  `J⋆ - E[J(θ_T)] ≤ (1 - γμ/4)^T Δ0 + Õ(M²B² / (1 + T/T0)) + O(γ V_WM / (1 + V_WM/V_E))`  
  - 偏差项现在随训练步骤收缩，当 `T → ∞` 时消失。
  - 方差项由于逆方差融合而严格小于单一流的方差。
  - 因此 WMRL 在极限下收敛到与真实执行训练相同的目标，而只需对少量 group 支付真实执行成本。

## 6. 论文的主要结论与发现

1. **世界模型能有效消除 AutoResearch RL 的扩展瓶颈**：在 A100 GPU 上，WMRL 的训练算力仅为真实环境 GRPO 的约 1/3，且加速效果随任务变重更明显。
2. **修正机制补偿了世界模型的不完美**：
   - 仅用世界模型训练会因偏差和噪声导致性能下降；加入在线去偏和逆方差去噪后，WMRL 性能匹配甚至超过真实环境 GRPO。
   - 消融实验显示两个机制各有增益且互补，去偏增益更大（与理论中偏差项占主导一致）。
3. **小模型后训练可超越大模型**：经过 WMRL 后训练的 4B 智能体在两个基准上均超过 48B 开源智能体，9B 智能体超过 120B 智能体，表明针对性 RL 后训练比单纯扩大模型规模更有效。
4. **方法具有跨领域泛化性**：在 VLA 后训练任务上，WMRL 同样提升成功率，尤其在未见初始状态上提升最大，说明该框架不限于 AutoResearch。
5. **理论保证**：两种修正机制严格改善收敛界，偏差项从永久地板变为随训练收敛，方差项低于任何单一奖励流。

- **测试集划分存在潜在风险**：MLE-Dojo 的测试集虽经过名称匹配检查，但 Kaggle 竞赛之间可能存在相似的数据来源或预处理方式，隐式重叠难以完全排除；DSBench 与训练集无重叠，但任务规模较小，可能不足以完全反映真实场景的复杂性和多样性。
- **训练成本仍非零**：虽然世界模型推理可批量共享计算，但世界模型本身仍需 GPU 资源；锚点组仍需真实执行，对于执行成本极高的环境（如大规模仿真、真实机器人），锚点开销仍可能成为瓶颈。
- **去偏映射的表达力受限**：等渗回归假设偏差是单调函数，实际中世界模型偏差可能非单调（如对特定类型方案系统性高估、对另一类型低估），此时单调映射无法完全消除偏差。
- **实验未报告多次运行方差**：论文结果虽在相同设置下比较，但未提供多次随机种子下的均值和标准差，结论的统计显著性有待进一步验证。
- **VLA 实验规模较小**：仅使用 1B 规模的 MiniVLA 模型，迁移到更大模型上的效果和资源节省比例尚不明确。
- **缺乏对世界模型推理延迟和吞吐量的详细分析**：GPU-hours 的减少不一定等价于 wall-clock 时间的减少，世界模型推理可能引入额外排队延迟或显存竞争，实际加速比可能低于报告值。

总体而言，论文提出了一种具有理论保证和实验验证的世界模型加速框架，有效缓解了 AutoResearch RL 的环境执行瓶颈，但方法对世界模型质量仍有一定依赖，未来工作可探索更鲁棒的去偏策略、完全无锚点的训练方案以及更大规模、多随机种子的验证。
