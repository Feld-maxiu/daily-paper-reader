## 摘要
语言推理使基础模型能够在难题上投入更多测试时计算，例如需要分解、约束跟踪和预测未来后果的问题。这一机制能否改进机器人操作仍不清楚，因为长时程任务需要跟踪部分进度、推理物体关系、从错误中恢复并引导存在噪声的低层策略。本文研究是否可以训练视觉语言模型（VLM）直接用自然语言推理来引导低层操作策略。我们引入了$R^3$，一种简单的事后训练方法，将现成的VLM转化为机器人推理器：它首先在专家生成的推理轨迹上对VLM进行中期训练，以初始化所需的推理风格，然后利用离线动作数据，通过基于评分准则的单步强化学习来改进推理器。与以往大多使用结构化轨迹作为辅助监督的机器人推理方法不同，$R^3$训练自由形式的语言推理，以产生动作的测试时指导。我们在Language Table和模拟双手食品杂货打包这两个受控测试平台上实例化了$R^3$，用于研究机器人推理和长时程操作。$R^3$提升了跨未见任务的探索和泛化能力，并在两个基准上显著优于仅指令的模仿学习基线。我们的分析表明，自由形式的语言推理可以作为一种测试时计算机制，用于引导低层策略。我们的项目页面见 https://robotic-reasoner.github.io/。

## Abstract
Reasoning in language allows foundation models to spend more test-time compute on hard problems, such as those requiring decomposition, constraint tracking, and prediction of future consequences. Whether this mechanism can improve robotic manipulation remains unclear, where long-horizon tasks require tracking partial progress, reasoning about object relations, recovering from mistakes, and steering noisy low-level policies. In this paper, we study whether VLMs can be trained to reason directly in natural language to guide low-level manipulation policies. We introduce $R^3$, a simple post-training recipe that turns off-the-shelf VLMs into robotic reasoners: it first mid-trains a VLM on expert-generated reasoning traces to initialize the desired reasoning style, then improves the reasoner with single-step rubric-based RL from offline action data. Unlike prior robotic reasoning methods that mostly use structured traces as auxiliary supervision, $R^3$ trains free-form language reasoning to produce test-time guidance for action. We instantiate $R^3$ on Language Table and simulated bimanual grocery packing, two controlled testbeds for studying robotic reasoning and long-horizon manipulation. $R^3$ improves exploration and generalization across unseen tasks and significantly outperforms instruction-only imitation learning baselines on both benchmarks. Our analyses suggest that free-form language reasoning can function as a test-time compute mechanism for steering low-level policies. Our project page is available at https://robotic-reasoner.github.io/.

## 2. 论文提出的方法论

- **整体架构**：
  - 高层 VLM 接收当前观测、交互历史与长时程目标，生成**推理轨迹 $z_t$** 和**短时程指令 $u_t$**。
  - 固定的低层语言条件策略 $\pi_{\text{lo}}(a_t|s_t,u_t)$ 将指令转换为机器人动作。
  - 高层策略表示：$\pi_\theta(z_t,u_t|x_t,g)$，其中 $x_t$ 为历史上下文。

- **两阶段训练配方（$R^3$）**：
  1. **Stage I：Mid-training（中期训练）**
     - 在专家生成的推理轨迹上做标准 next-token prediction SFT。
     - 损失函数：$\mathcal{L}_{\mathrm{SFT}}(\theta)=-\mathbb{E}_{(x_t,y_t)\sim\mathcal{D}_{\mathrm{SFT}},i\sim\mathrm{Unif}}\left[\log p_\theta(y_{t,i}|x_t,y_{t,<i})\right]$，其中 $y_t=(z_t,u_t)$。
     - 同时使用成功和不成功的轨迹，以暴露部分进度、错误和恢复行为。
     - 目的是初始化推理风格，如分解、约束追踪、自我纠正。
  2. **Stage II：Rubric-Based Single-Step RL（基于评分准则的单步强化学习）**
     - 使用更广泛的**仅含专家指令（无推理）**的离线数据。
     - 模型生成 $(z_t,u_t)$，通过奖励函数 $R(x_t,g,u_t^\star,z_t,u_t)$ 比较生成指令与专家指令的语义一致性。
     - 使用 Dr.GRPO 优化策略梯度：$\mathcal{L}_{\mathrm{GRPO}}(\theta)=-\mathbb{E}_{t,k}\left[\min\left(\rho_t^{(k)}A^{(k)},\mathrm{clip}(\rho_t^{(k)},1-\epsilon,1+\epsilon)A^{(k)}\right)\right]$，其中优势由组内奖励归一化得到。
     - Language Table 上用 VLM-as-a-judge 打分（语言匹配 1.0、副词不匹配 0.5、语义匹配 0.25、不匹配 0.0），并加入长度惩罚避免过短响应。
     - 杂货打包任务上用字符串精确匹配奖励。

- **关键设计选择**：
  - **交互历史**：使用上一步完整响应作为历史；杂货打包中简化为上一步指令。
  - **推理上下文填充**：RL 数据缺少上一步推理时，用中期训练模型采样并匹配专家指令进行填充。
  - **过滤重复步骤**：移除重复指令，防止 RL 陷入重复上一步的奖励捷径。
  - **杂货打包**：跳过 Stage I，直接从 base VLM 进行 RL（类似“RL zero”），且使用字符串匹配奖励。

## 6. 论文的主要结论与发现

- **$R^3$ 显著优于 instruction-only IL**，尤其在 OOD 任务上：在所有 5 个 OOD 任务中全面超越 IL。
- **RL alone 有效，mid-training 进一步放大 RL 收益**：$R^3$ (RL only) 已能提升训练任务性能；完整 $R^3$ 在训练和 OOD 任务上更优。
- **推理在测试时起因果作用，不只是表示学习**：
  - VQA 改善不能完全解释操作收益；
  - 有推理监督的 IL 变体仍不及完整 $R^3$；
  - 对同一 checkpoint 增加推理预算（截断推理长度）会显著提升成功率，说明测试时推理本身贡献巨大。
- **学到行为**：比较多个方案、在不确定时重新检查场景与历史、增量选择下一步；mid-training 稳定推理接口，RL 使推理更具状态感知和动作导向。
- **ECoT 结构化推理未提供额外收益**：加入物体坐标等结构化信息反而略降性能，表明长时程闭环重规划比视觉定位信息更重要。
- **跨域有效性**：在双手杂货打包上，$R^3$ (RL only) 也优于 IL 和 base 模型。

## 7. 优点

- **方法简洁**：两阶段训练将推理风格初始化与行为优化解耦，数据效率高。
- **离线训练，避免在线交互**：单步 RL 利用专家指令而非机器人 rollout，显著降低训练复杂度。
- **测试时计算视角新颖**：明确将自由形式语言推理定位为机器人操作中的测试时计算机制。
- **固定低层策略 + 高层推理分离**：干净地隔离推理的作用，便于因果分析。
- **充分的消融与因果证据**：通过推理预算截断、有无推理监督的 IL 对比，强有力地证明推理在测试时的因果贡献。
- **跨任务和跨域验证**：在 Language Table 与杂货打包两个不同平台上均有效。

## 8. 不足与局限

- **仅模拟环境**：实验均在仿真中完成，未在真实机器人上验证，真实世界噪声、感知不确定性和物理交互可能带来新挑战。
- **单步 RL 代理目标**：Stage II 优化语义匹配而非最终任务成功，可能产生与长期任务成功不一致的行为。
- **专家数据偏差**：Language Table 的专家推理由 Gemini 生成，可能与真实人类专家策略存在系统性差异；且 Stage I 仍依赖专家推理轨迹，获取成本高。
- **VLM judge 局限性**：虽有验证，但 judge 本身可能继承模型偏差；在小类别（如红色物体）上偶有混淆。
- **低层策略固定**：高层推理与低层执行分离可能导致意图与执行失配，且未探讨联合训练。
- **资源披露不足**：未明确 GPU 型号、训练时长、总算力，影响可复现性与成本评估。
