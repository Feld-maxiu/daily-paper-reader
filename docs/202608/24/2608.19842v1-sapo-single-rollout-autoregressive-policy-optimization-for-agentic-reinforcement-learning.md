## 摘要
智能体强化学习（RL）已成为大语言模型后训练中的关键阶段。现有的无 critic、群体相对方法通过多次展开来估计策略优势，避免了传统近端策略优化（PPO）的大量内存开销，并在长程交互任务上取得了强劲性能。尽管这些方法取得了成功，近期研究揭示了三个局限：（1）缺乏显式的价值泛化和有效的时间信用分配；（2）在长程复杂任务中可能出现优势坍缩；（3）需要在采样预算与策略性能之间做出代价高昂的权衡。本文提出单次展开自回归策略优化（SAPO），一种低内存且计算高效的框架，其中策略函数与价值函数共享同一个自回归骨干网络。SAPO 利用大语言模型的自回归结构，在共享参数下于不同的因果边界生成策略预测和价值预测，同时独立优化 PPO 目标与辅助的同策略 SARSA 目标。为稳健估计每个回合的贡献，我们进一步引入轨迹级广义优势估计器，将 λ 回报与批量归一化相结合。在 ALFWorld 和 WebShop 上使用 Qwen2.5-1.5B/7B 的实验表明，SAPO 训练稳定，平均性能分别比 PPO 和 GRPO 高出 15.1 和 12.1 个百分点，同时消除了单独 critic 模型的内存开销，并将每次迭代运行时间相比 PPO 减少 33.2%。

## Abstract
Agentic reinforcement learning (RL) has become a critical stage in the post-training of large language models. Existing critic-free, group-relative methods estimate policy advantages from multiple rollouts, avoiding the substantial memory overhead of conventional proximal policy optimization (PPO) and achieving strong performance on long-horizon interactive tasks. Despite their success, recent studies revealed three limitations: (1) Lack explicit value generalization and effective temporal credit assignment; (2) Suffer from potential advantage collapse in long-horizon complex tasks; (3) Require a costly trade-off between sampling budget and policy performance. In this work, we propose Single-rollout Autoregressive Policy Optimization (SAPO), a low-memory and compute-efficient framework in which the policy and value functions share a single autoregressive backbone. SAPO exploits the autoregressive structure of LLMs to produce policy and value predictions at distinct causal boundaries with shared parameters, while independently optimizing the PPO objectives and auxiliary on-policy SARSA objectives. To robustly estimate the contribution of each turn, we further introduce a trajectory-level generalized advantage estimator that combines lambda-returns with batch normalization. Experiments across ALFWorld and WebShop with Qwen2.5-1.5B/7B show that SAPO trains stably and outperforms PPO and GRPO by mean +15.1 and +12.1 percentage points, respectively, while eliminating the memory cost of a separate critic model and reducing per-iteration runtime by 33.2% over PPO.

## 1. 论文的核心问题与整体含义

- **研究背景**：智能体强化学习（Agentic RL）已成为大语言模型后训练的关键阶段，用于让 LLM 从环境反馈中学会多轮交互，如推理、工具调用、网页搜索等。
- **现有方法问题**：当前主流方法分为两类：
  - 有 critic 的 PPO：价值函数能提供显式的时间信用分配，但需要额外维护一个与策略规模相当的 critic 网络，内存和计算开销大。
  - 无 critic 的群体相对方法（如 GRPO）：通过同一提示下多个 rollout 的奖励归一化估计优势，避免 critic，但存在三个局限：
    1. 缺乏显式价值泛化和有效时间信用分配；
    2. 在长程复杂任务中，当多个 rollout 奖励相同或接近时，归一化优势趋近于零，出现“优势坍缩”；
    3. 采样预算与性能之间存在昂贵权衡：小群体噪声大，大群体稳定但计算成本和同步开销高。
- **核心动机**：如何在保持显式价值学习（时间信用分配）的同时，避免单独 critic 的内存/计算成本，以及避免群体采样的开销。
- **整体含义**：SAPO 提出一种“单次 rollout + 自回归 actor-critic”的框架，让策略和价值函数共享同一个骨干网络，在因果边界上读取价值，实现低内存、计算高效的稳定训练。

## 2. 论文提出的方法论

### 2.1 自回归 Actor–Critic 表示

- **核心思想**：利用 LLM 的自回归因果结构，在同一个序列中同时表示策略、状态价值和动作价值。
- **因果边界**：
  - 在某个交互回合 $t$，状态 $s_t$ 的 token 表示为 $c_t$；
  - 动作 $a_t$ 为生成的响应 token；
  - 状态价值 $V(s_t)$ 应该在生成动作**之前**的边界读取（即 $c_t$ 之后、第一个动作 token 之前）；
  - 动作价值 $Q(s_t, a_t)$ 应该在动作生成**之后**的边界读取（即最后一个动作 token 之后）。
- **共享双 token 价值基**：从词表中预留两个 token $w_+$ 和 $w_-$，对任意因果上下文 $c$，计算它们的 logits 差值并缩放：
  \[
  p_\theta(c) = \text{clip}\left(\frac{z_{\theta,w_+}(c)-z_{\theta,w_-}(c)}{\tau_v}, -1, 1\right)
  \]
  然后得到值：
  \[
  V_\theta(s_t)=R_{\max}\,p_\theta(c_{s_t}),\quad Q_\theta(s_t,a_t)=R_{\max}\,p_\theta(c_{s_t a_t})
  \]
  其中 $\tau_v$ 是价值温度，$R_{\max}$ 是回报范围，$\text{clip}$ 限制到 $[-1,1]$。
- **与动作分布隔离**：策略词汇表 $W_{\text{act}} = W \setminus \{w_+, w_-\}$，动作概率只在 $W_{\text{act}}$ 上归一化，避免价值基 token 被生成或影响策略。

### 2.2 单次 rollout 轨迹优势估计

- **轨迹级广义优势估计（GAE）**：对每个轨迹 $\tau = \{(s_t,a_t,r_t,d_t)\}_{t=1}^T$，从后往前递归计算 TD 残差和 GAE：
  \[
  \delta_t = r_t + \gamma(1-d_t)V^{\text{old}}_{t+1} - V^{\text{old}}_t
  \]
  \[
  A^{\text{GAE}}_t = \delta_t + \gamma\lambda(1-d_t)A^{\text{GAE}}_{t+1}
  \]
  其中 $V^{\text{old}}$ 来自冻结的 rollout 策略，$d_t$ 为终止标志。
- **价值目标**：
  - 状态价值目标：$y_t^V = V^{\text{old}}_t + A^{\text{GAE}}_t$（λ-return）
  - 动作价值目标：$y_t^Q = r_t + \gamma(1-d_t)Q^{\text{old}}_{t+1}$（on-policy SARSA）
- **批量归一化**：在将优势分配到 token 之前，先对当前训练批次中所有有效回合的 GAE 优势做批量归一化：
  \[
  \hat{A}_t = \frac{\tilde{A}_t - \mu_B}{\sigma_B + \epsilon_{\text{adv}}}
  \]
  其中 $\tilde{A}_t$ 可选地减去无效动作惩罚 $c_{\text{inv}}m_t^{\text{inv}}$。归一化后再广播到该回合的所有有效 token。

### 2.3 统一优化目标

- **策略损失**（token 级 PPO）：
  \[
  L^{\text{pol}}(\theta)=-\mathbb{E}_{t,j}\left[\min\left(\rho_{t,j}(\theta)\hat{A}_t,\ \text{clip}(\rho_{t,j}(\theta),1-\epsilon,1+\epsilon)\hat{A}_t\right)\right]
  \]
  其中 $\rho_{t,j}=\exp\left(\ell_{t,j}(\theta)-\ell^{\text{old}}_{t,j}\right)$，优势 $\hat{A}_t$ 在每个回合内被广播到所有 token。
- **价值损失**（clipped regression，对 $X\in\{V,Q\}$）：
  \[
  L^X(\theta)=\frac{1}{2}\mathbb{E}_t\left[\max\left((p_t^X-\bar{y}_t^X)^2,\ (p_{t,\text{clip}}^X-\bar{y}_t^X)^2\right)\right]
  \]
  其中 $p_t^X = X_\theta/R_{\max}$，$p_{t,\text{clip}}^X$ 是相对旧预测的裁剪版本。
- **总损失**：
  \[
  L^{\text{SAPO}}(\theta)=L^{\text{pol}} + c_V L^V + c_Q L^Q + \beta L^{\text{KL}} - c_H H(\pi_\theta)
  \]
  所有项在同一个 transformer 和 LM head 上反向传播更新。

### 2.4 算法流程

- 每次迭代：用当前策略采样一个 trajectory per task → 用旧模型评估 log probs、$V^{\text{old}}$、$Q^{\text{old}}$ → 反向计算 GAE 和目标 → 批量归一化优势并广播到 token → 一次前向获得当前策略、$V$、$Q$ → 最小化总损失更新参数。

## 7. 优点

- **新颖的架构设计**：将 actor 和 critic 统一到一个自回归模型中，利用因果边界自然分离状态价值和动作价值，概念简洁且与 LLM 结构高度契合。
- **内存和计算效率高**：省去独立 critic 的权重、优化器状态和前向/反向计算，同时不牺牲价值学习能力。
- **稳定的单次 rollout 训练**：通过轨迹级 GAE 和批量归一化，避免群体相对方法的优势坍缩和采样开销。
- **实验对比全面**：涵盖了闭源模型、prompting 方法和多种 RL 基线，且报告了标准差。
