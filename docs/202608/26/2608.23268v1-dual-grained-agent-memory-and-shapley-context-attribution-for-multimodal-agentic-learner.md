## 摘要
前沿多模态大语言模型（MLLMs）展现出令人印象深刻的感知能力，但在科学和数学推理上仍然表现不佳。对于闭源权重或端侧骨干模型，参数级适配不可行，而无状态提示则会丧失从已解决问题中获得的累积增益。我们提出DG-Mem，一个双粒度智能体记忆框架，它通过一种非参数、外部存储的记忆来增强冻结的MLLM；该记忆在训练时由rollout一次性构建，并在测试时以只读方式查询。受人类记忆的互补学习系统（CLS）理论启发，DG-Mem将其存储分解为基于实例的范例记忆和类别级的IF-THEN规则图式记忆，并借助一个瞬态反思存储来中介二者的构建，从而使得图式仅从抽象反思中合成，而非从范例文本中合成。两个设计选择使DG-Mem与众不同：在线概念分类器在训练期间逐步扩展类别空间，而不是固守预定义分类法；以及Shapley上下文归因过程，该过程将正确性分解到整个检索规则集上，并产生每条规则的效用，从而在测试时对检索进行重新加权。该流程不引入任何梯度更新，可部署在闭源权重或端侧骨干模型上。在MathVista、MMMU和MMMU-Pro上，基于四个开源权重和专有骨干模型（Qwen3.5-27B、Qwen3.5-122B-A10B、GPT-5-Nano、Gemini-3-Flash），DG-Mem相较于无记忆和竞争性记忆基线均取得了一致的改进。

## Abstract
Frontier multimodal large language models (MLLMs) deliver impressive perception yet still falter on scientific and mathematical reasoning. Parameter-level adaptation is unavailable for closed-weight or on-device backbones, and stateless prompting forfeits any compounding benefit from problems already solved. We propose \textbf{DG-Mem}, a dual-grained agentic memory framework that augments a frozen MLLM with a non-parametric, externally stored memory built once from training-time rollouts and consulted read-only at test time. Motivated by the Complementary Learning Systems (CLS) account of human memory, DG-Mem factors its store into an instance-grounded exemplar memory and a category-level schema memory of IF-THEN rules, with a transient reflection store mediating their construction so that schemas are synthesized only from abstract reflections, never from exemplar text. Two design choices distinguish DG-Mem: an online concept categorizer that grows the category space incrementally during training rather than committing to a predefined taxonomy, and a Shapley context attribution procedure that decomposes correctness across the entire retrieved rule set and yields a per-rule utility that re-weights retrieval at test time. The pipeline introduces no gradient updates and is deployable on closed-weight or on-device backbones. Across MathVista, MMMU, and MMMU-Pro on four open-weight and proprietary backbones (Qwen3.5-27B, Qwen3.5-122B-A10B, GPT-5-Nano, Gemini-3-Flash), DG-Mem improves consistently over no-memory and competitive memory baselines.

## 2. 论文提出的方法论

### 2.1 核心思想

- 在冻结的 MLLM 骨干之上，增加一个非参数、外部存储的记忆库 `M`。
- 记忆库在训练阶段由 rollout 一次性构建，测试阶段只读查询，不进行任何梯度更新。
- 记忆库被显式分解为三种存储：
  - **范例记忆 `ME`**：实例级、具体问题的可迁移策略与验证检查。
  - **图式记忆 `MS`**：类别级、抽象 IF-THEN 规则。
  - **瞬态反思存储 `MR`**：作为中间产物，仅用于生成 `MS`，测试时不被直接检索。

### 2.2 训练阶段（Stage 1：Memory Construction）

- 对每个训练问题 `q` 以及黄金答案 `a*_q`，采样 `N` 条温度采样的解轨迹，并通过验证级联（原生匹配器 → 符号解析器 → LLM 评判器）标记为正确/错误。
- 并行生成三类摘要：
  - `ρ(q)`：IF-THEN 规则（问题级反思，写入 `MR`）
  - `e(q)`：范例记录（写入 `ME`，包含推理策略与验证检查）
  - `κ(q)`：类别标签（由在线概念分类器 `Cat` 给出）
- 严格依赖关系：
  - `MR` 仅作为生成 `ME` 和 `MS` 的源材料。
  - `ME` 在每个范例内嵌有 `ρ(q)`，使一次检索同时获得实例级策略和关联抽象规则。
  - `MS` 在整轮训练结束后、按类别 `κ` 对 `MR` 分组，由 `Synth` 合成；**绝不读取 `ME` 中的范例文本**，避免具体解串污染抽象规则。
- 所有存储条目受**抽象性约束**：禁止包含具体数值、选项字母、变量绑定、命名实体等，保证规则可跨问题迁移。

### 2.3 在线概念分类器（Online Categorizer）

- 不使用预定义固定分类法，而是在训练过程中动态增长类别注册表。
- `Cat` 提取问题的关键概念 `K(q)`，与现有类别（仅比较标识符-名称对以降低提示开销）进行匹配；若匹配则归入已有类别，否则新建类别。
- 分类步骤与 `Refl_E`、`Refl_R` 并发执行，不增加串行开销。

### 2.4 测试阶段（Memory Access）

- 测试时记忆冻结，访问分为三个阶段，并有回退机制防止推理循环崩溃。
- **图式检索**：对每个候选规则 `r_i` 计算文本嵌入相似度 `sim(r_i, q)`，并与该规则的累积效用 `U(r_i)` 组合：
  - `s_i = α · norm(sim) + (1 − α) · norm(U)`
  - `α` 控制相似度与效用的相对权重；`α=1` 退化为纯相似度检索，`α=0` 退化为纯效用排序。
- **范例检索**：使用多模态嵌入 `Emb_M(I_q, t_q)` 计算查询与候选范例的余弦相似度，超过阈值 `τ_E` 才注入。
- **记忆注入**：支持两种互补模式：
  - **priming**：在问题前注入记忆，自上而下引导解题策略；
  - **verification**：在问题后注入相同内容，用于事后审计答案。

### 2.5 效用训练（Stage 2：Shapley Context Attribution）

- 利用同样的冻结 MLLM 作为归因设备，通过额外子集 rollout 估计每条规则的边际贡献。
- 对每个问题 `q`，采样 `B` 个规则子集（始终包含空集 `∅` 和全量 `R_κ*`，其余从中间层均匀采样），固定温度、解码种子和图像内容，仅改变注入的规则子集。
- 得到二进制奖励 `v(S_b) ∈ {0,1}`，将规则视为合作博弈中的玩家，以子集奖励作为价值函数。
- 规则 `r_i` 对问题 `q` 的 Shapley 贡献：
  - `Δ_q(r_i) = (1/K!) Σ_{π∈S_K} [ v(P_π^i ∪ {r_i}) − v(P_π^i) ]`
  - 其中 `P_π^i` 为排列 `π` 中位于 `r_i` 之前的规则集合，未观测联盟按 0 填补。
- 对多个问题的 `Δ_q` 取平均，得到每条规则的累积效用 `U(r_i)`，在测试阶段用于式(5)的加权。
- **范例记忆不参与效用更新**，以避免 Stage-2 问题与 Stage-1 问题同源造成的数据泄漏。

## 6. 论文的主要结论与发现

- **DG-Mem 在各骨干上一致优于 No-memory 与两种 ViLoMem 基线**，平均提升幅度：
  - Qwen3.5-122B-A10B：+5.6
  - Qwen3.5-27B：+2.3
  - GPT-5-Nano：+12.5
  - Gemini-3-Flash：+5.2
- **消融发现**：
  - 移除范例记忆 `ME`（仅图式）或移除图式记忆 `MS`（仅范例）都会导致性能下降，表明两种粒度覆盖了**非重叠的失败模式**。
  - 在 MMMU 上，仅图式记忆比 No-memory 略差，说明图式可能过度泛化，需要范例作为纠正。
  - 禁用 Shapley 效用（`α=1`，纯相似度检索）在三个基准上均略微下降，且在较难的 MMMU-Pro 上差距更大，验证了效用加权的作用。
- **定性案例**显示，检索到的图式规则和范例模板能够纠正基线在视觉枚举、阈值统计、实体基础算术等任务上的典型错误。
- 总体结论：DG-Mem 提供了一个无需梯度更新、可部署于闭源或端侧 MLLM 的智能体记忆框架，将 CLS 理论操作化为实例记忆与图式记忆的分离、图式介导巩固与效用加权检索。

## 7. 优点

- **新颖的双粒度设计**：实例级范例记忆与类别级图式记忆通过瞬态反思存储严格分离，符合 CLS 互补学习系统理论。
- **严格抽象性约束**：明确禁止存储问题特定数值、选项、实体，保障规则迁移安全性。
- **在线概念分类器**：动态扩展类别空间，避免固定分类法过粗/过细的问题，能跟踪语料经验概念分布。
- **Shapley 上下文归因**：解决多条规则共同贡献的正确定位问题，使检索从单纯相似度升级为“相似度 × 历史效用”，符合理性分析记忆框架。
- **完全梯度自由**：适用于闭源权重和端侧部署场景。
- **实验设计严谨**：同构骨干、固定划分、冻结测试记忆、抽象性约束，保证对比公平性与可复现性。
- **多骨干、多基准全面验证**，且包含定性审计，增强可解释性。
