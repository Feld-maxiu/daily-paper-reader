## 摘要
自主具身智能体必须维持一个包含感知、行动、验证和自我纠正的长时间决策循环。当前系统通过任务特定工作流或具身策略来维持这一循环。我们研究第三种形式，即智能体化具身控制，其中通用智能体自身维持该循环。以零样本导航作为受控测试平台，我们评估了三种软件工程智能体框架，仅提供单目 RGB 相机和离散动作。在这种严格最小条件下，复现的默认配置达到了 70.7±3.5% 的成功率（opus-5，三次运行均值），fable-5 在最大努力下达到 78%。当训练好的航点工具作为可选能力与基本原语一起暴露时，混合 fable-5 智能体在默认努力下达到 76.7±0.6% 的成功率，使用的环境步数仅为最大努力原语运行的一半，墙钟时间不到四分之一。受控干预表明，能力主要以模型为中心：模型选择强烈改变成功率，框架效应是描述性的，强制航点接口有助于较弱模型但可能阻碍更强模型。然而，在长视程任务上性能急剧下降，而延迟和上下文增长限制了持续操作。这些结果表明，智能体化控制在零样本导航中已具竞争力，模型、框架和接口为自主具身智能体提供了互补路径。

## Abstract
Autonomous embodied agents must sustain a long decision-making loop that involves perceiving, acting, verifying, and self-correcting over many steps. Current systems sustain this loop through task-specific workflows or embodied policies. We study a third form, agentic embodied control, in which a general-purpose agent holds the loop itself. Using zero-shot navigation as a controlled testbed, we evaluate three software-engineering agent harnesses given only a monocular RGB camera and discrete actions. Under this strictly minimal condition, replicated default-effort configurations reach 70.7$\pm$3.5% success (opus-5, mean over three runs), and fable-5 reaches 78% at maximum effort. When a trained waypoint tool is exposed alongside primitives as an optional capability, the hybrid fable-5 agent reaches 76.7$\pm$0.6% at default effort, using half the environment steps and less than one quarter of the wall time of the maximum-effort primitive run. Controlled interventions show that capability is primarily model-centered: model choice strongly changes success, harness effects are descriptive, and a forced waypoint interface helps weaker models but can hinder stronger ones. Performance nevertheless falls sharply on longer-horizon tasks, while latency and context growth limit sustained operation. These results show that agentic control is already competitive in zero-shot navigation and that models, harnesses, and interfaces offer complementary paths toward autonomous embodied agents.

### 2. 论文提出的方法论

- **核心思想：智能体化具身控制**
  - 将交互循环的**高级控制权**完全赋予模型。模型自主决定何时观察、采取何种动作序列、如何从错误中恢复、以及何时终止（`STOP`）。
  - 区别于“策略”（每一步由环境询问模型）和“工作流”（模型作为一个组件被人为管道调用），在此范式中，外围框架仅负责维持会话和执行工具调用，不预设交互序列。

- **关键技术细节：极小化界面探针**
  - **感知接口**：`observe()` 工具，返回单张 512×512 的前置单目 RGB 图像，不提供深度、全景、位姿或地图信息。
  - **动作接口**：`step(actions)` 工具，接收一个由低层级原语组成的序列并顺序执行。
    - `FORWARD`：前进 0.25 米。
    - `LEFT` / `RIGHT`：左右旋转 15°。
    - `STOP`：终止回合。
    - 工具仅返回已执行的原语数量和剩余预算，**不返回**图像或碰撞信号。模型必须主动调用 `observe()` 才能看到动作结果。
  - **智能体框架**：使用三个未经修改的、原本为软件工程任务设计的通用智能体框架（mini-swe-agent, Claude Agent SDK, Codex CLI）来驱动此接口。

### 6. 论文的主要结论与发现

- **极简接口下性能惊人**：卸载所有导航专用脚手架后，仅凭单目 RGB 相机和四个基本动作，最强模型（fable-5）在 R2R-CE 上达到 78% 的成功率，已与当前最先进的工业级训练策略处于同一性能区间。
- **能力以模型为中心**：
  - **模型选择是性能的最大决定因素**，在固定框架和接口下，更换模型可使成功率从 5% 跨越至 72%。
  - **框架效应是描述性的**而非根本性的，其对成功率的影响通常在几个点以内。
- **接口设计具有选择性**：
  - **强制航点界面**：对弱模型（如 Qwen3.5-4B）有巨大提升（+38 SR），但对强模型（如 fable-5）提升甚微，甚至在更复杂的 VLNVerse 场景下会**损害**性能。这表明错误的界面抽象会限制强模型的潜力。
  - **可选混合界面**：将航点预测器作为可选工具暴露，让智能体自主决定何时调用，能取得最佳效果。它在成功率和效率（步数、墙钟时间）上全面超越了强制使用任一单一界面的方案。
- **长程任务存在明显差距**：在更长的 RxR-CE 任务中，成功率骤降至 26-39%，伴随交互上下文的无限增长和延迟增加，暴露出面向持续自主性的巨大鸿沟。
- **失败模式分析**：典型的失败是“静默”的，置信度与准确性无关；失败主要发生在路线级（路点选择错误）而非停止级。
- **物理部署验证**：模型的语言推理和感知能力可以迁移到真实机器人，但“具身性”缺失，缺乏对自己身体、运动校准和持久空间记忆的感知，成为主要瓶颈。

### 7. 优点

- **极简主义诊断设计**：通过剥离几乎所有的导航专用组件，构建了一个干净的“探针”，从而能够直接度量 VLM 本身所蕴含的具身控制能力，方法学上非常优雅。
- **系统性的能力归因**：首次在导航任务中清晰地将性能解耦为**模型、框架、接口**三个轴，并分别进行受控消融，贡献了宝贵的分析和理解。
- **“可选”胜于“强制”的深刻洞察**：对比强制接口与可选工具的实验，有力证明了“将脚手架置于智能体控制之下”这一设计哲学的优势，为具身智能系统设计提供了关键指导。
- **高质量的经验性证据**：不仅包含主结果，还包括复制性运行、方差报告、详细的失败案例帧级别审计和真实机器人验证，实验十分严谨和全面。

### 8. 不足与局限

- **任务范围较窄**：实验被限定在视觉-语言导航任务中，虽然理由是离散动作可减少混淆，但其结论能否推广到需要更高频、连续控制的操作任务尚不可知。
- **资源消耗与延迟**：智能体在推理时需发送完整的交互历史，导致上下文无界增长和显著延迟，不具备实时性，无法支持长时间自主操作。
- **缺乏延续性和长期性**：研究中的智能体被设计为每回合从零开始，不携带跨任务的记忆或状态。这与论文开篇构想的“日复一日”自主运行的机器人愿景仍有巨大鸿沟。
- **物理实验的定性性质**：真实世界机器人的实验规模较小且偏定性，主要用于揭示问题，未能形成可与仿真对标的量化基准。
- **访问限制与复现性**：部分高端商业模型（如 opus-5）的 API 和服务路径可能变动，对第三方完全复现所有实验造成了潜在障碍。
