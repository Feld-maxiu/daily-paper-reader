## 摘要
循环上下文压缩控制了长时域智能体的上下文增长，但其行为影响仍鲜为人知。在这项初步实证研究中，我们表明压缩可能削弱近期交互的影响，增加受阻行为、重复探索和跨运行的不稳定性。受这些观察启发，我们提出TRACE，一个验证器引导的框架，通过来自相同环境状态的成对闭环延续来评估个别压缩事件，并使用摘要偏好来优化自然语言压缩提示，同时保持所有模型冻结。在AppWorld上的初步结果显示，与现有压缩基线相比，在任务性能、多运行可靠性和上下文执行效率方面均有提升。这些发现为通过边界局部评估实现可靠的智能体上下文压缩提供了早期证据，开辟了一个有前景的方向。

## Abstract
Recurrent context compression controls context growth in long-horizon agents, but its behavioral effects remain poorly understood. In this preliminary empirical study, we show that compression can weaken the influence of recent interactions, increasing blocked actions, repeated exploration, and instability across runs. Motivated by these observations, we introduce TRACE, a verifier-guided framework that evaluates individual compaction events through paired closed-loop continuations from the same environment state and uses summary preferences to optimize a natural-language compression prompt while keeping all models frozen. Initial results on AppWorld show improvements over existing compression baselines in task performance, multi-run reliability, and context--execution efficiency. These findings provide early evidence for boundary-local evaluation as a promising direction for reliable agent context compression.

### 2. 论文提出的方法论：TRACE框架

*   **核心思想**：TRACE（Trajectory-Relative Agent Context ComprEssion）的核心创新在于其**边界局部（Boundary-local）** 的优化视角。它不在整个任务结束后（终端）评判压缩质量，而是直接在每次压缩发生的时间点，通过对比压缩前后的行为来提供细粒度的优化信号。
*   **关键技术细节**：
    *   **边界局部执行验证器（Boundary-local Execution Verifier）**：
        *   **配对闭环延续**：在某个压缩边界，保持环境状态不变，分别使用**压缩前的完整上下文（PRE）**和**压缩后的摘要上下文（POST）**，让智能体从该点开始自由执行（rollout）一个短序列。
        *   **执行负担量化**：定义一个“执行负担” $G(\tau)$，它衡量在短序列中智能体产生**阻塞动作**（即环境报错）或**重复探索**（调用之前已经执行过的工具）的次数。
        *   **压缩诱导负担** $\Delta G_b(s) = E[G(\tau_b^+(s))] - E[G(\tau_b^-)]$，即POST条件下的负担期望减去PRE条件下的负担期望。分数越高，表示该摘要$s$引起的额外行为退化（regression）越少。
    *   **基于偏好的提示优化**：
        *   **候选对生成**：在选定的训练边界上，用基础压缩模板生成多个候选摘要，与同一状态的PRE控制组对比，用上述验证器评分，选出最好和最差的摘要构成偏好对 $(s^+_b, s^-_b)$。
        *   **冻结的提议器（Proposer）**：一个冻结的大模型仅仅接收这些**摘要偏好对**、当前的压缩模板和下游系统提示词，但不接触具体的执行动作、环境观察或错误信息。其任务是思考为什么一个摘要优于另一个，并据此修订出新的自然语言压缩模板。
        *   **端到端选择**：提议器生成多个候选的新压缩模板。最终，通过在整个开发集上运行完整的压缩和任务执行流程，并基于**Pass 2**（任务在两次独立运行中都成功的比例）这一多运行稳定性指标，选择出最优模板。
*   **算法流程**：
    1.  从训练集上选择表现出执行退化的压缩边界。
    2.  在每个边界，对同一状态运行PRE（无压缩）和多个POST（不同候选摘要）的短闭环延续。
    3.  用验证器计算每个摘要的边界局部分数，构建摘要偏好对。
    4.  将偏好对和下游系统提示词输入给冻结的提议器，生成4个新的压缩模板候选。
    5.  在开发集上对每个候选模板进行端到端评估，选择Pass 2最高的模板。
    6.  在测试集上评估最优模板。

*   **方法论创新**：

*   **单一基准测试**：所有实验仅在AppWorld上进行。这是一个有状态的API调用环境，结论是否能推广到更开放的知识密集型搜索或Web导航等任务尚待验证。
