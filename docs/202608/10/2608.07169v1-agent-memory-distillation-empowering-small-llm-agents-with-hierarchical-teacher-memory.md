## 摘要
记忆系统已显示出提高代理性能的潜力，但它们对于小型语言模型的潜力在很大程度上仍未被探索，因为小型语言模型难以自行生成足够的成功轨迹。我们提出了代理记忆蒸馏（AMD），这是一个无需训练的框架，通过分层记忆将结构化知识从大型教师代理转移到小型学生代理。AMD从成功的教师轨迹中构建了三种互补的记忆类型：工作流记忆编码任务级别的策略，子任务记忆以中等粒度提供具体的行为示例，而函数记忆捕获每个函数的调用约定和常见陷阱。工作流和子任务记忆在每个任务开始时主动注入，而函数记忆在工具调用错误时被动检索。我们在三个工具使用基准上评估了AMD，使用四个学生模型（4B-8B参数），以GPT-5-mini作为教师，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，同时始终优于现有的基于记忆的基线。进一步的分析表明，子任务记忆贡献了最大的收益，教师有效性既取决于教师能力也取决于学生兼容性，而4B大小的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

### 1. 核心问题与研究背景
- **问题**：小型语言模型（如4B–8B参数）作为智能体时，由于自身能力有限，难以在工具调用、复杂任务中生成足够的成功轨迹。这导致它们基于自身经验构建的记忆库质量低下，限制了记忆系统对性能的增强作用。
- **背景**：记忆系统已被证明能有效提升大型代理的性能，但针对小模型代理的记忆利用研究几乎空白。直接将教师（大模型）的原始记忆转移给学生时，会因“能力鸿沟”导致仅有微弱提升——学生无法理解或执行高层次策略。
- **整体含义**：本文旨在通过一种无需训练的分层记忆蒸馏框架，将教师智能体的结构化经验有效传递给学生，从而大幅提升小型代理在工具使用任务上的能力。

### 2. 方法论：Agent Memory Distillation (AMD)
- **核心思想**：不依赖参数更新的训练无关知识转移。将教师代理在成功轨迹中产生的知识，按照**任务级、子任务级、函数级**三个粒度组织成分层记忆，并在推理时以不同方式注入学生代理。
- **关键技术细节**：
    - **记忆构建**：
        - **工作流记忆**：从成功轨迹中提取高层任务解决策略（含决策规则、常见陷阱），并用类型占位符替换具体值，以保证泛化性。
        - **子任务记忆**：将轨迹分割为语义连贯的子任务段（如登录、查询），保留具体的执行代码/工具调用及环境观察。每个段配有短标签和描述。
        - **函数记忆**：记录每个函数的调用示例、上下文及可能提供的API文档。按函数名索引。
    - **记忆检索与注入**：
        - **主动注入**：任务开始时，检索 top-1 工作流记忆和每个分解子任务 top-1 的子任务记忆，注入系统提示。
        - **被动注入**：仅当工具调用返回错误时，根据失败函数名检索 top-1 函数记忆，追加到当前上下文中，进行即时纠错。相似度均用预训练嵌入模型计算。
- **算法流程**：教师先生成成功轨迹集 → 构建三层记忆库 → 学生推理时，先主动注入工作流和子任务记忆，执行循环中如遇错误则被动检索函数记忆。

### 6. 主要结论与发现
- **性能大幅提升**：AMD使小模型在三个基准上的平均准确率分别提升27.2、11.2和3.4个百分点，部分学生（如Gemma4-E4B、Qwen3-8B）在AppWorld和BFCL V3上达到甚至超过了教师GPT-5-mini的性能。
- **关键组件贡献**：子任务记忆带来的增益最大，是复杂长程任务的核心助推器；工作流记忆提供稳定高层规划；函数记忆在错误恢复中起辅助修补作用。
- **教师-学生兼容性**：教师更强并不一定带来更大收益，如GPT-5-mini对4B学生的增益反而超过更强的教师，表明存在教师与学生的兼容性问题。
- **模型规模效益**：4B大小的学生从AMD中获得的绝对增益最大（+34.52%p），模型再大其零样本基线已较高，提升空间缩小；模型太小则难以有效利用注入记忆。
- **交互效率**：AMD能使学生与环境的交互步数更接近教师，减少低效探索。

### 7. 优点
- **训练无关**：完全绕过昂贵的学生微调，直接即插即用地提升小模型代理性能，实践成本低。
- **分层记忆设计**：针对能力鸿沟，将知识解耦为任务策略、行为示例和函数细节三个层次，并以不同方式（主动/被动）注入，更贴合小模型的认知特点。
- **实验全面且扎实**：在多个工具使用场景、不同规模/系列的模型上进行了大量系统性评估，与多种记忆基线对比，并深入分析了各组件和各因素的作用。

### 8. 不足与局限
- **评估场景单一**：仅在文本工具调用基准（Python API、结构化函数）上测试，未验证在更复杂的多模态环境或开放代码生成任务中的有效性。
- **记忆固化且静态**：记忆从固定教师轨迹集离线构建，推理中无法整合学生自身的新成功/失败经验，难以适应任务分布的变化。
- **依赖教师轨迹质量**：教师选择需人为设定，自动选择合适教师来优化特定学生的蒸馏效果仍是开放问题。
- **较弱模型仍有瓶颈**：极弱模型（如1.7B参数）即使注入记忆也无法充分利用，被动函数记忆甚至可能增加干扰（如Llama3.1-8B中的精度下降）。
