## 摘要
多模态搜索智能体利用开放网络中最新出现和长尾的证据来扩展参数化知识。然而，许多现有的智能体搜索环境通常只以文本形式暴露检索到的证据，并在后续上下文中忽略工具返回的图像，导致视觉相关的轨迹退化为纯文本推理。长时间跨度的交互还会加剧工具调用、响应长度、超时和预算等方面的失败，这些失败可能丢弃仍可挽救的轨迹、浪费 rollout 计算并干扰策略更新。为解决这些问题，我们提出了 WeAgent-Harness，这是一个支持原生文本-视觉交互和运行时恢复的多模态智能体执行框架。检索到的图像会获得持久化的磁盘引用，使模型能够在整个轨迹中检查、处理和引用它们。基于该框架，我们开发了 WeAgent-MMSearch，这是一个涵盖数据构建、智能体后训练和多模态 rollout 的集成系统。在数据构建方面，一个强大的 MLLM 使用 WeAgent-Harness 来发现、合成并验证 MMSearch 风格的任务，并收集专家轨迹。在后训练过程中，我们的 Failure-Aware GSPO（FA-GSPO）恢复可挽救的异常 rollout，并过滤无效 rollout，以改进有界多模态规划和搜索。我们还引入了 VisTarget-Bench，这是一个包含 150 个任务且经人工验证的基准，每个问题都配有一个留出的目标图像，用以区分图像检索失败和视觉感知失败。在 VisTarget-Bench 和七个公开基准上的评估表明，智能体后训练将平均得分提高了 19.22 分，使我们的模型优于同等规模的开源模型，并能与参数规模约十倍于它的模型相抗衡。

## Abstract
Multimodal search agents extend parametric knowledge with newly emerging and long-tail evidence from the open web. Yet many existing agentic search environments often expose retrieved evidence only as text and omit tool-returned images from subsequent context, reducing visually grounded trajectories to text-only reasoning. Long-horizon interaction also compounds tool-call, response-length, timeout, and budget failures, which can discard salvageable trajectories, waste rollout computation, and disturb policy updates. To address these issues, we introduce WeAgent-Harness, a multimodal agentic harness that supports native text-vision interaction and runtime recovery. Retrieved images receive persistent disk references, allowing the model to inspect, process, and cite them throughout the trajectory. Based on this harness, we develop WeAgent-MMSearch, an integrated system spanning data construction, agentic post-training, and multimodal rollout. For data construction, a strong MLLM uses WeAgent-Harness to discover, synthesize, and verify MMSearch-style tasks and collect expert trajectories. During post-training, our Failure-Aware GSPO (FA-GSPO) recovers salvageable abnormal rollouts and filters invalid ones to improve bounded multimodal planning and search.We also introduce VisTarget-Bench, a 150-task human-verified benchmark that pairs each question with a held-out target image, distinguishing image-retrieval failures from visual-perception failures. Evaluation on VisTarget-Bench and seven public benchmarks shows that agentic post-training improves the average score by 19.22 points, enabling our model to outperform similarly sized open-source models and rival models with roughly ten times its parameter count.

## 1. 论文的核心问题与整体含义

- **核心问题**：现有多模态搜索智能体（Multimodal Search Agents）在执行长程检索任务时，存在两个关键缺陷：
  1. **视觉证据丢失**：许多智能体搜索环境只把检索证据以文本形式返回给模型，工具返回的图像在后续上下文中被直接丢弃，导致本应视觉驱动的轨迹退化为纯文本推理。
  2. **长程交互失败率高**：工具调用错误、模型输出过长、超时、预算耗尽等异常频繁发生，既浪费已消耗的 rollout 计算，又可能把与搜索策略质量无关的失败样本混入训练，污染策略更新。

- **研究背景与整体含义**：多模态大模型（MLLM）的静态参数知识有限，对长尾实体、近期事件和来源特定事实常不可靠。多模态搜索要求模型识别信息缺口、调用工具、整合外部多模态证据。然而，环境不完整、训练监督稀缺、执行不可靠共同限制了该方向的发展。论文旨在通过一个支持**原生文本-视觉交互**和**运行时恢复**的统一框架，构建从数据构造、后训练到推理的完整闭环，使小规模模型也能获得强多模态搜索能力。

## 2. 论文提出的方法论

### 2.1 WeAgent-Harness：多模态智能体执行框架

- **核心思想**：让工具返回的图像成为跨轮次可用的“地址化证据对象”，而不是一次性文本摘要；同时对执行过程进行缓存、恢复和预算控制，以产生可训练的有限轨迹。

- **工具接口**：提供 5 个原生工具：
  - `web_search`：通用网页搜索；
  - `web_extract`：抓取网页/PDF 并生成带图片的 Markdown 摘要；
  - `web_search_for_image`：文搜图，返回并直接重喂最多 4 张缩略图；
  - `web_search_based_on_image`：以图搜图/反向图像搜索；
  - `execute_code`：在持久沙箱中执行 Python，生成的新图像也会被注册并重喂。

- **持久化多模态状态**：
  - 检索到的图像保存到磁盘，绑定稳定引用（如 `<user_image_1>`、`<search_image_3>`），并保留来源元数据。
  - 后续轮次可以重新检查、处理、反向搜索或比较同一视觉证据，避免歧义。

- **可靠与有界执行**：
  - **缓存支持搜索**：对归一化搜索请求做共享精确匹配缓存，命中直接返回相同 schema，未命中走实时后端；周期性刷新避免退化为固定离线语料。
  - **恢复机制**：修正无歧义的工具名、参数名、序列化错误；意图不清时返回结构化错误让策略自纠正；抑制重复无效调用；单轮输出超长则拒绝并给一次重新生成机会。
  - **预算控制**：限制轮数、工具调用数、上下文长度和 wall-clock 时间；常规轮次用尽后触发一次无工具综合回答；超过上下文或时间限制的轨迹直接终止并排除训练。

### 2.2 数据构造流水线

- **四阶段 harness-native 流水线**：
  1. **种子生成**：从 Wikipedia 实体和实时网络事件中挖掘视觉相关事实，要求目标图像可通过 harness 到达、答案依赖像素而非标题/URL/元数据。
  2. **后向多跳扩展**：以目标图像 VQA 为终点，反向生成 2–4 跳检索链，使最终任务必须通过检索目标图像并读取像素才能回答。
  3. **任务验证**：检查结构完整性、桥接唯一性、无答案泄漏、图像依赖性，并生成最终查询。
  4. **轨迹采样**：由同一 harness 执行任务，成功轨迹进入 SFT，失败但仍有优化空间的任务保留给 RL。

- **开源数据归一化**：
  - 导入 Metis、OpenSearch-VL、REDSearcher 的开源数据。
  - 统一工具命名空间（如 `RED_` 前缀），统一轨迹语法为 `<think>...</think><tool_call>...</tool_call>` 和 `<think>...</think><response>...</response>`。

- **最终数据规模**：
  - SFT 混合：59.5K 轨迹（3.3K 自建 + 56.2K 开源归一化）。
  - RL 混合：13.3K prompts（4.9K 自建 + 8.3K 开源过滤）。

### 2.3 VisTarget-Bench 评估基准

- 150 个人工验证任务，每个问题配一个留出的目标图像；80 个带输入图像，70 个纯文本。
- 模型需返回最终答案和支持图像索引，用于区分：
  - **图像检索失败**（没找到目标图像）；
  - **视觉感知失败**（找到目标图像但答案错误）。
- 指标：
  - `Accuracy`：最终答案正确率；
  - `Image Cite`：是否引用了工具返回图像；
  - `Target Match`：引用图像是否与目标图像匹配；
  - `Match+Acc`：目标图像匹配后答案是否正确的条件准确率。

### 2.4 智能体后训练

- **SFT**：
  - 从成功演示轨迹学习 ReAct 风格策略。
  - 工具返回观察和 harness 插入的干预 prompt 被 mask，只在模型生成 token 上计算下一 token 预测损失。

- **Failure-Aware GSPO（FA-GSPO）**：
  - 在 Group Sequence Policy Optimization（GSPO）基础上加入恢复与过滤。
  - **恢复**：超长轮次重新生成一次；格式错误返回结构化观察供自纠正；预算耗尽触发一次无工具最终回答；仍超长或超时/超上下文的轨迹排除。
  - **合格集合动态归一化**：对于每个 prompt 的 8 条 rollout，构建合格集合 \(E_g\)，数量为 \(n_g\)；只对合格轨迹计算组均值 \(\bar{R}_g\) 和标准差 \(\sigma_g\)。
  - **奖励**：\(R_{gi} = 0.9 C_{gi} + 0.1 F_{gi}\)，其中 \(C_{gi}\) 为答案正确性，\(F_{gi}\) 为格式合规性。
  - **优势**：\( \hat{A}_{gi} = \frac{R_{gi} - \bar{R}_g}{\sigma_g + \delta}\)，仅 \(i\in E_g\) 且 \(n_g\ge2\)；不合格轨迹优势为 0。
  - **目标函数**：对序列级 clipped 目标 \(S_{gi}(\theta)\) 求期望，重要性比率为轨迹内 token 对数概率差几何平均：
    \[
    S_{gi}(\theta)=\min\left(\rho_{gi}(\theta)\hat{A}_{gi},\ \text{clip}(\rho_{gi}(\theta),1-\epsilon_{lo},1+\epsilon_{hi})\hat{A}_{gi}\right)
    \]
    其中 \(\rho_{gi}\) 为 token 级比率的几何平均。

## 4. 资源与算力

- **训练配置**：
  - SFT：全局 batch size 32 trajectories；语言模型学习率 \(1.0\times10^{-5}\)，视觉塔学习率 \(1.0\times10^{-6}\)；更新全部语言模型和视觉模块。
  - RL：从 SFT 初始化，冻结视觉塔和投影器，只训练语言模型策略；prompt batch 64，每 prompt 采样 8 条，全局 trajectory batch 512；恒定学习率 \(5.0\times10^{-7}\)；rollout 温度 1.0。

## 6. 论文的主要结论与发现

- **Harness 本身的有效性**：
  - WeAgent-Harness 显著优于文本-only harness（Hermes）：Kimi K2.6 平均分从 55.09% 提升到 58.42%，Gemini3.6-Flash 从 60.95% 到 63.26%，Qwen3.5-Plus 从 49.63% 到 51.58%。
