## 摘要
长时程智能体任务需要大语言模型在多轮交互中迭代检索、整合和维护分散信息，但保留所有交互历史会导致工作上下文不断增长。最近的主动上下文管理方法允许模型使用专用工具编辑自己的工作上下文，但仍面临三个关键局限：（1）工具集有限，仅限于搜索、删除和摘要，不支持全局规划、长期记忆和自适应压缩；（2）探索效率低下，将上下文管理动作视为统一处理，尽管它们对最终结果的影响差异很大；（3）粗粒度信用分配，在强化学习期间将最终的轨迹级奖励分配给所有中间上下文编辑动作。为弥合这些差距，我们引入了ContextPilot，一个用于长时程智能体推理的主动上下文管理框架。我们的方法系统性地扩展了工具集，包括规划、长期记忆和软上下文卸载工具。我们进一步提出了一种针对上下文管理的强化学习方法，利用上下文和熵变化来识别关键编辑决策以进行分支采样，并从所有通过相应上下文编辑动作的分支轨迹中估计动作级优势。在长上下文问答和深度搜索任务上的实验表明，ContextPilot以更紧凑的工作上下文实现了更强的性能，在各种基础模型和基准上始终优于现有基线。代码可在 https://github.com/Tencent/ContextPilot 获取。

## Abstract
Long-horizon agentic tasks require large language models (LLMs) to iteratively retrieve, integrate, and maintain dispersed information across multi-turn interactions, but preserving all interaction histories leads to a continuously growing working context. Recent proactive context management methods allow models to edit their own working context with specialized tools, yet they still face three key limitations: (1) a limited toolset restricted to search, deletion, and summarization, with no support for global planning, long-term memory, and adaptive compression; (2) inefficient exploration that treats context management actions uniformly despite their heterogeneous impacts on final outcomes; and (3) coarse-grained credit assignment that assigns the final trajectory-level reward to all intermediate context editing actions during RL. To bridge these gaps, we introduce ContextPilot, a proactive context management framework for long-horizon agentic reasoning. Our approach systematically augments the toolset with planning, long-term memory, and soft context offloading tools. We further propose an RL method tailored for context management, which uses context and entropy variation to identify critical editing decisions for branch sampling and estimates action-level advantages from all branched trajectories that pass through the corresponding context editing action. Experiments on long-context QA and deep search tasks show that ContextPilot achieves stronger performance with a more compact working context, consistently outperforming existing baselines across various base models and benchmarks. Code is available at https://github.com/Tencent/ContextPilot.

### 2.1 工具集扩展

### 2.2 强化学习训练方法

#### 2.2.1 上下文感知部分展开（Context-Aware Partial Rollout）
- **动机**：不同上下文管理动作对最终结果影响不同，应把更多探索预算分配给关键决策。
- **关键度量**：
  - 上下文变化量：
    \[
    \Delta C_{cm_t} = \frac{\text{len}(c_{cm_{t+1}}) - \text{len}(c_{cm_t})}{\text{len}(c_{cm_t})}
    \]
  - 熵变化量：
    \[
    \Delta H_{cm_t} = H_{cm_t} - H_{\text{initial}}
    \]
    其中 \(H_{cm_t}\) 是接收观测后生成 \(k\) 个 token 的平均熵，\(H_{\text{initial}}\) 是轨迹起始阶段的平均熵（使用初始熵而非前一步熵，以识别相对于初始状态的不确定性变化）。
- **敏感度分数**：
  \[
  S(a_{cm_t}) = \alpha \cdot \Delta C_{cm_t} + \beta \cdot \Delta H_{cm_t}
  \]
  用于排序所有上下文管理动作，选择 top-(N-M) 个作为分支点，从父节点额外采样子轨迹，以补充快照池。

#### 2.2.2 细粒度信用分配（Fine-Grained Credit Assignment）
- 将完整轨迹在上下文编辑操作处切分为多个快照 \(S_1, S_2, \dots, S_M\)。
- **终端快照奖励**：
  \[
  R(S_M) = R_{\text{out}} + R_{\text{fmt}} + R_{\text{pen}}
  \]
  包括结果奖励（与真实答案比较）、格式奖励（最终输出是否可解析）、惩罚项（无效工具调用、上下文长度违规等）。
- **中间快照奖励**：取所有以该快照为前缀的终端轨迹的奖励平均值：
  \[
  R(S_i) = \frac{1}{|T(S_i)|} \sum_{T \in T(S_i)} R(T)
  \]
- **优势计算**：同一查询下所有快照构成组 \(G\)，用组内均值和标准差标准化：
  \[
  \hat{A}^{(j)}_t = \frac{R(S^{(j)}_t) - \text{mean}(\{R(S) \mid S \in G\})}{\text{std}(\{R(S) \mid S \in G\})}
  \]
- 使用 GRPO 目标优化，将每个快照视为独立样本。附录 A 从理论上证明该估计量是无偏的，且方差比轨迹级信用分配低（方差缩小 \(n_S\) 倍）。

## 6. 论文的主要结论与发现

- **性能提升**：ContextPilot 在 32K 上下文窗口下，超过 128K 无工具基线，并超越 StateLM 等既有主动管理代理。例如，ContextPilot-8B-RL 在四个长上下文 QA 基准上平均比 StateLM-8B-RL 高 3.55 分；深度搜索平均比 SUPO 高 1.51 分（跨两个 backbone）。
- **RL 增益随任务难度增大**：在更复杂的 BrowseComp+（平均输入 552K token）上，RL 相对 SFT 提升 5.34 分，而在 NovelQA（平均 119K）上提升较小，说明 RL 在更难场景下更有价值。
- **工具集扩展有效**：逐步添加规划、软卸载、长期记忆均带来性能提升，完整工具集在 BrowseComp+ 上从 63.49% 提升到 80.96%。
- **细粒度信用分配 + 上下文感知部分展开是关键**：仅用熵基部分展开不够稳定，加入上下文变化后更稳健，细粒度信用分配进一步在所有基准上提升。
- **行为层面变化**：RL 训练使模型从频繁使用信息检索工具转向更均衡地使用规划、记忆、卸载工具；各类工具的调用失败率显著下降，且与任务成功率提升同步。
- **上下文更紧凑**：ContextPilot 在 BrowseComp 等任务上将每轮输入 token 稳定在约 8K–10K，而基线线性增长至 30K 左右。

## 7. 优点

- **系统性工具扩展**：引入规划、长期记忆和软上下文卸载，覆盖了长时程任务中除简单删除/摘要外的关键需求。
- **针对上下文管理的 RL 设计**：上下文感知部分展开和细粒度信用分配直接回应了“不同上下文编辑动作影响不同”和“轨迹级奖励过于粗糙”两个核心问题，并有理论方差降低证明。
