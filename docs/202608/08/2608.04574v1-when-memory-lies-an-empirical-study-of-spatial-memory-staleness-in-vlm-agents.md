## 摘要
记忆增强的视觉语言模型（VLM）智能体依赖持久化的空间知识进行决策，但这些知识会随着环境变化悄然过时。我们探讨的问题是：当智能体必须在确信的记忆声明与矛盾的观察之间做出调和时会发生什么，以及当前模型能否在错误形成安全隐患之前捕捉到这种冲突。借助动态的 FrozenLake 测试平台，我们在文本和图像两种输入模式下，对三个闭源模型和三个开源权重的 VLM 进行了记忆过时性检测任务与下游导航任务的配对实验（共计 1800 次检测运行，以及在四个 LLM 导航器上以 50 个种子规模执行的 12000 段文本模式导航片段）。实验得出三点发现。首先，文本可解性并不意味着视觉基础能力：那些在文本中可靠标记出过时信息的模型，在相同网格上面对图像输入时，视觉 F1 值却从 0.887 下降到 0.067，而最弱的模型甚至会持续做出流利且自信却忽视图像信息的决策。其次，未经审查而使用过时记忆会带来安全风险：在主要的 GPT-4o 设置中，盲目信任原始记忆的智能体的死亡频率是完全未提供记忆的同一智能体的两倍以上。第三，对记忆进行审查虽有帮助，但未能完全弥合差距：在文本模式下，透明的读取时过滤可消除大部分安全成本，然而在当前网格尺寸下，即使使用神谕般的过时标签也不会带来进一步的显著增益；而当视觉审查不可靠时，过滤并未带来一致的收益。这些结果共同表明，空间记忆过时是一种安全失效模式，并指出了在记忆-观察冲突下可靠的视觉基础与行动选择是记忆增强型智能体面临的核心开放挑战。

## Abstract
Memory-augmented VLM agents act on persistent spatial knowledge, yet that knowledge silently goes stale as the environment changes. We ask what happens when an agent must reconcile a confident memory claim with a contradicting observation, and whether current models can catch the conflict before it becomes a safety-relevant mistake. Using a dynamic FrozenLake testbed, we pair a staleness-detection task with a downstream navigation task across three closed-source models and three open-weight VLMs under both text and image inputs (1,800 detection runs, and 12,000 text-mode navigation episodes over four LLM navigators at a shared 50-seed scale). Three findings emerge. First, text solvability does not imply visual grounding: models that flag stale entries reliably from text nonetheless span vision F1 from 0.887 down to 0.067 on the identical grids, and the weakest keeps making fluent, confident decisions that ignore the image. Second, consuming stale memory without an audit is a safety liability: in our primary GPT-4o setting, an agent that trusts raw memory dies more than twice as often as the same agent given no memory at all. Third, auditing helps but does not close the gap: a transparent read-time filter removes much of the safety cost in text mode, yet even oracle stale labels bring no further significant gain on the current grid size, and when visual auditing is unreliable, filtering yields no consistent benefit. Together these results frame spatial-memory staleness as a safety failure mode and isolate reliable visual grounding and action selection under memory--observation conflict as the central open challenges for memory-augmented agents.

### 2. 论文提出的方法论

*   **核心思想**：在一个可控的、动态变化的网格世界（FrozenLake）中，系统性地制造智能体固有记忆与当前环境观察之间的矛盾，从**条目级过时检测（审计）**和**下游导航安全**两个层面，来衡量这种冲突的影响及缓解措施的有效性。
*   **平台与形式化定义**：
    *   **SpatialSTALE测试台**：基于FrozenLake环境，生成一个8×8的网格。智能体持有一份包含所有64个格子状态（安全冰面`F`或危险洞穴`H`）的**文本记忆快照**。
    *   **变化机制**：设计了三种变化模式（L1-随机点状、L2-局部聚集、L3-在线动态），在记忆快照生成后改变部分格子的状态，制造过时信息。
    *   **过时性标签**：当一个记忆条目`m_i`声称格子`p_i`是`F`（安全），但当前世界状态显示`p_i`是`H`（危险），则该条目被定义为**过时（Stale）**。`h`为危险图函数，当格子为H时为1，否则为0。过时性判断公式为 `yi(t) = I[h(ci0) != h(gt[pi])]`。
*   **OMCD过滤干预算法**：
    *   **审计流程**：作为一种关键的读取时过滤策略，OMCD（Object-Memory Consistency Detection）的核心是在导航前和导航中，将记忆条目分批提交给模型，要求其结合当前观察进行**二进制审计**（判断`is_stale`并给出理由）。被判定为过时的条目将从供导航器使用的记忆视图中剔除。
    *   **算法步骤**：
        1.  **输入**：当前观察 `ot`，记忆库 `M`，批次大小 `B`。
        2.  **初始化**：将活动记忆集 `M_active` 初始化为全部记忆 `M`。
        3.  **循环审计**：将 `M` 按大小 `B` 分批。对每个批次 `B`，大型语言模型根据 `ot` 和 `B` 为每个条目 `m` 输出一个二元判决 `ŷ_m`（`stale` 或 `valid`）。
        4.  **过滤**：若 `ŷ_m == stale`，则将该条目 `m` 从 `M_active` 中移除。
        5.  **输出**：返回过滤后的活动记忆集 `M_active`，供导航器后续决策使用。
    *   **事件触发重审计**：在L3动态变化模式下，OMCD会在每次环境发生变化后重新执行审计，动态更新有效记忆。

### 3. 实验设计

*   **使用场景与基准**：

        2.  **下游导航任务**：在网格上从起点到达终点，踏上洞穴（H）即为死亡（失败）。评估指标为成功率、死亡率、路径长度。

    1.  **NoMemory（无记忆控制组）**：不提供任何记忆，仅基于当前观察行动。作为衡量记忆带来安全成本的上限参照。
    2.  **NoFilter（未过滤基线）**：提供全部原始（可能过时的）记忆。直接衡量信任原始过时记忆的安全风险。

### 6. 论文的主要结论与发现

1.  **文本与视觉能力的脱节**：模型在文本输入下能近乎完美地检测过时记忆（F1高达0.88+），但在相同实例的视觉输入下，性能出现巨大分化。有的模型（如Qwen）能保持高水平（F1 0.887），而有的模型（如GLM）则完全失效（F1 0.067），表现出一种“无视图像、自信虚构”的错误模式。
2.  **过时记忆是显著的安全负担**：在最主要的GPT-4o L2文本导航设置中，直接使用未过滤的过时记忆（NoFilter策略）导致死亡率高达**74.4%**，而完全没有记忆的智能体（NoMemory策略）死亡率仅为**28.0%**。过时记忆带来的危害远超无记忆状态，轨迹分析表明这是一种“径直冲入陷阱”的直接性失败。
3.  **审计过滤有效但非万能**：
    *   **在文本模式下**，OMCD过滤能大幅降低过时记忆带来的死亡率（如GPT-4o从74.4%降至31.6%），且其效果已接近使用神谕标签的上限，说明此时的瓶颈已从“检测过时”转移到“基于过滤后记忆的安全行动选择”。
    *   **在视觉模式下**，当视觉审计本身不可靠时，过滤下游的导航任务几乎没有带来一致的收益，表明可靠的视觉基础是安全审计的前提。
    *   **最终瓶颈**：即使审计可靠，模型仍可能因行动选择错误而失败，这将是未来的核心挑战。

### 8. 不足与局限

*   **场景局限性**：
