## 摘要
大语言模型（LLM）智能体从本地交互经验中学习世界动态，以支持后续规划和动作选择。然而，单个客户端可获得经验往往不完整，这促使跨客户端共享知识。现有联邦方法主要聚合模型参数，而智能体记忆共享方法通常汇集轨迹、记忆或规则，却不检查其是否对每个客户端仍然有效。这一假设存在问题，因为相同的抽象动作在不同的策略、环境或异常条件下可能产生不同效果。因此，一条为大多数客户所支持的规则可能覆盖少数客户持有的正确知识。为解决这一问题，我们提出 FEDWORLD，一种具有范围感知的联邦世界模型协议，它交换结构化的抽象转换规则。每个客户端将私有转换转变为规范化规则，服务器对相关规则进行对齐，以识别每条规则在客户端间的支持证据和矛盾证据。所得证据决定了规则是共享的、集群特定的、私有的还是待解决的。每个目标客户端保留其本地规则，仅对未覆盖且推断范围兼容的情况接受联邦更新；有歧义的规则则被保留。在 τ-bench 和 ALFWorld 上的实验表明，FEDWORLD 在保留有益跨客户端迁移的同时减少了冲突动态下的负迁移，从而减少状态倒退、重复动作和多余步骤，并提高任务成功率。

## Abstract
Large language model (LLM) agents learn world dynamics from local interaction experience to support subsequent planning and action selection. However, the experience available to a single client is often incomplete, which motivates sharing knowledge across clients. Existing federated methods mainly aggregate model parameters, while agent memory-sharing methods commonly pool trajectories, memories, or rules without checking whether they remain valid for each client. This assumption is problematic because the same abstract action may produce different effects under different policies, environments, or exception conditions. Consequently, a rule supported by most clients may overwrite correct knowledge held by a minority client. To address this problem, we propose FEDWORLD, a scope-aware federated world-model protocol that exchanges structured abstract transition rules. Each client converts private transitions into normalized rules, and the server aligns related rules to identify each rule supporting and contradicting evidence across clients. The resulting evidence determines whether a rule is shared, cluster-specific, private, or unresolved. Each target client retains its local rules and accepts federated updates only for uncovered cases whose inferred scope is compatible; ambiguous rules are withheld. Experiments on $τ$-bench and ALFWorld show that FEDWORLD reduces negative transfer under conflicting dynamics while retaining useful cross-client transfer, leading to fewer state regressions, repeated actions, and excess steps, as well as higher task success.

### 2. 方法论
- **核心思想**：将每个客户端的私有转移经验转换为规范化的抽象规则（key 由动作类型、归一化前状态、条件集、效果和异常结构组成），在服务器端对齐相关规则，基于跨客户端支持/矛盾证据推断规则的有效范围，最后采用“本地优先”的编译策略，仅将范围兼容且本地缺失的联邦规则注入目标客户端。
- **关键技术细节**：
  - **抽象规则映射（M1）**：通过归一化映射 ϕₖ 将本地细节转换为结构化的抽象规则 z，形成仅用于共享的抽象规则库 Aₖ，原始轨迹保留在本地。
  - **跨客户端规则对齐（M2）**：计算查询规则 u 与候选规则 g 的关系标签 rel(u,g) ∈ {match, compatible, conflict, unresolved}，仅匹配或兼容的规则进入后续范围推断。
  - **范围推断（M3）**：对每条规则 r，统计跨客户端的支持证据数 n⁺ᵣ 和矛盾证据数 n⁻ᵣ，计算拉普拉斯平滑置信度 qᵣ，以及客户端级别的支持/矛盾比例 pᵣ 和 ρ⁻ᵣ。根据证据分布将规则标记为 shared、cluster、private 或 unresolved，并确保仅当预条件在客户端可触发时该客户端才被计入证据池，避免误判。
  - **缺口检测与编译（M4）**：若目标客户端已有可靠本地规则（κₖ(u) ≥ τₗₒc），则直接使用；否则搜索范围内兼容的候选集 F_FW(k,u)，按关系类型、范围特异性和置信度排序，选择最优规则编译为可执行更新；无可兼容规则时回退本地预测或主动拒绝回答。
  - **算法流程**：给定查询 r → 抽象 key u → 本地命中则返回；否则在 F 中找到关系兼容候选 C → 推断每条候选规则的范围 σ(g) → 筛选出与目标客户端兼容的子集 Cₖ → 若 Cₖ 非空则选择最优 g⋆ 编译返回；否则尝试本地回退或返回 abstain。
- **形式化目标**：最小化预测错误的期望、有害覆盖的惩罚（λ_ntr）和拒绝回答的惩罚（λ_abs），且满足两条硬约束：本地已存在规则时绝不覆盖，未通过范围筛选的联邦规则绝不影响编译。

### 3. 实验设计
- **数据集/场景**：
  - **τ‑bench**：包含零售和航空领域的客服交互，不同业务策略会导致相同工具动作产生不同效果，模拟策略依赖型转移冲突。
  - **ALFWorld**：文本驱动的家务任务，物体状态、容器约束和环境布局变化导致动作效果差异，模拟环境依赖型转移冲突。
- **基准与划分**：将抽象规则按身份键划分为本地存储（60%）、验证（20%）和留出评估（20%）集。评测划分包含：S0（本地已有规则）、S3（跨客户端缺口填补）、S4（冲突案例，进一步分为严格冲突 S4_strict 和多数一致 S4_trivial）、S5（混合留出）。τ‑bench 构建 11 个客户端（6 零售+5 航空），ALFWorld 构建 12 个客户端。
- **对比方法**：
  - B0：无世界模型（仅固定控制器）
  - B1 (LocalWM)：仅本地详细经验
  - B2：仅本地抽象规则，无共享
  - B3 (NaiveUnion)：简单汇集所有客户端抽象规则，无对齐和范围过滤
  - B4：对齐跨客户端规则但不进行范围兼容性检查
  - B5 (FedWorld)：完整协议，含抽象映射、对齐、范围推断和本地优先编译
  - CDR：集中式详细检索（访问所有客户端原始轨迹，作为无隐私约束的参考）
- **评估指标**：离线用抽象下一状态的精确匹配率，以及配对的正迁移率(PTR)、负迁移率(NTR)和净迁移(Net)；在线用状态倒退次数、重复动作次数、多余步骤和任务成功率。

### 6. 主要结论与发现
- FedWorld 在 τ‑bench 和 ALFWorld 上均能**在保留本地正确知识的前提下有效填补跨客户端知识空白**（S3 和 S5 准确率显著提升 12‑21 个百分点）。
- 在冲突动态下，NaiveUnion 产生严重负迁移（准确率甚至低于纯本地），而 FedWorld 通过范围过滤大幅降低有害覆盖，在严格冲突场景下准确率超越本地和所有对比方法，净迁移由负转正。
- 在线执行中，FedWorld 使状态倒退减少约 45‑48%，重复动作减少约 48‑50%，多余步骤减少 38‑43%，任务成功率绝对值提升 11‑15 个百分点，且提升在不同客户端分区间保持稳定。
- 集中式详细检索并不能替代目标条件化的范围控制，因为即便拥有全部细节，不加过滤的检索仍会为错误目标客户端检索到不适用的冲突规则。
