## 摘要
长期记忆对于LVLM智能体在扩展的多模态交互中保持一致性并整合信息至关重要。然而，现有的智能体记忆系统通常将视觉经验简化为文本摘要，或依赖静态的“检索-推理”流水线，这在查询时效率低下，并且在需要图文绑定、时间更新或视觉细节的问题上表现脆弱。我们提出了前瞻性多模态记忆编译框架，将部分记忆推理过程从查询阶段转移到记忆巩固阶段。面对积累的多模态交互，提问器预测未来的候选问题，规划器编译以问题为条件的多模态记忆程序，而怀疑器验证规划的证据路径是否能支持预测的答案。经过验证的问题-程序对形成了一个结构化的问句库，便于高效查询时的路由和证据检索。在多模态长期记忆基准上的实验表明，我们的方法提高了答案质量和视觉证据召回率，同时降低了查询时的令牌和延迟成本。大量的消融实验分析了自我反馈、动态规划、原始图像访问以及问句库覆盖率的影响。

## Abstract
Long-term memory is essential for LVLM agents to maintain consistency and integrate information across extended multimodal interactions. Existing agent memory systems, however, often reduce visual experiences into textual summaries or rely on static retrieve-then-reason pipelines, which are inefficient at query time and brittle when questions require image-text binding, temporal updates, or visual details. We propose Prospective Multimodal Memory Compilation, a framework that shifts part of the memory reasoning process from query time to memory consolidation time. Given accumulated multimodal interactions, a Questioner predicts future question candidates, a Planner compiles question-conditioned multimodal memory programs, and a Doubter verifies whether the planned evidence path can support the predicted answer. The verified question-program pairs form a structured question bank for efficient query-time routing and evidence retrieval. Experiments on multimodal long-term memory benchmarks show that our method improves answer quality and visual evidence recall while reducing query-time token and latency costs. Extensive ablations analyze the effects of self-feedback, dynamic planning, raw-image access, and question bank coverage.

### 论文提出的方法论
- 核心思想：前瞻性多模态记忆编译，在记忆巩固期生成、编译并验证针对未来可能问题的记忆访问程序，形成结构化问句库；查询时只需匹配和执行预先编译好的程序，无需在线重复规划。
- 关键组件与流程：
  1. **提问器**：根据当前可见的多模态历史片段，生成一组有源信息支撑的预测性问题、改写及证据声明。
  2. **规划器**：针对每个候选问题及其需求合约（模态、能力、证据多重性），编译出一个类型化的有限步长记忆程序。程序由一组固定的检索与证据操作算子构成（如词汇/稠密文本检索、跨模态图像检索、图文上下文展开、时序扩展、原始图像物化等），禁止任意代码或工具调用。
  3. **怀疑器**：实际执行生成的程序，检查其执行轨迹与证据是否符合需求，并根据执行失败情况生成类型化的修订指令（如增加视觉检索、扩展时间上下文等），交由规划器迭代修订，最多进行固定轮次。只有通过执行验证的程序才会被接受。
  4. **问句库**：存储通过验证的规范问题、改写、需求合约、最早通过的冻结程序以及版本信息；预测答案和私有证据支持不会进入问句库，从而保证其只能指导“如何访问记忆”而非直接提供答案。
  5. **查询时路由与回答**：对真实查询进行语义匹配与倒排融合排序，选中置信度足够的已编译程序；在最新的可见记忆上重新执行该程序，物化证据；如路由失败或证据不足，则回退至原生多模态RAG。
- 技术特点：通过执行界定验证替代传统的文本规划自省，避免了“看起来合理但实际无效”的程序；通过问句库实现访问策略与具体证据标识符的分离，允许程序复用且能检索到编译后新产生的记忆。

### 优点
- 思路创新：将“如何访问记忆”的规划从查询阶段前移至巩固阶段，打破传统固定检索或在线自适应检索的范式。
- 设计严谨：采用执行界定验证而非纯文本自省，确保被接受程序的真实可用性；程序与证据标识符分离，支持增量记忆复用。
- 对多模态证据的友好支持：通过类型化算子保留原始图像访问、图文绑定、时间扩展等能力，避免过早文本压缩造成的信息丢失。
- 广泛兼容性：与多种闭源/开源骨干模型配合都能稳定提升效果，方法具有较强的骨干无关性。
- 实验分析深入：从消融、修正轮次、覆盖、路由到成本进行了全面诊断，结论支撑力强。

### 不足与局限
- 前瞻性问题覆盖不足：仍有部分未来需求未被预测到，问句库覆盖率存在天然上限，难以穷尽所有罕见或突发性问题。
- 写时间开销较大：每次记忆巩固需调用提问器、规划器、怀疑器并执行程序，使得单次编译成本较高，仅当长期记忆被多次查询时性价比才能显现。
- 路由瓶颈：问句库匹配精度仍有限，语义上无法完美对齐的查询会触发回退，削弱提前编译的优势。
- 扩展性待验证：目前工作局限于文本对话与图像模态，尚未扩展到视频、音频等更丰富模态或交互式环境；问句库的持续维护、程序策略的学习化等问题仍待探索。
- 实验设置依赖特定指令与模板，且未在更多样化的现实世界代理应用中进行评估，泛化到非基准场景可能存在未知风险。
