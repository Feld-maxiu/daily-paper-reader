## 摘要
基于大语言模型（LLM）的用户行为模拟越来越多地用于支持多智能体生态系统模拟。现有模拟器通常依赖从历史观测中推断出的静态用户画像，这在直播等社交密集环境中变得不足，因为交互动态会持续重塑用户行为。我们提出 LiveSim，一个基于 LLM 的直播生态系统模拟框架。它将用户表示为可编辑的行为假设，并通过基于轨迹的交互逐步细化这些假设，其中模拟轨迹与观测轨迹之间的差异揭示了缺失的环境塑造效应。这些信号被进一步提取为可迁移的环境-行为模式，并积累在集体行为记忆中，以提高用户级行为保真度并支持生态系统级模拟。在真实世界直播风控数据上的实验验证了 LiveSim 在提高用户级行为保真度以及支持风险演化和平台干预效果的生态系统级分析方面的有效性。

## Abstract
User behavior simulation with large language models~(LLMs) is increasingly used to support multi-agent ecosystem simulation. Existing simulators typically rely on static user profiles inferred from historical observations, which become inadequate in socially intensive environments such as live streaming where interaction dynamics continuously reshape user behavior. We propose \textbf{LiveSim}, an LLM-based framework for live-stream ecosystem simulation. It represents users as editable behavioral hypotheses and progressively refines them through trajectory-grounded interactions, where discrepancies between simulated and observed trajectories reveal missing environmental shaping effects. These signals are further extracted as transferable environment-behavior patterns and accumulated in a collective behavioral memory to improve user-level behavioral fidelity and support ecosystem-level simulation. Experiments on real-world live-stream risk-control data validate the effectiveness of LiveSim in improving user-level behavioral fidelity and enabling ecosystem-level analysis of risk evolution and platform intervention effects.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**
  - 基于 LLM 的用户行为模拟正被广泛用于多智能体生态系统模拟，但现有方法普遍依赖从历史观测中推断的**静态用户画像**。
  - 在直播等**社交密集环境**中，主播说服、实时观众反馈、会话动态会持续重塑用户行为倾向；静态画像无法回答“用户在未见过的交互条件下会如何反应”。

- **核心问题**
  - 历史日志只记录用户最终做了什么，而**无法刻画行为如何在交互中形成**。
  - 从历史推断的用户刻画天然是**欠定义的（underspecified）**，不足以应对新环境条件。

- **整体含义与重构**
  - LiveSim 将用户特性重新定义为**可编辑的行为假设（editable behavioral hypotheses）**：基于现有证据的临时假设，可随交互展开而修订。
  - 模拟因此被理解为**逐步塑造行为假设的过程**，而非从固定画像重复采样动作。
  - 模拟与观测轨迹之间的差异不再是单纯误差，而是揭示“当前假设未捕捉到的环境塑造效应”的**诊断信号**。

## 2. 论文提出的方法论

### 2.1 总体框架

LiveSim 在两个层级实现“可编辑假设”思想：

- **个体级：反思式行为假设塑造（Reflective Behavioral Hypothesis Shaping, RBHS）**
  - 从稀疏历史初始化用户假设，通过会话信号暴露假设不足，并将不匹配转化为环境条件化行为更新。
- **生态系统级：闭环多智能体模拟**
  - 将演化后的用户智能体与主播智能体、托儿/水军智能体部署到共享会话上下文中，研究诈骗演化与平台干预。

### 2.2 RBHS 三个关键阶段

1. **初始行为假设 \(P_u^0\)**
   - 从轻量用户元数据、历史访问会话、过往动作、评论内容推断。
   - 组织为三类属性：身份线索、兴趣偏好、风险相关倾向（如对夸大话术的怀疑、跟随意愿）。

2. **探针不匹配（Probe Mismatch）**
   - 由于直播会话严格串行，全轨迹模拟成本过高，故使用**行为探针（behavioral probes）**：从历史轨迹中抽取的高上下文单步预测窗口。
   - 探针提供当前刺激、同轨迹采样历史（主播话语、显著会话信号、观众评论、用户早期动作），要求 LLM 在 \(P_u\) 下预测单个下一步动作。
   - 多个探针可批量调用，生成密集的（预测，观测）对；预测与观测动作不一致即记录为不匹配，并总结为简短的**不匹配签名**。

3. **行为塑造循环（Behavioral Shaping Loop）**
   - **环境-行为补丁（environment-behavior patch）** \(\Delta_u\) 采用 `WHEN-THEN` 模式，描述“特定会话条件如何改变用户潜在状态并重塑动作倾向”。
   - 核心思想是：表面动作是更稳定内部状态的噪声实现，**修补状态转移比修补单个动作更具可迁移性**。
   - RBHS 将 \(P_u^0\) 演化为 \(\tilde{P}_u = P_u^0 \oplus \Delta_u\)。
   - **反思驱动循环**：重新探测修补后的假设，每个探针产生 HIT 分数，汇总为 \(\Delta HIT \in \{-1,0,+1\}\)；根据关联探针将补丁判定为 `effective / regressive / neutral`；LLM 汇总 Good/Bad 反思，指导下一轮补丁生成，新补丁标记 `new/replace`，三轮循环后停止。

### 2.3 集体行为记忆（Collective Behavioral Memory）

- 解决新用户第一轮缺少先验的冷启动问题。
- 跨用户池化 Good/Bad 反思，形成全局行为塑造模式的记忆 \(M\)。
- 在 learner 子集（规模 \(0.2 \cdot |U|\)）上运行 4 轮，预算为 6 条；新反思可强化旧条目，超出预算后淘汰最久未强化条目。
- 应用时通过轻量相关性门控，为每个目标用户引入合适全局先验。

### 2.4 闭环多智能体模拟

- **会话组成**：重放真实历史会话成员；观众智能体携带各自 \(\tilde{P}_u\)，主播智能体使用固定 \(P_{str}\)，不参与 RBHS。
- **每步动态**：观众可选 6 种动作：`LIKE, COMMENT, GIFT, FOLLOW, PRIVATE-MESSAGE, JOIN-GROUP`；`COMMENT` 可生成自由文本。
- 每个观众维护认知状态 \(s_u^t \in \{interest, trust, desire, fatigue\}\) 和交互记忆 \(H_u^t\)。
- 动作与下一状态在一次 LLM 调用中联合生成：
  \[
  (a_u^t, s_u^{t+1}) \sim \pi_\Theta(c_t, \tilde{P}_u, s_u^t, H_u^t)
  \]
- 所有动作和主播话语写入共享上下文 \(c_{t+1}\)，形成闭环，使个体行为通过观众间、观众与主播间耦合产生会话级动态。

## 3. 实验设计

- **划分**：按用户-会话对划分；历史集 11,267 对用于假设初始化和塑造循环；测试集 3,124 对用于轨迹接地评估；同一会话不跨划分，防止泄漏。
- **范围**：仅模拟有足够历史的真实用户，无历史用户不在范围。

### 3.2 评估协议与指标

- **Trajectory-grounded protocol（轨迹接地协议）**
  - 固定真实主播、周围观众和会话上下文，只将目标用户替换为由 \(\tilde{P}_u\) 驱动的模拟智能体。
  - 每一步基于真实上下文预测下一步动作，但用**真实动作**写回记忆（teacher-forced），避免自由 roll-out 的 off-policy 漂移。
- **Closed-loop protocol（闭环协议）**
  - 按 2.4 节联合模拟主播和观众，研究涌现动态、干预反事实。
- **客观指标**
  - 微观：`HIT`（逐步动作精确匹配）、`A-JSD`（每用户动作分布 JS 散度）、`Tr-JSD`（动作转移分布 JS 散度）。
  - 宏观：`Conv-Acc`、`Conv-F1`（针对 follow/私聊/入群等转化行为）。
- **主观指标（LLM Judge）**
  - `Align`（与真实轨迹和证据对齐）、`Consist`（内部一致性/连贯性）、`Plaus`（像真实观众而非机器人）。

## 6. 论文的主要结论与发现

- **RBHS 实现更均衡的用户级保真度**
  - 在 Doubao 1.8 上，A-JSD 下降 43%，Conv-F1 提升 13%，三项 LLM-Judge 得分均列第一；HIT 仅小幅变化，说明 RBHS 主要改进对会话信号的动态响应，而非简单一步模仿。
- **HIT 单独可能是误导性指标**
  - Qwen2.5 7B HIT 很高但分布指标和 Judge 得分差，原因是模型用通用评论坍缩了多样化动作。
- **更强 backbone 不等于更好模拟器**
  - 更大模型可能因内置安全先验抑制转化行为，导致 Conv-F1 下降。
- **消融发现两种反思机制互补**
  - `Direct` 已提供增益；`Self-Reflective` 和 `Direct(+Global Ref)` 各自进一步改善；`LiveSim` 组合效果最好。
- **欺诈演化规律**
  - Shill 密度提升转化但边际递减；前 10 轮贡献 62%–77% 最终转化，存在窄而前置的关键干预窗口；共情转换型 shill 比统一支持型更能提升转化。
- **State-aware 干预最有效**
  - 基于用户当前认知状态的警告最低转化率（8.61%）、最高 Guard 率（58.68%），且延迟转化平均 2.76 轮，落在关键干预窗口内。
- **案例研究**
  - 演化智能体能够激活 \(\Delta_u\) 补丁，恢复真实用户由怀疑到兴趣、欲望、信任并最终 follow 的状态转变；静态智能体则始终停留在怀疑状态。

## 7. 优点

- **范式创新**：把用户从静态画像升级为可编辑行为假设，强调环境如何塑造用户而非用户是谁。
- **可迁移的 WHEN-THEN 补丁**：将环境-行为映射表示为局部、可复用规则，支持跨用户和会话迁移。
- **集体行为记忆**：通过全局反思缓解冷启动，提升新用户初始化质量。
- **轨迹接地协议**：采用 teacher-forced 评估，避免自由 roll-out 的 off-policy 漂移，更贴近在线保护场景。
- **多层次评估**：结合微观/宏观/LLM Judge 指标，避免单一指标误导。
- **闭环模拟支持干预反事实**：可研究诈骗演化与平台干预效果，为风控策略提供沙盒。
- **伦理与合规**：明确数据去标识化、仅用于安全分析、不用于操纵用户等边界。

- **模型安全**：LLM 生成行为可能继承模型内置安全先验，导致风控场景下转化行为被抑制；模拟器输出可能被对抗性提示操纵或产生有害内容，需在部署中设置过滤、审计与使用边界，防止滥用。
