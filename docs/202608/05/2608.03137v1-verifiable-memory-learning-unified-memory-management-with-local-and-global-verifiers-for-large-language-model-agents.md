## 摘要
大语言模型智能体必须在长时程交互中保留可复用信息、控制有限的活动上下文，并恢复先前的证据。现有方法通常分别优化长期记忆和短期记忆，而统一策略往往主要使用轨迹级反馈进行训练，这给单个记忆决策提供的奖励信号很弱。我们提出可验证记忆，该框架将长期记忆、活动上下文和情景历史表示为不同状态，并通过单一记忆操作策略进行控制。七种原子操作允许策略添加、修订或软删除长期记忆条目；将长期记忆检索至活动上下文；过滤或总结活动上下文；以及恢复选定的情景片段。可验证记忆通过监督微调进行初始化，并使用三阶段强化学习课程进行训练。局部验证器对可执行的记忆转换进行评分，全局验证器在任务完成后评估证据连贯性和终端记忆一致性。这些评分通过分层信用分配，与程序化计算得到的任务、证据回忆、效率和约束信号相结合。验证器仅在训练期间使用。在五个基准测试和两个大语言模型骨干上，可验证记忆在绝大多数报告指标上取得了最佳结果，并始终优于强大的记忆基线。在三个交互基准的受控在线令牌预算下，它在对比方法中也实现了最强的效率-性能边界。代码可在 https://github.com/Sun-SYSU-24/VerMem 获取。

## Abstract
Large language model (LLM) agents must retain reusable information, control a bounded active context, and recover earlier evidence during long-horizon interaction. Existing methods commonly optimize long-term memory (LTM) and short-term memory (STM) separately, while unified policies are often trained primarily with trajectory-level feedback, which provides weak credit for individual memory decisions. We present Verifiable Memory (VerMem), a framework that represents LTM, active context, and episodic history as distinct states and controls them with one memory operation policy. Seven atomic operations let the policy add, revise, or soft-delete LTM entries; retrieve LTM into the active context; filter or summarize the active context; and restore selected episodic fragments. VerMem is initialized by supervised fine-tuning and trained with a three-stage reinforcement-learning curriculum. The local verifier scores executable memory transitions, and a global verifier assesses evidence coherence and terminal-memory consistency after task completion. These scores are combined with programmatically computed task, evidence-recall, efficiency, and constraint signals through hierarchical credit assignment. The verifiers are used only during training. Across five benchmarks and two LLM backbones, VerMem achieves the best result on the vast majority of reported metrics and consistently outperforms strong memory baselines. Under controlled online-token budgets on three interactive benchmarks, it also achieves the strongest efficiency--performance frontier among the compared methods. Code is available at https://github.com/Sun-SYSU-24/VerMem.

### 2. 论文提出的方法论

论文提出的核心方法是 **Verifiable Memory (VerMem)** 框架，其关键思想和技术细节如下：

*   **统一的状态与操作空间 (Unified States and Operation Space)**
    *   **三种不同状态**：框架将智能体的记忆明确区分为三种独立但可交互的状态：
        *   **长期记忆 (LTM, Mt)**：持久存储可复用的知识。
        *   **活动上下文 (Active Context, Ct)**：受预算限制、供任务求解器直接使用的当前上下文。
        *   **情景历史 (Episodic History, Ht)**：保存了任务中所有观察、动作和决策的完整有序记录。
    *   **七种原子记忆操作**：一个统一的策略 (πθ) 通过七个原子工具来控制上述状态，这解决了“异构记忆协调”的挑战：
        *   **LTM操作**: `Add` (添加), `Update` (修订，保留历史版本), `Delete` (软删除)。
        *   **STM/上下文操作**: `Retrieve` (从LTM检索到Ct), `Filter` (过滤Ct中低价值内容), `Summarize` (总结Ct)。
        *   **历史恢复操作**: `SelectEpisode` (从Ht中恢复相关片段到Ct)，这解决了“历史上下文恢复”的挑战。
        *   **空操作 (`∅`)**: 一个可被训练的“不执行任何操作”的决策，避免不必要的工具调用。

*   **三阶段强化学习课程 (Three-Stage RL Curriculum)**
    训练遵循 `θ_SFT → θ_A → θ_B → θ_C = θ*` 的参数传递路径：
    1.  **监督微调 (SFT) 预热**：使用精心构建的高质量数据集，由 `DeepSeek-V3.2` 教师模型生成候选，经过严格过滤，初始化策略。
    2.  **阶段A (LTM训练)**: 仅使用LTM工具集 (Add, Update, Delete, ∅)，在涉及增删改查的场景中训练。
    3.  **阶段B (STM训练)**: 仅使用STM工具集 (Retrieve, Filter, SelectEpisode, Summarize, ∅)，在有干扰项的上下文中训练。
    4.  **阶段C (联合训练)**: 启用全部七种工具，在完整的、LTM和STM操作可能交替出现的多步任务中联合优化。

*   **局部与全局验证器引导的分层信用分配**
    这是解决“多粒度信用分配”挑战的核心创新。训练信号被明确分解并组合：
    *   **局部验证器 (Local Verifier)**: 在每一个记忆决策时刻，评估**单个可执行操作**的语义质量（任务相关性、证据基础、局部进展、信息保真度），生成操作级优势 `A_local`。该验证器不会为被硬约束拒绝的命令打分。
    *   **全局验证器 (Global Verifier)**: 在轨迹完成后，评估**整体轨迹的证据连贯性和终端记忆一致性**，并结合程序化计算的任务正确性、证据召回率、在线令牌效率等，生成轨迹级优势 `A_global`。
    *   **信用组合**: 最终用于策略更新的层次化优势值 `A_hier` 是上述两者的加权和，再减去记录硬约束违反的惩罚项 `c_t,k`。公式为：
        `A_t,k^hier = λ_local * A_t,k^local + λ_global * A_k^global - λ_constraint * c_t,k`
        这种设计使得一个好的操作在一个失败的轨迹中也能够保留正向信号，反之亦然。

*   **关键公式与流程**
    *   **状态转换**: 记忆决策 `u_t` 通过转换函数 `T_m` 改变记忆状态，然后任务求解器基于新活动上下文产生动作 `b_t`，环境返回观察 `z_{t+1}`，并通过 `T_e` 进入下一个状态。
    *   **优化目标**: 使用基于PPO (Clipped Surrogate) 和GRPO (Group Relative Policy Optimization) 的优势归一化的联合目标函数 `J_GRPO(θ)`，所有序列化同一个命令的Token共享 `A_hier` 优势值。

### 8. 不足与局限

*   **算力与训练成本**: 虽然推理无开销，但训练成本高昂，因为它依赖于一个冻结的**大型教师模型**和两个独立的**验证器模型**，离线计算量可观。
*   **评估的会话独立性**: 评估设定为**每个任务结束后重置所有记忆状态**，仅评估了“任务内”的记忆持久性。该方法在跨会话、跨用户的长期记忆累积场景下的表现未经测试，而这正是许多现实应用的需求。
*   **模型与领域的局限性**: 训练策略仅在Qwen系列模型上评估，其在其他模型家族上的迁移性未知。训练数据仅基于HotpotQA（文本QA），其在其他垂直领域（如代码、医疗、法律）的潜力需要进一步验证。
*   **评估依赖闭源模型**: 关键的HotpotQA评测指标 `J_judge` 和记忆质量指标 `MQ` 依赖于特定的闭源模型 (`Qwen-Max` 快照），这在一定程度上限制了结果的**完全独立复现性**，尽管作者公开了快照和提示词。
*   **鲁棒性未验证**: 论文未探讨在对抗性记忆、隐私敏感内容或冲突性信息注入等条件下的鲁棒性。
