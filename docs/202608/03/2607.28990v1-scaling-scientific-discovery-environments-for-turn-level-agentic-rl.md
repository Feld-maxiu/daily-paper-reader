## 摘要
大型语言模型智能体在数据驱动的科学发现任务中展现出有前景的能力，智能体与环境交互并生成统计断言。受限于缺乏基于真实科学数据的过程监督环境，长期科学分析仍面临挑战。本文介绍SciDisco，一个用于在过程可验证环境中训练科学发现智能体的可扩展框架。SciThèque将假设、数据集、隐藏证据图和验证器编译为任务环境，在交互过程中可检查分析进展。基于DAG的轨迹合成利用这些环境构建验证器过滤的多轮演示。DiscoPO随后将环境作为训练信号的来源，为产生可验证分析证据的动作分配回合级功劳。实验表明，SciDisco-14B在假设驱动的科学数据分析基准上达到最先进水平。

## Abstract
Large language model agents have shown promising capabilities in data-driven scientific discovery tasks, where an agent interacts with an execution environment and produces a statistical claim. Long-horizon scientific analysis remains constrained by the lack of process supervised environments over real-world scientific data. This paper introduces SciDisco, a scalable framework for training Scientific Discovery agents in process-verifiable environments. SciThèque compiles hypotheses, datasets, hidden evidence graphs, and verifiers into task environments where analytical progress can be checked during interaction. DAG-grounded trajectory synthesis uses these environments to construct verifier-filtered multi-turn demonstrations. DiscoPO then uses the environment as the source of training signal, assigning turn-level credit to actions that produce verifiable analytical evidence. Experiments show that SciDisco-14B reaches state-of-the-art on hypothesis-driven scientific data analysis benchmarks.

### 2. 论文提出的方法论：SciDisco框架

SciDisco是一个三阶段的后训练流程，其核心是任务局部的隐藏证据有向无环图(hidden evidence DAG)，它贯穿所有阶段，定义了可合成的内容、在线互动中可接受的状态转移以及强化学习(RL)中的进度奖励。

*   **核心思想**：将对科学发现的过程监督建模为在隐藏证据图上的状态转移，智能体通过在图中完成验证节点来获得回合级奖励。
*   **关键技术细节**：
    1.  **SciThèque：可扩展环境编译**
        *   **功能**：将开放科学数据集、假设模板和验证逻辑编译为沙盒化的交互任务环境。
        *   **关键组件**：每个环境都包含一个**隐藏证据DAG**。图的节点代表可验证的科学状态转移（如数据检查、模型拟合、诊断检查），边代表前置依赖关系。只有当前沿节点（前置任务已完成）才在特定回合中可被验证。
        *   **可见性分割**：智能体仅能看到任务假设和数据文件，而验证器逻辑、证据DAG和进度状态均对其隐藏。
    2.  **基于DAG的轨迹合成 (SFT冷启动)**
        *   **功能**：为模型冷启动生成经过验证的多轮监督微调(SFT)演示数据。
        *   **流程**：合成器为每个任务规划一条遍历证据DAG的转移计划，并选择可执行的代码变体。在新鲜沙盒中执行这些代码后，环境验证器检查是否生成了匹配前沿节点且符合过程约束的证据。仅保留所有步骤均被接受且最终结论一致的轨迹。
        *   **数据清洗**：保留的SFT轨迹会移除所有隐藏标签、参考值等泄露信息。
    3.  **DiscoPO：回合级信用分配强化学习**
        *   **功能**：在一个组内，根据验证器门控的DAG进度为每个回合分配奖励，而非整个轨迹的最终结果。
        *   **算法流程**：
            *   **状态转移验证**：在每个回合，验证器`v_j`检查当前回合的执行结果是否为**唯一一个**合格的前沿节点生成了可观察证据。被接受则节点被记入`C_{j,k,t+1}`，否则状态不变。
            *   **信用分配**：定义DAG进度潜力函数`Φ_j(C) = |C ∩ P_j| / |P_j|`，回合级过程奖励`r_{j,k,t}`为该潜力的增量。完成一个原始节点或最终提交节点获得正奖励，否则为零。
            *   **组内归一化**：对于同一任务的G个采样轨迹，在同一步骤索引`t`上计算基线`b_{j,t}`和优势`A_{j,k,t} = r_{j,k,t} - b_{j,t}`。
            *   **策略优化**：将回合级优势赋值给该回合内由策略生成的所有token，屏蔽观测token，并使用PPO裁剪代理目标函数进行参数更新。
