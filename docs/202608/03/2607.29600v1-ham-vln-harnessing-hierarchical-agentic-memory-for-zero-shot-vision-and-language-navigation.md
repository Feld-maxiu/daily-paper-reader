## 摘要
视觉语言导航（VLN）使机器人能够在未曾见过的环境中遵循指令。近期涌现出一种无需训练的范式：机器人查询多模态大语言模型来理解其观察并规划下一步动作。然而，基于图像流或密集地图的长程导航不可避免地引入不断增长的内存和推理瓶颈。我们提出了HAM-VLN，这是一种决策耦合、由代理编写的记忆，为机器人配备了一个持久的、基于深度的世界图。在用于选择下一步动作的同一模型调用中，HAM-VLN还记录语义和反思信息——包括房间类型、物体、导航进度和失败记录。最近的路点会在一个限定窗口内保持逐字记录，而更早的历史信息仅通过基于相关性、新近度和显著性的检索以及一跳拓扑扩展重新进入上下文。这种设计不需要在每步决策之外进行额外的大语言模型调用。与先前方法相比，HAM-VLN不仅改善了各种导航指标，还将上下文长度减少了超过65%。具体而言，HAM-VLN在VLN-CE R2R上实现了61.0%的成功率（SR），在VLN-CE RxR上达到52.7%的SR，在HM3D-v2 ObjectNav上达到79.7%的SR，且无需任何训练。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

### 2. 论文提出的方法论

*   **核心思想：层次化代理记忆与深度锚定的世界图**
    该方法突破了传统“被动记录”的记忆模式，让智能体**主动构建**一个结构化的持久记忆，用于指导后续决策。
*   **关键技术细节**
    *   **双进程架构（Dual-Process Architecture）**：
        *   **System 2（推理与规划）**：一个慢速、深思熟虑的MLLM。在每个路点，它接收当前全景观察、有限的近期工作记忆和从世界图中检索到的相关切片，然后输出高层决策（前进方向、回溯或停止），并同步生成结构化的记忆写入。
        *   **System 1（快速策略）**：一个轻量级、专用于视觉定位的MLLM。它将System 2的高层意图（如“走向走廊”）转化为当前视角下的像素级目标框，然后通过确定性控制器（基于深度和里程计）将其转化为可执行的机器人动作。
    *   **决策耦合的记忆更新**：System 2的每次调用不仅产生动作 `at`，还生成一个结构化记录 `wt`，包含**地点语义、观察到的物体、指令进度更新和失败证据（反思）**。这些信息被自动地关联并更新到世界图中，无需额外的LLM调用进行记忆维护。
    *   **稀疏的、深度锚定的世界图**：记忆的主体是一个**地点-物体图**，其节点（地点、物体）和边（导航连接、语义包含）都通过深度信息与物理空间锚定。图的大小仅随**发现的实体的数量**增长，而非探索面积或轨迹长度。
    *   **层次化记忆视图**：记忆系统为System 2提供四种功能视图：
        1.  **工作记忆（Working Memory）**：保留最近 `K` 个路点的原始视觉帧。
        2.  **情景记忆（Episodic Memory）**：记录访问序列和时间戳，用于检索的“新近度”评分。
        3.  **语义记忆（Semantic Memory）**：地点-物体的语义内容和拓扑关系，用于检索的“相关性”评分。
        4.  **反思记忆（Reflection Memory）**：与地点关联的失败笔记，仅在相关地点被检索到时重新进入上下文。
    *   **子目标驱动的记忆检索（Subgoal-Conditioned Retrieval）**：在每个决策点，根据当前子目标 `qt`，对图 `Gt` 中的地点进行评分。评分公式为 `st(p) = α * rel(qt, p) + β * rec_t(p) + γ * sal(p)`，综合了**查询与地点的语义相关性、访问新近度以及地点的感知显著性**。然后，以得分最高的种子地点进行**单跳拓扑扩展**，形成一个紧凑的图切片 `R(Gt, qt)`，作为System 2的上下文输入。
