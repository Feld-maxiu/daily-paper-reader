## 摘要
大型语言模型（LLM）为社会模拟提供了一种可扩展的方法，但其可信度取决于智能体的构建方式。现有方法能够部分再现群体层面的模式，但往往难以捕捉类似人类的多样性。我们的分析表明，与人类相比，静态画像智能体表现出更强的人口统计学分离和组内压缩，这一模式与身份本质主义相一致：人口统计学标签可能促使模型将群体平均倾向视为个体特质，从而使组内反应同质化。我们认为，这一局限性源于两个相关因素：稀疏、静态的智能体表征，以及仅依赖提示的记忆持续整合经验的能力有限。受互补记忆系统启发，我们提出了 LifeMem，一个纵向记忆框架，它结合了结构化生活事件检索与智能体特定的参数记忆，以实现经验整合。在使用三个 LLM 对 Add Health 和 Understanding Society 数据集进行的实验中，LifeMem 在反应分布、整体及组内多样性，以及个体在不同人生阶段反应变化模式方面，均提高了与人类数据的一致性。这些发现凸显了纵向生活事件记忆对于构建更忠实且动态演化的社会智能体的价值。

## Abstract
Large language models (LLMs) offer a scalable approach to social simulation, but their credibility depends on how agents are constructed. Existing methods can partially reproduce population-level patterns, yet often fail to capture human-like diversity. Our analysis shows that static-profile agents exhibit stronger demographic separation and within-group compression than humans, a pattern consistent with identity essentialism: demographic labels can encourage models to treat group-average tendencies as individual traits, homogenizing responses within groups. We argue that this limitation arises from two related factors: sparse, static agent representations and the limited ability of prompt-only memory to persistently integrate experience. Inspired by complementary memory systems, we propose LifeMem, a longitudinal memory framework that combines structured life-event retrieval with agent-specific parametric memory for experience integration. Experiments on Add Health and Understanding Society with three LLMs show that LifeMem improves alignment with human data in terms of response distributions, overall and within-group diversity, and patterns of within-person response change across life stages. These findings highlight the value of longitudinal life-event memory for constructing more faithful and dynamically evolving social agents.

## 2. 论文提出的方法论

### 2.1 问题形式化

- 设 \(I=\{1,\dots,N\}\) 为个体集合，\(W=\{1,\dots,T\}\) 为有序纵向波次。
- 每个个体 \(i\) 有静态画像 \(P_i\)，以及第 \(t\) 波观察到的一组生活事件 \(E_{i,t}=\{e_{i,t,k}\}\)。
- 累积轨迹 \(T_{i,\le t} = \bigcup_{\tau=1}^{t} E_{i,\tau}\)。
- 对评估问题 \(q_{t,j}\)，LifeMem 预测：
  \[
  \hat y_{i,t,j} = F_{\theta,A_{i,t}}\bigl(P_i, R_{i,t}(q_{t,j}), q_{t,j}\bigr)
  \]
  其中 \(\theta\) 是冻结的基础 LLM，\(A_{i,t}\) 是智能体特定 LoRA 适配器，\(R_{i,t}(q)\) 是从结构化记忆中检索到的事件。

### 2.2 LifeMem 核心思想

- 受认知科学中的**互补学习系统理论**启发：
  - 海马体快速编码具体经历；
  - 新皮质逐步跨经历整合出持久表征。
- LifeMem 包含两个互补记忆组件：
  1. **海马式结构化记忆**：显式保存生活事件、语义嵌入和时间信息，用于问题相关检索；
  2. **皮层式参数记忆**：为每个智能体维护独立 LoRA 适配器，逐步将经验编码进参数，提供跨问题、跨波次的持久状态。

### 2.3 结构化生活事件记忆

- 每个生活事件由问卷问题–答案对转换而来，生成**第二人称陈述** \(x_{i,t,k}\)，并保留原始问题与回答。
- 冻结编码器 \(g_\phi\) 将陈述映射为嵌入 \(h_{i,t,k}\)。
- 存储形式：
  \[
  \mathcal M^S_{i,t} = \{(e_{i,\tau,k}, h_{i,\tau,k}, \tau) \mid 1\le \tau \le t\}
  \]
  新事件不断追加，旧事件保留，保证轨迹可追溯。
- 对问题 \(q\) 的检索分数结合语义相似度与时间衰减：
  \[
  \text{Score}_t(q,e_{i,\tau,k}) =
  \text{sim}\bigl(g_\phi(q), h_{i,\tau,k}\bigr)\exp[-\lambda(t-\tau)]
  \]
  其中 \(\lambda \ge 0\) 控制对近期事件的偏好；时间衰减只调整检索优先级，不删除旧事件。
- 取 top-K 事件作为证据插入推理 prompt，提供问题相关但可追溯的信息。

### 2.4 皮层参数记忆

- 保持基础 LLM 冻结，为每个智能体维护一个 LoRA 适配器：
  \[
  W^{(l)}_{i,t} = W^{(l)}_0 + \frac{\alpha_{\text{LoRA}}}{r} B^{(l)}_{i,t} A^{(l)}_{i,t}
  \]
  其中 \(r\) 为 LoRA rank，\(\alpha_{\text{LoRA}}\) 为缩放系数。
- 每个生活事件生成两类训练实例：
  1. **问卷问题–答案对**：保留观察到的回答信号；
  2. **事件重构实例**：从第二人称事件生成第一人称自我记忆。
- 适配器按波次顺序更新：
  \[
  \Theta^{\text{LoRA},(0)}_{i,t} = \Theta^{\text{LoRA}}_{i,t-1}, \quad t>1
  \]
  第一波从共享适配器状态初始化。
- 训练目标混合当前事件与少量历史事件重放：
  \[
  \mathcal L_{i,t} =
  \sum_{z\in B^{\text{cur}}_{i,t}} \ell(z;\theta,\Theta^{\text{LoRA}}_{i,t})
  + \eta \sum_{z\in B^{\text{rep}}_{i,t}} \ell(z;\theta,\Theta^{\text{LoRA}}_{i,t})
  \]
  其中 \(\eta\) 控制重放权重。默认 replay size = 4，replay weight \(\eta=0.5\)。
- 还加入**稳定性正则化**，限制单波更新幅度，缓解灾难性遗忘：
  \[
  \gamma \left\|\Theta_{i,t} - \Theta^{\text{before}}_{i,t}\right\|_2^2
  \]
  默认 \(\gamma=0.01\)。

### 2.5 关键设计选择

- 默认参数：LoRA rank 8，缩放系数 16，dropout 0，目标模块为 q_proj、v_proj、o_proj、down_proj；学习率 \(1\times10^{-4}\)；每波训练 2 epoch。
- 结构化检索使用 all-MiniLM-L6-v2，top-K=5；时间衰减默认约 0.9 等效果数。
- 与 Event RAG 比，LifeMem 用更轻量 retriever，但凭借参数记忆仍取得更好效果。

## 3. 实验设计

### 3.1 数据集

- **Add Health**：美国青少年到成人健康纵向研究，使用全部 6 波（Wave I–VI），追踪从青春期到成年早期。
- **Understanding Society / UKHLS**：英国家户纵向研究，使用 15 波（2009–2024），支持评估相邻波次之间的回答变化。
- 仅保留在所有波次中均被观察到的受访者：Add Health 对齐后 2,048 人，UKHLS 对齐后 14,104 人；主实验随机抽样 **100 人**（seed 42）。
- 变量分类：
  - **demographic**：用于初始画像；
  - **life event**：用于结构化记忆和参数记忆更新；
  - **evaluate**：仅用于评估，严格排除在画像和记忆之外，防止泄漏。
- UKHLS 构建了一个跨 15 波共享的纵向评估集（50 个变量），用于计算转移分布 JS 散度。

### 3.2 评估指标

均为越小越好：

- **KL 散度**：人类与智能体回答分布的差异；
- **组内成对距离差 / WG Gap**：衡量组内多样性与人类的接近程度，反映身份本质主义程度；
- **归一化熵差**：回答集中度或分散度的匹配程度；
- **转移分布 JS 散度**：仅 UKHLS，衡量相邻波次之间回答变化模式是否接近人类。

### 3.3 基线方法

- **静态条件**：Direct（仅问题）、Profile（人口画像）。
- **多样性导向提示**：Multilingual（随机翻译为四种语言）、Anti-Stereotype（追加反刻板印象指令）。
- **非参数记忆**：SimVBG（生成背景故事）、Full History（完整历史事件）、Event RAG（检索相关事件）。
- **控制基线**：Random Event（随机使用他人事件，保留格式但去除个体对应关系）。
- **LifeMem**：本文方法。

### 3.4 模型与实现

- 三个 instruction-tuned LLM：
  - Llama-3.1-8B-Instruct（Llama-8B）
  - Ministral-3-8B-Instruct-2512
  - Qwen3.5-9B（关闭 thinking mode）
- 所有方法共享：相同样本、问题、骨干、温度 0、确定性解码、最大输入 4096 token、最大输出 16 token、bfloat16。
- 减少随机性：同一样本和 deterministic hash 等，保证对比公平。
