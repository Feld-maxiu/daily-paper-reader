## 摘要
在自动化网页测试中，利用自然语言功能描述生成测试用例并执行测试对于提升效率至关重要。这些任务要求测试智能体能够在目标应用上自主执行任务并生成测试。我们提出 HxAgent，一种基于 LLM 的迭代式规划智能体，采用主动纠错策略。每执行一步后，HxAgent 会重新评估网页状态，以确定下一步动作，综合利用（1）当前观察、（2）过去动作的短期记忆，以及（3）从过去正确或错误动作序列中提取的长期经验。HxAgent 在 MiniWoB++ 上实现了 97.4% 的精确匹配准确率，与无需人类演示的最佳基线相当，并且比最新的 WALT 高出 10.5%。在包含 350 个网页任务的数据集上，它达到了 83.8% 的精确匹配和 91.8% 的前缀匹配，超出 WALT 13.4%。在 OnlineMind2Web 上，它进一步比 WALT 提升了 4.6%。

## Abstract
In automated web testing, generating test cases and performing testing using functionality descriptions in natural-language is crucial for improving efficacy. These tasks require such a testing agent to carry out tasks on the target application and generating tests autonomously. We introduce HxAgent, an iterative LLM-based planning agent with a proactive correction strategy. After each step, HxAgent reassesses the web state to determine the next action using (1) current observations, (2) short-term memory of past actions, and (3) long-term experience extracted from past (in)correct sequences of actions. HxAgent achieves 97.4% Exact-Match accuracy on MiniWoB++, comparable to the best baselines without human demonstrations and surpassing the recent WALT by 10.5%. On a dataset of 350 web tasks, it attains 83.8% Exact-Match and 91.8% Prefix-Match, exceeding WALT by 13.4%. On OnlineMind2Web, it further improves over WALT by 4.6%.

- **整体含义**：HxAgent 提出一种迭代式 LLM 规划智能体，通过主动纠错、短期记忆和长期经验三者的结合，实现从任务目标自动生成可执行的测试动作序列，提升端到端网页测试的效能与泛化能力。

## 2. 论文提出的方法论

### 2.1 核心建模

- 将 Web 任务执行建模为**部分可观测马尔可夫决策过程（POMDP）**：  
  `M = (S, A, O, T, R, γ)`
- **多模态观察**：每个时间步 t 的观察 `o_t = (o_t^txt, o_t^img, o_t^elm)`，分别包含文本 DOM 信息、网页截图和可交互元素集合。
- **可行动作集合**：`A(o_t) = {(op, e, v) | e ∈ o_t^elm, op ∈ O, v ∈ V ∪ {∅}}`，其中 `op` 为操作类型（如 click、input），`e` 为网页元素，`v` 为可选输入值。
- **动作序列**：`τ_t = ((s_0, a_0), (s_1, a_1), ..., (s_t, a_t))`。
- **短期记忆（Sequence Action Memory, SAM）**：  
  `M_t = {(ŝ_{t-k}, a_{t-k}), ..., (ŝ_{t-1}, a_{t-1})}`，保存最近 k 步状态-动作对，维护近期交互上下文。
- **长期经验记忆（Experience Memory）**：  
  `E = {(τ^(i), y^(i))}_{i=1}^N ∪ K^(j)`，存储历史轨迹及成功/失败标签，以及抽象出的行为规则。
- **规则提取函数**：`K^(j+1) = ϕ(τ^(i), E)`，通过 LLM 从轨迹中抽象出简洁的行为规则（例如“点击前先验证标签”），避免重复存储已有规则。
- **动作接地函数**：`a_t ∼ π(· | o_t, A(o_t), M_t, E)`，由 LLM 实现，并在可行动作集合上受限。
- **状态评估函数**：`{success, stop} ∼ G(τ_t, M_t, E)`，决定任务是否完成或是否提前终止。

### 2.2 关键设计理念

- **迭代式 LLM 规划**：每步根据当前页面、可行动作、短期记忆和长期经验，在反馈循环中确定下一步动作，并将推理锚定在文本和视觉证据上，减少幻觉。
- **主动纠错**：与反应式修复（如 Reflexion）不同，HxAgent 在每一步后重新评估状态并调整计划，而不是在整条轨迹失败后才修正。
- **短期记忆**：保存历史状态-动作对，避免重复失败决策，为推理提供显式上下文。
- **经验强化**：训练阶段收集成功/失败轨迹，提取规则；评估阶段使用最优经验作为固定提示输入。
- **视觉增强**：当存在多个相同或模糊的可选动作时，利用截图辅助选择正确元素；对于大型 DOM，使用 LLM 从截图生成文本摘要以避免上下文溢出。

### 2.3 架构与算法流程

HxAgent 架构包含四个主要组件：

1. **Content Extractor**：从当前网页状态 `s_t` 提取内容表示 `ŝ_t` 和可行动作集合 `A(o_t)`；对大型 DOM 生成文本摘要或简化 HTML。
2. **State Evaluator**：利用 LLM 评估当前动作序列、短期记忆和经验，判断成功、提前终止或继续。
3. **Action Grounding**：根据当前观察、可行动作、短期记忆和经验，用 LLM 选择下一步动作；若候选动作重复，则利用视觉观察重新选择；若动作需要输入值，则由 LLM 生成输入内容。
4. **Rule Extractor**：从完成的轨迹中提取新的行为规则，更新长期经验。

**算法伪代码逻辑**（Algorithm 1 归纳）：
- 初始化短期记忆为空，加载目标页面。
- 循环直至达到最大步数：
  - 提取当前状态和可行动作。
  - 用状态评估器判断是否成功或提前终止；若终止，记录结果到经验并跳出循环。
  - 否则用动作接地选择下一步动作。
  - 若候选动作重复，利用视觉观察重新选择。
  - 若动作需要输入，生成输入值并附加到动作。
  - 更新短期记忆，执行动作得到新状态。
- 若达到最大步数仍未完成，记录为失败。
- 循环结束后，从轨迹提取规则更新经验。

**测试用例生成**：将成功完成任务的 SoA 转换为测试用例，任务描述作为测试用例名称，每个步骤对应动作类型、值、目标元素和页面状态，可在回归测试中自动回放。

## 6. 主要结论与发现

- **性能优势**：
  - Real-world 数据集：Exact-Match 83.8%，Prefix-Match 91.8%，分别超出 WALT 13.4% 和 13.0%，超出 Li et al. 56.8%。
  - OnlineMind2Web：Exact-Match 50.7%，Prefix-Match 62.4%，超出 WALT 4.6%，在 easy/medium/hard 各难度均优于基线。
  - MiniWoB++：Exact-Match 97.4%，与最佳基线（Synapse 97.3%）相当，但无需人类演示；在挑战性任务上 Exact-Match 81.6%，远高于 Li et al.（9.6%）和 SeeAct（8.0%）。
- **测试生成有效性**：MiniWoB++ 上 100% 成功生成可执行脚本，Real-world 为 90.8%，OnlineMind2Web 为 77.3%。
- **组件贡献**（消融）：
  - 移除短期记忆和经验的组合，Exact-Match 从 97% 降至 47%，降幅最大，表明短期记忆最关键。
  - 移除迭代规划，Exact-Match 降至 75%。
  - 仅移除长期经验，Exact-Match 降至 88%，影响相对较小，但验证了经验+短期记忆的组合价值。
- **成本效率**：HxAgent 总 token 约为 WALT 的 1/3，输出 token 更少。
- **经验学习趋势**：随着训练进行，moving average 正确率上升，说明长期经验持续积累有效知识。

## 7. 优点

- **创新性设计**：首次将短期动作记忆与长期经验规则提取相结合，并引入主动纠错机制，区别于传统的被动反思。
- **可执行输出**：生成的动作序列可直接转换为可回放的回归测试脚本，无需在回放时再调用 LLM，落地价值高。
- **多模态增强**：利用截图辅助解决重复元素、复杂布局和大型 DOM 上下文溢出问题。
- **经验可解释**：通过规则提取形成文本启发式，便于人类理解和维护。
- **成本控制**：相比 WALT 具有明显 token 效率优势。
- **实验覆盖较广**：在三个不同来源的数据集上验证，包含消融和成本

分析等实验，验证了方法的有效性和效率。

## 8. 缺点与局限性

- **单一主干模型依赖**：所有实验均基于 GPT-4o，未验证在其他 LLM（如 Claude、Gemini、开源模型等）上的表现，难以判断方法的模型无关性和稳定性。
- **数据与评估的潜在偏差**：
  - Real-world 数据集由模板实例化生成，任务类型相对固定，不一定覆盖真实用户行为的多样性与不可预测性。
  - OnlineMind2Web 剔除了 15 个不可访问任务，可能排除了部分困难或动态变化较大的网站，导致评估结果偏乐观。
  - MiniWoB++ 训练仅使用 20 个任务实例，规则提取的泛化性存疑；且训练集与评估集来自同一环境，存在一定过拟合风险。
- **失败模式与边界场景未充分讨论**：论文未系统分析登录、验证码、弹窗、多标签页、异步加载、动态变化界面等真实 Web 测试中的典型挑战，这些场景下 HxAgent 的成功率和鲁棒性尚不明确。
- **评估指标可能过于严格或不足**：Exact-Match 要求整条序列完全正确，可能低估部分正确但最终可接受的情况；Prefix-Match 仅衡量前缀正确率，未考虑后续动作的实际可执行性；两者均未直接反映回放时的真实通过率。
- **缺乏重复运行与方差报告**：虽然设置温度 0，但未说明是否多次运行取平均或报告置信区间，结果稳定性无法评估。
- **短期记忆窗口选择缺乏理论依据**：窗口大小 k 通过消融实验确定，但未提供自适应或动态调整机制，不同任务复杂度下固定窗口可能不是最优。
- **长期经验的更新与冲突消解未深入**：经验规则提取可能产生冗余、冲突或过时规则，论文未说明如何维护规则库的一致性、去重或遗忘机制。
- **动作接地依赖可行动作集合**：当候选动作集合不完整或元素定位失效时，智能体可能无法选择正确操作；视觉增强虽能缓解，但未解决根本的定位脆弱性问题。
- **计算成本仍较高**：尽管总 token 仅为 WALT 的 1/3，但平均每任务约 80k 输入 token、22k 输出 token，在大规模回归测试中成本仍不可忽视。
- **可解释性与可维护性局限**：虽然提取行为规则有助于理解，但整体决策过程仍是黑盒 LLM 推理，错误分析困难。

## 9. 可能的改进方向

- **多模型泛化验证**：在多个主流 LLM 及开源模型上测试 HxAgent，评估其对模型能力差异的鲁棒性，并探索模型无关的提示设计与经验迁移。
- **更真实的数据集与评估协议**：构建基于真实用户行为日志的数据集，纳入登录、验证码、弹窗、多标签页等边界场景；采用回放成功率作为核心指标，降低 Exact-Match 的严格性偏差。
- **动态短期记忆与自适应窗口**：根据任务复杂度、页面变化频率或模型置信度动态调整短期记忆窗口大小，甚至引入注意力机制选择最相关的历史状态-动作对。
- **经验规则的冲突消解与生命周期管理**：设计规则去重、冲突检测、优先级排序和遗忘机制，避免规则库臃肿或相互矛盾；可采用向量数据库或知识图谱存储与检索经验。
- **更强的视觉 grounding 与元素定位**：结合更先进的视觉模型（如 Grounding DINO、SAM）或 DOM-视觉融合定位技术，提升动态页面下的元素识别鲁棒性。
- **成本进一步优化**：通过缓存页面摘要、复用历史推理、使用更小模型处理简单步骤、或采用分层规划（高层计划 + 低层动作）来降低 token 消耗。
- **扩展到更多平台与应用**：将方法迁移到移动 App、桌面软件或 API 测试，验证跨平台的通用性；也可探索多智能体协作或人机协同的测试生成。
- **可解释性与调试支持**：提供逐步推理可视化、失败归因分析和交互式修正界面，帮助测试人员理解智能体决策并快速修复错误。
- **公开代码与数据**：发布可复现的实验环境、数据集和规则库，促进社区验证与后续研究。

## 10. 总结

HxAgent 提出了一种结合短期记忆与长期经验规则的迭代式 LLM 规划智能体，能够在无人工演示的情况下，从自然语言任务描述自动生成可执行、可回放的 Web 测试动作序列。论文在多个数据集上验证了其有效性和 token 效率，并通过消融实验揭示了主动纠错、短期记忆和经验强化的贡献。尽管存在单一模型依赖、数据集偏差、边界场景未覆盖等局限，但整体设计兼顾了自动化程度、可解释性和工程实用性，为 Web UI 测试领域的智能体研究提供了有价值的思路和基线。未来工作可在多模型鲁棒性、真实场景评估、成本优化和平台扩展等方面进一步深化。
