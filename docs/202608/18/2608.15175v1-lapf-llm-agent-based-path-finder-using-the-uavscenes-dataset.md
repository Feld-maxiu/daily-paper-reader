## 摘要
无人驾驶航空器（UAV）正越来越多地被部署用于复杂室外环境中的自主导航，在这些环境中，动态条件和任务需求要求智能自适应决策。现有的基于优化的方法、机器学习（ML）方法和强化学习（RL）方法通常依赖预定义模型或特定任务训练，限制了它们在不确定场景下的泛化能力和适应性。近期的大语言模型（LLM）辅助方法展现了有前景的推理能力，但仍受限于有限的智能体功能，包括记忆、规划及工具交互机制不足。本文提出了一种基于LLM智能体的路径查找器（LAPF）框架，用于城镇尺度室外环境中的自主UAV导航。LAPF通过将感知、记忆、规划与行动模块集成到闭环认知架构中，扩展了LLM辅助导航。所提出的智能体利用先前的导航经验，执行思维链（CoT）推理，将每个检测到的危险与一个有界纠正动作相耦合，并根据环境反馈动态细化航路点决策。每种方法的三次独立试验表明，LAPF在开阔场地和障碍物注入场景中的平均路径长度分别为512.83 m和506.37 m，而直线最优路径为497.33 m；相对于CoT提示，路径长度分别缩短了17.2%和15.6%，绝对路径效率分别达到97.1%和98.1%。此外，LAPF是唯一一种在保持近目标稳定性的同时，将每个检测到的危险都与一个有界且度量中立的纠正动作相耦合的评估方法，并且在两种场景中钳位事件均为零，而CoT提示的钳位事件从9.7次增加到14.0次。

## Abstract
Uncrewed aerial vehicles (UAVs) are increasingly deployed for autonomous navigation in complex outdoor environments, where dynamic conditions and mission requirements require intelligent adaptive decision-making. Existing optimization-based, Machine Learning (ML), and Reinforcement Learning (RL) approaches often rely on predefined models or task-specific training, limiting their generalization and adaptability in uncertain scenarios. Recent Large Language Model (LLM)-assisted approaches offer promising reasoning capabilities but remain constrained by limited agentic functionality, including insufficient memory, planning, and tool interaction mechanisms.This paper proposes an LLM-Agent-Based Path Finder (LAPF) framework for autonomous UAV navigation in town-scale outdoor environments. LAPF extends LLM-assisted navigation by integrating perception, memory, planning, and action modules into a closed-loop cognitive architecture. The proposed agent leverages prior navigation experiences, performs Chain-of-Thought (CoT) reasoning, couples each detected hazard to a bounded corrective action, and dynamically refines waypoint decisions based on environmental feedback.The three independent trials per method demonstrate that LAPF achieves mean path lengths of 512.83 m and 506.37 m, compared to the straight-line optimum of 497.33 m, corresponding to path length reductions of 17.2% and 15.6% relative to CoT prompting and absolute path efficiencies of 97.1% and 98.1% in open-field and obstacle-injected scenarios, respectively. Furthermore, LAPF is the only evaluated approach that couples every detected hazard to a bounded, metric-neutral corrective action while maintaining near-goal stability, with zero clamp events in both scenarios, whereas CoT prompting increases from 9.7 to 14.0 events.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将导航建模为**闭环的顺序决策过程**，而非单步“观察→航点”映射。
- 在每一决策步，智能体利用多模态观察（RGB 图像、LiDAR 摘要、6-DoF 位姿）、情节记忆（最近 k 个导航片段）和性能反馈信号，通过思维链（CoT）推理生成候选航点，并通过**工具强制安全机制**对模型输出进行有界修正。

### 2.2 系统架构

框架包含四个核心模块（感知、记忆、规划、动作），组成“感知→推理→行动→反馈”循环：

- **感知模块**：
  - 接收 RGB 图像 \(I_t\)（原生输入 VLM，不文本化）、LiDAR 点云摘要 \(\sigma_t\)（点数、距离范围、横向范围、下视净空 \(c_t\)）以及 6-DoF 位姿 \(L_t=(R_t,p_t)\)。
  - 其中 \(\sigma_t\) 中的 \(c_t = \min_i x_i\) 表示沿视线方向到最近表面的距离（保守下界），用于安全判断。
- **记忆模块**：
  - 维护**情节记忆** \(M_t\)，存储最近 \(k=3\) 个决策片段的观测、执行航点、执行结果和反思（reflection）。
  - 基于最近性检索（非相似性检索），为智能体提供时间连续性和历史经验。
  - 同时维护性能反馈信号 \(\phi_t\)（基于路径长度统计的滑动窗口趋势）。
- **规划模块**：
  - 使用策略 \(\pi:(\mathcal{P}_{sys}, G, O_t, M_t, \phi_t) \mapsto (\widehat{wp}_t, \text{Tools}_t)\)。
  - 在同一推理调用中将 RGB 图像（原图像块）和符号状态（文本）输入开放式权重 VLM（Qwen2-VL-7B），强制输出结构化 JSON，包含“情况分析”、“思考”、“航点”和“工具调用”。
  - 通过 CoT 推理联合考虑当前观测、记忆、反馈，生成一个候选航点。
- **动作模块（两层级防护策略）**：
  - **第一层（强制安全）**：每步评估危险指示 \(h_t = \mathbb{1}[c_t \le d_{\text{safe}}]\)（\(d_{\text{safe}}=5\) m），若触发，则丢弃模型建议，执行**确定性纠正算子** \(R(wp_{t-1}) = wp_{t-1} + \kappa(p_{\text{goal}} - wp_{t-1})\)，\(\kappa=0.5\)，保证有界、可复现，且度量中立（不改变路径效率指标）。
  - **第二层（自由裁量）**：若模型输出未触发危险，则应用稳定算子 \(C(\cdot)\) 限制近目标区步长；若模型请求“WaypointAdjust”工具，则应用保持位置算子 \(H(\cdot)\)。
  - 最终执行航点由有序复合 \(wp_t = H(\mathbb{1}[\text{WaypointAdjust}\in\text{Tools}_t])\left(h_t R(wp_{t-1}) + (1-h_t) C(\widehat{wp}_t)\right)\) 决定。

### 2.3 关键公式与性质

- **观测模型**：\(O_t = \{I_t, \sigma_t, L_t\}\)。
- **LiDAR 摘要**：\(\sigma_t = (n_t, r_{\min,t}, r_{\max,t}, b_{\min,t}, b_{\max,t}, c_t)\)，\(c_t\) 为下视净空。
- **路径效率度量**：
  - 已行驶长度 \(L_t = \sum_{i=1}^t \|wp_i - wp_{i-1}\|\)；
  - 直线最优 \(L^\star = \|p_{\text{goal}} - wp_0\|\)；
  - 投影任务长度 \(\tilde{L}_t = L_t + \|p_{\text{goal}} - wp_t\|\)；
  - 路径效率 \(\eta_t = L^\star / \tilde{L}_t\)；
  - 绕路比 \(\varrho_t = \eta_t^{-1}\)。
- **性质 1（\(R\) 的度量中立性）**：当触发 \(R\) 时，\(\Delta_t = \tilde{L}_t - \tilde{L}_{t-1} \ge 0\) 恒成立，且当且仅当航点位于 \([wp_{t-1}, p_{\text{goal}}]\) 线段上时取等号；\(R\) 始终使航点落在此线段上，因此其贡献为 0，即安全防护不影响路径效率指标。该“分离设计”将安全与轨迹质量解耦。

## 3. 实验设计

### 3.1 数据集与场景

- **数据集**：UAVScenes（多模态无人机感知基准），包含 RGB 图像、LiDAR、6-DoF 位姿、语义标签、3D 地图等。
- **具体序列**：AMtown03（城镇尺度室外环境），从中选取 41 帧，决策步长 \(T_{\max}=110\)（超出帧数时循环使用记录流，保证所有方法评分步数相同）。
- **两种实验场景**：
  1. **开阔场景**（无注入障碍）：记录流中 \(c_t\) 始终 >15 m，因此 \(h_t=0\) 对所有步。
  2. **障碍注入场景**：在 5 个预选决策步覆盖下视净空 \(c_t\)，其中 4 个低于安全阈值 5 m，触发危险。

### 3.2 对比方法（Benchmark）

- **Pure LLM**：非智能体基线，直接从输入状态生成航点，无记忆、无反馈、无迭代修正。
- **CoT LLM**：加入逐步推理的非智能体基线，但仍无外部反馈或工具交互。
- **LAPF**（本文方法）：上述智能体架构。
- **公平性控制**：三种方法使用**相同的 Qwen2-VL-7B-Instruct 骨干**、相同的解码设置（temperature=0.7 等）、**完全相同的多模态观察序列**（RGB 原图 + 符号状态逐字节一致）、相同的近目标稳定算子 \(C\) 和保持位置算子 \(H\)。

### 3.3 评估指标

- 平均路径长度（m）、路径效率（%，相对直线最优）、绕路比、**不安全事件数** \(N_h\)（危险指示触发次数）、**钳位事件数** \(N_c\)（近目标步长截断次数）。

## 6. 主要结论与发现

- **路径长度**：
  - 开阔场景：LAPF 平均 512.83 ± 26.78 m，Pure LLM 556.37 ± 15.02 m，CoT LLM 619.16 ± 29.01 m；最优直线 497.33 m。
  - 障碍注入场景：LAPF 506.37 ± 16.68 m，Pure LLM 581.51 ± 35.20 m，CoT LLM 599.89 ± 37.20 m。
- **路径效率**：
  - 开阔场景：LAPF 97.05 ± 5.09%，Pure LLM 89.43 ± 2.45%，CoT LLM 80.37 ± 3.85%。
  - 障碍注入场景：LAPF 98.09 ± 3.17%，Pure LLM 85.73 ± 5.05%，CoT LLM 82.96 ± 5.30%。
- **相对 CoT 的路径长度减少**：开阔场景 17.2%，障碍注入场景 15.6%。
- **钳位事件（近目标步长截断）**：
  - 开阔场景：LAPF 0，Pure LLM 0，CoT LLM 9.7。
  - 障碍注入场景：LAPF 0，Pure LLM 2.3，CoT LLM 14.0。
- **不安全事件**：障碍注入场景中三种方法均检测到 4 次危险（\(c_t < 5\) m），但只有 LAPF 能将每次危险与有界纠正动作耦合（通过强制工具），而基线方法无执行路径。
- **核心发现**：智能体架构中的**情节记忆 + 性能反馈 + 工具强制安全**是性能提升的关键；单纯增加推理深度（CoT）不足以保证航点校准和稳定性，甚至导致钳位事件增加。

## 7. 优点

- **架构创新**：将 LLM 从单次提示扩展为具有记忆、规划、工具调用的闭环智能体，填补了 UAV 导航中“智能体功能不足”的空白。
- **安全与度量解耦**：通过性质 1 设计有界、度量中立的纠正算子 \(R\)，既保证危险响应又不干扰路径效率评估，这一分离使实验结论更具可解释性。
- **公平对比**：严格统一了骨干、解码参数、多模态观察和外部算子，确保性能差异仅源于智能体机制，减少了混杂因素。
- **资源友好**：整个评估在消费级笔记本（Apple M5, 16 GB）上完成，证明开放权重 VLM 可支撑边缘端多模态导航，不依赖专有大模型。
- **透明性**：详细报告了提示模板、超参数、安全阈值、记忆窗口等实现细节，并明确说明哪些模块为未来工作（如语义/深度融合）。
- **实验控制**：障碍注入覆盖观察流而非命令状态，保持共同观察协议；相同不安全事件计数作为对照，验证方法暴露于相同危险。

## 8. 不足与局限

- **实验覆盖有限**：
  - 仅使用 UAVScenes 的 AMtown03 单个序列，未包含密集城市场景（高楼、窄街、行人），结论的外推性受限制。
  - 仅测试一种 VLM 骨干（Qwen2-VL-7B），未验证对其他模型（更强/更弱）的鲁棒性。
  - 仅 3 次独立试验，缺乏统计显著性检验或置信区间外的稳健性分析。
- **无消融实验**：未隔离记忆、反馈、工具各模块的单独贡献；视觉通道的消融也未进行（图像输入对所有方法相同，无法评估其独立价值）。
- **安全模型简化**：
  - 危险检测仅基于下视净空 \(c_t\)（单标量），无法评估水平方向障碍或完整 3D 碰撞风险；传感器为下视配置，不适用于前视避障。
  - 纠正算子 \(R\) 仅保证有界响应，不提供几何避障保证；缺少全局位移约束（\(\|\Delta wp\| \le \Delta_{\max}\)）与运动学可行性联合评估。
- **评估受控而非自然**：障碍注入为人工覆盖下视净空，未在实际低空飞行或真实障碍物环境中验证；记录流中 \(c_t\) 始终 >15 m，因此自然危险几乎不存在。
- **决策层与执行层分离**：论文仅建模决策层航点命令，未集成低层飞行控制器，实际飞行轨迹可能与命令航点存在偏差。
- **计算效率未充分讨论**：虽然运行在笔记本上，但规划调用超时达 600 s（LAPF），实时性存疑；未报告单步平均推理时间或端到端延迟。
