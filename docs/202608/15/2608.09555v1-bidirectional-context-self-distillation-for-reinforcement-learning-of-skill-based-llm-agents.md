## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用、可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为合适的动作。然而，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常以任务级奖励为中心的强化学习目标进行训练，这种目标提供的监督有限，难以捕捉策略在使用所提供的技能时有效性的细微差异。我们提出了BCSD（Bidirectional Context Self-Distillation，双向上下文自蒸馏），这是一个将自蒸馏与强化学习相结合的框架，用于训练LLM智能体更有效地使用外部技能。与以往依赖单一特权上下文的自蒸馏方法不同，BCSD从两个互补的技能-上下文视角评估每条轨迹。增强视角引入更高层次的元技能（Meta-Skill）指导，而缩减视角修剪一般性指导以突出任务特定技能。它们互补的token级信号被结合起来重新缩放强化学习优势。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下均取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和缩减上下文视角的互补贡献。代码将发布以确保完全可复现。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 2. 方法论

### 2.1 问题设定

- 技能条件长程智能体任务：给定查询 \(Q\)，技能库提供泛化技能 \(G\) 和任务特定技能 \(S_c\)，基础上下文为 \(C_0=(Q,G,S_c)\)。
- 对每个查询采样 \(K\) 条轨迹 \(\{\tau_i\}_{i=1}^{K}\)，得到轨迹级结果奖励 \(r_i\)。
- 标准 GRPO 的优势为组内相对优势 \(A_i^{GRPO}=\frac{r_i-\mu_r}{\sigma_r+\epsilon}\)，所有 token 共享同一优势。

### 2.2 元技能（Meta-Skill）提取与刷新

- **定义**：Meta-Skill \(M_c\) 是高层文本指导，总结策略在应用任务特定技能 \(S_c\) 时的成功/失败模式。它只作为教师特权上下文，不进入学生上下文或推理阶段。
- **初始化与刷新**：将预训练前的 rollout 轨迹划分为成功集和失败集，用冻结的外部 LLM 对比生成 \(M_c^{(0)}\)；每经过一个验证窗口，用该窗口收集的轨迹刷新 \(M_c^{(k+1)}\)，并重置证据缓冲区。

### 2.3 双向上下文构造

- **增强视图（augmented view）**：在 \(C_0\) 上加入 Meta-Skill：
  \[
  C_1 = (Q, G, S_c, M_c)
  \]
  提供“如何更好使用技能”的高层指导。
- **缩减视图（pruned view）**：用外部 LLM 对泛化技能 \(G\) 进行一次性修剪，保留必要程序性指导，得到 \(G_p\)，并保持任务特定技能 \(S_c\)：
  \[
  C_2 = (Q, G_p, S_c)
  \]
  减少冗余信息，提供一个聚焦参考。
- 这两个方向构成“双向”上下文自蒸馏。

### 2.4 基于差距的优势重缩放

- 对同一条轨迹的响应 token 序列 \(y_i\)，在 \(C_0, C_1, C_2\) 下用同一策略重新计算 log 概率，得到 token 级 log-prob 差距：
  \[
  \Delta_{i,t}^{aug} = \log \pi_\theta(y_{i,t}|C_1,y_{i,<t}) - \log \pi_\theta(y_{i,t}|C_0,y_{i,<t})
  \]
  \[
  \Delta_{i,t}^{pru} = \log \pi_\theta(y_{i,t}|C_2,y_{i,<t}) - \log \pi_\theta(y_{i,t}|C_0,y_{i,<t})
  \]
- 加权融合：
  \[
  \Delta_{i,t} = \alpha \Delta_{i,t}^{aug} + (1-\alpha)\Delta_{i,t}^{pru}
  \]
- 生成 token 级权重 \(w_{i,t}\)，只改变优势大小、不改变方向：
  \[
  w_{i,t} = \text{clip}\left(\exp\left(\text{sign}(A_i^{GRPO})\Delta_{i,t}\right), 1-c, 1+c\right)
  \]
  \[
  A_{i,t}^{BCSD} = A_i^{GRPO}[(1-\lambda_n)+\lambda_n w_{i,t}]
  \]
- \(\lambda_n\) 从初始值 \(\lambda_0\) 线性衰减到 0，早期提供密集上下文指导，后期逐步交还给环境奖励。

### 2.5 优化目标

- 使用标准 clipped GRPO 目标，将原优势替换为 \(A_{i,t}^{BCSD}\)，并加入 KL 正则：
  \[
  \mathcal{L}_{BCSD}(\theta) = -\mathbb{E}_{i,t}\left[\min\left(\rho_{i,t}(\theta)A_{i,t}^{BCSD}, \text{clip}(\rho_{i,t}(\theta),1-\epsilon,1+\epsilon)A_{i,t}^{BCSD}\right)\right] + \beta \mathcal{L}_{KL}
  \]
- 算法流程（Algorithm 1）：预构建 \(G_p\) 和初始 Meta-Skill；每步采样、重评分、计算重缩放优势；按梯度更新；周期性刷新 Meta-Skill。

## 6. 主要结论与发现

- **整体性能**：BCSD 在 ALFWorld 和 WebShop 上、在三个模型规模下均取得最强或接近最强的整体性能。
  - Qwen2.5-7B：ALFWorld 成功率 83.6（比最强基线高 3.1），WebShop 成功率 78.1（最高）。
  - Qwen2.5-3B：ALFWorld 82.0（高 5.4），WebShop 分数 82.3（高 4.4），成功率 66.4（高 9.4）。
  - Qwen3-1.7B：ALFWorld 46.9（高 3.9），WebShop 分数 76.8（最高）。
- **消融结论**：
  - Meta-Skill 视角贡献最大，移除后性能大幅下降；
  - Pruned-Skill 视角也有明显贡献，仅靠单一方向教师信号不够可靠；
  - \(\lambda_n\) 线性衰减很重要，固定强度会损害后期训练；
  - Meta-Skill 周期性刷新对保持指导有效性很关键。
- **超参数分析**：\(\lambda_0=0.1\) 最佳；\(\alpha=0.9\)（偏向 Meta-Skill 视角）比平衡或偏向 Pruned-Skill 更好。
- **训练动态**：BCSD 早期（约 60 步）实现更快提升，后期保持稳定，没有明显回归。
- **技能利用率**：移除任务特定技能后，BCSD 性能下降比 Skill_GRPO* 更大，说明 BCSD 更依赖外部任务技能，而非将知识记忆进参数。

## 7. 优点

- **新颖的双向上下文自蒸馏**：从增强和缩减两个方向构造教师信号，比单一特权上下文更可靠。
- **保留技能显式性**：训练和推理都使用外部技能，不牺牲可编辑、可检查、可迁移性。
- **与 RL 优势重缩放结合**：不改变 GRPO 优化方向，只调节 token 级优势大小，方法简单且易于实现。
- **互补信号设计**：Meta-Skill 提供高层“如何用技能”，Pruned-Skill 提供聚焦参考，两者在 token 级别上约 50% 不一致，说明确实互补。
- **实验充分**：在三个模型规模、两个不同任务上都取得一致提升，消融和进一步分析完整。
- **明确的训练动态观察**：自蒸馏作为早期脚手架，\(\lambda_n\) 衰减后交还环境奖励，符合直觉且有效。
