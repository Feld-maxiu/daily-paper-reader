## 摘要
强化学习（RL）在数学推理和代码执行等具有静态、可验证奖励的任务上，已在改进大语言模型（LLM）方面取得了显著成果。在这些场景中，环境遵循固定规则，不会针对智能体进行策略性适应。战略对话在这方面有所不同：环境是另一个会随策略调整的智能体，成功取决于双方之间的交互。尽管存在这种交互性质，当前的强化学习方法通常让目标智能体针对固定的对手或模拟器进行训练。我们发现，这种训练范式促使策略利用对手特有的规律，而不是学习能跨对手泛化的策略。我们将此问题称为静态对手不匹配，并在实验中直接对其进行了量化。为解决该问题，我们提出了隔离双边强化学习（IB-RL），其中两个角色通过联合推演共同演化，同时每个角色通过完全独立的优势函数、动作掩码和更新路径来优化自身奖励。我们在两个领域中使用完全独立的留出对手对冻结策略进行评估。在 Vehicle TeleSales 上，IB-RL 取得了 89.6% 的 Success@1，而最佳单边强化学习基线为 84.6%。在 Deal-or-NoDeal 上，它对 DeepSeek V4 Pro 的达成协议率达到 98.4%，而最佳单边基线为 86.4%。这些结果表明，在严格的逐智能体隔离下联合训练两个角色，能够产生对未见对手泛化更有效的策略。

## Abstract
Reinforcement learning (RL) has achieved strong results in improving large language models (LLMs) on tasks with stationary, verifiable rewards, such as mathematical reasoning and code execution. In these settings, the environment follows fixed rules and does not adapt strategically to the agent. Strategic dialogue differs in this respect: the environment is another agent that adapts to the policy, and success depends on the interaction between the two sides. Despite this interactive nature, current RL approaches typically train a target agent against a fixed counterpart or simulator. We find that this training paradigm encourages the policy to exploit counterpart-specific regularities rather than learn strategies that generalize across counterparts. We call this problem the static-counterpart mismatch, which we quantify directly in our experiments. To address it, we propose Isolated Bilateral Reinforcement Learning (IB-RL), in which the two roles coevolve through joint rollouts while each role optimizes its own reward through fully independent advantages, action masks, and update paths. We evaluate frozen policies against fully independent held-out counterparts in both domains. On Vehicle TeleSales, IB-RL achieves 89.6% Success@1, compared to 84.6% for the best unilateral RL baseline. On Deal-or-NoDeal, it reaches 98.4% agreement against DeepSeek V4 Pro, compared to 86.4% for the best unilateral baseline. These results indicate that jointly training both roles with strict peragent isolation produces policies that generalize more effectively to unseen counterparts.

## 1. 核心问题与整体含义

- **研究背景**：强化学习（RL）在数学推理、代码执行等“静态、可验证奖励”任务上已显著提升大语言模型（LLM）能力。这类环境中，环境规则固定，不会针对智能体的策略进行策略性适应。
- **核心问题**：战略对话（如谈判、说服、销售）与此不同：环境本身是另一个会自适应、会对抗或配合的智能体，成功与否取决于双方策略的交互，而非单方输出。
- **静态对手不匹配（static-counterpart mismatch）**：现有主流范式通常让目标智能体针对一个**固定的对手或模拟器**进行单边 RL 训练。这种做法会促使策略去利用该特定对手的规律（如固定回应模式、固定偏好），而不是学习可跨对手泛化的对话策略。
- **现象与后果**：单边训练策略可能在训练对手甚至某些留出的强模型上得分很高，但一旦面对自身副本（self-play）或分布外对手，性能会大幅塌缩，说明其收益主要来自对训练对手特定规律的过拟合，而非可迁移能力。
- **整体含义**：战略对话智能体的训练应当让“环境”这一侧与目标智能体共同演化，而不是冻结；同时必须严格隔离两个角色的学习信号，避免共享奖励或联合归一化导致共谋或信号污染。

## 2. 方法论

### 2.1 核心思想

- 提出 **Isolated Bilateral Reinforcement Learning（IB-RL）**：两个对话角色通过**联合 rollout** 共同演化，但每个角色的奖励、优势函数、动作掩码和优化器状态**完全解耦**。
- IB-RL 建立在 **GRPO** 上，理由是无 critic 的结构天然适配双侧隔离：没有共享价值函数，优势函数在各自组内归一化，因此不会通过 critic 耦合两个角色的学习信号。

### 2.2 关键公式与机制

**共享轨迹、解耦梯度**：

- 每个 prompt 下，角色 i 的 rollout 组为 \(G_{i,q}\)。
- 角色 i 的轨迹奖励 \(R_i(\tau_g)\) 只在自己的组内标准化：
  \[
  \hat{A}^{(i)}_g = \frac{R_i(\tau_g) - \mu_{i,q}}{\sigma_{i,q}}
  \]
  其中 \(\mu_{i,q},\sigma_{i,q}\) 分别为组内均值和标准差。
- GRPO 目标仅施加在角色 i 自己的 token 上，通过 turn-level mask \(m_i(w)\) 屏蔽对手 token：
  \[
  J_i(\theta_i)=\mathbb{E}_{\tau_g}\left[\sum_{w\in\tau_g}m_i(w)\min(\rho_i(w)\hat A^{(i)}_g,\;\text{clip}(\rho_i(w),1-\epsilon,1+\epsilon)\hat A^{(i)}_g)\right]-\beta D_{KL}(\pi_{\theta_i}\|\pi^{ref}_{\theta_i})
  \]
  其中 \(\rho_i(w)\) 是 token 级重要性比。

**稳定化共同演化**：

- **对手池采样**：每个角色维护最多 K 个历史检查点池 \(P_i\)。每轮按概率采样以下三种配置之一：
  - 双方都面对当前对手检查点（概率 \(p_{both}\)）；
  - Agent 1 面对历史 Agent 2 检查点，Agent 2 面对当前 Agent 1（概率 \(p_{agent1}\)）；
  - 对称情况（概率 \(p_{agent2}\)）。
- **解耦角色更新调度**：通过二元指示器 \(u_i(k)\) 控制每个角色是否在第 k 轮更新，实际中两个角色使用不同更新频率和学习率，避免同步大更新导致训练不稳定。

## 3. 实验设计

### 3.1 数据集 / 场景

- **Vehicle TeleSales（主实验域）**：
  - 外呼电话销售场景：销售智能体致电潜在客户，推广购车并争取客户同意添加微信（行业标准转化目标）。
  - 客户预算、顾虑等为私有信息，销售智能体不可见。
  - SFT 使用约 50K 条真实中文外呼记录；RL 阶段构建 3,000 个模拟客户画像，每个画像含 28 个属性。
  - 评估使用 **500 个留出画像**，每个画像扩展为 40 个属性，且属性覆盖与训练分布不同。
  - 训练奖励由 DeepSeek V4 Pro 判断，结合回合级结果和折扣回合级得分（\(\lambda_{turn}=0.2,\lambda_{episode}=0.8,\gamma=0.9\)）。
- **Deal-or-No-Deal（DoND）**：
  - Lewis et al. (2017) 的谈判基准。两名智能体就书籍、帽子、球三类物品进行分配谈判，各自持有私有效用函数。
  - 达成一致则获得各自效用，失败为零；规则可验证，无需 LLM 判官。
  - 训练使用原始训练集；测试在 1,000 个原始测试集场景上报告。

### 3.2 模型与训练配置

- 角色模型为 Qwen-3.5-4B 或 Qwen-3.5-9B。
- GRPO 配置：每个 prompt 4 条 rollout；KL 系数 0.02；全局 batch size 64。
- TeleSales 中策略从任务专用 SFT 检查点初始化；DoND 无域内 SFT，策略直接从基座模型初始化。
- TeleSales 学习率：销售侧 1e-6，客户侧 1e-7；客户更新频率为销售的一半。
- 对手配置采样概率：\(p_{both}=0.7\)，\(p_{agent1}=0.2\)，\(p_{agent2}=0.1\)。

### 3.3 对比方法与评估协议

- **单边 RL 基线**：
  - TeleSales：SFT；单边 RL（对手为 Qwen-3.5-4B/9B-SFT）；单边 RL（对手为 DeepSeek V4 Pro）；单边 RL（对手为三个强模型的池）。
  - DoND：单边 RL（vs Qwen-3.5-4B/9B）、单边 RL（vs DeepSeek V4 Pro）。
- **前沿参照模型（仅提示，不训练）**：Qwen-3.5-122B、GLM-5.2、DeepSeek V4 Pro。
- **留出对手协议**：冻结策略与**完全独立**的留出对手测试，这些对手与任何训练系统不共享参数、提示或奖励逻辑。
  - TeleSales 留出对手：GPT-5.5 按照评估画像脚本扮演客户；GLM-5.2 审计动作标签与客户话语一致性；人类审计验证结果。
  - DoND 留出对手：GLM-5.2、DeepSeek V4 Pro（对单边基线 DS V4 Pro 报告为 in-system）。
- **指标**：
  - TeleSales：Success@1/2/3、幻觉率、意愿变化、耐心变化；
  - DoND：协议率、自身效用、联合价值。
- **统计检验**：二元结果使用 logistic GEE（按画像或场景聚类），Holm 校正，调整后 \(p<0.05\)。

## 6. 主要结论与发现

- **IB-RL 显著优于单边 RL**：
  - TeleSales：IB-RL 取得 **89.6% Success@1**，最佳单边基线为 84.6%；
  - DoND：对 DeepSeek V4 Pro 的协议率达到 **98.4%**，最佳单边基线为 86.4%。
- **静态对手不匹配被直接量化**：
  - 单边训练策略在训练对手上可达 86.4–89.7%，但换到 self-play 时只有 46.2–56.3%；
  - IB-RL 策略在留出对手上保持 94.8–98.4%，self-play 仍为 70.6–71.9%，对局内和留出表现更一致。
- **IB-RL 缩小与前沿能力的差距**：
  - TeleSales 上 9B IB-RL 超过 GLM-5.2（85.4%）、DeepSeek V4 Pro（83.6%）和 Qwen-3.5-122B（71.8%）；
  - DoND 上 9B IB-RL 对留出 GLM-5.2 平均 93.9%，接近 GLM-5.2 的 self-play 水平 95.2%。
- **隔离的必要性**：
  - 共享奖励会导致两个角色发展共谋惯例，Success@1 从 89.6% 跌至 38.0%，幻觉率升至 23.9%；
  - 联合优势归一化会混合不同奖励尺度，使 GRPO 优势估计偏置，Success@1 降至 78.8%。
- **稳定化措施必要**：移除对手池和错峰更新后，销售奖励在约 25 轮后不可恢复地衰减。
- **共同演化产生两类能力**：
  - 对训练伙伴的配对共同适应（in-pair co-adaptation）；
  - 可迁移到留出对手的跨对手能力（transferable competence）。

## 7. 优点

- **问题形式化清晰**：将战略对话建模为部分可观测随机博弈，并在附录 A 中给出静态对手不匹配的协方差分解：
  \[
  J_{deploy}=J_{train}-\mathrm{Cov}_{\tau\sim(\pi_{\theta_1},\pi_{\theta_2})}(R_1(\tau),1-\bar w(\tau))
  \]
  直观说明“高奖励轨迹在部署分布下越不可能，性能下降越大”。
- **方法设计简洁且针对性**：利用 GRPO 的无 critic 特性，通过独立奖励组、独立优势归一化、turn-level mask 和独立优化器实现严格隔离，避免共享信号带来的共谋。
- **评估协议严谨**：
  - 强调留出对手不共享参数、提示或奖励逻辑；
  - 使用统计检验（GEE + Holm 校正）；
  - 引入人类盲审验证结构化动作标签的语义有效性。
- **消融与分析有说服力**：不仅报告最终指标，还通过奖励轨迹、对手语义多样性、系统内

vs 留出差异等机制性证据，使结论不仅停留在分数层面，还能解释为什么 IB-RL 有效。

## 8. 总体评价

- 论文针对战略对话中“静态对手不匹配”这一关键问题，提出了隔离双边强化学习（IB-RL）框架，通过解耦角色奖励、优势归一化、动作掩码与优化器状态，实现了两个自适应智能体的共同演化，同时避免了共享信号带来的共谋与信号污染。
- 在 Vehicle TeleSales 和 Deal-or-No-Deal 两个互补场景、4B 与 9B 两个模型规模、多种基线与消融条件下，IB-RL 均展现出显著且稳定的性能提升，尤其在留出对手上保持了较高的泛化能力，直接量化并缓解了单边 RL 的过拟合问题。
- 评估设计较为严谨：采用完全独立的留出对手、盲法人工审计、GEE + Holm 校正等统计手段，增强了结论的可信度；消融实验分别验证了隔离机制与稳定化措施的必要性，机制分析揭示了共同演化产生的两类能力。
- 尽管存在留出对手集合有限、稳定化消融未能分解各组件贡献、算力细节披露不足等局限，但整体上 IB-RL 为多智能体强化学习与战略对话智能体的训练提供了清晰、可复用的方法论，具有重要的学术价值与实践参考意义。
