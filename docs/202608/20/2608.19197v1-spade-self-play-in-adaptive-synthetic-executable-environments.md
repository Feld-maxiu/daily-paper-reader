## 摘要
持续自我提升需要不断扩展的、自生成的、多样化的、自适应的目标池。对于语言智能体，现有的训练环境池（手工策划的、静态合成的或冻结验证器的）随着学习者的扩展，目标分布保持固定。我们提出 SPADE（自适应合成可执行环境中的自我博弈），一个自我博弈强化学习框架，其中单一大型语言模型扮演两个角色：环境设计器，将完整的、长时程训练环境编写为具有 OpenAI Gym 风格 reset()/step() 接口的可执行代码；以及推理智能体，学习在其中行动。每个环境都是有状态的、多轮环境（状态转移、奖励函数和验证代码），因此单一接口可覆盖推理问题和多步骤智能体工具使用。推理智能体的遗憾值通过使用其有无特权提示时奖励之间的差距来估计；在优化该遗憾信号时，环境设计器学会将环境设定在智能体能力的边缘，同时保持其可行性。通过大量实验，我们发现几个组件对成功至关重要：将环境设计器基于从大型预训练语料库中采样的文档，并赋予其累积的环境记忆。扩展到 300 亿参数模型后，SPADE 在八个留出的数学、科学、代码和推理基准上平均比最强的固定环境基线提升 +5.3，并在工具使用设置中，BFCL-v4 多轮提升 +5.7，ACEBench-Agent 提升 +13.9；在游戏设置中，相对于最强基线的优势随着模型规模增大而增长。通过使环境设计本身成为可学习组件，SPADE 向开放式自我提升迈出了具体一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 1. 论文的核心问题与整体含义

- **背景**：语言智能体能力提升越来越依赖“从经验中学习”，但高质量人类文本有限，训练环境（互动任务与可验证奖励）成为瓶颈。现有环境池主要分为三类：
  - 手工策划（human-curated）
  - 静态合成（statically synthesized）
  - 冻结验证器（frozen-verifier）
- **核心问题**：这些环境池的目标分布固定，不会随着智能体能力提升而自适应变化，因此智能体在耗尽环境后停止改进。
- **整体含义**：SPADE 提出将“环境设计”本身变成可学习组件，使环境和智能体能力共同进化，从而朝着开放式、持续的自我改进迈出一步。

## 2. 方法论

- **整体框架**：单一 LLM（πθ）在自我博弈中扮演两个角色：
  - **环境设计器（Environment Designer, ED）**：编写完整、长时程训练环境，形式为可执行 Python 代码，实现 OpenAI Gym 风格 `reset()/step()` 接口；同时为每个环境生成特权提示（hint）。
  - **推理智能体（Reasoning Agent, RA）**：在环境中多轮交互并学习求解。
- **代码即环境（code-as-environment）**：任何可计算 MDP 都可以用 Python 程序表达，因此统一单轮推理任务与多轮智能体工具使用任务。
- **提示遗憾奖励（Hint-Based Regret Reward）**：
  - 定义 ED 奖励：
    \[
    r_D(e) = \bar{r}_A(e|h) - \bar{r}_A(e)
    \]
    其中 \(\bar{r}_A(e|h)\) 是带提示时 RA 的平均回报，\(\bar{r}_A(e)\) 是无提示时 RA 的平均回报。
  - 该信号是 PAIRED minimax regret 的轻量估计，目标是让 ED 生成“位于 RA 能力边缘”且可解的环境。
  - 高遗憾 = 前沿可学习；低遗憾 + 高回报 = 已掌握；低遗憾 + 低回报 = 不可解。
- **训练算法**：
  - 使用 GRPO 更新共享策略 πθ，两个角色的优势独立归一化。
  - ED 更新延迟 \(k\) 个 rollout，并用截断重要性采样修正 off-policy 偏差。
  - 不对称裁剪范围：\(\varepsilon_{low}=0.2,\ \varepsilon_{high}=0.28\)。
  - ED 奖励混合：floor 后的遗憾（权重 0.4）+ 平坦顶难度锚（权重 0.6，奖励 RA 胜率落在 [0.4, 0.6] 的环境）。
- **环境设计支撑组件**：
  - **语料库接地（Corpus Grounding）**：每轮 ED 基于从预训练语料库新采样的人类文档生成环境，避免模式崩溃。
  - **环境记忆（Environment Memory）**：保存过去环境及其遗憾分数和技能标签，供 ED 参考高遗憾种子和负样本。
- **算法流程**（Algorithm 1）：
  1. ED 采样领域提示，生成环境并验证语法/可执行性，生成 hint。
  2. RA 分别在无提示和有提示条件下采样 \(G\) 个 rollout。
  3. 计算 ED 的遗憾奖励和 RA 的任务正确性奖励。
  4. 两者共同更新共享策略 πθ。

## 6. 主要结论与发现

- **自适应环境设计优于固定环境**：
  - 游戏设置 30B-A3B 上，SPADE 平均 58.3，较基础模型 +8.1，较最强固定基线（Fixed-env RLVE）+5.3。

- **可学习的环境设计是收益来源**：
  - 冻结 ED 并移除记忆导致性能大幅下降，低于未训练基础模型（40.5 vs 50.2）。

- **语料库接地和记忆是关键**：
  - 移除语料库导致多样性崩溃（Vendi/n 从 0.68 降到 0.04），并连续生成同一任务 41 次。

- **提示遗憾优于 EMA 学习潜力**：遗憾奖励获得 +8.1 增益，EMA 学习潜力约 +5.7。
- **能力随规模增长**：SPADE 对基线的优势从 4B 的 +5.2 增长到 30B-A3B 的 +8.1，而 Fixed-env GRPO 始终约 +1.2。
- **课程多样性重要**：6 技能课程优于 2 技能课程（58.3 vs 53.7）。
- **定性发现**：训练中 ED 逐步隐藏解题公式、奖励粒度增加、可学习环境比例上升；RA 从“先推导后行动”转向“先收集证据再推导”。

## 7. 优点

- **新颖的自适应环境设计**：将环境生成者本身作为 RL 学习器，实现环境与智能体共同进化。
- **提示遗憾奖励机制**：轻量估计 minimax regret，无需训练独立对抗者，有效规避不可解环境和奖励通胀。
- **代码即环境统一接口**：一个 Gym 风格接口覆盖单轮推理和多轮工具使用，适用范围广。
- **语料库接地 + 记忆**：有效缓解自博弈中的模式崩溃和信息对称问题，保持多样性与难度前沿。
- **稳定训练配方**：提出异步裁剪、延迟 ED 更新、截断重要性采样等稳定化技巧，具备工程参考价值。
- **实验扎实**：包含多骨干、多基准、多基线、多消融和跨模型家族验证，定性分析也较深入。

## 8. 不足与局限

- **复杂度受限于基础模型**：ED 无法生成超出基础模型上下文表达能力的环境复杂度，存在“隐形牵引”（invisible leash）问题。
- **优化算法固定**：两个角色仍由人类设计的 GRPO 更新，SPADE 不修改自身学习规则。
- **缺乏正式最优性保证**：提示遗憾虽受 PAIRED 启发，但未证明能产出最优课程。
- **评估仍是固定任务基准**：未直接衡量开放式推理能力增长，无法证明真正的 open-ended 自我改进。
- **算力信息缺失**：未报告 GPU 数量、训练时长和能耗，限制了资源可行性的评估。
- **参考系统对比偏差**：Table 2 中部分外部系统使用不同训练数据、预算和评估协议，横向公平性有限。
- **工具使用部分基准提升有限**：如 τ²-bench 仅 +3.6，说明生成环境与某些任务结构的迁移仍有限。
- **潜在奖励黑客风险**：尽管有验证和锚定机制，但生成环境仍可能被优化出非预期漏洞（如部分验证检查无法捕获的语义问题）。
