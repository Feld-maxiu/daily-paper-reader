## 摘要
我们提出 ASENA，一个具身智能体系统，将通用编码智能体与机器人感知、计算、受监督执行和持久经验相连接。智能体可以编写和执行程序、检查记录的结果、修复失败，并在保持模型权重固定的情况下重用笔记和可执行技能。我们进一步引入 ASENA-VLN，一个 4B 单目导航策略，作为该可编程系统中的可选工具。ASENA-VLN 使用共享视觉-语言解码器，在路线指令、视觉问答和新整理的几何派生原子导航任务数据集上训练，预测身体坐标系下长距离路线和短时程行为的轨迹。作为独立策略，ASENA-VLN 在 R2R 上取得 68.7%、在 RxR 上取得 70.2% 的最先进成功率。当与编码智能体集成时，学习到的导航在两项智能体基准上将 ASENA 的成功率提高 11 个百分点，同时减少执行时间。通过持久工作空间演化和模拟器反馈，对反复出现的 100 个任务子集进行十轮迭代后，R2R 成功率从 72% 提高到 98%，RxR 从 65% 提高到 89%。在具身问答上，ASENA 以更少的交互步骤取得最先进准确率。最后，在 Unitree G1 上的真实世界演示在没有预建地图的情况下结合了搜索、视觉检测、空间推理和合成手势，说明在线编程如何将机器人行为扩展到路线跟随和预定义技能之外。

## Abstract
We present ASENA, an embodied agent system that connects general-purpose coding agents to robot sensing, computation, supervised execution, and persistent experience. Agents can write and execute programs, inspect recorded outcomes, repair failures, and reuse notes and executable skills while keeping their model weights fixed. We further introduce ASENA-VLN, a 4B monocular navigation policy that serves as an optional tool within this programmable system. ASENA-VLN predicts body-frame trajectories for both extended routes and short-horizon behaviors using a shared vision-language decoder trained on route instructions, visual question answering, and a newly curated dataset of geometry-derived atomic navigation tasks. As a standalone policy, ASENA-VLN achieves state-of-the-art success rates of 68.7% on R2R and 70.2% on RxR. When integrated with a coding agent, learned navigation improves ASENA's success rate by 11 percentage points on both agentic benchmarks while reducing execution time. Through persistent workspace evolution and simulator feedback, ten passes over recurring 100-task subsets further improve success from 72% to 98% on R2R and from 65% to 89% on RxR. On embodied question answering, ASENA achieves state-of-the-art accuracy with fewer interaction steps. Finally, real-world demonstrations on a Unitree G1 combine search, visual inspection, spatial reasoning, and synthesized gestures without a pre-built map, illustrating how online programming extends robot behavior beyond route following and predefined skills.

## 1. 论文的核心问题与整体含义

- **研究背景**：具身导航机器人不能只完成“到达目的地”这类单一任务。实际请求（例如“检查自动售货机里有没有某件商品并回来告诉我”）要求机器人自主决定搜索位置、识别物品、记忆用户位置并以合适方式汇报结果。
- **核心问题**：导航只是更大任务链的一部分，下一步行动依赖实时观察。传统预定义技能难以覆盖开放式任务；学习型导航策略能提供运动能力，但无法决定“检查什么、计算什么、如何沟通”。
- **整体含义**：论文提出 ASENA，让通用编码智能体在任务执行过程中动态编写、执行、检查并修复程序，通过程序化访问感知、计算、仿真与动作接口，将导航能力扩展为可编程的具身行为；同时引入轻量 4B 视觉语言导航策略 ASENA-VLN 作为可选工具，实现固定权重下的持续自我改进。

## 2. 论文提出的方法论

- **核心系统架构（ASENA）**
  - 将编码智能体（如 Codex、Claude Code）连接到机器人的传感器、执行器、持久工作空间和监督执行层。
  - 提供“写—运行—检查”闭环：智能体可编写程序、执行程序、读取视觉/几何反馈、检查生成的图表和记录，并修复失败。
  - **持久工作空间**：以 \(W_k=(N_k, S_k)\) 表示，\(N_k\) 为笔记，\(S_k\) 为可执行技能。固定权重智能体在解决任务时参考该工作空间；每次修订后由独立的固定权重改进器 \(I_\varphi\) 基于执行轨迹 \(\mathcal{T}_k\) 和反馈 \(f_k\) 更新工作空间：\(W_{k+1}=I_\varphi(W_k,\mathcal{T}_k,f_k)\)。
  - **监督执行与安全层**：所有物理动作需通过独立验证（MuJoCo 运动学检查、LiDAR 占用地图与间隙检查、操作员批准、心跳停止机制、速度/续航限制等），确保生成程序不会绕过安全约束。

- **ASENA-VLN 导航策略**
  - **模型基础**：基于 Qwen3-VL-4B-Instruct，扩展专用词表以预测身体坐标系轨迹（最多 8 个累积位姿 \((x,y,\theta)\)）和像素目标（辅助监督）。
  - **输入**：最多 8 帧前视图 + 结构化 JSON 指令（含目标文本、质量、可选末端位姿锚点、约束等）。
  - **训练数据**：新增九类“原子导航任务”（度量运动、旋转、相对目标、对齐、房间目标、门穿越、走廊跟随、楼层变化等），由几何派生和验证；结合 R2R、RxR、ScaleVLN、SRDF 等路线数据；再以 3:1 比例混合轨迹预测与多视角 VQA 训练，共约 430 万样本。

## 6. 论文的主要结论与发现

- **独立策略表现**：ASENA-VLN-4B 在 R2R 上 SR 68.7%、RxR 上 SR 70.2%，达到单目 VLN-CE 的最先进水平，导航误差和 nDTW 显著优于此前方法。
- **编码智能体 + VLN 互补**：强编码后端（GPT-6 Astra）无需策略即可达到高成功率，但添加 ASENA-VLN 后工具调用次数平均下降 46.9%–62.5%；弱后端（Claude Sonnet 5）集成策略后成功率提升 11 个百分点（R2R 和 RxR），且 SPL 提高。
- **持久经验自进化**：十轮工作空间演化后，R2R 成功率从 72% 升至 98%，RxR 从 65% 升至 89%；成本递减，SPL 保持在有 VLN 时更高。
- **EQA 结果**：ASENA 以更少交互步数取得 HM-EQA 和 MT-HM3D 上的最优准确率；演化后的工作空间在低推理努力下达到与手工“效率”配置相近的步数、更高精度。
- **真实世界**：G1 成功完成搜索、视觉检测、空间推理、记忆和手势合成等复合任务，展示在线编程超越路线跟随。

## 7. 优点

- **固定权重下的自我改进**：通过工作空间演化而非模型微调提升性能，降低部署风险和计算成本，且模型、策略、控制器权重全部保持固定。
- **系统级安全设计**：程序生成与物理执行解耦，多层验证（MuJoCo 仿真、LiDAR 间隙、操作员审批、心跳停止）适用于全身人形机器人的高风险场景。
- **可解释与可检查**：所有运行以 MCAP 格式记录传感器、动作、代码和可视化，支持失败回溯与程序修复。
- **策略设计轻量且可组合**：4B 单目策略预测身体系轨迹，输入结构化 JSON，便于编码智能体直接调用；原子导航数据专门训练短时行为，增强策略在局部任务中的可复用性。
- **实验全面**：兼顾独立策略、系统集成、消融、多轮演化和真实机器人，结果一致性强。

## 8. 不足与局限

- **真实世界效率低**：G1 任务耗时 10–20 分钟，无法满足快速交互需求；论文承认需加快推理与执行。
- **依赖地面真值与仿真反馈**：导航自演化使用地面真值反馈和模拟器，物理部署仍需操作员把关；在完全未知、动态环境中可能受限。
- **安全局限**：当前安全验证主要面向静态/结构化环境，对动态障碍和复杂人流交互的防护仍需加强（论文在讨论中提及）。
- **算力与模型依赖**：部分实验使用未公开的私有编码模型（如 GPT-6 Astra、Claude Sonnet 5）和地面真值反馈，可复现性受一定影响；EQA 中手工配置并非严格消融。
- **策略更新缺失**：工作空间演化只更新笔记和技能，不更新导航策略权重；对于需要学习新运动能力的长期适应仍有不足。
- **评估偏差风险**：R2R/RxR 演化实验使用相同任务重复出现，可能高估真实场景中的泛化能力；部分结果在“agentic splits”的 100 个任务子集上，任务量相对有限。
