## 摘要
多模态代理通常在每个动作前生成自由形式的推理。对于小型模型，有限的模型容量可能导致冗长的推理，对动作生成几乎无益，同时产生大量推理成本。为了解决这一挑战，我们引入基于选择的结构化推理（SSR），该框架将推理重新表述为选择而非开放式生成。SSR将反复出现的高级推理表示为预先指定的、可重用的自然语言候选。每一轮，模型根据给定当前上下文的似然从这些推理候选中选择，无需辅助任务头。使用预先指定的推理轨迹可实现并行评分，其中教师强制预填充利用共享上下文KV缓存在候选内部及跨候选并发计算令牌似然。我们在七个多模态搜索基准上使用2B和4B模型评估SSR。在多个强化学习目标和监督微调下，SSR在不牺牲任务性能的情况下实现了显著的效率提升。SSR取得了与同规模领先搜索代理相竞争的平均成功率，同时将每轮推理延迟降低90%以上，并将每个问题的总模型推理延迟降低28-54%。项目页面：https://zfy0314.github.io/ssr-webpage/。

## Abstract
Multimodal agents commonly generate free-form reasoning before each action. For small models, limited model capacity can result in lengthy reasoning that provides little useful guidance for action generation while incurring substantial inference cost. To address this challenge, we introduce Selection-based Structured Reasoning (SSR), a framework that reformulates reasoning as selection instead of open-ended generation. SSR represents recurring high-level reasoning as pre-specified, reusable natural-language candidates. At each turn, the model selects from these reasoning candidates based on their likelihoods given the current context, without requiring an auxiliary task head. Using pre-specified reasoning traces enables parallel scoring, where teacher-forced prefilling computes token likelihoods concurrently within and across candidates using a shared context KV cache. We evaluate SSR on seven multimodal search benchmarks using 2B and 4B models. Across multiple reinforcement learning objectives and supervised fine-tuning, SSR delivers significant efficiency gains without sacrificing task performance. SSR achieves an average success rate competitive with leading search agents of the same scale, while reducing per-turn reasoning latency by over 90% and total per-question model inference latency by 28-54%. ## 1. 核心问题与研究背景

- **研究动机**：多模态搜索代理（Multimodal Search Agent）通常采用 ReAct 式设计，在每一轮动作前生成一段自由形式的推理文本（freeform reasoning）。然而，对于 2B、4B 这类小型端侧模型，模型容量有限，往往产生冗长但缺乏实质指导意义的推理内容。
- **核心矛盾**：自由形式推理的每个 token 都需要自回归解码，推理长度越长，推理延迟越高，但其对后续动作生成的边际贡献可能很低。这种"生成成本高、指导价值低"的错配严重拉低了小模型搜索代理的推理效率。
- **关键观察**：在多模态搜索任务中，虽然实体、查询和观测内容随问题变化，但代理在每一步所需的**高层推理模式**（如"我无法从图像确认实体，应进行反向图像搜索"）是高度重复的。换言之，搜索代理所需的推理空间并非整个自然语言空间，而是一个紧凑的有限候选集。
- **整体含义**：本研究提出一个根本性的范式转变——将推理从"开放式生成"重构为"预定义候选项中的选择"，从而在保持任务成功率的同时，大幅降低推理延迟。

## 2. 方法论：Selection-based Structured Reasoning (SSR)

### 2.1 核心思想

SSR 用**选择**取代**生成**：预先构建一个推理库 `R = {r₁, ..., r_N}`，每个候选项是一段简短的自然语言推理描述。在每个决策轮，模型基于当前交互历史 `h_t` 对每个候选的适配度进行评分，选中最优候选后，将其作为推理文本注入上下文，指导后续动作生成。

### 2.2 并行推理解码（Parallel Reasoning Decoding）

- **评分函数**：对候选 `r_i`（含 `K_i` 个 token），计算其长度归一化对数似然：

  \[
  S_\theta(r_i \mid h_t) = \frac{1}{K_i^\alpha} \sum_{j=1}^{K_i} \log p_\theta(r_{i,j} \mid h_t, r_{i,<j})
  \]

  其中 α=1 时即为平均 token 对数似然，可消除短候选因 token 数少而在求和得分上的长度偏差。

- **选择策略**：对评分施加 softmax（温度为 τ），得到候选上的分类分布 `q_θ(·|h_t)`，据此采样得到本轮的推理候选。

- **并行机制的关键**：由于所有候选 token 是预先给定的，推理解码不再需要逐 token 自回归生成，而是通过 **teacher forcing + 共享 KV 缓存**实现两层并行：
  - **Token 级并行**：同一候选内的所有 token 在一次前向传播中同时计算；
  - **候选级并行**：不同候选共享同一个历史上下文 KV 缓存，并发完成评分。

- **复杂度对比**（论文式 (3)）：自回归推理的临界路径深度为 `O(L log(H+L))`，而 SSR 仅为 `O(log(H+K_max) + log N)`，从理论上消除了线性因子 L。

### 2.3 SSR 训练

- **SFT 损失**：将推理选择损失（对真值候选的分类交叉熵）与动作 token 生成损失加权组合：

  \[
  L_{SFT} = -\sum_t \left[ \lambda^{SFT}_{reason} \log q_\theta(z_t|h_t) + \frac{1}{|a_t|} \sum_k \log p_\theta(a_{t,k}|h_t, z_t, a_{t,<k}) \right]
  \]

- **GRPO 风格强化学习**：将自由形式推理的 token 级重要性比率替换为**单一的分类比率**：

  \[
  \rho^{reason}_t = \frac{q_\theta(z_t|h_t)}{q_{old}(z_t|h_t)}
  \]

  动作 token 保留原有的重要性比率。最终目标函数（式 (6)）合并了推理选择项与动作 token 项，并加入参考策略 KL 正则。论文指出 SSR 同样兼容 GSPO 和 SAPO 等变体，并采用了"分离竞争项"（detached competitors）的梯度近似来降低计算开销。

- **推理库**：默认包含 6 个手写候选（表 6），覆盖 6 种典型搜索状态：通用知识作答、图像直接作答、细部检查、反向图像识别、事实检索、基于证据作答。

## 6. 主要结论与发现

1. **性能持平**：4B SSR GRPO 模型平均成功率 61.37%，与同规模最强的 TAPO+GSPO（61.25%）相当，优于 MMSearch-R1 和 SenseNova-MARS 的 4B 版本；2B SSR 达 51.26%，接近零样本 8B 模型。
2. **效率大幅提升**：相对 freeform，SSR 每轮推理延迟降低 90% 以上（如 GRPO 4B 从 0.896s 降至 0.061s），每问模型延迟降低 28–54%。
3. **吞吐量飞跃**：有效推理吞吐量从约 70 tokens/s 提升至 2500–3300 tokens/s，提升 35–45 倍。
4. **延迟稳定性**：SSR 的 p95 推理延迟仅比均值高约 10ms，远优于所有基线（0.8–1.9s 的 p95）。
5. **选择质量优于单纯索引**：按全文语义评分比按候选项索引评分平均高 3.9 个百分点，说明语义层面的条件似然对正确选择至关重要。
6. **无需 SFT 预热**：由于选择机制本身就约束了推理空间，SSR 可直接从 RL 开始训练，不必先通过 SFT 教会模型生成指定格式的推理。
7. **库规模与任务适应性**：成功率随库大小从 1 到 6 单调上升；同一模型在不同基准上呈现明显不同的候选选择分布，且 99.9% 的轮次中动作类型与所选候选的预期一致。

## 7. 优点

- **范式创新**：将"生成推理"转变为"选择推理"，从源头消除了自回归解码的延迟瓶颈，思路直观且可操作性强。
- **零额外组件**：直接利用语言模型自身的条件似然作为候选分类器，无需辅助分类头或独立检索系统。
- **训练目标通用**：SSR 与 GRPO、GSPO、SAPO、SFT 均兼容，表明其不局限于特定 RL 算法。
- **理论分析清晰**：给出了自由形式推理与 SSR 在并行计算深度上的正式对比（式 (3)）。
- **实验体系完整**：涵盖多基准、多模型规模、多训练目标、多消融维度，且兼顾性能与效率两个维度。
- **实际价值显著**：对于部署在端侧设备上的小模型搜索代理，90% 以上的推理延迟削减和 28–54% 的总延迟削减具有直接的落地意义。

## 8. 不足与局限

- **推理库依赖人工设计**：6 个候选由研究者手工撰写，覆盖范围有限；对于新的搜索场景或未预见的代理状态，固定的候选集可能无法提供合适的高层推理。论文也承认这一局限，并提出可结合 SkillOpt 等方法自动构建和演化推理库。
- **在部分训练目标下性能略有下降**：GSPO-SSR 较 freeform 降 3.1%，SAPO-SSR 降 1.3%，可能源于分离竞争项梯度近似在多步更新中精度下降。
- **仅验证了小模型**（2B/4B）：对于更大模型（如 7B/8B/32B），自由形式推理的边际价值可能更高，SSR 的性能与效率优势是否依然成立尚待验证。
- **任务范围限于多模态搜索**：SSR 的成功部分建立在搜索任务中高层推理模式高度重复这一前提上，对于推理模式更多样化的开放域任务，候选覆盖度不足的问题会更加突出。
- **训练资源细节披露不足**：未报告训练 GPU 数量与总训练时长，影响可复现性评估。
- **评估偏差风险**：使用 LLM 作为裁判（Qwen3-VL-32B）以及使用 Gemini 3.1 Pro 生成 SFT 真值轨迹，可能引入模型特有的偏好偏差。
