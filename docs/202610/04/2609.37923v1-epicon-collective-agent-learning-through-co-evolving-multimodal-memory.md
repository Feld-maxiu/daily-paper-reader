## 摘要
智能体可以从过去的执行中学习，但让不同智能体重用并在他人的经验基础上继续构建仍然具有挑战性。我们提出 EpiCon，一种共享多模态记忆框架，用于在不更新宿主模型参数的情况下实现智能体集体学习。EpiCon 通过两个独立训练的 2B 模型——记忆控制器和树自组织器——将问题级记忆演化与持久经验库相连接。控制器在多次尝试中联合细化文本指导和视觉证据，并选择性地纳入视觉记忆。自组织器以分层方式整合经验教训，并为新问题检索经验和规则。我们在涵盖四个多模态任务领域的十一个基准上评估 EpiCon，使用两种测试框架和多个骨干模型。即使仅进行一次求解尝试，冻结的经验库也能改善其他系统。第二种测试框架使原始系统在十一个基准上的宏平均分数提高 2.6 分。在四种宿主配置下，EpiCon 相较于无记忆的宏平均分数提高 1.7 到 4.9 分，并将记忆操作时间相对于骨干规模记忆模型减少 67% 到 74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

## 2. 论文提出的方法论

- **总体框架**：EpiCon 由两个独立训练的 2B 模型组成：
  - **记忆控制器（Memory Controller, Cθ）**：负责在单个问题内部联合精炼文本指导与视觉证据。
  - **树自组织器（Tree Self-Organizer, Sφ）**：负责跨问题、跨系统维护共享经验库，进行分层整合与检索。
  - 另有一个专用记忆 harness 协调记忆更新、视觉裁剪、存储与检索。

- **数据构造**（用于训练两个模型）：
  - 使用 Qwen3.8-27B 作为初始教师，Qwen3.8-Flash-Next 进行选择性修订。
  - 源数据集来自 MathNet、MathV360K、ChartQA、InfoVQA、DocVQA、ChartNet，覆盖视觉数学、文档理解、图表推理三个领域。
  - 从 CAMEL、Codex、DeepSeek-Harness 三个 MAS 中收集执行轨迹，离线筛选得到约 **25K** 条“Repair/Compress”记忆变换监督样本，以及约 **6.5K** 条树组织操作监督样本。

- **共享多模态记忆与更新规则**：
  - 维护一个独立于任何 MAS 的持久经验库 **B**。
  - 更新公式：\( B^{(k+1)} = S_\phi(B^{(k)}, U_k) \)，其中 \( U_k \) 表示一批被接受的经验教训与修订；评估阶段库冻结，仅做局部问题级更新。

- **问题级多模态记忆共演化**：
  - 记忆状态 \( W_{i,t} = (M^{\text{text}}_{i,t}, M^{\text{vis}}_{i,t}) \)，包含文本指导与视觉区域指向。

  - 控制器可联合修订文本、源图像与区域，并决定保留、替换或移除视觉证据。

- **自适应视觉记忆注入**：
  - 门控 \( g_{i,t} \in \{0,1\} \) 决定是否将视觉记忆送入下一次求解输入。
  - \( c_{i,t} = (T_{i,t}, \emptyset) \) 或 \( (T_{i,t}, V_{i,t}) \)，原始任务图像始终保留。

- **共享经验整合与检索**：
  - 使用树结构组织经验：叶子节点存放问题级教训，内部节点分组与汇总。
  - 支持 Place、Merge、Split + Lift、Consolidation 等操作，并可抽象出可复用规则。
  - 检索：\( R_i = S^{\text{retrieve}}_\phi(x_i, \text{Recall}(x_i, B)) \)，Recall 使用冻结文本编码器检索候选节点。

- **训练细节**（附录 B）：

## 7. 优点

- **无需更新宿主参数**：通过外部记忆实现能力增强，部署成本低，兼容不同 backbone 和 harness。
- **轻量模型**：两个 2B 模型即可完成记忆控制与组织，显著降低记忆操作时延。
- **多模态经验共演化**：联合精炼文本与视觉证据，并自适应决定是否注入视觉信息，比单纯文本记忆更灵活。
- **跨系统可复用**：经验库独立于具体 agent 系统，支持不同系统间贡献与复用。
- **层次化树组织**：能将碎片化教训整合成可复用规则，提升检索与泛化能力。
- **实验设计较严格**：构建集与评测集分离、单次尝试协议、成本分别归一化等做法增强了结果可信度。
