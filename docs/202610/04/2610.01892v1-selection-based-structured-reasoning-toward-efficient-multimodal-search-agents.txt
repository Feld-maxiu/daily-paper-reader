ABSTRACT 

Multimodal agents commonly generate freeform reasoning before each action. For small mod-els, limited model capacity can result in lengthy reasoning that provides little useful guidance for action generation while incurring substantial inference cost. To address this challenge, we introduce Selection-based Structured Reasoning (SSR), a framework that reformulates reasoning as selection instead of open-ended generation. SSR represents recurring high-level reasoning as pre-specified, reusable natural-language candidates. At each turn, the model selects from the rea-soning candidates based on their likelihoods given the current context, without an auxiliary task head. Using pre-specified reasoning traces enables parallel scoring, where teacher-forced prefill-ing computes token likelihoods concurrently within and across candidates using a shared context KV cache. We evaluated SSR on seven multimodal search benchmarks using 2B and 4B mod-els. Across multiple reinforcement learning objectives and supervised fine-tuning, SSR delivers significant efficiency gains without sacrificing task performance. SSR achieves an average success rate competitive with leading search agents of the same scale, while reducing per-turn reasoning latency by over 90% and total per-question model inference latency by 28–54%. 1 INTRODUCTION 

Multimodal agents turn textual and visual observations into actions: they analyze multimodal inputs, gather information, and use tools to resolve tasks that require multi-turn interactions (He et al., 2024; Chng et al., 2025). A common agent design interleaves observations, freeform reasoning, and actions (Yao et al., 2022). The reasoning step lets the model assess the available evidence and decide what to do next, but adds sequential token generation cost before every action. For small, on-device models with limited reasoning capacity, lengthy texts and repeated deliberations may waste the generation cost without providing useful guidance for generating better actions. An efficient agent needs reasoning that guides it to choose the desired action with minimal repeating cost of generating reasoning traces. Existing approaches reduce this overhead by prompting concise traces or rewarding shorter reason-ing (Xu et al., 2025; Arora & Zanette, 2025). These approaches reduce the amount of text generated, yet keep the sequential dependency between its tokens during autoregressive decoding. We inves-tigate an orthogonal direction: changing the representation of reasoning itself. We observed that in multimodal search, entities, queries, and observations vary across questions, but the high-level reasoning for taking the next action often recurs. For example, finding the location of an upcoming AI conference and the year LEGO was founded can share the same rationale: the entity is known but the requested information is missing, so search for the entity name and the attribute of interest. Pre-vious work on thought templates (Yang et al., 2024; Ouyang et al., 2026) reported a similar finding, showing the value of reusing reasoning knowledge across problems. Therefore, the required reason-ing space for search agents does not span the entire natural language space. Instead, the model can achieve a decent success rate with a few reasoning candidates to choose from. Motivated by this, we introduce Selection-based Structured Reasoning (SSR) , a framework that formulates reasoning as selection among reusable natural-language candidates instead of open-ended freeform generation. At each turn, the agent selects a reasoning candidate conditioned on its interaction history, then uses the selected reasoning to generate the next action and its arguments (e.g., a text search with a question-specific query). We use the language model directly as a candidate classifier, without any additional head, to score each reasoning candidate by its length-normalized likelihood conditioned on the current context. Since all candidate tokens are pre-specified, teacher forcing computes token likelihoods in parallel within each reasoning candidate, and candidates are also scored concurrently sharing the same KV cache. We evaluate SSR across seven multimodal search benchmarks. Our 4B SSR with GRPO model achieves an average success rate of 61 .37% , matching the performance of leading trained 4B search agents ( 61 .25% ). Across GRPO (Shao et al., 2024), GSPO (Zheng et al., 2025b), SAPO (Gao et al., 2025), and SFT, the SSR agents achieve comparable task performance while significantly reducing model inference latency compared to the freeform reasoning counterpart. Against four representa-tive efficient reasoning baselines, SSR achieves a higher success rate, lower model inference time, and more consistent latency. In summary, our contributions are three-fold: • Reasoning by selection rather than generation. We introduce Selection-based Structured Rea-soning (SSR), which replaces freeform reasoning with selection among reusable natural lan-guage candidates conditioned on the current context. • Parallel reasoning decoding. We use the language model itself to score reasoning candidates by their length-normalized likelihoods. This approach requires neither an additional classification head nor an SFT warm start. Teacher forcing enables parallel scoring across all tokens within and between candidates, eliminating autoregressive generation of reasoning traces. • Competitive performance with substantial efficiency gains. Across GRPO, GSPO, SAPO, and SFT, our 4B agents maintain competitive performance while reducing mean reasoning la-tency per turn by over 90% and mean model latency per question by 28 –54% .

2 RELATED WORK 

2.1 MULTIMODAL SEARCH AGENTS 

Prior work trained multimodal agents to interleave perception, retrieval, and tool use. In multimodal search, MMSearch-R1 (Wu et al., 2025) and DeepMMSearch-R1 (Narayan et al., 2025) trained mod-els to use text and image search, while Visual-ARFT (Liu et al., 2025) and DeepEyes (Zheng et al., 2026) added image operations such as cropping and zooming. DeepEyesV2 (Hong et al., 2026) combined image operations with code execution and web search. SenseNova-MARS (Chng et al., 2025), TAPO (Dong et al., 2026), and WebWatcher (Geng et al., 2025) investigated multi-turn rein-forcement learning, tool-aware credit assignment, and deep-research behavior. More recent systems extended the scale and supervision of this recipe: VSearcher trained long-horizon search over text, 2images, and webpages (Zhang et al., 2026), while ProMMSearchAgent introduced process-oriented rewards in a static sandbox before transfer to live search (Yan et al., 2026). These approaches fo-cused on training-data mixtures, gradient routing, and credit assignment for performance improve-ments, while we explore an orthogonal direction that improves inference efficiency. 2.2 EFFICIENT REASONING FOR MLLM A GENTS 

Efficient-reasoning methods controlled model deliberation through token budgets, early stopping, compressed chains of thought, or adaptive test-time computation (Han et al., 2025; Ma et al., 2025; Sui et al., 2025). Agentic settings add another resource axis: the model must decide not only how long to think, but also whether to spend the next unit of budget on retrieval, interaction, or answer commitment. Inference-time budget control for search agents explicitly modeled this trade-off (Fang et al., 2026). Closest to our efficiency goal, HyperEyes (Li et al., 2026) treated inference efficiency as a first-class training objective: it dispatched multiple grounded queries concurrently within a round and rewarded trajectories that avoided superfluous tool calls, reducing the number of interaction rounds, whereas we reduce the cost of the reasoning span within each round. Grammar-constrained decoding enforced admissible output forms (Geng et al., 2023), with engines such as XGrammar reducing the cost of constraint checking (Dong et al., 2025). SSR instead scores complete candidates in parallel and directly supplies the selected text as the reasoning trace. 2.3 REUSABLE REASONING AND AGENT SKILLS 

Prior work explored reusable knowledge through thought templates (Yang et al., 2024), context-aware guidelines (Fu et al., 2024), reasoning memories (Ouyang et al., 2026), and task work-flows (Wang et al., 2025). Given a library of reasoning candidates, SSR directly uses the act-ing MLLM’s internal semantic knowledge to select among them through context-conditioned like-lihoods, without any auxiliary knowledge-management or retrieval system. Trajectory-level ap-proaches such as StraTA (Xue et al., 2026) generated a strategy from the initial task state and kept that strategy fixed throughout the interaction. SSR instead selects a reasoning candidate at every turn based on the updated interaction history, allowing new observations to change the guidance for subsequent actions. Programmatic approaches (Wang et al., 2023; Zheng et al., 2025a) encoded reusable skills as fixed, executable programs. An SSR candidate instead supplies natural-language guidance that biases action generation without prescribing executable control flow. This leaves con-crete queries, tool arguments, and answers flexible, allowing the same reasoning candidate to support different actions across contexts without modifying the candidate itself. 

3 SELECTION -B ASED STRUCTURED REASONING 

3.1 OVERVIEW 

We introduce Selection-based Structured Reasoning (SSR) , which replaces freeform reasoning in ReAct agents (Yao et al., 2022) with selection among reusable reasoning candidates. At turn t, the interaction history of an agent is ht = [ x, z 0, a 0, o 0, . . . , z t−1, a t−1, o t−1], where x is the initial user request, zi is a reasoning trace, ai is an action, and oi is the observation returned by an external tool. A tool call extends the history with a new observation, while a final answer terminates the trajectory. Conventionally, an MLLM with distribution pθ generates a freeform reasoning trace 

zt ∼ pθ (· | ht) before generating the action at ∼ pθ (· | ht, z t). Since zt is unconstrained natural-language text, its tokens must be decoded autoregressively, resulting in substantial inference latency. To eliminate this sequential decoding cost, SSR selects zt from reusable natural-language candidates conditioned on ht, instead of generating it token by token (Figure 2). SSR contains a reasoning library R = {r1, . . . , r N }, which consists of short natural-language candidates. Each candidate is a reusable reasoning trace that describes what information is available or missing in the current context and what step to take next. Parallel reasoning decoding uses the language model itself to score the full text of each candidate conditioned on ht and select one as zt. Since all candidate texts are specified in advance, their token likelihoods can be computed with teacher-forced prefill and different candidates can be scored in parallel. The selected reasoning is then inserted into the context to guide instance-specific action generation, such as a search query, crop location, or final answer. 3SHARED INPUT

All tokens in the reasoning text will be processed concurrently parallel within each attention layer. At the candidate level, each Sθ (ri | ht) can be computed concurrently given the same history KV cache for ht. 4.1 SETUP 

Datasets. Following prior work (Chng et al., 2025; Dong et al., 2026), we use VisualProbe (Lai et al., 2026), DeepEyes (Zheng et al., 2026), and FVQA-train (Wu et al., 2025) for training, and use MMSearch (Jiang et al., 2024), HR-MMSearch (Chng et al., 2025), FVQA-test (Wu et al., 2025), InfoSeek (Chen et al., 2023), SimpleVQA (Cheng et al., 2025), LiveVQA (Fu et al., 2025), and MAT-Search (Liu et al., 2025) for evaluation. Appendix D details the datasets used. 

Implementation details. We use the 2B/4B Qwen3-VL (Qwen Team, 2025) models for our exper-iments. Following the aforementioned prior work, we use the same tool harness with reverse-image search, text search, and image cropping, as well as the same LLM-as-judge for evaluation. Our reasoning library contains six manually written reasoning candidates shared across benchmarks (de-tails in Appendix E): (1) doing an image search to identify the entity when unsure, (2) looking up specific information through a text search, (3) zooming into a specific part of the image for targeted inspection, (4) answering the question from the gathered evidence, (5) answering the question based on the image, and (6) answering with general knowledge. Each of them covers a general case that the search agent may encounter. Unless otherwise noted, we train each RL model in a single stage for one epoch with a learning rate of 10 −5 using outcome and format rewards. For simplicity, we set λSFT reason = γRL reason = 1 and β = 10 −3. Appendix F contains additional implementation details. 

Evaluation metrics. We report success rate on all seven multimodal search benchmarks and infer-ence efficiency. For latency profiling, we sample 100 questions per benchmark and measure per-turn reasoning latency (time to produce the reasoning trace) and per-question model latency (prefill, rea-soning, action generation, and other model inference over the full trajectory). We report mean and 95th-percentile latency. Environment-side processing, including tool execution and LLM-as-judge evaluation, is excluded as it introduces excessive model-independent variations. We also report ef-fective reasoning throughput, computed as the total number of reasoning tokens processed divided by the total reasoning time. For SSR, this counts all candidate tokens being scored in parallel. For autoregressive generation, it counts the tokens in the generated reasoning trace. We run the profiling on an NVIDIA H100 GPU with an offline SGLang (Zheng et al., 2024) inference engine. 4.2 SSR A CHIEVES COMPETITIVE TASK PERFORMANCE

4.4 INFERENCE LATENCY AND REASONING THROUGHPUT 

To compare SSR with existing efficient-reasoning methods, we compare four baselines spanning three approaches: prompt-based compression with Chain-of-Draft (Xu et al., 2025) and Sketch-of-Thought (Aytes et al., 2025), learning shorter reasoning through efficiency-reward RL (Arora & Zanette, 2025), and optional reasoning trace decoding with a lightweight classification head in Probe & Prefill (Sun et al., 2026). We implement the efficiency baselines on the GRPO-freeform pipeline for a fair comparison and report the results in Table 3. 

Higher success rate with lower inference latency. SSR achieves the highest success rate and delivers approximately 7× or greater speedup in reasoning on all baselines. The gains extend to question-level: mean model latency is around 2.5s, approximately 30% lower than Sketch-of-Thought, the fastest baseline on this metric. These results show that parallel reasoning decoding is a more effective than reasoning-compression methods at reducing latency while maintaining high success rate. The speed advantage is even larger at the 95 th percentile. SSR has a p95 reasoning time of 0.071 s,

10 ms above its mean, whereas the p95 latency for the baselines range from 0.798 to 1.892 s. The tight mean-to-p95 gap indicates consistent reasoning latency in SSR, matching the predictable com-putation of scoring all candidates in parallel as opposed to freeform generation with varying lengths. At the question level, p95 latency is 4.6s, about a 30% reduction from the 6.6s of the fastest baseline. 4.5 COMPARISON BETWEEN DIFFERENT REASONING METHODS

Selection vs. autoregressive generation. Autoregressive decoding can also generate the specified reasoning candidate when the model is trained to use the library entries. 5 CONCLUSION 

We presented Selection-based Structured Reasoning (SSR) , which reformulates reasoning in small multimodal search agents as selection rather than open-ended generation. SSR captures re-curring high-level reasoning as reusable natural-language candidates and selects among them based on their likelihoods under the current context. Pre-specified candidates enable teacher-forced paral-lel scoring within and across candidates, eliminating token-by-token reasoning generation. Across seven multimodal search benchmarks, SSR achieves competitive task performance while reducing per-turn reasoning latency by over 90% and total per-question model inference latency by 28 -54% .More broadly, our results suggest that small search agents may not need to reason over the full lan-guage space at every step, and that organizing recurring reasoning into a compact, reusable space can enable more efficient multimodal agents. 9ACKNOWLEDGEMENTS

B.2 SSR R OLLOUTS ARE ON-P OLICY IN GRPO During rollout collection, parallel reasoning decoding scores the reasoning candidates under the rollout parameters θold and samples zt ∼ qold (· | ht). The harness inserts the selected candidate into the context, after which the model generates action tokens autoregressively from pold (· | ht, z t).The retained behavior probabilities therefore correspond to the process that generated the trajectory: one categorical probability for the reasoning selection and token-level probabilities for the subse-quent action. Selecting from the reasoning library defines the support of the reasoning policy, while inserting the selected text is deterministic conditional on that selection. Thus, rollout collection is on-policy with respect to the composite SSR behavior policy. When a rollout batch is reused after parameter updates, the current policy differs from the behavior policy, as in standard GRPO. The reasoning- and action-level importance ratios in Eq. (5) com-pare the current probabilities with the fixed probabilities recorded during rollout collection. The detached-competitor approximation in Eq. (10) concerns the current selector probability and its gra-dient during optimization; it does not change the policy used to collect the rollouts. Each inserted reasoning span is consequently represented by one categorical selection term, while token-level ac-tion terms apply only to the autoregressively generated action tokens. D.2 EVALUATION BENCHMARKS 

We evaluate on seven publicly available multimodal search benchmarks that collectively span a broad range of retrieval difficulty, temporal freshness, and image resolution requirements. We use the benchmark versions distributed in the SenseNova evaluation collection (Chng et al., 2025). 

MMSearch (Jiang et al., 2024) contains 300 manually collected questions spanning 14 subfields, of which 171 are accompanied by an image; its News area covers events from May to August 2024, testing the model’s ability to ground visual observations in up-to-date factual knowledge. We follow the standard split of 171 questions used for system-level evaluation. 

HR-MMSearch (Chng et al., 2025) is a knowledge-intensive benchmark comprising 305 ques-tions paired with high-resolution (4K) images sourced from international news agencies (2025 events), spanning eight topical domains. Approximately 60% of questions are classified as hard, requiring three or more tool invocations to answer correctly. 

FVQA-test (Wu et al., 2025) is a curated 1,800-sample test set consisting of three equal-sized subsets: FVQA-auto-vc (600 automatically constructed samples, each manually checked for cor-rectness and disjoint from the training set), InfoSeek Human Split (600 samples with manually corrected annotations), and an expert-annotated subset (600 samples). 

InfoSeek (Chen et al., 2023) is a visual question answering dataset for information-seeking ques-tions that cannot be answered through commonsense reasoning alone. It is built on visual entity recognition and grounded in Wikidata, targeting fine-grained factual attributes that models do not reliably surface without retrieval. We sample 2,000 instances from its test split. 

SimpleVQA (Cheng et al., 2025) focuses on factual accuracy, combining post-2023 VQA in-stances with expert-curated image-question pairs across 1,013 English samples. 

LiveVQA (Fu et al., 2025) aggregates 3,602 image-question pairs from major news outlets, in-cluding CNN and BBC, spanning 14 thematic categories, and emphasizes temporal reasoning over recently published content. 

MAT-Search (Liu et al., 2025) is a manually crafted and human-verified benchmark of 150 ex-amples designed to evaluate agentic multimodal reasoning, requiring models to handle composite 19 multi-hop queries, retrieve external information, and invoke tools effectively across varying reason-ing depths.

F TRAINING DETAILS 

Reference recipe and our adaptation. We adapt the multimodal-search setup of TAPO (Dong et al., 2026). The agent is trained directly with RL, without an SFT warm-up, using VeRL, a global batch size of 64, learning rate 1 × 10 −5, and 8 rollouts per GRPO group. Each trajectory permits at most 10 interaction rounds during training, 8,192 generated tokens per round, and 32,768 tokens across the full trajectory. If it exceeds any of these, it will be marked as incorrect. Text retrieval during training uses a local Wikipedia retrieval index to reduce cost and evaluation uses web search through Serp API. 

Action space. The agent can choose among three information-acquisition tools and a terminal answer: (i) image search tool , which performs reverse-image search on the question image and returns image captions; (ii) text search tool(query) , which performs query-specified search and returns a Qwen3-32B-generated summary; (iii) image zoom in tool(bbox) ,which crops a bounding box and returns the resulting image patch; and (iv) a terminal <answer> 

action. At every non-terminal turn, the base protocol expects a thinking block followed by exactly one <tool call> conforming to the JSON schema; SSR supplies the thinking block through candidate selection while retaining the same tool-call schema. 

Reward. For RL, we use a combination of accuracy reward and format reward. 

rfinal = raccuracy + 0 .5rformat (20) Non-multiple-choice questions are judged by Qwen3-VL-32B-Instruct with greedy decoding and temperature zero given the image, question, ground truth, and the final answer generated by the model. Multiple-choice questions use exact match. Format reward is model-dependent: all condi-tions have to generate valid <think> delimiters and correct tool call format; SSR models (includ-ing the index-only variant) additionally have to use the expected tool of each reasoning that they select for full format reward, otherwise they only get partial format reward for the correct tool call 20 format; the autoregressive structured reasoning model gets the format reward only if it generates reasoning in the library with exact match.
