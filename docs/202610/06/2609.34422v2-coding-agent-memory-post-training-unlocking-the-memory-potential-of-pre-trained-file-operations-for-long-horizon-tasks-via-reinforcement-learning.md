## 摘要
语言模型智能体越来越多地处理长时程任务，其交互历史超出了模型的活跃上下文。最近的工作开始使用强化学习将记忆控制纳入策略，通常依赖于领域特定、时程相对较短的训练环境中的预定义记忆工具。这种设置将学到的记忆行为与基础模型预训练之外的环境特定接口绑定，必须从头学习，因此即使经过后训练，智能体在长时程任务中仍难以使用记忆。为克服这些局限，我们提出了 Coding Agent Memory Gym（CAMG），一套涵盖 Shop、Coding、DeepResearch 和 AutoResearch 的长时程智能体强化学习环境。除了每个环境的原生任务接口外，CAMG 还提供可执行的 shell 访问和一个在 episode 内持久的工作区，使智能体能够在整个 episode 期间创建、修改、搜索和重用文件作为记忆。我们还引入了 CAMG-RL，它在全部四个环境中使用完全异步 PPO 联合训练单一策略，直接从下游任务奖励中学习这种基于文件的记忆行为；我们从相应规模的 Qwen3.5 模型训练得到 CAMG-RL-4B 和 CAMG-RL-9B。在 SWE-bench Verified 和 MLE-bench Lite 上，CAMG-RL-4B 和 CAMG-RL-9B 分别与 Qwen3.5-35B-A3B 和 Qwen3.5-122B-A10B 表现相当。

## Abstract
Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the model's active context. Recent work has begun to use reinforcement learning to make memory control part of the policy, often relying on predefined memory tools within domain-specific training environments of relatively short horizons. This setup ties learned memory behavior to environment-specific interfaces that lie outside the base model's pre-training and must be learned from scratch, so even after post-training, agents struggle to use memory in long-horizon tasks. To address these limitations, we introduce Coding Agent Memory Gym (CAMG), a suite of long-horizon agentic-RL environments spanning Shop, Coding, DeepResearch, and AutoResearch. Alongside each environment's native task interface, CAMG provides executable shell access and an episode-persistent workspace, enabling agents to create, revise, search, and reuse files as memory throughout an episode. We also introduce CAMG-RL, which trains a single policy jointly across all four environments with fully asynchronous PPO, learning this file-based memory behavior directly from downstream task reward, and we train CAMG-RL-4B and CAMG-RL-9B from Qwen3.5 models of matching size. On SWE-bench Verified and MLE-bench Lite, CAMG-RL-4B and CAMG-RL-9B are competitive with Qwen3.5-35B-A3B and Qwen3.5-122B-A10B, respectively.

- **CAMG 环境套件**：

    - **episode 内持久工作区**：智能体可以通过文件系统操作创建、修改、搜索和重用文件作为记忆。
  - 上下文替换机制：环境在上下文边界要求策略写入 `.agent_memory/CONTINUATION.md`（受 8,192 字节限制），验证写入后替换活跃消息历史；策略之后可通过普通文件读取恢复状态，也可维护其他记忆文件。
- **CAMG-RL 训练方法**：
  - 训练**单一策略**联合处理四个环境，动作空间为原生任务动作与文件系统动作的并集。
  - 每个响应可以以自由形式推理开头，并以可执行动作结束；所有采样 token（包括策略生成的文件内容）都参与策略优化。
  - 使用 **GAE** 传播下游任务奖励，并用 **clipped PPO** 在任务回报目标下优化。
  - **双粒度 PPO**：每个响应估计一个优势值（turn 级，稳定），但每个 token 独立裁剪概率比（token 级，细粒度），兼顾稳定性与更新粒度。

## 7. 论文的贡献与意义

- **提出 CAMG 环境套件**：为研究长时程智能体记忆提供了统一、可执行、支持 shell 与持久工作区的基准，弥补了以往训练环境时程短、依赖专用记忆工具的不足。
- **证明文件操作可作为通用记忆机制**：通过 surprisal 分析、RL 训练与消融实验，系统性地验证了预训练中已经熟悉的文件系统动作比外部专用记忆工具更容易被策略掌握并用于跨上下文信息保留。
- **展示小模型的能力跃升**：CAMG-RL-4B 在长时程任务上达到 54.4% 平均成功率，超过多个更大规模的冻结模型；在 SWE-bench Verified 与 MLE-bench Lite 上分别与 35B-A3B 和 122B-A10B 冻结模型相当，说明正确的记忆机制比单纯增加参数更有效。
- **提出可扩展的 RL 训练配方**：双粒度 PPO 与完全异步 rollout-learner 架构能够处理不同环境 episode 时长差异大的问题，训练在一天内完成，具有实际可复现性。

## 8. 局限性与未来工作

- **环境与真实任务仍有差距**：CAMG 环境中的上下文替换规则和 continuation 文件机制由人为设计，不一定完全对应真实部署中的上下文窗口限制方式；例如真实系统中可能使用滑动窗口或动态压缩，而非固定字节限制。
- **测试集与任务类型有限**：四个环境虽然具有代表性，但任务规模较小（每环境 128 个测试任务），且 DeepResearch 和 AutoResearch 的评分依赖于冻结裁判或预设指标，可能引入偏差。
- **主要基于单一基座模型**：论文主要使用 Qwen3.5-4B 和 9B 进行训练，未验证其他基座模型（如非代码预训练模型或不同架构）上的可迁移性。
- **未充分探索更大训练规模**：训练仅进行 200 次 learner 更新、12,800 个 episode，提升空间仍存在；更大规模训练是否会进一步拉开与专用记忆工具的差距尚不清楚。
- **文件系统动作可能造成安全风险**：允许策略自由执行 shell 命令，在真实部署中可能带来副作用，需要额外沙箱与权限控制。

## 9. 总体评价

这篇论文以清晰的理论动机和充分的实验证据，论证了“利用预训练分布内的文件操作作为长时程记忆”这一简洁但有效的思想。它不仅提出了可复现的 CAMG 环境套件和稳定的 RL 训练方案，还通过因果干预和 surprisal 分析揭示了策略习得记忆行为的内在机制。尽管存在环境理想化和基座模型单一等局限，但该工作为长时程智能体记忆研究提供了重要基准和实用方法论，对后续在真实软件工程和自主研究场景中的记忆增强训练具有直接启发意义。
