## 摘要
逼真的环境副本对训练和评估 LLM 智能体越来越有价值，但原始系统可能无法访问或难以复现。我们探索智能体语言世界建模：不是重建可执行环境，而是由一个世界模型智能体充当任务智能体的环境，并支持忠实且有状态的模拟。我们通过 Trace2Env 实例化这一范式，Trace2Env 是一个无需学习的框架，适用于原始系统不可用但历史交互轨迹仍可访问的场景。Trace2Env 将这些轨迹重构为一个可复用的环境世界手册，其中包含环境模式、有依据的证据和归纳出的行为知识。在运行时，世界模型智能体主动查阅该世界手册以及持久的情节状态，以推断每个动作的观察结果和持久状态效果。在九个环境中，与传统的基于提示的语言世界模型相比，Trace2Env 在下一观察保真度和长时程交互一致性上均有提升。在多轮交互中，针对 Trace2Env 生成的任务智能体动作在真实环境中回放时更经常保持有效，表明其模拟动态更好地在连续轮次中保留了先前动作的后果。这些结果确立了智能体语言世界建模作为构建逼真环境副本的另一种方向，而无需重建原始可执行系统。

## Abstract
Realistic environment replicas are increasingly valuable for training and evaluating LLM agents, yet the original systems may be inaccessible or impractical to reproduce. We explore agentic language world modeling: rather than rebuilding an executable environment, a world model agent serves as the environment for a task agent and supports faithful and stateful simulation. We instantiate this paradigm with Trace2Env, a learning-free framework for settings where the original system is unavailable but historical interaction traces remain accessible. Trace2Env reconstructs these traces into a reusable environment worldbook containing environment schemas, grounded evidence, and induced behavioral knowledge. At runtime, the world model agent actively consults the worldbook together with persistent episodic state to infer each action's observation and lasting state effects. Across nine environments, Trace2Env improves both next-observation fidelity and long-horizon interaction consistency over conventional prompt-based LWMs. In multi-turn interaction, task agent actions generated against Trace2Env remain valid more often when replayed in the real environment, indicating that its simulated dynamics better preserve the consequences of earlier actions across successive turns. These results establish agentic language world modeling as an alternative direction for building realistic environment replicas without reconstructing the original executable system.

## 2. 论文提出的方法论

### 2.1 核心思想

- **Trace2Env** 是一个无需学习（learning-free）的框架，由两个阶段组成：
  - **离线阶段**：将历史交互轨迹重构为“环境世界手册”（environment worldbook）。
  - **在线阶段**：由世界模型智能体运行该世界手册，结合持久情景状态和情景记忆，模拟任务智能体动作的环境响应。

### 2.2 环境世界手册（Worldbook）的构建

- 世界手册包含四类互补构件：
  - **Schema（模式）**：定义动作接口和模拟器可维护的状态变量。
  - **Grounded evidence（有依据的证据）**：保留原始轨迹中的动作—观察对、选定示范和逐字记录。
  - **Induced abstractions（归纳抽象）**：从重复行为中归纳出条件效应、状态约束、观察契约和描述惯例。
  - **Provenance（出处）**：记录每个构件来自哪些轨迹和轮次，支持可追溯性。
- 构建过程包括：动作与结果对齐；本地证据提取；模式归纳；规则提议与审查（成功/失败对比、反例约束）；只保留被支持的规则为可执行规则，模糊或矛盾的候选规则被保留为归档。

### 2.3 持久情景工作区

- 在线模拟采用三元组工作区 \( W_t = (K_E, \hat{s}_t, M_t) \)：
  - \( K_E \)：固定、跨情景共享的世界手册，描述环境如何行为。
  - \( \hat{s}_t \)：当前情景的可变表示状态，记录环境当前事实。
  - \( M_t \)：情景交互记忆，保留动作—观察顺序和临时细节。
- 关键设计：状态缺失表示“未知”，而非“不存在”，避免错误推断。

### 2.4 智能体模拟流程

- 世界模型智能体通过工具主动检查工作区（读取模式、规则、证据、状态和记忆），而不是一次性接受所有信息。
- 对检索到的世界手册条目，先用**适用性门（applicability gate）** \( g_{app} \) 标记为 supporting / uncertain / format-only，以区分可迁移行为与特定情景事实。
- 智能体输出一个**转换提案** \( q_t = (\Delta_t, \tilde{o}_{t+1}) \)，其中 \( \Delta_t \) 是有序状态效应列表，\( \tilde{o}_{t+1} \) 是预测的观察。
- 共享**验证门（validation gate）** \( g_{val} \) 将提案应用到状态副本上，检查模式、规则支持和状态约束；只有被接受的提案才会被提交并解析最终观察。
- 该过程保证状态和记忆跨轮次持续，即行为后果得到保留。

### 2.5 公式化描述

- 传统提示型 LWM：\( \hat{o}_{t+1} \sim p_\theta(\cdot | d_E, h_t, a_t) \)。
- Trace2Env 的模拟器预测：\( \hat{o}_{t+1} \sim Q_\theta(\cdot | \hat{h}_t, a_t, D_{build}) \)，其中 \( Q_\theta \) 表示包含智能体推理和检索的分布，\( D_{build} \) 为构建轨迹。

## 6. 论文的主要结论与发现

- **整体性能提升**：Trace2Env 在两个骨干上的平均五维得分均最高（GPT 75.94，DeepSeek 75.75），相比 Direct Prompting 分别提升 6.43 和 7.04 分；在 14 个环境—骨干对中 11 个达到最佳。
- **维度一致性改善**：Factuality、Consistency、Realism、Quality 在所有环境—骨干对上均提高；Format 仅少数下降。
- **长时程一致性显著**：ALFWorld 上 Direct Prompting 的 W2R 仅 3%，而 Trace2Env 达到 85%（CR=0.914）；SciWorld 上 Direct Prompting 45% vs Trace2Env 60%（CR=0.706）。说明高模拟内成功率不一定意味着真实可迁移，而 Trace2Env 更好地保持状态后果。
- **组件互补性**：世界手册与运行框架贡献互补；证据层（evidence）比抽象层（abstraction）单独收益更大，但两者结合最佳；状态跟踪和自适应检索各贡献约 1–2 分。
- **构建轨迹规模效应**：Terminal 上性能随轨迹数从 5 增至 36 持续提升，但一次性构建成本也上升。
- **跨任务泛化**：Trace2Env 的增益不局限于构建集中出现过的任务，在未见任务子集上仍显著。
- **效率权衡**：完整智能体运行提供最强保真度，但代价为额外模型调用和成本；可以关闭自适应循环或状态跟踪以降低开销，同时保留大部分增益。

## 7. 优点

- **新范式提出**：将环境模拟视为智能体任务，突破了传统提示型 LWM 的扁平上下文限制，为“不可复现环境”的模拟提供了可行路径。
- **结构化世界手册**：将模式、证据、抽象和出处分离，兼顾具体行为与泛化规则；支持可追溯性。
- **状态与记忆分离**：显式区分可迁移知识（世界手册）与情景事实（状态和记忆），避免跨情景污染，并正确处理“未知”而非“不存在”。
- **适用性门与验证门**：通过 supporting/uncertain/format-only 标签和状态验证，降低了错误知识迁移和幻觉效应。
- **无学习成本**：无需训练或微调，仅需轨迹重构和 LLM 推理；世界手册可跨骨干复用。
- **评估严谨**：轨迹聚类置信区间、交叉拟合、泄漏控制、未见任务分层分析、多轮 W2R 回放度量；多维裁判评分。
- **实际意义**：展示了从痕迹到可复用模拟器的可行路径，为智能体训练和评估提供了替代方案。

## 8. 不足与局限

- **多轮评估规模小**：长时程一致性实验仅在 ALFWorld 和 SciWorld 两个环境进行，任务数量有限（100/40），外部效度有待扩展。
- **高度依赖轨迹质量与覆盖**：世界手册质量受构建轨迹限制；未覆盖的行为或状态可能缺失；轨迹偏差会传递到模拟器。
- **推理成本较高**：完整 Trace2Env 每行模型调用最多约 5 次，成本显著高于单次调用基线；效率与精度的权衡需要用户自定义。
- **部分收益不稳定**：在某些环境—骨干组合中，Trace2Env 相比 Worldbook Prompting 或 Harness only 的增益较小甚至为负（如 DeepSeek Terminal 上 T2E − WB = −0.24）；对骨干模型能力有一定依赖。
- **仍受 LLM 能力限制**：作为语言世界模型，无法保证完全真实的环境行为；复杂状态更新或未见过的新颖行为仍可能出错。
- **缺乏与其他 LWM 方法的广泛比较**：主要与提示型和自身变体对比，未直接与 RAWM、WorldEvolver 等现有外部经验增强 LWM 进行全面基准测试。
- **构建过程依赖 LLM 归纳**：规则诱导和模式提取可能引入近似或错误，虽然通过验证门缓解，但根本上仍受模型理解和轨迹覆盖率限制。
- **实验未报告完整成本或资源细节**：仅给出推理成本，未提供环境影响、总构建成本或 API 调用总数汇总。
