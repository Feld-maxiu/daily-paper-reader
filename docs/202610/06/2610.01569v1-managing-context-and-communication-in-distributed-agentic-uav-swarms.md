## 摘要
无人机（UAV）集群越来越依赖语言模型智能体在不确定环境中提供任务级自适应推理。完全分布式控制中，每架无人机承载一个独立的小型语言模型（SLM），消除了对集中协调器的依赖，但也带来了信息管理问题：长期交互历史可能降低推理上下文质量，而不加区分的信息传播会增加通信和推理开销。我们通过一种分布式无人机-智能体架构应对这些挑战，该架构通过事件驱动的“推理-行动-观察”生命周期实现持续的本地SLM控制。运行时知识被表示为结构化原子笔记，并组织为核心记忆、本地记忆和针对特定对等方的记忆。确定性的兴趣感知gossip引擎根据接收方特定的语义新颖性和时效性选择性地传播这些笔记。我们在模拟搜救任务中使用十架无人机对该架构进行了评估。我们的方法完成了所有实验运行，而无限制洪泛消息方案仅能完成70–85%的实验运行，将转发决策委托给SLM则在每次运行中都无法完成任务。与无限制洪泛相比，我们的方法大约将推理token消耗减半，减少了传输数据量，并实现了更低的幸存者计数误差。

## Abstract
Unmanned aerial vehicle (UAV) swarms increasingly rely on language-model agents to provide adaptive mission-level reasoning in uncertain environments. Fully distributed control, in which each UAV hosts an independent Small Language Model (SLM), removes reliance on a centralized coordinator but introduces an information-management problem: long-running interaction histories can degrade the reasoning context, while indiscriminate information dissemination increases communication and inference overhead. We address these challenges with a distributed UAV-agent architecture that enables continuous local SLM control through an event-driven reason-act-observe lifecycle. Runtime knowledge is represented as structured atomic notes and organized into core, local, and peer-specific memory. A deterministic interest-aware gossip engine selectively disseminates these notes according to recipient-specific semantic novelty and recency. We evaluate the architecture using ten UAVs in a simulated search-and-rescue mission. Our approach completes all experimental runs, whereas unrestricted flooding messages completes only 70-85\%, and delegating forwarding decisions to the SLM prevents mission completion in every run. Compared with unrestricted flooding, our approach approximately halves inference-token consumption, reduces transmitted data, and achieves lower survivor-count error.

# 论文总结：《分布式智能体无人机集群中的上下文与通信管理》

## 1. 论文的核心问题与整体含义

- **研究背景**：无人机集群在搜救、灾害恢复、环境监测等任务中需要在不确定环境下进行自适应任务级推理。近年来，语言模型智能体（agentic AI）被引入以增强无人机的目标解释、情境推理与自适应规划能力。
- **核心问题**：完全分布式控制下，每架无人机独立承载一个小型语言模型（SLM），虽然消除了对中心协调器的依赖，但带来两个关键挑战：
  - **上下文退化（context rot）**：长期运行中不断积累的动作、观测和同伴消息会塞满上下文，使模型难以关注关键信息，甚至可能忽略安全指令。
  - **通信与推理开销**：不加选择地洪泛（flooding）观测信息会浪费带宽、填满同伴上下文，而把每条消息的转发决策交给 SLM 会引入巨大推理开销，干扰控制生命周期。
- **整体含义**：该论文旨在提出一种统一的分布式无人机智能体架构，通过结构化记忆管理和基于语义新颖性的选择性通信，让每架无人机在资源受限条件下实现持续、可靠、低开销的自主任务执行。

## 2. 论文提出的方法论

论文提出一种事件驱动的“**推理–行动–观察**”生命周期，以及两大核心机制：**上下文与记忆管理**和**兴趣感知 Gossip 引擎**。

### 2.1 系统架构与生命周期

- 每架无人机上运行一个独立 SLM 智能体、一个 Context Manager 和一个 Interest-Aware Gossip Engine。
- 通过 Model Context Protocol（MCP）暴露无人机能力，SLM 以结构化工具调用（而非代码生成）执行任务级动作。
- 生命周期：SLM 解析当前上下文 → 选择动作 → 通过 MCP 调用工具 → 执行结果/观测通过回调返回 → 生成新笔记 → 触发下一轮推理。
- 消息异步到达，在下一个推理步骤中纳入上下文，无需单独同步阶段。

### 2.2 上下文与记忆管理

- **原子笔记（atomic notes）**：将运行时知识表示为自包含、带元数据的语义单元，字段包括：
  - 唯一标识符、原始生成无人机、生成时间、事实语义内容、简短摘要、关键词集、应用特定元数据、语义标签（如 `ROUTE_CONTROL`）。
- **三类记忆区域**：
  - **Core Memory**（固定核心记忆）：包含操作策略、任务规范、无人机元数据和标识符，每次推理均注入。
  - **Local Note Queue**：存储本机产生的笔记，有 token 容量限制 \(B_L\)。
  - **Neighbor Note Queue**：为每个对等方单独维护，存储从该对等方收到的笔记，每个队列有独立 token 容量 \(B_N\)。
- 队列按 token 预算约束，插入新笔记时若超出容量，则删除最旧笔记。
- 每次 SLM 调用时，上下文由核心记忆、本地笔记队列和所有邻居笔记队列组成，从而保证上下文大小有界。

### 2.3 兴趣感知 Gossip 引擎

- **核心原则**：只有对接收方而言具有足够新颖性的信息才应转发。
- **转发决策流程**：
  1. 对每个一跳邻居，使用该邻居对应的 Neighbor Note Queue 作为“该邻居已知信息”的估计。
  2. 只评估与任务相关的语义标签。
  3. 使用文本编码器 \(f_{\text{enc}}\) 将笔记映射为稠密语义向量。
  4. 计算标签特定的平均嵌入，并减去该平均向量得到残差嵌入，以减少同类标签的结构性相似性。
  5. 使用非负余弦相似度衡量候选笔记与历史笔记的语义相似度。
  6. 引入时间衰减权重 \(w_\ell(t)=\max(0, 1-(t-t_\ell)/W)\)，其中 \(W\) 为时间窗口。
  7. 计算每条历史笔记的新颖性贡献 \(d_\ell = 1 - \cos^+(\hat{e}_n, \hat{e}_\ell) \cdot w_\ell(t)\)。
  8. 取最小值作为邻居特定新颖性得分 \(N_{i,j}(m_n)\)：
     \[
     N_{i,j}(m_n) = \min_{d \in V_{i,j}(m_n)} d
     \]
     若历史为空则设为 1。
  9. 根据阈值 \(\tau_{\text{send}}\) 和 \(\tau_{\text{full}}\) 决策：
     - 若 \(N_{i,j} < \tau_{\text{send}}\)：**DISCARD**（抑制转发）。
     - 若 \(\tau_{\text{send}} \le N_{i,j} < \tau_{\text{full}}\)：**COMPACT**（由 SLM 生成紧凑摘要后转发）。
     - 若 \(N_{i,j} \ge \tau_{\text{full}}\)：**FULL**（转发完整笔记）。
- 该过程完全确定性，不依赖额外 SLM 调用来做转发决策（仅在 COMPACT 模式下调用一次 SLM 进行摘要）。

## 3. 实验设计

## 7. 优点

- **统一的分布式架构**：将上下文管理、记忆组织与兴趣感知通信集成到同一框架，解决了完全去中心化 SLM 控制的两大核心挑战。
- **确定性转发决策**：不依赖 SLM 做每个转发决策，避免了级联推理开销，同时保持低延迟、透明、可解释。
- **语义新颖性 + 时效性结合**：使用残差嵌入降低标签内结构性相似性，时间衰减函数合理反映信息时效性，最小相似度策略保守可靠。
- **有界记忆设计**：核心/本地/邻居队列的分离，使上下文始终有界，避免“上下文腐烂”。
- **实验对比有针对性**：包含无智能体确定性、无限制洪泛、SLM 决策转发三种有意义的基线，能清晰展示各设计选择的收益。
- **通信与 token 双重节省**：在保证任务完成的同时，大幅降低通信量和推理开销。
