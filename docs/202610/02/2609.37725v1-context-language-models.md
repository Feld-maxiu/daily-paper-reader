## 摘要
我们提出了上下文语言模型（Context Language Models，CLMs），这是一种能够原生管理自身上下文的语言模型。我们通过将上下文视为一个文件，并允许模型对该文件进行不受限制的更新来实现这一点。这使得模型能够学习在上下文中需要维护哪些最重要的信息，并自然地扩展到多智能体系统，其中多个智能体的上下文以文件形式共存。使用现有模型零样本构建 CLMs 在多种任务上优于最先进的上下文管理策略：在 BrowseComp-Plus 上准确率提高 11.4%，FLOPs 减少 21.5%；在 12 小时 EdgeBench 上分数提高 5%，FLOPs 减少 59%；在 24 小时多仓库智能体集群任务上，在相同计算量下提升幅度高出 65%。此外，通过将上下文管理从外部框架控制转变为模型内在行为，CLMs 天然支持对上下文管理策略的上下文内学习和参数化学习。我们表明，可以通过标准的技能优化循环演化出的自然语言指令来引导 CLMs，在上下文管理任务上留出集准确率最多提高 35.9 个百分点，同时减少计算量。我们还为 CLMs 引入了一种在线强化学习方法，在 BrowseComp-Plus 上将 Qwen3.5-9B 的性能提高 47.6%，同时使用的 FLOPs 减少 12%。最后，我们协同设计了面向 CLM 服务的后缀缓存重用（Suffix Cache Reuse），在相同性能下，相比标准 SGLang 进一步将服务器端计算量减少 35%。

## Abstract
We introduce Context Language Models (CLMs), language models that natively manage their own context. We implement this by treating the context as a file and allowing the model to make unrestricted updates to this file. This allows the model to learn what is most important to maintain in context, and naturally extends to multi-agent systems where multiple agent contexts coexist as files. Building CLMs zero-shot with existing models outperforms SOTA context management strategies across a variety of tasks: 11.4% higher accuracy with 21.5% fewer FLOPs on BrowseComp-Plus, 5% higher scores with 59% fewer FLOPs on 12-hour EdgeBench, and 65% greater improvement with the same compute on a 24-hour multi-repository agent-swarm task. Moreover, by shifting context management from external harness control to intrinsic model behavior, CLMs naturally enable both in-context and parametric learning of context-management strategies. We show that CLMs can be steered with natural-language instructions evolved through a standard skill-optimization loop, improving held-out accuracy by up to 35.9 points on a context-management task while reducing compute. We also introduce an online reinforcement learning method for CLMs, improving Qwen3.5-9B performance on BrowseComp-Plus by 47.6% while using 12% fewer FLOPs. Finally, we co-design Suffix Cache Reuse for CLM serving, further reducing server-side compute by 35% relative to standard SGLang at matched performance.

# 论文总结：Context Language Models（上下文语言模型）

## 1. 核心问题与研究动机

- **背景与问题**：传统语言模型（LM）的上下文管理并非模型原生能力，而是依赖外部框架（harness）通过固定策略（如摘要压缩、卸载、检索）来维护上下文。这些策略通常由人工设计或离线优化，灵活性有限，难以适应复杂、长时程任务。
- **研究动机**：受“Bitter Lesson”启发，作者认为应当让模型自主搜索和学习上下文管理策略，而非依赖人类预设。由此提出 **Context Language Models (CLMs)**，将上下文管理从外部控制转变为模型的内在行为。
- **核心创新**：把“上下文”视为一个**可编辑文件**，模型拥有不受限制的读写权限，可以自主决定保留、删除、重写哪些信息，从而更高效地利用有限上下文窗口，并自然扩展到多智能体系统。

## 2. 方法论

- **形式化定义**：
  - 标准 LM 的上下文转移为追加式：\(c_{t+1} = c_t \oplus f^{LM}_\theta(c_t)\)。
  - CLM 将上下文转移泛化为任意函数：\(c_{t+1} = f^{CLM}_\theta(c_t)\)，即模型直接决定下一时刻的上下文内容。
- **实现方式：Context-as-a-File**：
  - 将 live context 镜像为一个可编辑文件，并向模型提供文件路径。
  - 模型可通过通用 Bash 命令自由编辑该文件；不编辑时默认追加生成 token。
  - 编辑会立即同步到 LLM 服务器的输入上下文。
  - 多智能体场景下，多个上下文文件可共存，支持智能体集群或子智能体工作流。
- **效率度量：prefix-reuse FLOPs**：
  - 考虑标准前缀缓存下的成本：只有前缀匹配部分复用缓存，不匹配后缀需重新预填充，同时考虑解码计算。
  - 公式（文字描述）：总 FLOPs = 预填充未匹配后缀的成本 + 解码生成 token 的成本，其中注意力部分依赖上下文长度和可复用前缀长度。
- **学习机制**：
  - **上下文内学习**：通过自然语言指令或技能文档 \(s\) 引导 CLM：\(c_{t+1} = f^{CLM}_\theta(c_t; s)\)。
  - **技能演化循环**：以轨迹奖励为目标，优化技能文档 \(s^* = \arg\max_s \mathbb{E}_{x\sim\mathcal{D}}[R(\tau(x;s))]\)，可通过外部强模型（assisted evolution）或自身（self-evolution）提出候选技能。
  - **强化学习（RL）**：使用 stepwise GRPO，将轨迹级优势分配给每个生成片段；引入 **success-gated efficiency advantage**，仅在成功轨迹中根据 prefix-reuse FLOPs 进行排序，奖励更高效的轨迹，避免奖励黑客行为。
- **服务优化：Suffix Cache Reuse (SCR)**：
  - 在上下文发生中间编辑后，标准前缀缓存会重新预填充所有后续 token；SCR 重用未改变后缀 token 的缓存状态（包括 KV 缓存），仅重新预填充新插入或追加的 token。
  - 对于混合注意力架构（如 Qwen3.6-27B 的线性注意力层），使用 recurrent state 快照方法；限制每次编辑最多重定位 \(K=6\) 个后缀片段以平衡近似误差与效率。
  - SCR 也可推广到标准聊天服务中 reasoning token 被剥离的场景。
