## 摘要
使用强化学习（RL）训练LLM智能体受到环境瓶颈的限制，环境必须提供可验证的奖励、支持长时程交互并且能够低成本扩展。现有方法依赖昂贵的人工标注数据或LLM生成的环境，但这些环境存在幻觉和基准污染的风险。我们证明，可以使用完全由规则生成的合成环境将LLM训练成有能力的搜索智能体，这类环境的生成无需LLM且边际成本为零。我们构建了PhantomEnvironments，这是来自虚构世界的多轮RL环境，智能体必须在模板化文章语料库中搜索以回答多跳问题。尽管与真实世界没有任何事实共享，这些极其简单的环境仍能产生可迁移到真实世界多跳搜索基准的智能体，在较新的基准上通常优于使用真实世界训练数据训练的结果。训练后的智能体能泛化到未见过的虚构宇宙，并且Qwen模型学会使搜索预算随问题难度大致线性扩展，这表明仅通过环境交互就能涌现出搜索扩展能力。对环境复杂度的消融实验表明，跳数比约束或比较更能驱动迁移：即使是最简单的规则生成环境，也是训练可泛化LLM智能体的令人惊讶的有效免费资源。

## Abstract
Training LLM agents with reinforcement learning (RL) is bottlenecked by environments, which must provide verifiable rewards, support long-horizon interaction, and scale cheaply. Existing approaches rely on costly human-curated data or on LLM-generated environments that risk hallucinations and benchmark contamination. We show that LLMs can instead be trained into capable search agents using synthetic environments generated entirely by rules, whose generation requires no LLM and has zero marginal cost. We build PhantomEnvironments, multi-turn RL environments from fictional worlds, where agents must search a corpus of templated articles to answer multi-hop questions. Despite sharing no facts with the real world, these strikingly simple environments yield agents that transfer to real-world multi-hop search benchmarks, often outperforming real-world training data on newer benchmarks. Trained agents generalize to unseen fictional universes, and Qwen models learn to scale their search budget roughly linearly with question difficulty, suggesting emergent search scaling from environment interaction alone. Ablating environment complexity reveals that hop count drives transfer more than constraints or comparisons: even the simplest rule-generated environments are a surprisingly effective, free resource for training generalizable LLM agents.

## 2. 论文提出的方法论

### 2.1 核心思想

- 基于 **PhantomWiki** 的规则生成思想，构建 **PhantomEnvironments**：由虚构人物及其关系（家庭、朋友、属性）组成的多轮检索环境。
- 智能体必须在模板化文章语料库中检索、分解问题、组合证据，最终回答多跳问题，从而学习**可泛化的搜索技能**（分解 → 检索 → 组合），而非记忆事实。

### 2.2 关键技术细节

- **环境生成**：使用上下文无关文法（CFG）采样关系链（最多 7 跳线性跳），每个采样问题编译为 Prolog 查询以获得ground-truth答案；问题可有多答案。
- **检索接口**：将模板化文章编码进 FAISS 索引，训练时使用 `intfloat/e5-base-v2` 稠密检索器，返回 top-3 文档，与真实搜索设置一致。
- **RL 训练**：
  - 采用 **GRPO**（Group Relative Policy Optimization），每个问题采样 8 条独立轨迹，仅在最终答案上计算 F1 奖励。
  - 模型输出 XML 标签：`<search>查询</search>` 执行检索，`<answer>答案</answer>` 结束轨迹。
  - 环境中返回的 `<information>...</information>` 部分在 GRPO 目标中被屏蔽，只更新策略生成 token。
  - 训练约 55K 个合成问题，1 个 epoch，2 个随机种子。
- **复杂度轴扩展**：
  - **Hops**：最多 7 跳线性关系链。
  - **Hops+Comparisons**：在纯跳问题上加入属性比较（如年龄比较）。
  - **Hops+Constraints**：在链中插入最多 3 个属性约束过滤器。
  - 三者均保持语料固定，训练集按难度分层平衡。

## 6. 论文的主要结论与发现

- **合成环境可迁移**：在 PhantomEnvironments 中 RL 微调可显著提升所有四款 LLM 在真实多跳搜索基准上的表现：
  - 旧基准平均提升 **1.7×**，新基准平均提升 **2.2×**。
  - Llama-3.2-3B-Instruct 在 SynthWorlds-SM 上提升 **7.1×**。
- **域内/域外差异**：
  - 真实 NQ+HotpotQA 训练在域内基准（Wikipedia 2018 相关）上胜过合成训练。
  - 在较新、域外基准（SynthWorlds、FRAMES）上，合成训练优于真实训练。
  - 合成训练可将 SynthWorlds 的知识优势（KA gap）降至 0%，表明消除了对记忆事实的捷径依赖。
- **搜索扩展行为涌现**：Qwen 系列模型在 RL 训练后学会根据问题跳数线性调节搜索调用次数；Llama-3.2-3B 部分出现该行为，Phi-4-mini 未出现。
- **未见环境泛化**：智能体在未见虚构宇宙上与训练宇宙表现相当，证明学到的是通用搜索技能而非记忆特定图谱。
- **复杂度轴作用**：
  - **线性跳数（Hops）是迁移的主要驱动力**。
  - Hops+Comparisons 能针对性提升真实比较类问题的表现。
  - Hops+Constraints 反而伤害迁移：智能体学会直接粘贴整句问题作为单一检索查询，跳过问题分解，利用罕见属性捷径。
- **规则生成环境是零边际成本、可验证、永不过时的训练资源**，与人工标注、LLM 生成环境互补。

## 7. 优点

- **低成本、高可扩展**：环境生成无需人类标注或 LLM，边际成本为零，可任意调节宇宙大小、跳数和问题预算。
- **严格可验证**：由 Prolog 查询保证答案正确，不存在幻觉奖励或基准污染风险。
- **系统化实验设计**：
  - 固定训练设置，仅改变环境来源，公平对比合成与真实数据。
  - 利用 SynthWorlds 镜像对定量分离“推理能力”与“知识记忆”。
  - 通过复杂度轴消融揭示迁移的关键因素，并发现约束捷径的反效果。
- **行为分析深入**：通过搜索调用次数、轨迹示例等，展示了智能体是在学习分解问题还是走捷径。
- **发现“搜索扩展”涌现现象**：为理解 RL 训练如何塑造智能体搜索行为提供了新视角。

## 8. 不足与局限

- **模型规模有限**：仅训练了 3B 和 7B 级别模型，未验证更大模型（如 32B、72B）上的效果。
- **评估场景受限**：基准主要基于 Wikipedia 检索，未覆盖开放网络搜索、长上下文任务（如 BrowseComp-Plus）。
- **训练不稳定问题**：部分真实数据训练和个别合成消融出现熵尖峰和训练退化，需人工选择最优检查点。

- **域内性能仍落后**：在与训练事实重叠的 Wikipedia 2018 基准上，真实数据训练仍占优。
- **环境组合尚需研究**：如何针对已知能力缺陷设计合成环境组合，文中仅提出开放方向，未给出系统配方。
- **参数知识轻微受损**：个别模型（如 Phi-4-mini）在 PopQA、Wiki-18 PPL 上有明显下降，说明 RL 微调可能对某些参数记忆造成影响。
