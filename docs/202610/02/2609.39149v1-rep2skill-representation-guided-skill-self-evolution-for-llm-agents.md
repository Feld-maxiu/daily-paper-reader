## 摘要
文本技能使基于大语言模型（LLM）的智能体能够在不更新模型参数的情况下积累可复用的程序性知识。然而，现有的技能演化仍主要局限于文本空间：优化器必须仅从长执行轨迹和稀疏任务结果中诊断成功与失败模式并修订技能。这种纯文本范式将智能体内部表征——其中包含其不断演化的执行状态的丰富记录——排除在技能优化循环之外。我们提出一个问题：智能体能否通过反思自身内部表征来改进其外部文本技能？我们引入了 Rep2Skill，一个表征引导的智能体技能自演化框架。具体来说，在收集到的智能体执行轨迹上，Rep2Skill 对其内部模型表征轨迹进行建模，以定位偏离成功执行动态的轮次，并进一步将这些信号与执行上下文一起解释为可操作的文本反馈，用于有针对性的技能修订。在两个智能体环境和两个开源 LLM 上的实验表明，在自演化设定下（同一个 LLM 同时充当执行器和优化器，且没有更强的外部模型），Rep2Skill 始终优于纯文本方法。这为将智能体自我改进推进到超越纯文本反思的方向奠定了有前景的基础。

## Abstract
Textual skills enable large language model (LLM) based agents to accumulate reusable procedural knowledge without updating model parameters. Yet existing skill evolution remains largely confined to the text space: an optimizer must diagnose success and failure patterns, and revise skills solely from long execution trajectories and sparse task outcomes. This text-only paradigm leaves the agent's internal representations, which contain rich records of its evolving execution state, outside the skill optimization loop. We ask whether an agent can improve its external textual skills by reflecting on its own internal representations. We introduce Rep2Skill, a representation-guided framework for self-evolution on agent skills. Specifically, upon the collected agent rollouts, Rep2Skill models their internal model representation trajectories to localize turns that deviate from successful execution dynamics, and it further interprets these signals alongside the execution contexts as actionable textual feedback for targeted skill revision. Experiments on two agent environments with two open-source LLMs show that Rep2Skill consistently outperforms text-only approaches in the self-evolution setting, where the same LLM serves as both executor and optimizer without a stronger external model. This establishes a promising direction moving agent self-improvement beyond text-only reflection.

## 2. 方法论

### 2.1 核心思想

- 在给定任务实例和当前文本技能下，对同一任务采样一组多个执行轨迹（group rollout）。
- 对每条轨迹提取**内部隐藏状态序列**，用成功轨迹训练的**神经受控微分方程（Neural CDE）** 建模成功执行动态。
- 计算每个轮次的**表征预测误差**作为**轮次级归因分数**，误差越大表示越偏离成功动态。
- 选择 Top-Kc 个关键轮次，让一个“分析器”（与智能体相同的 LLM）结合轨迹文本和当前技能，将表征信号**口头化**为可操作的文本反馈。
- 技能优化器利用该反馈进行**有界修订**，并通过验证集门控决定是否接受新技能。

### 2.2 关键流程

1. **分组采样**  
   对任务 \(x\) 和当前技能 \(s_n\)，采样 \(K\) 条轨迹：
   \[
   G(x, s_n) = \{\tau^{(k)} \sim \pi_\theta(\cdot | x, s_n)\}_{k=1}^{K}
   \]
   组内轨迹共享任务和技能，但执行路径多样，为相对比较提供受控参考。

2. **表征轨迹提取与降维**  
   从冻结智能体的固定层（如第 24 层）提取每个轮次的隐藏状态 \(h_t^{(k)}\)，并对所有 token 的隐藏状态取平均。  
   使用 PCA 将高维隐藏状态投影到 64 维潜空间，投影统计量只用成功训练轨迹拟合。

3. **轮次级归因**  
   用 Neural CDE 对潜轨迹建模。给定前 \(t-1\) 轮表征历史，预测下一轮表征 \(\hat{h}_t^{(k)}\)。  
   归因分数：
   \[
   c_t^{(k)} = \| h_t^{(k)} - \hat{h}_t^{(k)} \|_2^2
   \]
   分数越大，表示该轮次偏离成功执行动态的程度越高。  
   选择分数最高的 \(K_c=3\) 个轮次作为“关键轮次”。

4. **表征到文本的口头化**  
   将关键轮次及其分数、完整轨迹、当前技能和任务描述输入分析器 \(M_a\)，生成结构化文本反馈 \(F^{(k)}\)。  
   反馈形式包括诊断类型（如 `suspect_rule`、`rule_conflict`、`execution_deviation`、`missing_rule`、`insufficient_evidence`）、相关技能规则引用、轨迹证据、反证、适用条件和修改假设。  
   程序化校验确保反馈中的技能引用和轨迹引用是原文精确子串，未通过校验的反馈被丢弃。

5. **技能修订与验证门控**  
   技能优化器 \(O\) 根据分组轨迹和反馈生成候选技能：
   \[
   s_{n+1} = O(s_n, \{\tau^{(k)}, F^{(k)}\}_{k=1}^{K})
   \]
   候选技能在验证集上评估，只有严格优于当前技能才被接受，否则保留原技能。

### 2.3 训练与推断

- **轨迹模型训练**：只使用成功轨迹，数据量约 50 条/数据集，来自与演化任务不重叠的训练任务。  
- **训练目标**：最小化单步潜状态预测误差：
  \[
  \frac{1}{T_k-1}\sum_{t=2}^{T_k} \|z_t^{(k)} - \hat{z}_t^{(k)}\|_2^2
  \]
- **优化器**：AdamW，学习率 \(10^{-4}\)，权重衰减 \(10^{-5}\)，batch size 32，最多 300 轮，早停 20 轮。  
- **推断**：在线评分时，投影和轨迹模型保持冻结，只计算预测误差作为归因分数。

## 6. 主要结论与发现

- **下游性能提升（RQ1）**：Rep2Skill 在两个基准和两个模型上均取得最佳平均性能。例如 ALFWorld 上，Qwen3-4B 成功率 52.24% 比最强文本基线高 4.98 个百分点；Qwen3.5-9B 成功率 69.90% 比最强基线高 7.77 个百分点。WebShop 上也有明显提升。  
- **演化可靠性提升**：在自演化设置下，纯文本方法有时会退化（如 SkillOpt 在 WebShop Qwen3-4B 上低于 No Skill），而 Rep2Skill 均相对 No Skill 有正增益，说明表征引导能提供更稳健的更新方向，尤其在优化器能力有限时。  
- **表征信号有助于细粒度归因（RQ2）**：单独使用表征分数时 AUROC 为 0.592，纯文本为 0.494，而文本+表征引导达到 0.838 AUROC、0.876 AUPRC、88.22% Precision@Top-3，说明表征信号与轨迹文本结合能大幅提升错误轮次定位能力。  
- **多样性分析（RQ3）**：同一任务和技能下的 rollouts 在文本和表征空间都高度发散（第 5 轮动作分歧 82.7%，第 10 轮唯一前缀 98.5%），为分组采样和相对比较提供了必要性证据。  
- **消融结论**：移除表征口头化、表征分析器、分组证据都会降低成功率，说明三个成分——分组比较、表征归因、语义解释——都对最终性能有贡献。  
- **定性结论**：表征归因能精确定位“重复搜索橱柜”等具体失败模式，并生成针对性的技能修订（如“如果橱柜找不到目标，检查台面、抽屉或水槽”），而纯文本优化器只能给出泛泛的“更彻底搜索”建议，导致复用失败。

## 7. 优点

- **新颖视角**：首次将模型内部表征纳入文本技能演化，突破纯文本反思范式。  
- **方法设计合理**：分组采样利用同任务、同技能下的行为多样性进行相对比较；Neural CDE 有效建模成功动态；表征分数与文本上下文结合，生成可验证的、可操作的结构化反馈。  
- **实验一致性**：在两个模型、两个环境中均优于基线，且消融实验和归因分析共同支撑结论，不是单一指标或偶然结果。  
- **可解释性**：通过口头化将隐式表征信号转化为显式文本反馈，使表征引导的过程可审计、可检查，增强可信度。  
- **自演化友好**：不依赖更强外部模型，仅用自身表征和文本即可提升技能，符合真实应用场景。  
- **验证门控机制**：防止无效或退化修订，提高演化稳定性。
