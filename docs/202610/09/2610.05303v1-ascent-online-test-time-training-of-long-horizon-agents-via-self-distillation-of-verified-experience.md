## 摘要
大语言模型（LLM）智能体通过多轮推理-行动回合来解决长程任务，并在终止时获得一个验证信号。部署后的智能体会面对一系列相关任务流，因此其执行轨迹成为改进的天然资源。基于上下文适应的智能体将反思、记忆或技能存储为文本，因此其重用依赖于检索到正确经验，并依赖冻结策略来执行该经验。我们研究在线智能体测试时训练（OaTTT），即在部署期间利用智能体自身的执行轨迹来训练 LLM 的权重。智能体对任务流中的每个任务仅执行一次，执行轨迹及其验证结果是跨任务持续更新权重的唯一学习信号。直接模仿或强化单次尝试所生成的 token 会破坏策略的稳定性。我们提出 ASCENT（Agentic Self-distillation for Cross-task EvolutioN at Test-time，测试时跨任务演进的智能体自蒸馏），它改为对已验证经验进行自蒸馏。LLM 的一个稳定版本，即其冻结的初始副本，将已验证轨迹作为特权信息，并基于此后见之明预测沿轨迹的下一个 token 分布。将其蒸馏到持久 LoRA 快速权重中，可在没有外部参考解或更强教师的情况下为后续任务更新智能体。通过进一步移除无效行动回合，ASCENT 蒸馏出增强的特权经验，以实现更高效的执行。我们刻画了其总体目标以及稀疏结果选择的局限性。在 ALFWorld、WebShop 和 AppWorld 上以及不同模型规模下，随着经验积累，ASCENT 提高了任务成功率和交互效率，优于在线适应方法，并能迁移到留出场景，表明智能体可以将已验证经验整合到其权重中，而无需单独的训练阶段或记忆检索。项目页面：https://artificer-ai-lab.github.io/ASCENT

## Abstract
A large language model (LLM) agent solves long-horizon tasks through many reasoning-action turns, with one verification signal at termination. Deployed agents face streams of related tasks, making their trajectories a natural resource for improvement. In-context adaptation agents store reflections, memories, or skills as text, so reuse depends on retrieving the right experience and on a frozen policy executing it. We study Online Agentic Test-Time Training (OaTTT), which trains the LLM's weights on its own execution trajectories during deployment. The agent executes each task once, in one pass over the stream, and the executed trajectory with its verification result is the only learning signal for weight updates that persist across tasks. Directly imitating or reinforcing the generated tokens of this single attempt destabilizes the policy. We introduce ASCENT (Agentic Self-distillation for Cross-task EvolutioN at Test-time), which instead self-distills verified experience. A stable version of the LLM, its frozen initial copy, receives the verified trajectory as privileged information and predicts next-token distributions along it with this hindsight. Distilling them into persistent LoRA fast weights updates the agent for later tasks, without an external reference solution or stronger teacher. By further removing invalid-action turns, ASCENT distills enhanced privileged experience for more efficient execution. We characterize its population target and the limits of sparse outcome selection. Across ALFWorld, WebShop, and AppWorld at varied model scales, ASCENT improves task success and interaction efficiency as experience accumulates, outperforms online adaptation methods, and transfers to held-out scenes, showing that an agent can consolidate verified experience into its weights without a separate training phase or memory retrieval. Project page: https://artificer-ai-lab.github.io/ASCENT

- 本文研究**长程 LLM 智能体在部署后的持续改进问题**。这类智能体通过多轮“推理—行动”与环境交互完成任务，通常只在任务结束时获得一个稀疏的验证信号（成功/失败）。
- 部署中的智能体会遇到一系列相关任务，其自身的执行轨迹是宝贵的改进资源。但现有**上下文内适应（in-context adaptation）**方法只是在 harness 层面存储反思、记忆或技能，模型权重保持冻结，性能受限于：
  - 能否检索到合适的经验；
  - 冻结策略能否在长程交互中可靠执行这些经验。
- 因此，论文提出并研究**在线智能体测试时训练（OaTTT）**：在部署期间，智能体对任务流中的每个任务**只尝试一次**，用本次执行轨迹及其验证结果作为**唯一的、跨任务持续更新模型权重**的学习信号。
- 论文发现，直接模仿或强化这些单次尝试生成的 token 会**破坏策略稳定性**：策略漂移、有效动作率下降、任务成功率低于基座模型。
- 为此提出 **ASCENT**，核心思想是**对已验证经验进行自蒸馏**，将验证成功轨迹中的后见之明（hindsight）通过冻结的初始模型蒸馏到持久 LoRA 快速权重中，实现稳定、无需外部教师或重放缓冲的在线演化。

## 2. 方法论

### 2.1 OaTTT 协议

- 任务以单遍流形式到达：\(X_{1:N} = (x_1,\dots,x_N)\)。
- 对每个任务 \(x_i\)，当前策略 \(\pi_i\) 只进行一次尝试，得到轨迹 \(\tau_i \sim P_{\pi_i,E}(\cdot|x_i)\) 和稀疏验证结果 \(v_i = V(x_i,\tau_i)\in\{0,1\}\)。
- 然后执行演化更新：\((\theta_{i+1}, M_{i+1}) = \text{Evolve}(\theta_i, M_i; x_i,\tau_i,v_i)\)，其中 \(M_i\) 是可选记忆，\(\theta_i\) 是策略参数。
- 遵循预序（prequential）在线协议：每个任务结果在本次轨迹影响策略之前被记录；成功判定可以比学习门控 \(v_i\) 更严格。
- 没有重试、没有重放缓冲区，更新只来自当前这一条轨迹。

### 2.2 直接模仿与强化的不稳定性

论文构造了五种直观基线（用于对照研究）：

1. **Online ungated imitation**：对所有轨迹（包括失败）直接模仿。
2. **Online RFT**：只模仿验证成功的轨迹。
3. **Online RFT+KL**：在 RFT 基础上加入对冻结基座模型的 KL 正则。
4. **Online REINFORCE**：使用跨任务运行均值作为 baseline 的单次策略梯度。
5. **Online REINFORCE++**：采用运行归一化 token advantage 和裁剪代理目标。

这些方法的共同问题：只对**智能体实际生成的 token** 做硬目标匹配，更新会围绕自身输出锐化，容易过拟合单条轨迹、策略漂移、有效动作率下降，最终成功率低于未训练基座。

### 2.3 ASCENT 核心方法

ASCENT 采用**在线策略自蒸馏**，主要步骤如下：

- **教师与特权信息**：
  - 教师是**冻结的初始模型 \(p_{\theta_0}\)**。
  - 对于通过验证的轨迹，构造特权信息 \(z_i\)：默认包含任务目标、成功声明、以及**有效回合的推理—行动响应**（去掉无效行动回合）。
  - 教师基于 \(z_i\) 和学生前缀 \(c_{i,t,j}\) 计算下一 token 分布：
    \[
    q_{i,t,j}(\cdot) = \text{stopgrad}[p_{\theta_0}(\cdot|z_i \oplus c_{i,t,j})]
    \]
  - 学生分布为：
    \[
    p_{\phi}^{i,t,j}(\cdot) = p_{\theta_0,\phi}(\cdot|c_{i,t,j})
    \]
    其中 \(\phi\) 为 LoRA 快速权重。

- **蒸馏目标**：
  - 对每个有非空响应的回合 \(t\)、每个 token 位置 \(j\)，最小化教师分布与学生分布之间的**前向 KL**：
    \[
    L_i^{\text{ASCENT}}(\phi) =
    \sum_{t\in I_i}\sum_{j=1}^{L_{i,t}}
    \alpha_{i,t,j}\, D_{KL}(q_{i,t,j} \,\|\, p_{\phi}^{i,t,j})
    \]
  - \(\alpha_{i,t,j}\) 先在回合内对 token 平均，再跨回合平均。
  - 与直接模仿相比，ASCENT 做**全词表分布匹配**：不仅提高生成 token 的概率，还会提升教师偏好的其他 token，降低教师不认可的 token。

- **更新门控**：
  - 仅当 \(v_i=1\) 时更新 LoRA 快速权重；否则跳过本次更新。
  - 每个验证成功的回合后，从当前 \(\phi_i\) 开始进行少量优化步（论文中为 2 步）。

- **无效行动过滤**：
  - 根据环境执行情况定义有效性指标 \(d_{i,t}\)：环境成功解析并执行动作则为 1，否则为 0。
  - 在构造教师特权信息时只保留 \(d_{i,t}=1\) 的回合；学生前缀仍包含所有非空响应（包括无效回合），因此训练覆盖更广，但教师信息更干净。

- **理论刻画**：
  - 验证选择等价于对完整轨迹的**拒绝采样**：\(P^+_\pi(\tau|x) = R(\tau)P_\pi(\tau|x)/J_x(\pi)\)。
  - 前向 KL 的总体目标可分解为不可约项 + 对**平均教师分布** \(\bar{q}(\cdot|c)\) 的 KL，非受限最优解会匹配该平均分布。
  - 论文指出：稀疏结果选择**不能识别因果学分**，也不自动偏好更短路径；效率提升需通过实验验证。

## 6. 主要结论与发现

- **ASCENT 稳定提升任务成功率**：
  - ALFWorld seen：4B 模型从 Base 46.4% 提升到 ASCENT 69.5%；9B 模型从 55.0% 提升到 77.4%。
  - WebShop：4B 严格成功率从 17.8% 提升到 41.9%；9B 从 17.2% 提升到 41.5%；平均分数也显著提高。
  - 在多个任务族中改善明显，尤其是基座几乎不成功的 Heat、Cool 等困难任务。
- **ASCENT 优于在线和离线基线**：
  - 在 ALFWorld、WebShop 上超过最强的在线上下文适应和离线方法。
  - 明显优于 TT-OPSD，证明**完整已验证轨迹的后见之明**比局部回合特权信息更重要。
- **交互效率提升**：
  - ASCENT 在 ALFWorld 和 WebShop 上都有最低的平均回合数。
  - 在“基座和 ASCENT 都解决的任务”上，ASCENT 仍使用更少回合（4B 约 63.8%、9B 约 67.3% 的任务更短），说明不是仅由成功率构成变化导致。
- **跨场景迁移与继续学习**：
  - 在 ALFWorld unseen 上，冻结迁移时 ASCENT 领先（4B 62.7%、9B 88.8%），继续 OaTTT 还可进一步获益（4B 78.6%、9B 90.0%）。
- **直接模仿/强化不稳定**：
  - 五种直接更新基线在流式更新中策略熵下降、KL 漂移、有效动作率下降，最终成功率低于 Base。
- **特权信息消融发现**：
  - **推理（reasoning）是最关键组件**；仅动作后见之明效果接近或低于 Base。
  - 较小模型（4B）更受益于较短、经过滤的特权信息；较大模型（9B）对完整轨迹容忍度更高，但过滤仍提升有效动作率。
- **蒸馏散度**：前向 KL 总体最稳健；反向 KL 和 JS 也有一定效果，但在 9B 上表现不稳定。
- **教师应保持冻结**：EMA 或快照演化的教师会形成“学生漂移 → 教师漂移 → 更强漂移”的反馈回路，且无净收益。
- **上下文与参数协同演化**：ASCENT 与 MemP、ACE 等上下文方法可互补，尤其在 9B 上组合效果更好；4B 上单纯 ASCENT 可能更好，额外的检索上下文可能分散弱模型注意力。

## 7. 优点

- **问题新颖且定义清晰**：明确提出 OaTTT 协议，统一考察“单次尝试、单遍流、稀疏验证、跨任务持久更新”约束。
- **方法简洁有效**：
  - 用冻结初始模型作教师，避免教师与学生共同漂移。
  - 使用前向 KL 做全词表分布匹配，而不是硬目标模仿，提升更新稳定性。
  - 利用环境已有信号（无效动作）进行轨迹过滤，无需额外学分或奖励。
- **经验选择的合理性**：通过验证结果实现拒绝采样，仅用成功轨迹，且不需要价值模型或 critic。
- **实验对比充分、公平**：包含多种离线/在线上下文和参数基线，统一协议和配置，多次运行报告标准差。
- **分析深入**：
  - 图 1 清楚展示直接更新基线的崩溃模式。
  - 特权信息、散度、教师演化、共享成功回合效率分析等都提供了机制性理解。
  - 案例研究直观展示 ASCENT 与上下文适应的差异。
- **实用性强**：方法只在验证成功时进行少量 LoRA 更新，计算开销可控；无需重放缓冲区或大规模离线训练。
