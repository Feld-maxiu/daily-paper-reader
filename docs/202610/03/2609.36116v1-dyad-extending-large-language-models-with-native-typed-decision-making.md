## 摘要
我们研究如何通过用原生类型化决策扩展大语言模型（LLM）来构建能力更强的通用智能体。我们提出了 Dyad，一种架构，它通过一个以环境为条件的动作编码器来增强预训练 LLM，该编码器并行地嵌入每个候选动作描述，然后将这些嵌入与 LLM 的内部状态进行评分，从而得到类型化动作上的分布。通过将决策分解为不断演化的交互状态表示和特定于环境的动作语义表示，Dyad 引入了一种归纳偏置，用于学习可复用表示，同时在动作空间增长时仍能保持动作评分高效。我们研究了由环境交互驱动的两种互补强化学习设置。在冻结 LLM 的情况下，仅训练动作编码器就能在四个未见环境中取得一致提升，从而无需修改任何 LLM 参数即可实现模块化适应。联合优化两个组件在多种交互任务和模型规模上均优于传统 RL 后训练，包括在 ALFWorld 上使用 9B 模型时平均绝对提升 3.80%，同时改善通用知识、推理和编程能力。

## Abstract
We study how to build more capable general-purpose agents by extending large language models (LLMs) with native typed decision-making. We introduce Dyad, an architecture that augments a pretrained LLM with an environment-conditioned action encoder that embeds each candidate action description in parallel, then scores these embeddings against the LLM's internal state to yield a distribution over typed actions. By factorizing decision-making into representations of the evolving interaction state and environment-specific action semantics, Dyad introduces an inductive bias for learning reusable representations while keeping action scoring efficient even as the action space grows. We investigate two complementary reinforcement learning settings driven by environment interaction. With the LLM frozen, training the action encoder alone achieves consistent gains across four unseen environments, enabling modular adaptation without modifying any LLM parameters. Jointly optimizing both components outperforms conventional RL post-training across diverse interactive tasks and model scales, including a 3.80% average absolute gain on ALFWorld with a 9B model, while improving general knowledge, reasoning, and coding.

## 1. 核心问题与整体含义

- **研究背景**：大语言模型（LLM）驱动的智能体通常通过自回归文本生成来同时完成“推理”和“动作选择”。这种设计把动作选择强行塞进语言模型的词表预测任务，模型只能逐 token 生成动作文本，而不是直接对环境中可选的动作集合打分。
- **问题定位**：现有的专用 System 1 决策模型（如 Jev、Laya 等）虽然能够直接输出类型化动作分布，但它们通常与语言推理能力相互独立，或只支持固定、预先定义的动作空间，难以泛化到动态变化、未见过的环境中。
- **研究动机**：能否让预训练 LLM 原生支持动态动作空间上的类型化决策，同时保留其语言推理能力？本文认为，语言推理（System 2）和类型化决策（System 1）可以统一在同一个策略中。
- **整体含义**：Dyad 提出了一种将“交互状态表示”和“环境条件动作表示”分解的架构，使同一个 LLM 既能生成语言 token，又能直接对当前可用动作集合输出决策分布，从而支持动态动作空间、模块化适应和更高效的决策评分。

## 2. 方法论

- **核心思想**：将类型化决策分解为两个独立计算的表示：
  - 由预训练 LLM 的 transformer backbone 计算交互状态表示 \(q_t\)。
  - 由独立动作编码器 \(g\) 计算环境条件动作表示 \(z_a\)。
  - 动作选择时，将二者点积后经 softmax 得到动作概率分布。
- **架构细节**：
  - 输入拼接：环境描述 \(\text{desc}(e)\) 与语言历史 \(h_t\) 拼接后输入 LLM backbone，得到状态表示 \(q_t\)。
  - 动作编码：对每个候选动作 \(a \in A_t\)，将环境描述与动作描述拼接后输入动作编码器 \(g\)，得到 \(z_a\)。
  - 语言生成：保留原始语言建模头，以 \(q_t\) 生成词汇表上的分布，支持正常文本推理。
  - 动作决策：当模型生成专用交互 token \(v_{\text{act}}\) 时，构建动作评分矩阵 \(Z_t\)（由所有 \(z_a\) 组成），通过 \(Z_t q_t\) 计算当前动作集合上的分布，直接选择可执行动作。
- **关键性质**：
  - **状态-动作解耦**：动作表示只依赖环境和动作描述，不依赖当前交互状态，因此可在动作集合不变时缓存复用。
  - **动态动作空间**：新出现的动作只需首次遇到时编码，之后即可复用，支持未见动作空间。
  - **排列等变性**：对候选动作重新排序只会相应重排概率，不改变决策本质。
- **初始化流程**：
  - 合成一组动作选择示例 \(D = \{(h_i, e_i, A_i, a^\star_i)\}\)。
  - 使用教师 LLM（如 GPT-5.5）生成支持选择目标动作的任务上下文和推理文本。
  - 冻结 LLM、语言建模头和动作编码器 backbone，仅训练投影器，最小化目标动作的交叉熵损失，以对齐两个表示空间。
- **强化学习训练**：
  - 使用 GRPO 或 GiGPO，以任务结果奖励为信号。
  - 策略梯度同时覆盖采样的语言 token 和类型化动作；语言 token 使用语言策略分布，动作使用动作策略分布。
  - 支持两种训练模式：
    1. **联合优化**：同时更新 LLM 和整个动作编码器。
    2. **冻结 LLM 适应**：仅更新动作编码器（含 backbone 和投影器），不修改预训练 LLM 参数。
