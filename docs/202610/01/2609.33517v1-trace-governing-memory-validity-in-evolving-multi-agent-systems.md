## 摘要
持久记忆使语言模型智能体能够在长期协作中携带信息，但也留下一个生命周期问题：一旦共享状态发生变化，返回的智能体还可以依据什么继续行动？一条记忆可能被正确检索、与当前任务相关且忠于其来源，但仍不可用于行动：暂停前保存的行程仍写着团队后来已更换的酒店。我们将此形式化为时序记忆准入，并提出 TRACE，一个免训练层，它将重新进入视为资格判定而非存储或检索操作，依据缺席期间的更新来协调离开检查点，解决显式与隐式失效，并且仅当返回视图覆盖返回角色的未完成义务时才释放有界的返回视图。我们在三种智能体模型上、在 Memora、STALE Type II 以及衍生的 ManBench-Return 设置中评估 TRACE，每个设置都被重构为返回情节：一个智能体离开，四个队友改变共享状态，然后该智能体重新加入。区分方法的关键不是总体准确率，而是能否同时保留有效记忆并拒绝陈旧记忆；没有任何单策略基线能做到这一点：Restore（完整恢复离开检查点）会接纳陈旧状态，Reset（从空记忆开始返回）会丢弃有效状态，二者各在其中一个指标上跌至 0%。TRACE 是唯一在两方面都表现良好的方法，在 ManBench-Return 上达到 92.6–98.3% 的有效信息可用率以及 98.4–99.5% 的无效信息拒绝率，与最佳基线的总体准确率相差在 3.8 个百分点以内。在 STALE Type II 上，TRACE 的 Overall 相比最强对比策略分别提高 22.3（Qwen）、18.5（Gemini）和 27.5（DeepSeek）个百分点，而 token 成本约为它们的 2.3 倍；一种写入时整合流水线准确率更高，但 token 成本是 TRACE 的 3.99 倍。

## Abstract
Persistent memory lets language-model agents carry information across long-running collaborations, but leaves a lifecycle question open: what may a returning agent still act on once the shared state has changed? A memory can be correctly retrieved, relevant to the current task, and faithful to its source, and nonetheless be inadmissible for action: an itinerary saved before a pause still names the hotel the team has since replaced. We formalize this as temporal memory admission and present TRACE, a training-free layer that treats re-entry as an eligibility decision rather than a storage or retrieval operation, reconciling a departure checkpoint against absence-period updates, resolving explicit and implicit invalidation, and releasing a bounded Return View only when it covers the returning role's open obligations. We evaluate TRACE under three actor models on Memora, STALE Type II, and a derived ManBench-Return setting, each recast as return episodes: one agent departs, four teammates change the shared state, and the agent rejoins. What separates methods is not overall accuracy but whether one can retain valid memory and reject stale memory at once, and no single-policy baseline can: Restore (reinstate the departure checkpoint in full) admits stale state, Reset (start the return from an empty memory) discards valid state, each bottoming out at 0% on one of the two. TRACE is the only method high on both, reaching 92.6-98.3% valid-information availability with 98.4-99.5% invalid-information rejection on ManBench-Return, within 3.8 points of the best baseline's overall accuracy. On STALE Type II it improves Overall over the strongest comparison policy by 22.3 (Qwen), 18.5 (Gemini), and 27.5 (DeepSeek) points at roughly 2.3 times their tokens, while a write-time consolidation pipeline is more accurate still at 3.99 times TRACE's.

# TRACE 论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：长期运行的多智能体系统（MAS）中，智能体会暂停、被重新分配并重新加入一个已被其他成员继续改变的共享工作区。
- **核心问题**：持久记忆虽然可被正确检索、与当前任务相关且忠于来源，但在共享状态变化后，该记忆**未必仍可用于行动**。例如，离开前保存的行程仍写着已被团队更换的酒店。
- **形式化定义**：论文将这一检查形式化为“**时序记忆准入**（temporal memory admission）”：返回智能体依据当前状态、身份、任务目的和未完成义务，重新评估保留记忆是否可行动。
- **关键区分**：记忆的**历史正确性**与**查询相关性**，不等于**当前可行动性**。离开前的记录可能已因显式或隐式状态变化而失效。
- **整体含义**：多智能体系统的记忆治理应把“重新进入”视为一个**资格判定边界**，而不是简单的存储、检索或无条件的恢复/清空。

## 2. 论文提出的方法论

- **核心思想**：TRACE 是一个**免训练层**，位于记忆后端与智能体之间，在返回边界上执行有界、可审计的准入决策。
- **四个主要阶段**（如图 2 所示）：
  1. **捕获返回周期检查点（Capture）**：离开时记录检查点 \(D_a\)；返回时将其与缺席期间增量 \(\Delta\) 合并，得到单一不可变的后缺席检查点 \(C = D_a \oplus \Delta\)。候选池包含验证事实、进度前沿、开放义务及角色/接口约束。
  2. **解决显式与隐式失效（Resolve）**：
     - 显式失效：撤销、替换边、封闭有效期或同身份更新，可直接机器处理。
     - 隐式失效（II）：后期事件改变了某记忆当前使用所依赖的前提，但未直接否定该记忆。TRACE 采用“高召回扫描 + 有根据的验证器”两阶段：先提出可能的事件-记忆依赖对，再由验证器基于检查点证据判断是否确实失效。
  3. **验证条目资格（Validate）**：每个候选条目须通过四个门：
     - \(A\)：授权（principal、role、scope）；
     - \(T\)：新鲜度（epoch、validity、supersession）；
     - \(U\)：适用性（task、purpose、item kind）；
     - \(P\)：来源（receipt-bound references）。
     - 资格集合定义为 \(E=\{m \in P: A(m) \land T(m) \land U(m) \land P(m)\}\)。
  4. **覆盖义务（Cover Obligations）**：构建义务-依赖图 \(G_O\)，先从开放义务和进度前沿中强制纳入必要项，再以贪婪方式选择低披露成本且覆盖未满足依赖的条目。目标近似为在条目数预算 \(B_n\) 和字符预算 \(B_c\) 约束下，使覆盖度 \(Cov(S) \ge \gamma\)、关键依赖覆盖 \(Crit(S) \ge \rho\)。若覆盖不足，返回被重置或阻止，而不是静默发出不完整视图。
  5. **签名与再准入（Sign & Readmit）**：将选中集序列化为携带返回周期标识、身份、角色、任务、epoch、过期时间、条目摘要和覆盖报告的签名 Return View；私有经验只有在所绑定的工作状态项仍存在于视图内时才能被再准入。

- **关键特性**：
  - 采用属性基访问控制（ABAC）与来源记录（PROV）分离授权和溯源。
  - “功能遗忘”：被拒绝的状态可留在审计存储中，但不能作为返回工作负载的前提。
  - 私有记忆若不与已准入工作项绑定，就无法通过私有记忆检索路径重新进入。

## 6. 论文的主要结论与发现

- **双重保留与拒绝**：TRACE 是唯一能在保留有效记忆的同时拒绝陈旧记忆的方法；单策略基线无法同时做到：Restore 接纳陈旧状态，Reset 丢弃有效状态，它们在各自失败方向上可低至 0%。
- **ManBench-Return**：TRACE 达到 **92.6–98.3% VIA** 和 **98.4–99.5% IIR**，总体准确率与最佳基线差距在 **3.8 个百分点**以内。
- **STALE Type II**：TRACE 相比最强对比策略，Overall 提升 **22.3（Qwen）、18.5（Gemini）、27.5（DeepSeek）** 个百分点；Qwen 的 Lifecycle Success 从 18.0% 提升到 39.0%。
- **Memora（显式更新）**：TRACE 没有一致优势，表明当显式替换信息已可用时，普通存储语义已足够，返回时准入层的收益有限。
- **消融结论**：移除隐式失效（II）导致最大性能下降；义务感知选择（OAS）、完整视图门（CVG）和源绑定私有再准入（SBPR）都对最终表现有贡献，证明准入机制的各部分各有作用。
- **成本权衡**：TRACE 以约 2.3 倍 token 成本换取联合保留与拒绝能力；CUPMem 写时整合更准确，但 token 成本是 TRACE 的 3.99 倍。
- **稳定性**：团队规模从 4 到 32 活跃智能体变化时，TRACE 的指标波动很小；四个后端集成均可行，但 VIA 略有下降、IIR 上升，FAMA 变化混合。

## 7. 优点

- **问题定义清晰且新颖**：第一次在多智能体场景中明确区分记忆的历史正确性、查询相关性与当前可行动性，将“返回”形式化为资格判定边界。
- **方法论系统完整**：将授权、时间有效性、适用性、来源证明与义务覆盖结合在一个免训练层中，形成可审计、可签名、有界且有覆盖保障的返回视图。
- **可解释性与审计性**：独立的四个门产生理由编码的审计轨迹；Return View 带签名、摘要、覆盖报告和过期时间，便于追踪；功能遗忘不删除存储，从边界上限制使用。
- **公平的实验设计**：统一协议、闭卷评估、分离记忆上下文、失败情节保留在分母中，有助于客观比较。
- **多维评估**：覆盖显式、隐式、传播失效；三种模型、三类基准、三种离开点；同时报告 VIA/IIR/LS/RSR，而不仅看总体准确率。
- **成本透明**：明确 token 成本权衡，并进行消融、规模和后端可移植性研究，展示适用边界。

## 8. 不足与局限

- **强假设前提**：假设可信的返回身份、保存的离开检查点和源收据；未评估任意记忆投毒或伪造证据的对抗环境。
- **隐式失效依赖扫描与验证质量**：漏判依赖会接纳陈旧状态，过宽检查会丢弃有用上下文；附录 C.8 给出了漏判和过度弃权的案例。
- **性能随缺席时长下降**：在 STALE 子集中，TRACE 的 Overall 从 Early 的 73.33% 降到 Late 的 43.33%，token 同时上升。
- **算力与延迟信息缺失**：未披露 GPU 型号/数量、训练/推理时长、峰值上下文、重试成本；仅报告 token 总量，无法完全比较计算开销。
- **基准与协议限制**：ManBench-Return 是派生设置；规模研究是诊断性而非证明增益随团队规模单调增长；后端研究只验证接口可移植性，不比较后端质量。
- **部分结果缺失**：MemStrata 和 MemTX 在 STALE 分桶表因数据不一致未报告，可能影响细粒度比较。
- **成本仍较高**：TRACE 并非最优准确率，尤其在 STALE 上 CUPMem 更准确（但更贵）；在 Memora 上无一致收益。
- **应用边界**：只适用于有明确返回事件、角色/义务可表达式且有来源绑定的系统；对开放式任务、不确定性验证器和更长缺席间隔仍需进一步研究。
