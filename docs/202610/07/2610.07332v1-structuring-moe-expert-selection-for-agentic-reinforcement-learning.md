## 摘要
长程 LLM 智能体通常采用稀疏混合专家（MoE）模型实现，但智能体行为与 MoE 结构的协同设计仍未得到充分探索。本文全面研究了智能体后训练与 MoE 专家选择之间的关联。在现成的 MoE 模型中，我们观察到专家选择呈现出一种专门化结构，与智能体轨迹自然对齐。具体而言，与执行不同操作的轮次之间相比，智能体执行语义相似操作（如 READ、UPDATE）的轮次之间，专家路由重叠程度更高。然而，标准强化学习算法忽视这种专门化，导致 MoE 路由在训练过程中不受控制，经验上限制了任务性能和推理效率。为此，我们引入了一个面向智能体任务的分层路由控制框架。我们显式鼓励轮次级专家选择与智能体操作对齐，同时对 token 级专家选择进行正则化以保持局部一致性。为解决所提方法在后训练期间出现的稳定性问题，我们进一步引入熵门控控制机制。总体而言，我们的路由控制框架在所有评估基准上的成功率均实现了超过 10 个百分点的提升。这些结果表明，智能体轨迹结构为强化学习后训练期间优化 MoE 容量提供了有效信号。

## Abstract
Long-horizon LLM agents are frequently implemented using sparse mixture-of-experts (MoE) models, yet the co-design of agentic behavior and MoE structures remains underexplored. In this work, we comprehensively study the connections between agentic post-training and MoE expert selection. In off-the-shelf MoE models, we observe expert selection exhibits a specialized structure that naturally aligns with agentic trajectories. Specifically, expert routing overlaps more between turns where the agent performs semantically similar operations (e.g., READ, UPDATE) than between turns with differing operations. However, standard RL algorithms ignore this specialization, allowing the MoE routing to go uncontrolled during training, which empirically limit task performance and inference efficiency. To address this, we introduce a hierarchical routing control framework for agentic tasks. We explicitly encourage turn-level expert selections to align with agentic operations while regularizing token-level expert selections to maintain local consistency. To resolve stability issues that arise during post-training with the proposed methods, we further introduce an entropy-gated control mechanism. Overall, our routing control framework achieves over 10-point improvements in success rate on all evaluated benchmarks. These results demonstrate that agentic trajectory structure provides an effective signal for optimizing MoE capacity during RL post-training.

# 论文总结：面向智能体强化学习的 MoE 专家选择结构化

## 1. 论文的核心问题与整体含义

- **研究背景**：长程 LLM 智能体通常以稀疏混合专家（MoE）模型作为底座，以高效扩展模型容量。但现有工作很少将“智能体行为结构”与“MoE 专家选择”进行协同设计。
- **观察到的现象**：在现成的 MoE 模型中，专家路由已表现出一定的结构化特征：
  - 执行语义相似操作的轮次（如 READ、UPDATE）之间，专家路由分布重叠更高；
  - 同一 turn 内、同一 thinking 或 tool-use field 内的相邻 token，专家集合重叠程度也更高。
- **核心问题**：标准强化学习（RL）后训练只优化任务奖励，不会显式保持或强化上述路由结构，导致 MoE 路由在训练中不受控地漂移，最终限制任务性能和推理效率。
- **整体含义**：将智能体轨迹中的操作语义作为监督信号，结构化组织 MoE 专家选择，可以同时提升智能体任务成功率、训练稳定性和推理吞吐量。

## 2. 论文提出的方法论

该方法称为**分层路由控制框架**，由三部分组成，不需要改变 MoE 架构，可兼容 PPO、GRPO、LOOP、GiGPO 等多种策略梯度算法。

### 2.1 Turn 级操作感知控制

- **思想**：最大化 turn 级专家选择分布与操作标签（如 READ、CREATE、UPDATE）之间的互信息（MI）。
- **具体形式**：
  - 对每个 turn 的 thinking / tool-use field，先对 token 级路由概率取平均，得到 turn 级专家分布 \(q_i(e)\)；
  - 为每个操作 \(o\) 构造二元标签 \(y_i^o\)，估计专家与操作的联合分布；
  - 目标 \(J_{turn}\) 通过对数比率并 clip 到 \([-h_c,h_c]\) 来稳定估计，鼓励相同操作轮次使用相似专家集，不同操作使用不同专家集。
- **作用**：增强跨 turn 的操作级专家专门化，同时不与标准负载均衡目标冲突，但它补充了操作条件使用，而不强制均匀使用。

### 2.2 Token 级局部一致性控制

- **思想**：同一 field 内相邻 token 的路由应保持局部一致，但不应对所有相邻 token 无差别惩罚，否则会压制合理的语义转变。
- **具体形式**：
  - 对相邻 token \(t-1\) 和 \(t\)，计算 top-k 专家集合的 gap：\(\delta_t = 1 - |S_{t-1} \cap S_t| / |S_t|\)；
  - 仅当 \(\delta_t < h_\delta\)（即二者已经很相似）时，才最小化当前 router 对前一 token 专家集合的负对数概率：
    \[
    \ell_{token,t} = - \mathbb{I}[\delta_t < h_\delta] \cdot \frac{1}{|S_{t-1}|}\sum_{e \in S_{t-1}} \log p_t[e]
    \]
  - 前一 token 的分布和门控被 detach，只有当前 token 概率可微；跨 field 或跨 turn 的 token 对不参与。
- **作用**：减少局部路由噪声，提高相邻 token 的专家复用，从而改善推理效率。

### 2.3 熵门控控制机制

- **问题**：直接对 MoE router 施加辅助梯度可能破坏 RL 训练稳定性，表现为策略熵剧烈波动甚至训练崩溃。
- **方案**：
  - 监控 rollout batch 中 thinking/tool-use token 的平均策略熵 \(\bar H\)；
  - 仅当 \(\bar H \in [H_{low}, H_{high}]\) 时，才让路由控制梯度生效；否则关闭路由控制，仅保留标准 RL 更新。
- **总目标**：
  \[
  J = J_{RL} + g \cdot (\lambda_{turn} J_{turn} + \lambda_{token} J_{token}),\quad g = \mathbb{I}[H_{low} \le \bar H \le H_{high}]
  \]
- **梯度注入方式**：在 MoE router logits 处注入辅助梯度，根据 incoming gradient 范数动态缩放，避免辅助项压制原始 RL 梯度；前向计算不变，保留原生 top-k 选择。

## 6. 论文的主要结论与发现

- 现成 MoE 模型的专家选择已天然具有操作分组专门化，说明智能体操作语义确实是有效的路由组织信号。
- 标准 RL 后训练会破坏这种结构，引入路由噪声，限制任务性能和推理效率。
- 所提分层路由控制框架能：
  - 在多个 RL 算法和两个基准上稳定提升任务成功率，例如 AppWorld 上最高提升 **+12.9 个点**（LOOP test-challenge TGC），AutomationBench 上 LOOP 提升 **+11.34 个点**；
